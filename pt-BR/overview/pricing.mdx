Preços por 1M de tokens salvo indicação. Todos os preços em USD. 1 Diem = $1/dia de computação.

## Como funciona a cobrança da API

A Venice API é **pay-as-you-go**: toda requisição é medida e cobrada do saldo de créditos Venice da sua conta (financiado em USD ou via DIEM em staking). Não há camada gratuita, cota mensal de API nem plano de assinatura baseado em login para a API — o acesso é autenticado por uma chave de API e cobrado por requisição.

<Note>
Os planos Free, Pro e Max do app para consumidores [venice.ai](https://venice.ai) (chat web, desktop e mobile) são separados da API. Os limites das assinaturas para consumidores — como contagem de imagens, cotas de caracteres ou chat ilimitado — se aplicam apenas a esses apps, **não** ao uso da API. As chamadas de API são sempre medidas contra o saldo de créditos Venice, independentemente do seu plano de consumidor. Veja [Usuários Pro](#usuários-pro) abaixo para o crédito único que os assinantes Pro recebem.
</Note>

Para usar a API você precisa de uma [chave de API](/guides/getting-started/generating-api-key) e de um saldo utilizável, financiado através de uma das [opções de pagamento](#opções-de-pagamento) abaixo. Todo modelo listado nesta página está disponível para qualquer chave de API com saldo suficiente — não há uma separação entre modelos "base" e "Pro" na API.

### Usuários Pro

Assinantes Pro recebem um crédito único de $10 de Venice ao fazer upgrade para Pro. Use-o para testar e construir pequenos apps.

Além desse crédito, o uso da API é cobrado pelas mesmas tarifas pay-per-use listadas acima — a assinatura Pro em si não inclui cotas adicionais de API, como imagens, caracteres ou tokens inclusos. Alguns modelos são restritos a contas Pro (`PRO_ONLY_MODEL`); chamá-los a partir de uma conta sem uma assinatura Pro ativa retorna `AUTHENTICATION_FAILED_INACTIVE_KEY`. Veja [Códigos de erro](/api-reference/error-codes).

### Plano gratuito

A API da Venice não tem um plano gratuito. Toda chamada de chat, imagem, áudio, vídeo e embedding é paga por meio de créditos, DIEM ou [x402/USDC](/guides/integrations/x402-venice-api). Os modelos de texto de menor custo começam em $0,05 por 1M de tokens de entrada, e os modelos de embedding começam em $0,01 por 1M de tokens.

<Note>
A cota gratuita diária de prompts em [venice.ai](https://venice.ai) é um recurso do app web para consumidores, não da API. As requisições à API sempre consomem do seu saldo carregado.
</Note>

### Usando chaves da Venice com outros provedores

As chaves da API da Venice só funcionam contra `https://api.venice.ai/api/v1`. Elas não são intercambiáveis com chaves do OpenRouter, OpenAI, Anthropic ou outros provedores, e chaves desses provedores não autenticarão na Venice. Para usar os modelos da Venice, gere uma chave em [venice.ai/settings/api](https://venice.ai/settings/api) e aponte seu cliente para a URL base da Venice.
