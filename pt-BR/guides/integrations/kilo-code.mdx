O [Kilo Code](https://kilo.ai/) é um agente de codificação com IA de código aberto para VS Code e para o terminal. A Venice está disponível como **provedor nativo**, então você pode selecionar modelos Venice sem configurar um endpoint personalizado compatível com OpenAI.

## Pré-requisitos

- Uma chave de API Venice em [venice.ai/settings/api](https://venice.ai/settings/api)
- [Kilo Code para VS Code](https://marketplace.visualstudio.com/items?itemName=kilocode.Kilo-Code) e/ou a [Kilo CLI](https://kilo.ai/docs/code-with-ai/platforms/cli)

---

## Configuração

<Tabs>
  <Tab title="VS Code">
    <Steps>
      <Step title="Instale o Kilo Code">
        No VS Code, abra **Extensions**, pesquise por **Kilo Code** e instale a extensão a partir do [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=kilocode.Kilo-Code).

        Prefira o canal **Pre-Release** do Marketplace quando essa for a build recomendada no momento — consulte a [documentação de instalação do Kilo](https://kilo.ai/docs/getting-started/installing).
      </Step>

      <Step title="Obtenha sua chave de API Venice">
        Gere uma chave em [venice.ai/settings/api](https://venice.ai/settings/api). Copie-a imediatamente e armazene-a com segurança.
      </Step>

      <Step title="Adicione o provedor Venice">
        Abra as **Settings** do Kilo (ícone de engrenagem) e vá até a aba **Providers**. Selecione **Venice AI** e cole sua chave de API Venice.

        A extensão armazena o provedor na sua configuração `kilo.json`. Você também pode editar esse arquivo diretamente — veja a aba **CLI** para o formato.
      </Step>

      <Step title="Selecione um modelo e teste">
        Escolha um modelo Venice no seletor de modelos e envie uma pequena tarefa como:

        ```txt
        Review the current file and suggest one safe improvement.
        ```

        Explore os IDs disponíveis no [catálogo de modelos de texto](/models/text).
      </Step>
    </Steps>
  </Tab>

  <Tab title="CLI">
    <Steps>
      <Step title="Instale a Kilo CLI">
        ```bash
        npm install -g @kilocode/cli
        kilo --version
        ```

        Veja a [documentação da Kilo CLI](https://kilo.ai/docs/code-with-ai/platforms/cli) para outras opções de instalação.
      </Step>

      <Step title="Defina sua chave de API Venice">
        Exporte a chave no shell em que você executa o Kilo:

        ```bash
        export VENICE_API_KEY="your-api-key"
        ```
      </Step>

      <Step title="Configure o provedor Venice">
        Crie ou edite `~/.config/kilo/kilo.json` (global) ou `./kilo.json` (projeto):

        ```json
        {
          "provider": {
            "venice": {
              "env": ["VENICE_API_KEY"]
            }
          },
          "model": "venice/zai-org-glm-5-1"
        }
        ```

        Substitua `zai-org-glm-5-1` por qualquer ID de modelo do [catálogo de modelos de texto](/models/text). As referências de modelo do Kilo usam o formato `venice/<model-id>`.
      </Step>

      <Step title="Inicie o Kilo">
        No diretório do seu projeto:

        ```bash
        kilo
        ```

        Selecione um modelo Venice no seletor de modelos caso você não tenha definido um `model` padrão e, em seguida, envie um pequeno prompt de teste.
      </Step>
    </Steps>
  </Tab>
</Tabs>

## Verifique a API Venice

Se o Kilo não conseguir se conectar, confirme a chave e os IDs de modelo de forma independente:

```bash
curl https://api.venice.ai/api/v1/models \
  -H "Authorization: Bearer $VENICE_API_KEY"
```

Copie o `id` de um modelo exatamente para o Kilo. Na configuração da CLI, adicione o prefixo `venice/`, por exemplo `venice/zai-org-glm-5-1`.

---

## Notas de configuração

- A Venice é um provedor **nativo** do Kilo. Prefira **Venice AI** nas configurações de Providers em vez de um endpoint personalizado genérico compatível com OpenAI.
- A extensão e a CLI compartilham os mesmos arquivos de configuração (`~/.config/kilo/kilo.json` globalmente ou `./kilo.json` em um projeto).
- Alguns modelos Venice expõem controles de raciocínio. O Kilo mapeia as opções suportadas de esforço de raciocínio e de desabilitar o thinking quando o modelo selecionado as suporta.
- IDs de modelos e o acesso por plano podem mudar. Use o seletor de modelos, o [catálogo de modelos de texto](/models/text) ou `GET /models` para obter a lista atual.
- Mantenha sua chave de API Venice privada. Não a cole em arquivos-fonte nem faça commit dela no git.

## Solução de problemas

<AccordionGroup>
  <Accordion title="Chave de API inválida ou 401">
    Confirme que a chave veio de [venice.ai/settings/api](https://venice.ai/settings/api). Para a CLI, verifique se `VENICE_API_KEY` está definida no mesmo ambiente que inicia o Kilo. No VS Code, reconecte o Venice AI em **Providers**.
  </Accordion>
  <Accordion title="Modelo indisponível">
    Confirme que sua conta Venice tem acesso ao modelo selecionado, copie o ID do [catálogo de modelos de texto](/models/text) ou de `GET /models` e, na configuração da CLI, use o formato `venice/<model-id>`.
  </Accordion>
  <Accordion title="Configurações do provedor não encontradas na extensão">
    Atualize para a build recomendada atual do Kilo (incluindo a Pre-Release quando esse for o padrão documentado). Você também pode definir o provedor no `kilo.json` como mostrado na aba CLI — a extensão lê a mesma configuração.
  </Accordion>
</AccordionGroup>
