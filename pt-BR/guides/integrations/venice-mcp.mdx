O [Venice MCP Server](https://github.com/veniceai/venice-mcp-server) é o servidor oficial do [Model Context Protocol](https://modelcontextprotocol.io/) para a Venice. Ele expõe a API Venice (chat, imagem, vídeo, áudio, música, embeddings, web augment, characters, RPC cripto e atestação TEE) além de operações de conta (faturamento e chaves de API) como **45 ferramentas** que qualquer agente compatível com MCP pode chamar.

## Quickstart

<Steps>
  <Step title="Obtenha uma chave de API Venice">
    Gere uma em [venice.ai/settings/api](https://venice.ai/settings/api?utm_source=venice-api-documentation). Veja o [guia de chaves de API](/guides/getting-started/generating-api-key) para o passo a passo.
  </Step>

  <Step title="Adicione a Venice à configuração do seu host MCP">
    Cole isto no arquivo de configuração do seu host MCP:

    ```json
    {
      "mcpServers": {
        "venice": {
          "command": "npx",
          "args": ["-y", "@veniceai/mcp-server@0.3.0"],
          "env": { "VENICE_API_KEY": "<your-venice-api-key>" }
        }
      }
    }
    ```

    Caminhos de configuração comuns:

    | Host | Caminho |
    |---|---|
    | Claude Desktop (macOS) | `~/Library/Application Support/Claude/claude_desktop_config.json` |
    | Claude Desktop (Windows) | `%APPDATA%\Claude\claude_desktop_config.json` |
    | Cursor | `~/.cursor/mcp.json` |
    | LM Studio | `mcp.json` (nas configurações MCP do app) |
  </Step>

  <Step title="Reinicie seu host MCP">
    Seu agente agora tem chat, imagem, vídeo, música, TTS, ASR, faturamento, chaves de API e mais 39 ferramentas da Venice disponíveis.
  </Step>
</Steps>

<Note>
A maioria dos hosts MCP só repassa as variáveis de ambiente **explicitamente listadas** no bloco `env`. Variáveis de ambiente do sistema não são herdadas. Se você vir erros 402 com uma chave de API definida, confira se `VENICE_API_KEY` está dentro de `env` na sua configuração.
</Note>

## O que você obtém

**45 ferramentas** cobrindo todas as modalidades da Venice mais operações de conta, **3 recursos** (`venice://models`, `venice://styles`, `venice://voices`) e **3 modelos de prompt** (pesquisa sem censura, escrita criativa NSFW, explorador de estilos de imagem).

Cada ferramenta declara anotações explícitas `readOnlyHint`, `destructiveHint`, `idempotentHint` e `openWorldHint`, para que os hosts executem consultas sem pedir confirmação e peçam confirmação antes de qualquer ação destrutiva, como limpeza de mídia ou um relay cripto.

### Chat e embeddings

| Ferramenta | Descrição |
|---|---|
| `venice_chat` | Chat completion compatível com OpenAI sobre todo o catálogo de LLMs da Venice, com blocos de texto/imagem/áudio/vídeo/arquivo, saídas estruturadas, function tools, prompt caching e controle de raciocínio. As chamadas são em texto puro e sem streaming. |
| `venice_responses` | API Responses alfa e sem estado, compatível com OpenAI, com entrada de texto/imagem e controle de raciocínio. Modelos com E2EE e campos de tools não são suportados. |
| `venice_embeddings` | Calcula embeddings para texto. |
| `venice_chat_with_character` | Converse com um personagem da Venice por slug. |

### Imagem

| Ferramenta | Descrição |
|---|---|
| `venice_image_generate` | Gera uma imagem (Flux 2, Lustify SDXL, Anime/WAI, Qwen Image, GPT Image, Nano Banana Pro e mais), com proporção ou largura/altura, níveis de qualidade, aprimoramento de prompt, referências de estilo, busca na web e variantes. |
| `venice_image_edit` | Edita uma imagem com um prompt. |
| `venice_image_multi_edit` | Edita até 8 imagens juntas com um único prompt (composição / outpainting). |
| `venice_image_upscale` | Aumenta a resolução de uma imagem de 2 a 4×, com controle de `creativity`. |
| `venice_image_remove_bg` | Remove o fundo de uma imagem. |
| `venice_image_styles` | Lista os presets de estilo de imagem. |

### Vídeo

| Ferramenta | Descrição |
|---|---|
| `venice_video_generate` | Enfileira uma geração de vídeo (Sora 2, Veo 3.1, Kling, Wan, LTX 2, Seedance, Runway Gen-4 e mais) com entradas de imagem, vídeo, áudio, referência e elementos. |
| `venice_video_status` | Verifica o status de um job de vídeo (`POST /video/retrieve`). |
| `venice_video_complete` | Marca um vídeo concluído como baixado; só remove a mídia no servidor quando a Venice confirma. |
| `venice_video_quote` | Obtém uma cotação de preço antes de enfileirar. |

### Áudio (TTS / ASR)

| Ferramenta | Descrição |
|---|---|
| `venice_tts` | Texto para fala com vozes clonadas, temperature e tags de emoção. O streaming é agrupado em um único resultado de áudio completo. |
| `venice_asr` | Transcreve áudio de uma URL, com timestamps opcionais por palavra/caractere. Transcrições grandes são paginadas por um handle de sessão. |
| `venice_voice_clone` | Lista vozes ao vivo por modelo ou clona uma voz a partir de uma URL de amostra (retorna um handle `vv_<id>` para `venice_tts`). |
| `venice_audio_quote` | Obtém uma cotação de preço para geração de música. |

### Música

| Ferramenta | Descrição |
|---|---|
| `venice_music_generate` | Enfileira uma geração de música (`ace-step-15`, `elevenlabs-music`, `minimax-music-v2/v25/v26`, `stable-audio-25`, `mmaudio-v2-text-to-audio`, `elevenlabs-sound-effects-v2`) com controles de letra, instrumental, loop, voz, idioma, velocidade e duração. |
| `venice_music_status` | Verifica o status de um job de música. |
| `venice_music_complete` | Marca um job de música concluído como baixado. |

### Web augment

| Ferramenta | Descrição |
|---|---|
| `venice_web_search` | Pesquisa na web com Brave (padrão, Zero Data Retention) ou Google (proxied e anonimizado pela Venice). |
| `venice_web_scrape` | Scrapa uma URL para markdown. |
| `venice_text_parser` | Extrai texto de PDF/DOCX/EPUB/PPTX/XLSX. |

### Catálogo e personagens

| Ferramenta | Descrição |
|---|---|
| `venice_list_models` | Percorre o catálogo ao vivo de modelos de todos os tipos, com resumos compactos, preços e flags de capacidade. |
| `venice_model_details` | Obtém a linha completa de um modelo exato: restrições de `model_spec`, capacidades e preços. |
| `venice_model_traits` | Mapeia nomes de trait (`default`, `most_uncensored`, …) para os IDs de modelo atuais. |
| `venice_model_compatibility_mapping` | Mapeia nomes de modelo compatíveis para IDs de modelo da Venice. |
| `venice_list_characters` | Lista personagens públicos da Venice com filtros de busca, tag, modelo e ordenação. **Somente chave de API.** |
| `venice_get_character` | Obtém um personagem público por slug. **Somente chave de API.** |
| `venice_character_reviews` | Lista as avaliações públicas de um personagem, com paginação. **Somente chave de API.** |

### Atestação TEE

| Ferramenta | Descrição |
|---|---|
| `venice_tee_attestation` | Obtém evidências de atestação de hardware (quote Intel TDX, evidência NVIDIA opcional, chave de assinatura) para um modelo de texto com TEE, usando seu próprio nonce de 32 bytes. |
| `venice_tee_signature` | Obtém o payload de assinatura do enclave para o ID de uma requisição de chat TEE concluída. |

<Warning>
As duas ferramentas TEE retornam apenas as evidências do provedor: não as verificam e não criptografam o chat. Verifique você mesmo o nonce retornado, o estado de debug e a vinculação da chave de assinatura antes de confiar em um modelo TEE, e use `venice_chat` (nunca `venice_responses`) para modelos TEE. Este servidor rejeita `enable_e2ee`.
</Warning>

### Cripto

| Ferramenta | Descrição |
|---|---|
| `venice_crypto_networks` | Lista os slugs de rede ao vivo aceitos pelo proxy RPC. |
| `venice_crypto_rpc` | Faz proxy de uma requisição JSON-RPC, ou um lote de até 100, para Ethereum, Base, Arbitrum, Optimism, Polygon, Solana, Starknet, zkSync, Linea, BSC, Avalanche, Blast e mais. |

Transmissões de transações (`eth_sendRawTransaction`, `eth_sendUserOperation`, `sendTransaction` da Solana, escritas na Starknet) devem ser enviadas como requisições únicas com `idempotency_key`, e a mesma chave deve ser reutilizada em retentativas.

### Faturamento (chaves admin)

| Ferramenta | Descrição |
|---|---|
| `venice_billing_balance` | Disponibilidade atual de USD, DIEM e créditos inclusos. |
| `venice_billing_usage_analytics` | Uso agregado em beta por data, modelo e chave de API (lookback ou intervalo personalizado). |
| `venice_billing_usage_history` | Uso detalhado com paginação por cursor e saída JSON ou CSV. |

<Note>
As ferramentas de faturamento exigem uma chave de API **ADMIN**. Chaves de inferência não podem chamar esses endpoints, e o servidor falha localmente em vez de recorrer a um token de carteira. A rota obsoleta `/billing/usage` não é coberta.
</Note>

### Chaves de API

| Ferramenta | Descrição |
|---|---|
| `venice_list_api_keys` | Lista metadados de chaves ativas, incluindo apenas os últimos seis caracteres. Somente chave admin. |
| `venice_get_api_key` | Obtém metadados, uso, saldos e rate limits de uma chave por ID. Somente chave admin. |
| `venice_api_key_rate_limits` | Saldos atuais, status de acesso, tier, expiração e rate limits por modelo. Chave de inferência ou admin. |
| `venice_api_key_rate_limit_logs` | Os últimos 50 eventos de rate limit excedidos (experimental). Somente chave admin. |

### Helpers de carteira x402

Relevantes apenas se você autenticar com uma carteira via [x402](/guides/integrations/x402-venice-api) em vez de uma chave de API.

| Ferramenta | Descrição |
|---|---|
| `venice_x402_balance` | Verifica o saldo de crédito x402 pré-pago de um endereço de carteira EVM ou Solana. |
| `venice_x402_top_up_info` | Obtém os requisitos de recarga (rede, token USDC, recebedor, valor mínimo). Não aceita argumentos. |
| `venice_x402_transactions` | Lista recargas e débitos x402 recentes de um endereço de carteira EVM ou Solana. |

## Configuração

O servidor é configurado inteiramente por variáveis de ambiente.

### Modelos e requisições

| Variável | Padrão | Notas |
|---|---|---|
| `VENICE_API_KEY` | _(nenhuma)_ | Sua chave de API Venice. A configuração mais simples. |
| `VENICE_DEFAULT_CHAT_MODEL` | `deepseek-v4-flash-0731` | |
| `VENICE_DEFAULT_IMAGE_MODEL` | `flux-2-pro` | |
| `VENICE_DEFAULT_TTS_MODEL` | `tts-kokoro` | |
| `VENICE_DEFAULT_ASR_MODEL` | `openai/whisper-large-v3` | |
| `VENICE_DISABLE_NSFW` | `0` | Defina `1` para remover as notas de capacidade NSFW das descrições das ferramentas. |
| `VENICE_HTTP_TIMEOUT_MS` | `60000` | |
| `VENICE_SIWX_TOKEN` | _(nenhum)_ | Token de auth para o modo carteira x402. Veja [x402 abaixo](#modo-carteira-x402). |

Se `VENICE_API_KEY` e `VENICE_SIWX_TOKEN` estiverem definidos, a chave de API vence.

### Limites de tamanho de resposta

A mídia gerada é armazenada em buffer e embutida em base64 no resultado MCP, então cada modalidade tem um teto em bytes.

| Variável | Padrão | Aplica-se a |
|---|---|---|
| `VENICE_MAX_IMAGE_RESPONSE_BYTES` | `33554432` (32 MiB) | `venice_image_generate`, `venice_image_edit`, `venice_image_multi_edit`, `venice_image_upscale`, `venice_image_remove_bg` |
| `VENICE_MAX_VIDEO_RESPONSE_BYTES` | `26214400` (25 MiB) | `venice_video_status` |
| `VENICE_MAX_AUDIO_RESPONSE_BYTES` | `33554432` (32 MiB) | `venice_tts`, `venice_music_status` |

Um resultado de imagem ou TTS grande demais é descartado com erro. Um vídeo ou música grande demais permanece na fila, então você pode chamar a ferramenta de status novamente com o mesmo queue ID após aumentar o limite.

### Servidor HTTP

Relevante apenas na [implantação Streamable HTTP](#auto-hospedagem-streamable-http).

| Variável | Padrão | Notas |
|---|---|---|
| `PORT` | `3333` | Porta do listener HTTP. |
| `VENICE_MCP_HOST` | `127.0.0.1` | Endereço de bind. Defina `0.0.0.0` para expor em LAN ou container. |
| `VENICE_MCP_AUTH_TOKEN` | _(nenhum)_ | Token bearer exigido por `/mcp` quando o bind sai do loopback. |
| `VENICE_MCP_ALLOW_UNAUTHENTICATED_HTTP` | `0` | Válvula de escape para HTTP exposto sem autenticação. Use apenas atrás de um proxy autenticado confiável. |
| `VENICE_MCP_MAX_SESSIONS` | `100` | Máximo de sessões Streamable HTTP ativas. |
| `VENICE_MCP_SESSION_TTL_MS` | `1800000` | Tempo de vida de uma sessão ociosa antes da limpeza. |

## Comportamento de geração de mídia

- **Mídia concluída pode ser bytes ou uma URL.** Jobs de vídeo e música retornam recursos MP4/áudio embutidos, ou JSON com uma `download_url` que volta como resource link. Baixe esse link primeiro e depois chame `venice_video_complete` ou `venice_music_complete`; a limpeza de mídia nunca é aplicada a um resultado `download_url`, porque o link deixa de funcionar após o arquivo ser removido.
- **Alguns modelos só retornam a URL no enfileiramento.** Nos modelos VPS e Grok Imagine Private, guarde a `download_url` retornada por `venice_video_generate` e passe-a para `venice_video_status`; um retrieve `COMPLETED` sem URL inline ainda fornece um link utilizável.
- **O aprimoramento de prompt é retornado.** Quando `enhance_prompt` é aplicado, os resultados de geração, edição e multi-edição de imagem incluem o prompt URL-decodificado retornado pela Venice.
- **A paginação do ASR é cobrada uma única vez.** Transcrições com timestamps ou com mais de 8000 caracteres retornam um `result_handle` com a primeira página. Peça as páginas seguintes com esse handle. Os handles vivem em memória por sessão MCP durante 10 minutos, e apenas os 16 mais recentes são mantidos.
- **O consentimento do Seedance não é um bypass de política.** Os modelos públicos atuais do Seedance podem rejeitar de imediato mídia com pessoas detectáveis. Quando uma resposta `needs_consent` é retornada, os três flags de `consents.seedance` são atestações legais: defina-os como `true` apenas depois que o usuário confirmar explicitamente cada declaração.

## Modo carteira x402

A Venice suporta autenticação com um [token de carteira Sign-In-With-X](/guides/integrations/x402-venice-api) respaldado por crédito USDC pré-pago em Base ou Solana, além do fluxo normal com chave de API. Sem e-mail, telefone ou KYC: sua carteira é a única identidade.

```json
{
  "mcpServers": {
    "venice": {
      "command": "npx",
      "args": ["-y", "@veniceai/mcp-server@0.3.0"],
      "env": { "VENICE_SIWX_TOKEN": "<base64 Sign-In-With-X payload>" }
    }
  }
}
```

O servidor MCP encaminha `VENICE_SIWX_TOKEN` no header `SIGN-IN-WITH-X` em cada chamada à API da Venice. O servidor nunca vê sua chave privada. A assinatura da carteira e as autorizações de recarga de USDC acontecem na sua própria carteira.

| Fluxo | O que acontece |
|---|---|
| **Configuração inicial** | Você assina uma mensagem Sign-In-With-X na sua carteira → produz um token SIWX (JSON em base64). |
| **Recarga** | `POST /api/v1/x402/top-up` retorna 402 + requisitos de pagamento. Assine um pagamento em USDC para uma das opções Base ou Solana retornadas, reenvie e a Venice credita seu saldo. |
| **Cada chamada de inferência** | O servidor MCP envia `SIGN-IN-WITH-X: <SIWX>`; a Venice debita seu saldo pré-pago. |

A recarga mínima é **\$5 USD**. O saldo mínimo para chamar inferência é **\$0.10**. Uma vez recarregado, as chamadas levam menos de 100 ms porque a liquidação acontece off-chain em uma conta de crédito rápida.

<Tip>
Carteiras vinculadas a uma conta Venice com DIEM em staking consomem do saldo de staking em vez dos créditos USDC, então não precisam de recarga.
</Tip>

A Venice não aceita headers de pagamento nas rotas de inferência, então este servidor nunca envia um. `PAYMENT-SIGNATURE` pertence apenas a `/x402/top-up`, e o helper de recarga descobre os requisitos sem enviar nenhum pagamento.

### Cobertura dos modos de auth

Alguns endpoints aceitam apenas um modo de auth:

| Ferramenta | Chave de API | x402 |
|---|---|---|
| Inferência, mídia, web augment, RPC cripto, chat com personagem | ✓ | ✓ |
| `venice_list_characters`, `venice_get_character`, `venice_character_reviews` | ✓ | ✗ |
| `venice_billing_*`, `venice_list_api_keys`, `venice_get_api_key`, `venice_api_key_rate_limit_logs` | ✓ (admin) | ✗ |
| `venice_api_key_rate_limits` | ✓ (qualquer chave) | ✗ |
| `venice_x402_balance`, `venice_x402_transactions` | ✗ | ✓ |
| `venice_x402_top_up_info` | ✓ | ✓ |

Se você definir as duas credenciais, a chave de API vence em todas as chamadas, então os helpers exclusivos de SIWX (`venice_x402_balance`, `venice_x402_transactions`) só funcionam quando o token da carteira é sua única credencial.

## Auto-hospedagem (Streamable HTTP)

Para implantações de equipe ou workspace, execute o servidor MCP via HTTP em vez de stdio:

```bash
docker run -p 3333:3333 \
  -e VENICE_API_KEY=<your-venice-api-key> \
  -e VENICE_MCP_AUTH_TOKEN=<choose-a-long-random-token> \
  ghcr.io/veniceai/venice-mcp-server:latest
```

O servidor fica disponível em `http://localhost:3333/mcp`. Clientes HTTP devem enviar `Authorization: Bearer <VENICE_MCP_AUTH_TOKEN>` e criar novas sessões sem o header `mcp-session-id`, depois reutilizar o ID de sessão emitido pelo servidor.

<Warning>
`/mcp` é um endpoint de execução de ferramentas respaldado por credenciais: quem chamar pode gastar a chave de API Venice configurada ou o saldo x402. Quando o modo HTTP faz bind fora do loopback, a inicialização falha a menos que `VENICE_MCP_AUTH_TOKEN` esteja definido, ou que `VENICE_MCP_ALLOW_UNAUTHENTICATED_HTTP=1` seja configurado atrás de um proxy autenticado confiável. Em produção, fixe explicitamente a versão do pacote npm em vez de confiar em `latest`.
</Warning>
