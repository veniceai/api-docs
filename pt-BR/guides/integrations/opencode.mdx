O [OpenCode](https://opencode.ai/) é um agente de programação com IA para o terminal. O OpenCode já inclui um provedor da Venice AI, então você se conecta com um único comando e escolhe um modelo do catálogo completo da Venice. Nenhum arquivo de configuração é necessário.

<Note>
  Este guia segue o OpenCode 1, que é a versão configurada pelo instalador padrão. O OpenCode 2 também inclui a Venice AI, com algumas mudanças de rótulos. Veja [OpenCode 2](#opencode-2).
</Note>

## Pré-requisitos {#prerequisites}

- Uma chave de API Venice em [venice.ai/settings/api](https://venice.ai/settings/api?utm_source=venice-api-documentation)
- OpenCode instalado e funcionando na sua máquina

---

## Configuração {#setup}

<Steps>
  <Step title="Conecte a Venice AI">
    Abra o OpenCode e execute o comando de conexão:

    ```txt
    /connect
    ```

    Procure por **Venice AI** e selecione.

    <Frame as="div">
      <img
        src="/images/guides/opencode/connect-venice.png"
        alt="A paleta /connect do OpenCode filtrada por Venice AI"
      />
    </Frame>
  </Step>

  <Step title="Cole sua chave de API da Venice">
    Cole a chave no campo **API key** e pressione Enter.

    O OpenCode armazena a credencial em `~/.local/share/opencode/auth.json`, então ela fica disponível em todos os projetos.
  </Step>

  <Step title="Escolha um modelo">
    Execute o comando de modelos e escolha um modelo da Venice:

    ```txt
    /models
    ```

    `z-ai-glm-5-3-flash` é uma boa opção padrão para programação: rápido, barato e com uma janela de contexto de 1M tokens. Veja [IDs de modelo](#model-ids) para outras opções.

    O OpenCode também lista seu próprio nível gratuito hospedado com nomes parecidos, por exemplo **GLM-5.3-Flash Free** da **OpenCode** ao lado de **GLM 5.3 Flash** da **Venice AI**. O nome do provedor na coluna da direita diferencia os dois, e a linha da Venice AI é a que usa sua chave e seus créditos.
  </Step>
</Steps>

Envie uma tarefa pequena para confirmar o fluxo completo, por exemplo:

```txt
Review the current file and suggest one safe improvement.
```

## Defina um modelo padrão {#pin-a-default-model}

Depois de conectar, o OpenCode pode iniciar novas sessões em um modelo roteado, como o Claude Sonnet 4.6, que custa mais do que os modelos em [IDs de modelo](#model-ids). Para escolher o modelo com que o OpenCode inicia, adicione-o ao `opencode.json` na raiz do seu projeto (ou em `~/.config/opencode/opencode.json` para um padrão global):

```json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "venice/z-ai-glm-5-3-flash",
  "small_model": "venice/z-ai-glm-5-3-flash"
}
```

As referências de modelo usam o formato `venice/<model-id>`, e `small_model` define o modelo mais barato para tarefas em segundo plano.

## Conectar sem `/connect` {#connect-without-/connect}

O provedor incluído também lê `VENICE_API_KEY` do ambiente. Exporte a variável antes de iniciar o OpenCode e os modelos da Venice AI aparecem em `/models` sem executar `/connect`:

```bash
export VENICE_API_KEY="your-api-key"
```

Em uma versão do OpenCode anterior ao provedor incluído, ou para fixar a lista de modelos que o OpenCode mostra, configure a Venice como provedor compatível com OpenAI no `opencode.json`. Mantenha `VENICE_API_KEY` exportada:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "venice/z-ai-glm-5-3-flash",
  "small_model": "venice/z-ai-glm-5-3-flash",
  "provider": {
    "venice": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Venice AI",
      "options": {
        "baseURL": "https://api.venice.ai/api/v1",
        "apiKey": "{env:VENICE_API_KEY}"
      },
      "models": {
        "z-ai-glm-5-3-flash": {
          "name": "GLM 5.3 Flash"
        },
        "kimi-k2-6": {
          "name": "Kimi K2.6"
        },
        "minimax-m25": {
          "name": "MiniMax M2.5"
        }
      }
    }
  }
}
```

Liste em `models` os modelos que você quer. O OpenCode mostra apenas as entradas declaradas aqui para este provedor. Nas versões com o provedor incluído, a variável de ambiente sozinha já dá acesso ao catálogo completo.

## OpenCode 2 {#opencode-2}

O OpenCode 2 é uma linha de versões separada, com seu próprio instalador:

```bash
curl -fsSL https://opencode.ai/v2/install | bash
```

Ele inclui um provedor nativo da Venice AI, e a configuração acima funciona com algumas diferenças:

- A caixa de diálogo do `/connect` se chama **Connect an integration**. Pesquise **Venice AI** em **Services** e cole sua chave na caixa de diálogo **Connect Venice AI**.
- Exportar `VENICE_API_KEY` antes de iniciar também ativa o provedor sem `/connect`.
- Sem um modelo fixado, o OpenCode 2 também pode iniciar com um modelo roteado, como o Claude Fable 5.2.
- Os exemplos de `opencode.json` desta página continuam funcionando, porque o OpenCode 2 ainda lê o formato de configuração do OpenCode 1. Na configuração nativa do OpenCode 2, defina o modelo de segundo plano com `agents.title.model` em vez de `small_model`. Veja o [guia de migração](https://opencode.ai/docs/migrate-v1) do OpenCode para o restante do formato nativo.

## IDs de modelo {#model-ids}

Alguns modelos da Venice que funcionam bem em um agente de programação. O catálogo muda, então use [`GET /models?type=text`](/pt-BR/api-reference/endpoint/models/list) para obter a lista atual.

| Modelo | ID na Venice |
|-------|-----------|
| GLM 5.3 Flash | `z-ai-glm-5-3-flash` |
| GLM 5.3 | `z-ai-glm-5-3` |
| Kimi K2.6 | `kimi-k2-6` |
| MiniMax M2.5 | `minimax-m25` |
| DeepSeek V4.1 Flash | `deepseek-v4-1-flash` |

Modelos de pesos abertos como estes rodam de forma totalmente privada. Modelos roteados da Anthropic, OpenAI e Google rodam de forma anonimizada, então o laboratório de origem nunca vê sua identidade.

## Notas de configuração {#config-notes}

- Mantenha `baseURL` definido como `https://api.venice.ai/api/v1` no bloco de provedor manual. O provedor incluído já aponta para lá.
- O ID do provedor é `venice`, então as referências de modelo usam o formato `venice/<model-id>` nos dois caminhos.
- Execute `/connect` novamente a qualquer momento para substituir a chave da Venice armazenada.
- Amplie o contexto quando o modelo suportar: vários modelos da Venice aceitam 1M tokens.

## Solução de problemas {#troubleshooting}

<AccordionGroup>
  <Accordion title="A Venice AI não aparece em /connect">
    Atualize o OpenCode para a versão 1.x mais recente com `opencode upgrade`. O provedor Venice AI vem nas versões atuais, então uma instalação antiga pode oferecer apenas o caminho de configuração manual acima.
  </Accordion>
  <Accordion title="Chave de API inválida ou 401">
    Confirme que a chave vem de [venice.ai/settings/api](https://venice.ai/settings/api?utm_source=venice-api-documentation), depois execute `/connect`, selecione **Venice AI** e cole a chave novamente. Quando a chave armazenada está desatualizada, o OpenCode informa uma falha de autenticação em vez de chegar à Venice.
  </Accordion>
  <Accordion title="Modelo não disponível">
    Copie o ID exatamente de [IDs de modelo](#model-ids), do [catálogo de modelos de texto](/pt-BR/models/text) ou de `GET /models`, e confirme que sua conta da Venice tem acesso a ele.
  </Accordion>
</AccordionGroup>
