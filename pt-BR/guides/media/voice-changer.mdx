O Trocador de Voz é speech-to-speech. Você fornece uma gravação, escolhe uma voz e recebe a mesma performance de volta nessa voz: as mesmas palavras, as mesmas pausas, a mesma ênfase, a mesma duração. Ele serve para quando você já tem uma tomada que quer manter. Se você só tem texto, use [text-to-speech](/pt-BR/guides/media/text-to-speech); se quiser que a sua própria voz esteja disponível como destino, veja [clonagem de voz](/pt-BR/guides/media/voice-cloning).

Aqui está um clipe de 7 segundos gerado por `/audio/speech` e o resultado da conversão para a voz George. As formas de onda estão no mesmo eixo de tempo, e os intervalos entre as frases caem nos mesmos lugares.

A conversão é executada de forma assíncrona por meio de quatro endpoints em `/audio/voice-changer/`: [quote](/pt-BR/api-reference/endpoint/audio/voice-changer/quote) cota o preço de uma duração, [queue](/pt-BR/api-reference/endpoint/audio/voice-changer/queue) envia a gravação e faz a cobrança, [retrieve](/pt-BR/api-reference/endpoint/audio/voice-changer/retrieve) faz polling até o MP3 ficar pronto e [complete](/pt-BR/api-reference/endpoint/audio/voice-changer/complete) exclui a mídia armazenada depois que você a obtém. O formato é o mesmo dos endpoints de música, mas o caminho é diferente e um não aceita os modelos do outro.

Os exemplos pressupõem que `VENICE_API_KEY` está definida:

```bash
export VENICE_API_KEY="your-api-key"
```

## Escolha um modelo

Os modelos de trocador de voz ficam em `GET /models?type=music` com `model_spec.voice_changer` definido como `true`; não há um filtro de tipo dedicado. No momento existe apenas um, `elevenlabs-voice-changer`: ele aceita origens `mp3`, `wav`, `ogg`, `mp4` ou `aac` de até 300 segundos, oferece 20 vozes nomeadas com `Aria` como padrão, aceita um Voice ID bruto da ElevenLabs no lugar de um nome e suporta `remove_background_noise` e `seed`. Esses detalhes podem mudar, então leia-os da API. Esta consulta retorna tudo de que o restante do guia depende:

```bash
curl "https://api.venice.ai/api/v1/models?type=music" \
  -H "Authorization: Bearer $VENICE_API_KEY" |
  jq '.data[] | select(.model_spec.voice_changer == true) | {
    id,
    voices: .model_spec.voices,
    default_voice: .model_spec.default_voice,
    supports_custom_voice_id: .model_spec.supports_custom_voice_id,
    accepted_audio_formats: .model_spec.accepted_audio_formats,
    max_source_audio_duration_seconds: .model_spec.max_source_audio_duration_seconds,
    supports_background_noise_removal: .model_spec.supports_background_noise_removal,
    supports_seed: .model_spec.supports_seed,
    durations: .model_spec.pricing.durations
  }'
```

Enviar um campo que o modelo não suporta retorna `400`. Uma gravação mais longa que `max_source_audio_duration_seconds` retorna `422` antes de qualquer cobrança, com o limite na mensagem.

Uma coisa que a API não verifica no momento do queue é o nome da voz. Se você enfileirar uma `voice` que o modelo não tem, ainda assim recebe `200` e um `queue_id`; a rejeição chega no primeiro retrieve, com a cobrança reembolsada. Você recebe o dinheiro de volta, mas perde a viagem de ida e volta, então verifique `voices` antes de enfileirar.

## 1. Obtenha uma cotação de preço

A cobrança é feita pela duração da gravação de origem, arredondada para cima para o próximo minuto inteiro. Para `elevenlabs-voice-changer`, isso significa $0.35 para qualquer coisa até 60 segundos, $0.69 até 120, $1.04 até 180, $1.38 até 240 e $1.73 até 300. Um clipe de 7 segundos custa o mesmo que um de 60 segundos, e 60,5 segundos são cobrados como dois minutos. Se você tem muitos segmentos curtos, junte-os em um único arquivo que fique abaixo de um limite de minuto, em vez de enfileirar cada um separadamente. As faixas vêm de `pricing.durations` em `/models`.

A cotação recebe um número inteiro de segundos e não precisa de chave de API:

```bash
curl https://api.venice.ai/api/v1/audio/voice-changer/quote \
  -H "Content-Type: application/json" \
  -d '{
    "model": "elevenlabs-voice-changer",
    "duration_seconds": 60
  }'
```

```json
{
  "quote": 0.35,
  "duration_seconds": 60
}
```

Isso é uma estimativa. O valor cobrado é calculado a partir da duração que a Venice mede quando a gravação é enfileirada.

## 2. Enfileire a conversão

Envie a gravação como upload `file` multipart ou como um `audio_url` em um corpo JSON, mas não ambos. Uma URL precisa ser publicamente acessível sem cabeçalhos ou cookies; a Venice busca os bytes por conta própria e nunca repassa a URL ao provedor. A Venice verifica os bytes, não a extensão, então o arquivo precisa realmente estar em um dos contêineres aceitos, e arquivos com faixa de vídeo são rejeitados.

Com `curl -F`, não mexa no `Content-Type` para que o curl possa definir o boundary do multipart, e envie `remove_background_noise` como `true`/`false` e `seed` como dígitos.

<CodeGroup>
```bash File upload
curl https://api.venice.ai/api/v1/audio/voice-changer/queue \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -F "model=elevenlabs-voice-changer" \
  -F "voice=George" \
  -F "file=@./source-recording.mp3"
```

```bash Audio URL
curl https://api.venice.ai/api/v1/audio/voice-changer/queue \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "elevenlabs-voice-changer",
    "voice": "George",
    "audio_url": "https://example.com/source-recording.mp3",
    "remove_background_noise": true,
    "seed": 42
  }'
```
</CodeGroup>

A requisição multipart acima é a que gerou o clipe com a voz George no topo da página. Omita `voice` para usar `default_voice`. Quando `supports_custom_voice_id` é true, `voice` também pode ser um Voice ID do provedor; para `elevenlabs-voice-changer`, isso significa qualquer voz da ElevenLabs à qual você tenha acesso, incluindo vozes da biblioteca que não estão na lista `voices` da Venice. `remove_background_noise` e `seed` são aceitos somente quando o modelo informa suporte a eles.

A resposta fornece o identificador para tudo o que vem a seguir:

```json
{
  "duration_seconds": 7.008,
  "model": "elevenlabs-voice-changer",
  "queue_id": "01a164db-8652-7fa9-94d6-25754090bd64",
  "status": "QUEUED"
}
```

`duration_seconds` é a duração que a Venice mediu e a faixa na qual você foi cobrado. Se você cotou 60 e aqui aparece 61.2, você pagou por dois minutos. Guarde `model` e `queue_id`; retrieve e complete precisam de ambos, e o ID vale por 24 horas.

A cobrança acontece neste momento, não quando o áudio volta, então não repita uma requisição de queue. Se você tem um `queue_id`, faça polling com ele. Se a resposta nunca chegou, enviar a gravação novamente pode gerar uma cobrança dupla. O queue é limitado a 40 requisições por minuto e o retrieve a 120; ambos informam `x-ratelimit-remaining-requests`.

## 3. Faça polling e baixe

Chame retrieve com os valores da resposta de queue:

```bash
curl https://api.venice.ai/api/v1/audio/voice-changer/retrieve \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "elevenlabs-voice-changer",
    "queue_id": "0190f2c4-9c1e-7a3b-8f42-2c9d5e7a1b34"
  }' \
  --output response.bin
```

A resposta é uma de duas coisas. Enquanto o job está em execução, você recebe JSON:

```json
{
  "status": "PROCESSING",
  "average_execution_time": 10000,
  "execution_duration": 4200
}
```

Quando termina, você recebe `audio/mpeg` e o corpo é o MP3. Decida com base no `Content-Type`.

Os dois números estão em milissegundos: quanto tempo os jobs desse modelo costumam levar e há quanto tempo o seu está em execução. A diferença é uma boa primeira espera, mas a média é apenas uma referência. Uma origem de 148 segundos levou 24 segundos contra uma média de 7, então em entradas mais longas `execution_duration` vai ultrapassar `average_execution_time`. Quando isso acontecer, passe a usar um intervalo fixo de alguns segundos e continue. Clipes curtos vão no sentido contrário: o exemplo de 7 segundos voltou já no primeiro polling.

A resposta concluída traz `x-venice-audio-duration` (segundos), `x-venice-inference-time`, `x-venice-audio-format`, `x-venice-model-id` e `x-venice-model-name`. A saída é sempre MP3 mono de 128 kbps a 44,1 kHz, independentemente do que você enviou. A duração do áudio deve coincidir com a da origem com diferença de poucos milissegundos; se a diferença for maior que isso, ouça antes de publicar.

### Se falhar

Um job que o provedor aceitou e depois falhou volta como um status de erro com `error` e `credits_refunded` no corpo. `true` significa que a cobrança foi estornada. `false` com uma mensagem terminando em "please contact support" significa que o próprio reembolso falhou e o próximo polling tentará novamente. O resultado fica armazenado, então fazer polling de novo o reproduz.

Um job que nunca chegou ao provedor tem outra aparência. O retrieve continua respondendo `PROCESSING` por até 10 minutos, depois retorna `504` e reembolsa você, então espere pelo menos esse tempo com um job em `PROCESSING` antes de considerá-lo travado. O conjunto completo de resultados terminais está na [referência de retrieve](/pt-BR/api-reference/endpoint/audio/voice-changer/retrieve).

### Limpeza

Passe `delete_media_on_completion: true` em retrieve e a mídia armazenada será excluída na mesma chamada que entrega o áudio. Qualquer retrieve posterior para esse ID retorna `404`. Se quiser baixar mais de uma vez, não use essa opção e chame [complete](/pt-BR/api-reference/endpoint/audio/voice-changer/complete) quando terminar. O complete retorna `{"success": true}` e pode ser chamado repetidamente com segurança.

## Exemplo completo

Tudo o que foi visto acima, de ponta a ponta: verifica se a voz existe, cota, envia, faz polling até o áudio chegar e o salva. O prazo é de 12 minutos para que uma falha de despacho apareça como reembolso e não como timeout.

```python
import os
import time
from pathlib import Path

import requests

BASE_URL = "https://api.venice.ai/api/v1"
HEADERS = {"Authorization": f"Bearer {os.environ['VENICE_API_KEY']}"}
MODEL = "elevenlabs-voice-changer"
VOICE = "George"
# Length you expect to send, in whole seconds. The charge uses the length Venice measures.
EXPECTED_DURATION_SECONDS = 60

source = Path("source-recording.mp3")

# Voice names are not validated at queue time, so check before paying for a round trip.
models = requests.get(f"{BASE_URL}/models", params={"type": "music"}, headers=HEADERS)
models.raise_for_status()
spec = next(m["model_spec"] for m in models.json()["data"] if m["id"] == MODEL)
if VOICE not in spec["voices"] and not spec.get("supports_custom_voice_id"):
    raise SystemExit(f"{VOICE!r} is not a voice on {MODEL}: {spec['voices']}")

quote = requests.post(
    f"{BASE_URL}/audio/voice-changer/quote",
    json={"model": MODEL, "duration_seconds": EXPECTED_DURATION_SECONDS},
)
quote.raise_for_status()
print(f"Estimated cost: ${quote.json()['quote']:.2f}")

with source.open("rb") as audio:
    queued = requests.post(
        f"{BASE_URL}/audio/voice-changer/queue",
        headers=HEADERS,
        data={"model": MODEL, "voice": VOICE},
        files={"file": audio},
    )
queued.raise_for_status()
job = queued.json()
print(f"Queued {job['queue_id']} ({job['duration_seconds']:.1f}s billed)")

deadline = time.monotonic() + 12 * 60
while time.monotonic() < deadline:
    result = requests.post(
        f"{BASE_URL}/audio/voice-changer/retrieve",
        headers=HEADERS,
        json={
            "model": job["model"],
            "queue_id": job["queue_id"],
            "delete_media_on_completion": True,
        },
    )

    content_type = result.headers.get("Content-Type", "").split(";")[0].strip()
    if content_type == "audio/mpeg":
        output = Path("converted-audio.mp3")
        output.write_bytes(result.content)
        print(f"Saved {output} ({result.headers.get('x-venice-audio-duration')}s)")
        break

    body = result.json()
    if not result.ok:
        # Terminal failure. credits_refunded tells you whether the charge came back.
        print(f"{result.status_code}: {body.get('error')}")
        print(f"credits_refunded: {body.get('credits_refunded')}")
        raise SystemExit(1)

    if body.get("status") != "PROCESSING":
        print(body)
        raise SystemExit(1)

    # The average is a hint. On long inputs execution_duration overtakes it; fall back to a fixed interval.
    remaining_ms = body["average_execution_time"] - body["execution_duration"]
    time.sleep(5 if remaining_ms <= 0 else min(remaining_ms / 1000, 15))
else:
    raise SystemExit(
        f"Still processing after 12 minutes. Poll retrieve again with queue_id={job['queue_id']}."
    )
```

Não há chamada a complete porque o retrieve exclui a mídia ao entregá-la. Remova `delete_media_on_completion` e chame complete você mesmo se precisar do arquivo mais de uma vez.

## Parâmetros da API

### Queue

| Campo | Tipo | Obrigatório | Descrição |
|---|---|---|---|
| `model` | string | Sim | ID do modelo de trocador de voz. |
| `file` | file | Um entre `file` ou `audio_url` | Upload multipart da gravação de origem. Mutuamente exclusivo com `audio_url`. |
| `audio_url` | string | Um entre `file` ou `audio_url` | URL pública `http` ou `https` da gravação de origem, em um corpo JSON. Mutuamente exclusivo com `file`. |
| `voice` | string | Não | Um nome de `voices`, ou um Voice ID do provedor quando `supports_custom_voice_id` é true. O padrão é `default_voice`. |
| `remove_background_noise` | boolean | Não | Remove o ruído de fundo antes da conversão. Envie somente quando o modelo informar suporte. Multipart aceita `true` ou `false`. |
| `seed` | integer | Não | Inteiro ≥ 0, para um resultado reproduzível. Envie somente quando o modelo informar suporte. |

### Retrieve e complete

| Campo | Tipo | Obrigatório | Padrão | Descrição |
|---|---|---|---|---|
| `model` | string | Sim | - | `model` da resposta de queue. |
| `queue_id` | string | Sim | - | `queue_id` da resposta de queue. |
| `delete_media_on_completion` | boolean | Não | `false` | Em retrieve, exclui a mídia armazenada quando esta chamada retorna o áudio. |

## Erros

| Status | Endpoint | Corpo | Solução |
|---|---|---|---|
| `400` | queue | ``Provide exactly one source recording: the multipart `file` field or `audio_url`.`` | Envie `file` ou `audio_url`, nem ambos nem nenhum. |
| `400` | queue | `Source audio must be one of: MP3, WAV, OGG, MP4, AAC.` | Os bytes não estão em um contêiner suportado. Renomear o arquivo não resolve. |
| `400` | queue | `Upstream returned 404 Not Found` | O host do `audio_url` retornou um erro. Verifique se a URL é pública e não exige cabeçalhos. |
| `400` | retrieve | `The requested voice is not available. Check the Voice ID and try again.` com `credits_refunded: true` | A `voice` que você enfileirou não existe. A cobrança é reembolsada. Verifique `voices` antes de enfileirar. |
| `400` | retrieve, complete | `Request ID is invalid.` | Desconhecido, malformado, de outra conta ou com mais de 24 horas. Use o `queue_id` da sua própria resposta de queue. |
| `401` | todos | Chave de API inválida | Verifique a chave em [venice.ai/settings/api](https://venice.ai/settings/api). |
| `402` | queue, retrieve, complete | `Authentication required` mais uma oferta de pagamento x402 | Nenhum cabeçalho `Authorization` foi enviado. |
| `402` | queue | Saldo insuficiente | Recarregue seu saldo na Venice. |
| `404` | queue, quote | `Specified model not found: ...` | O ID do modelo está errado. O corpo sugere correspondências próximas. |
| `404` | retrieve | `Media could not be found. Request may be invalid, expired, or deleted.` | A mídia já foi excluída por complete ou por `delete_media_on_completion`. Não há nada a reembolsar. |
| `413` | queue | Arquivo maior que 25 MB | Use um arquivo menor. Rejeitado antes de qualquer cobrança. |
| `422` | queue | `Source audio must be at most N seconds.` | Encurte a gravação. Rejeitado antes de qualquer cobrança. |
| `429` | todos | Limite de taxa excedido | O queue permite 40/min e o retrieve 120/min. Aguarde e tente novamente. |
| `503` | queue | Modelo sem capacidade disponível | Tente novamente mais tarde. |
| `504` | retrieve | `The conversion was never accepted by the provider and can no longer complete.` com `credits_refunded` | O job ficou órfão no despacho. A cobrança é reembolsada. Enfileire novamente. |
