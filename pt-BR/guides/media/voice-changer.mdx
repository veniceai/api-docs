O Trocador de Voz é speech-to-speech: ele regrava um arquivo de origem em uma voz diferente, preservando a entrega, o ritmo e o timing. É assíncrono e usa seus próprios endpoints. Não é [`/audio/queue`](/pt-BR/api-reference/endpoint/audio/queue), tampouco [text-to-speech](/pt-BR/guides/media/text-to-speech) ou [clonagem de voz](/pt-BR/guides/media/voice-cloning).

<Note>
Uma conversão enfileirada é cobrada imediatamente. Salve o `queue_id` da resposta de queue antes de fazer qualquer outra coisa.
</Note>

## Como funciona

1. **Cotação** - Cote o preço do comprimento que você espera enviar
2. **Fila** - Envie a gravação ou passe uma URL pública
3. **Polling** - Baixe o MP3 quando o retrieve retornar áudio
4. **Conclusão** - Exclua a mídia armazenada depois que o arquivo for salvo

| Endpoint | Finalidade |
|----------|---------|
| [`POST /audio/voice-changer/quote`](/pt-BR/api-reference/endpoint/audio/voice-changer/quote) | Estimar o custo da conversão em USD |
| [`POST /audio/voice-changer/queue`](/pt-BR/api-reference/endpoint/audio/voice-changer/queue) | Iniciar uma conversão speech-to-speech |
| [`POST /audio/voice-changer/retrieve`](/pt-BR/api-reference/endpoint/audio/voice-changer/retrieve) | Consultar o job e baixar o áudio convertido |
| [`POST /audio/voice-changer/complete`](/pt-BR/api-reference/endpoint/audio/voice-changer/complete) | Excluir a mídia armazenada após baixá-la |

## Pré-requisitos

- Uma chave de API da Venice para queue, retrieve e complete. A cotação não usa a chave.
- Uma gravação de origem em um contêiner listado em `accepted_audio_formats` do modelo. A Venice verifica a assinatura binária do arquivo, portanto o nome do arquivo não determina a aceitação.
- Uma gravação com duração não superior a `max_source_audio_duration_seconds` do modelo e tamanho não superior a 25 MB.
- Para `audio_url`, uma URL `http` ou `https` publicamente acessível. A Venice busca os bytes por conta própria e encaminha apenas esses bytes para o provedor.

Defina sua chave de API:

```bash
export VENICE_API_KEY="your-api-key"
```

## Escolha um modelo

Modelos de trocador de voz são retornados por `GET /models?type=music` com `model_spec.voice_changer` definido como `true`. Não há um filtro `?type=voice-changer`. Consulte [Modelos de Música e Efeitos Sonoros](/pt-BR/models/music) para ver a lista atual. Os exemplos abaixo usam `elevenlabs-voice-changer`, e `Aria` é um dos nomes de voz desse modelo. Passe um nome de `voices` ou omita `voice` para usar `default_voice`.

```bash
curl "https://api.venice.ai/api/v1/models?type=music" \
  -H "Authorization: Bearer $VENICE_API_KEY" |
  jq '.data[] | select(.model_spec.voice_changer == true) | {
    id,
    voices: .model_spec.voices,
    default_voice: .model_spec.default_voice,
    supports_custom_voice_id: .model_spec.supports_custom_voice_id,
    accepted_audio_formats: .model_spec.accepted_audio_formats,
    max_source_audio_duration_seconds: .model_spec.max_source_audio_duration_seconds,
    supports_background_noise_removal: .model_spec.supports_background_noise_removal,
    supports_seed: .model_spec.supports_seed,
    durations: .model_spec.pricing.durations
  }'
```

Verifique os metadados de cada modelo antes de definir campos opcionais:

| Campo | Use para |
|-------|------------|
| `voices` / `default_voice` | Nomes de vozes de destino. Omita `voice` para usar o padrão. |
| `supports_custom_voice_id` | Se `voice` também aceita um Voice ID do provedor |
| `accepted_audio_formats` | Contêineres de origem que a Venice aceita |
| `max_source_audio_duration_seconds` | Gravação de origem mais longa que o modelo aceita |
| `supports_background_noise_removal` | Se `remove_background_noise` é aceito |
| `supports_seed` | Se `seed` é aceito |
| `pricing.durations` | Faixas de preço por minuto inteiro, cada uma com `min_seconds`, `max_seconds` e `usd` |

Campos não suportados causam uma resposta HTTP `400`. Gravações mais longas que `max_source_audio_duration_seconds` são rejeitadas com HTTP `422` antes de qualquer cobrança. O corpo do erro informa esse máximo, no formato `Source audio must be at most N seconds.`

## 1. Obtenha uma cotação de preço

O Trocador de Voz é cobrado com base na duração da gravação de origem, arredondada para cima para o próximo minuto inteiro. Um múltiplo exato de 60 segundos permanece na faixa desse minuto. Um segundo a mais usa a faixa seguinte. Para `elevenlabs-voice-changer`, a cotação retorna $0.35 para 60 segundos e $0.69 para 61 segundos. Leia `pricing.durations` ou chame a cotação para o modelo que você está usando. O valor cobrado é calculado a partir do comprimento que a Venice mede quando a gravação é enfileirada.

<Note>
A cotação não requer autenticação. As requisições de queue, retrieve e complete requerem.
</Note>

```bash
curl https://api.venice.ai/api/v1/audio/voice-changer/quote \
  -H "Content-Type: application/json" \
  -d '{
    "model": "elevenlabs-voice-changer",
    "duration_seconds": 60
  }'
```

A resposta contém o custo estimado em USD e a duração para a qual a cotação foi calculada:

```json
{
  "quote": 0.35,
  "duration_seconds": 60
}
```

## 2. Enfileire a conversão

Forneça a gravação de origem exatamente de uma de duas formas: como upload `file` multipart, ou como um `audio_url` em um corpo JSON. Fornecer ambos, ou nenhum, é rejeitado.

Um arquivo que contém uma faixa de vídeo é rejeitado. Extraia o áudio e envie-o. Quando você passa uma URL, ela precisa ser publicamente acessível. A Venice busca e valida os bytes por conta própria, e a URL nunca é repassada ao provedor.

Ao usar `curl -F`, não defina `Content-Type` manualmente. O `curl` adiciona o cabeçalho `multipart/form-data` e o boundary necessário. Em um corpo multipart, envie `remove_background_noise` como `true` ou `false` e `seed` como dígitos.

<CodeGroup>
```bash File upload
curl https://api.venice.ai/api/v1/audio/voice-changer/queue \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -F "model=elevenlabs-voice-changer" \
  -F "voice=Aria" \
  -F "file=@./source-recording.mp3"
```

```bash Audio URL
curl https://api.venice.ai/api/v1/audio/voice-changer/queue \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "elevenlabs-voice-changer",
    "voice": "Aria",
    "audio_url": "https://example.com/source-recording.mp3",
    "remove_background_noise": true,
    "seed": 42
  }'
```
</CodeGroup>

`remove_background_noise` e `seed` são aceitos somente quando o modelo informa suporte a eles. Omita `voice` para usar `default_voice`. Quando `supports_custom_voice_id` é true, `voice` pode ser um Voice ID do provedor em vez de um nome de `voices`.

Uma requisição bem-sucedida retorna o modelo, um ID de fila e o comprimento medido da origem:

```json
{
  "model": "elevenlabs-voice-changer",
  "queue_id": "0190f2c4-9c1e-7a3b-8f42-2c9d5e7a1b34",
  "status": "QUEUED",
  "duration_seconds": 52
}
```

Salve `model` e `queue_id`. Os endpoints retrieve e complete exigem ambos. Compare `duration_seconds` com sua cotação para reconciliar a estimativa com o comprimento cobrado.

<Warning>
Enfileirar não é seguro para retry. Uma requisição de queue bem-sucedida já foi cobrada. Se você tem o `queue_id`, faça polling em retrieve com ele. Se a resposta de queue nunca chegou, você não tem um ID para consultar, e enviar a gravação novamente pode gerar uma segunda cobrança.
</Warning>

## 3. Faça polling e baixe

Chame `/audio/voice-changer/retrieve` com os valores da resposta de queue. Um `queue_id` pode ser recuperado por 24 horas. Um ID desconhecido, um ID de outra conta, um ID malformado e um ID expirado retornam HTTP `400` com `Request ID is invalid.`

```bash
curl https://api.venice.ai/api/v1/audio/voice-changer/retrieve \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "elevenlabs-voice-changer",
    "queue_id": "0190f2c4-9c1e-7a3b-8f42-2c9d5e7a1b34"
  }' \
  --output response.bin
```

Inspecione o `Content-Type` da resposta:

| Content-Type | Significado | Ação |
|--------------|---------|--------|
| `application/json` | A conversão ainda está em processamento | Leia os campos de tempo, aguarde e faça polling novamente |
| `audio/mpeg` | A conversão está concluída | Salve o corpo binário como um `.mp3` |

Uma resposta de processamento se parece com esta:

```json
{
  "status": "PROCESSING",
  "average_execution_time": 10000,
  "execution_duration": 4200
}
```

Ambos os valores de tempo estão em milissegundos. Aguarde a diferença entre `execution_duration` e `average_execution_time` antes de fazer polling novamente. Uma resposta concluída também inclui `x-venice-audio-format`, `x-venice-audio-duration` (segundos), `x-venice-inference-time` (segundos), `x-venice-model-id` e `x-venice-model-name`.

Uma falha do provedor, e uma conversão que nunca chega ao provedor (HTTP `504`), retornam `credits_refunded` no corpo do erro. A [API Retrieve do Trocador de Voz](/pt-BR/api-reference/endpoint/audio/voice-changer/retrieve) descreve quando essa flag é false e o que a string `error` indica que você deve fazer. Fazer polling novamente reproduz o mesmo resultado.

Defina `delete_media_on_completion` como `true` em retrieve para excluir a mídia armazenada na mesma chamada que retorna o áudio. O áudio não pode ser recuperado novamente depois disso. Caso contrário, chame [`POST /audio/voice-changer/complete`](/pt-BR/api-reference/endpoint/audio/voice-changer/complete) depois que o arquivo for salvo. É seguro chamar complete mais de uma vez.

## Exemplo completo

Este exemplo cota uma duração representativa de um minuto, envia um arquivo, faz polling até o áudio chegar ou até passarem cinco minutos e salva um MP3. O prazo de cinco minutos é apenas para o exemplo. Um job pode ser consultado por 24 horas com o `queue_id` salvo.

```python
import os
import time
from pathlib import Path

import requests

BASE_URL = "https://api.venice.ai/api/v1"
HEADERS = {"Authorization": f"Bearer {os.environ['VENICE_API_KEY']}"}
MODEL = "elevenlabs-voice-changer"
# Length you expect to send. The charge uses the length Venice measures.
EXPECTED_DURATION_SECONDS = 60

source = Path("source-recording.mp3")

quote = requests.post(
    f"{BASE_URL}/audio/voice-changer/quote",
    json={"model": MODEL, "duration_seconds": EXPECTED_DURATION_SECONDS},
)
quote.raise_for_status()
print(f"Estimated cost: ${quote.json()['quote']:.2f}")

with source.open("rb") as audio:
    queued = requests.post(
        f"{BASE_URL}/audio/voice-changer/queue",
        headers=HEADERS,
        data={"model": MODEL, "voice": "Aria"},
        files={"file": audio},
    )
queued.raise_for_status()
job = queued.json()
print(f"Queued {job['queue_id']} ({job['duration_seconds']}s billed)")

deadline = time.monotonic() + 5 * 60
while time.monotonic() < deadline:
    result = requests.post(
        f"{BASE_URL}/audio/voice-changer/retrieve",
        headers=HEADERS,
        json={"model": job["model"], "queue_id": job["queue_id"]},
    )
    if not result.ok:
        body = result.json()
        print(body.get("error"))
        if "credits_refunded" in body:
            print(f"credits_refunded: {body['credits_refunded']}")
        raise SystemExit(1)

    content_type = result.headers.get("Content-Type", "").split(";")[0].strip()
    if content_type == "audio/mpeg":
        output = Path("converted-audio.mp3")
        output.write_bytes(result.content)
        print(f"Saved {output}")
        break

    status = result.json()
    if status.get("status") != "PROCESSING":
        print(status)
        raise SystemExit(1)

    remaining_ms = status["average_execution_time"] - status["execution_duration"]
    time.sleep(min(max(remaining_ms / 1000, 1), 15))
else:
    raise SystemExit("Still processing. Poll retrieve again with the saved queue_id.")

requests.post(
    f"{BASE_URL}/audio/voice-changer/complete",
    headers=HEADERS,
    json={"model": job["model"], "queue_id": job["queue_id"]},
).raise_for_status()
```

## Parâmetros da API

### Queue

| Campo | Tipo | Obrigatório | Descrição |
|---|---|---|---|
| `model` | string | Sim | ID do modelo de trocador de voz. |
| `file` | file | Um entre `file` ou `audio_url` | Upload multipart da gravação de origem. Mutuamente exclusivo com `audio_url`. |
| `audio_url` | string | Um entre `file` ou `audio_url` | URL pública `http` ou `https` da gravação de origem, em um corpo JSON. Mutuamente exclusivo com `file`. |
| `voice` | string | Não | Um nome de `voices`, ou um Voice ID do provedor quando `supports_custom_voice_id` é true. O padrão é `default_voice`. |
| `remove_background_noise` | boolean | Não | Remove o ruído de fundo antes da conversão. Envie somente quando o modelo informar suporte. Multipart aceita `true` ou `false`. |
| `seed` | integer | Não | Inteiro ≥ 0, para um resultado reproduzível. Envie somente quando o modelo informar suporte. |

### Retrieve e complete

| Campo | Tipo | Obrigatório | Padrão | Descrição |
|---|---|---|---|---|
| `model` | string | Sim | - | `model` da resposta de queue. |
| `queue_id` | string | Sim | - | `queue_id` da resposta de queue. |
| `delete_media_on_completion` | boolean | Não | `false` | Em retrieve, exclui a mídia armazenada quando esta chamada retorna o áudio. |

## Erros comuns

Os resultados terminais de retrieve, incluindo `credits_refunded`, estão documentados na [API Retrieve do Trocador de Voz](/pt-BR/api-reference/endpoint/audio/voice-changer/retrieve).

| Status | Causa | Solução |
|---|---|---|
| `400` | Campo não suportado, voz desconhecida, contêiner não aceito, áudio ilegível, faixa de vídeo, ou `queue_id` desconhecido, de outra conta ou expirado | Verifique os metadados do modelo, envie uma única origem e faça polling com o `queue_id` retornado para sua conta. |
| `401` | Chave de API inválida, ou um modelo limitado a usuários Pro | Verifique a chave em [venice.ai/settings/api](https://venice.ai/settings/api). |
| `402` com `"error": "Authentication required"` | Nenhuma chave de API enviada | Envie `Authorization: Bearer $VENICE_API_KEY`. |
| `402` | Saldo insuficiente | Recarregue seu saldo na Venice. |
| `413` | Arquivo maior que 25 MB | Use um arquivo menor. Rejeitado antes de qualquer cobrança. |
| `422` | Mais longo que `max_source_audio_duration_seconds` | Encurte a gravação. O corpo informa o máximo. Rejeitado antes de qualquer cobrança. |
| `429` | Limite de taxa excedido | Tente novamente após a janela do limite de taxa ser redefinida. |
| `503` | Modelo sem capacidade disponível | Tente novamente mais tarde. |

## Dicas para produção

- Anote o `queue_id` antes de analisar o restante da resposta de queue.
- Compare o `duration_seconds` medido com a cotação antes de tratar a estimativa como o valor cobrado.
- Envie o arquivo, ou passe uma URL pública que não precise de cabeçalhos de requisição.
- Chame complete depois que o MP3 estiver em disco. `delete_media_on_completion: true` em retrieve faz essa limpeza na própria chamada de download.
