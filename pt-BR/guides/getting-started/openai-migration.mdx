A Venice AI é uma **substituição direta** da OpenAI. Mesmo SDK, mesmo código — basta alterar duas linhas. Tenha inferência com foco em privacidade, modelos sem censura e preços competitivos.

## A migração em 2 linhas

<CodeGroup>
```python Python
# Antes (OpenAI)
from openai import OpenAI
client = OpenAI()

# Depois (Venice) — altere api_key e base_url
from openai import OpenAI
client = OpenAI(
    api_key="your-venice-api-key",           # ← Alteração 1
    base_url="https://api.venice.ai/api/v1",  # ← Alteração 2
)
```

```javascript Node.js
// Antes (OpenAI)
import OpenAI from "openai";
const client = new OpenAI();

// Depois (Venice)
import OpenAI from "openai";
const client = new OpenAI({
  apiKey: "your-venice-api-key",
  baseURL: "https://api.venice.ai/api/v1",
});
```

```bash cURL
# Antes
curl https://api.openai.com/v1/chat/completions ...

# Depois — basta alterar a URL e a chave
curl https://api.venice.ai/api/v1/chat/completions ...
```
</CodeGroup>

Gere uma chave em [venice.ai/settings/api](https://venice.ai/settings/api?utm_source=venice-api-documentation) ou siga o [guia de chave de API](/guides/getting-started/generating-api-key).

### Variáveis de ambiente

```bash
# Antes
OPENAI_API_KEY=sk-...
OPENAI_BASE_URL=https://api.openai.com/v1

# Depois
OPENAI_API_KEY=your-venice-api-key
OPENAI_BASE_URL=https://api.venice.ai/api/v1
```

<Tip>
Muitas bibliotecas e ferramentas leem `OPENAI_API_KEY` e `OPENAI_BASE_URL` automaticamente. Atualizar essas variáveis de ambiente pode ser tudo o que você precisa. Algumas ferramentas ainda usam `OPENAI_API_BASE` para a mesma URL.
</Tip>

## Modelos

Passe um ID de modelo da Venice, um trait como `default` ou `most_uncensored`, ou um nome familiar no estilo OpenAI. A Venice mapeia nomes da OpenAI por meio do [mapeamento de compatibilidade](/api-reference/endpoint/models/compatibility_mapping). Traits sempre resolvem para o modelo atual daquele papel — veja [traits de modelo](/api-reference/endpoint/models/traits).

Navegue pelo catálogo ao vivo em [Modelos de texto](/models/text) e [Preços](/overview/pricing). Para um passo a passo da primeira requisição, veja o [Guia rápido](/getting-started/quick-start).

## Compatibilidade de recursos

| Recurso | OpenAI | Venice | Observações |
|---------|--------|--------|-------------|
| Chat Completions | ✅ | ✅ | Totalmente compatível |
| Streaming | ✅ | ✅ | Mesmo formato SSE |
| Function Calling | ✅ | ✅ | Mesmo parâmetro `tools` |
| Saída estruturada | ✅ | ✅ | Mesmo `response_format` |
| Visão | ✅ | ✅ | Mesmo formato de array de conteúdo |
| Embeddings | ✅ | ✅ | Apenas texto; arrays de tokens retornam HTTP 400 |
| Geração de imagem | ✅ | ✅ | Compatível com OpenAI via `/images/generations` |
| TTS | ✅ | ✅ | Compatível |
| STT | ✅ | ✅ | Compatível |
| Responses API | ✅ | ✅ | Alpha |
| Assistants API | ✅ | ❌ | Use [Characters](/guides/features/characters) ou [function calling](/guides/features/function-calling) |
| Batch API | ✅ | ❌ | Ainda não disponível |
| Fine-tuning | ✅ | ❌ | Não disponível |

Para opções nativas de imagem além do endpoint compatível com OpenAI, veja [Geração de imagem](/guides/media/image-generation).

## Recursos exclusivos da Venice

Passe opções específicas da Venice através de `extra_body` como `venice_parameters`. A busca web integrada é normalmente o primeiro extra:

```python
response = client.chat.completions.create(
    model="default",
    messages=[{"role": "user", "content": "Latest AI news today"}],
    extra_body={
        "venice_parameters": {
            "enable_web_search": "auto"
        }
    },
)
```

O mesmo padrão vale para web scraping, citações e [Characters](/guides/features/characters). Se um cliente não puder alterar o corpo da requisição, adicione um [sufixo de recurso do modelo](/api-reference/endpoint/chat/model_feature_suffix) como `default:enable_web_search=auto`.

A Venice também tem APIs nativas de [vídeo](/guides/media/video-generation), [música](/guides/media/music-and-sound-effects), [busca web](/guides/tools/web-retrieval) e [x402](/guides/integrations/x402-venice-api) ao lado da superfície compatível com OpenAI.

## Modelos sem censura

Os modelos privados sem censura da Venice não têm filtragem de conteúdo, o que os torna adequados para:

- Escrita criativa sem barreiras
- Pesquisa de segurança e red teaming
- Análise honesta sem padrões de recusa
- Informações médicas e jurídicas sem avisos extras

Use o trait `most_uncensored` ou um ID atual de modelo sem censura em [Modelos de texto](/models/text).
