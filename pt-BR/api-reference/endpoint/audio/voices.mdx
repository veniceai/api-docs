Envie uma amostra de áudio para criar um identificador de voz clonada e, em seguida, passe-o como `voice` para [`/audio/speech`](/pt-BR/api-reference/endpoint/audio/speech) com o mesmo `model` usado para criá-lo. Para um passo a passo, consulte o [guia de clonagem de voz](/pt-BR/guides/media/voice-cloning).
