Chame este endpoint após baixar com sucesso o áudio convertido, quando quiser que a Venice limpe a mídia armazenada associada à solicitação. Passar `delete_media_on_completion: true` para [`/audio/voice-changer/retrieve`](/pt-BR/api-reference/endpoint/audio/voice-changer/retrieve) executa a mesma limpeza de forma inline.

Modelos de trocador de voz não são aceitos em [`/audio/complete`](/pt-BR/api-reference/endpoint/audio/complete).
