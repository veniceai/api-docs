<Note>
`balances` reporta apenas `diem` e `usd`. Créditos empacotados não aparecem como um campo numérico. Se os créditos empacotados forem a fonte da qual sua próxima requisição será debitada, `consumptionCurrency` retorna `BUNDLED_CREDITS`. Para ver o valor restante de créditos empacotados, verifique [venice.ai/settings/api](https://venice.ai/settings/api?utm_source=venice-api-documentation). Para saber como a API escolhe entre DIEM, créditos empacotados e USD, consulte [VVV & DIEM](/overview/vvv-diem#how-funding-works).
</Note>
