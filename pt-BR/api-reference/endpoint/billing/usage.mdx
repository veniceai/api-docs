<Warning>
Este endpoint foi descontinuado em 2026-09-16 e agora retorna `410 Gone` para todas as requisições. Use o [Histórico de uso de faturamento](/pt-BR/api-reference/endpoint/billing/usage-history).
</Warning>

O Histórico de uso de faturamento retorna as mesmas entradas do registro com paginação por cursor. Para migrar:

- Substitua `page` e `limit` por `pageSize` e passe o `nextCursor` de cada resposta para buscar a próxima página.
- Substitua `startDate` e `endDate` por `startTimestamp` e `endTimestamp`.
