Se a resposta de `/video/queue` incluiu uma `download_url`, baixe o arquivo finalizado a partir dessa URL (não como binário deste endpoint). Caso contrário, este endpoint retorna o vídeo. Veja [Links privados de download](/pt-BR/guides/media/video-generation#links-de-download-privados) para entender como o link funciona, novas tentativas e `DELETE` opcional.
