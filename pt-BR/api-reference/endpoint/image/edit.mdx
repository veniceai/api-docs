## Salvar a imagem editada {#save-the-edited-image}

O corpo da resposta é a própria imagem editada, não JSON, então grave-o em um arquivo em vez de analisá-lo:

```bash
curl https://api.venice.ai/api/v1/image/edit \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "Turn the scene into a snowy winter evening", "image": "https://venice.ai/samples/gpt-image-2-6-flare/hero.webp"}' \
  --output edited.png
```

`image` também aceita uma string base64 ou um upload de arquivo multipart. O [guia de Edição de Imagens](/pt-BR/guides/media/image-editing) aborda edições com várias imagens, remoção de fundo e como escolher um modelo.

## Níveis de qualidade

`/image/edit` não aceita o parâmetro `quality`, e enviá-lo retorna `400`. Edições neste endpoint são cobradas pelo nível padrão do modelo (`high` para `gpt-image-2-edit`).

Para escolher um nível (`low`, `medium`, `high`), use [`/image/multi-edit`](/pt-BR/api-reference/endpoint/image/multi-edit), que aceita `quality` nos modelos que o suportam. Os preços por nível (1K/2K/4K × low/medium/high) ficam em `model_spec.pricing.quality` no [endpoint de Modelos](/pt-BR/api-reference/endpoint/models/list) e estão listados em [Modelos de imagem](/pt-BR/models/image).
