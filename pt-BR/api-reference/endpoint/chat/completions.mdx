<Info>
  **Os parâmetros específicos da Venice ficam em [`venice_parameters`](#body-venice-parameters).** Este endpoint é compatível com a OpenAI, mas o objeto `venice_parameters` habilita recursos que não fazem parte da API padrão da OpenAI, e muitos integradores acabam ignorando:

  - **Busca na web e citações** — `enable_web_search`, `enable_web_citations`, `enable_web_scraping`
  - **Personagens** — `character_slug`
  - **Controle do prompt de sistema** — `include_venice_system_prompt`
  - **Controles de raciocínio** — `disable_thinking`, `strip_thinking_response`
  - **Privacidade** — `enable_e2ee`

  Veja a lista completa na seção [`venice_parameters`](#body-venice-parameters) abaixo.
</Info>
