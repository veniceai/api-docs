Quando ocorre um erro, a API Venice retorna um código de status HTTP e uma mensagem descritiva. Alguns erros também incluem campos adicionais, como status de reembolso, modelos sugeridos para nova tentativa, detalhes de validação ou IDs de requisição.

## Formato da resposta de erro

A maioria dos erros retorna um campo `error` com uma mensagem legível por humanos:

```json
{
  "error": "Invalid request parameters"
}
```

Alguns endpoints incluem campos adicionais específicos do endpoint. Por exemplo, erros de moderação de vídeo podem incluir se os créditos foram reembolsados:

```json
{
  "error": "Your generation was blocked due to the model provider's content policies. Credits have been refunded.",
  "credits_refunded": true
}
```

Erros de validação podem incluir campos `details` e `issues` com informações de validação por campo:

```json
{
  "error": "Invalid request parameters",
  "details": {
    "_errors": [],
    "field": {
      "_errors": ["Field is required"]
    }
  },
  "issues": []
}
```

Alguns endpoints compatíveis com OpenAI podem retornar objetos de erro no estilo OpenAI para casos específicos, como erros de comprimento de contexto:

```json
{
  "error": {
    "message": "Your request exceeds the model's maximum context. Please reduce your prompt or completion length.",
    "type": "invalid_request_error",
    "param": "messages",
    "code": "context_length_exceeded"
  }
}
```

## Credenciais ausentes

Uma solicitação sem credenciais retorna `402 Payment Required`, e não `401`. Todas as rotas pagas também aceitam [autenticação por carteira x402](/pt-BR/guides/integrations/x402-venice-api), então a resposta é um desafio de pagamento: ela inclui um cabeçalho `PAYMENT-REQUIRED` e um corpo descrevendo as duas formas de autenticação.

```json
{
  "x402Version": 2,
  "error": "Authentication required",
  "accepts": [ ... ],
  "authOptions": {
    "apiKey": {
      "header": "Authorization: Bearer YOUR_API_KEY",
      "getKey": "https://venice.ai/settings/api"
    },
    "x402Wallet": {
      "header": "SIGN-IN-WITH-X",
      "topUp": "POST /api/v1/x402/top-up"
    }
  }
}
```

Se você pretendia usar uma chave de API, verifique se o cabeçalho `Authorization: Bearer` está definido. Uma chave presente, mas inválida, retorna `401`.

## Erros de formato da requisição

Esses erros ocorrem durante a leitura do corpo da requisição, antes de qualquer validação específica do endpoint.

| Status HTTP | Mensagem | Causa |
| --- | --- | --- |
| 400 | `'Content-Type' must be 'application/json'` | Um corpo de `POST`, `PUT` ou `PATCH` enviado sem `Content-Type: application/json`. Endpoints que recebem upload de arquivos também aceitam `multipart/form-data` |
| 400 | `Invalid JSON request` | O corpo não é um JSON válido |
| 400 | `Invalid multipart request: malformed part header` | Um corpo `multipart/form-data` que não pode ser interpretado |
| 413 | `Request body exceeds the maximum allowed size.` | O corpo da requisição é grande demais |
| 415 | `Request encoding is not supported` | Um `Content-Encoding` ou charset que a API não consegue decodificar |

Um `Content-Type` incorreto retorna `400`, não `415`. Respostas `413` por limite de tamanho também incluem um campo `code`:

```json
{
  "code": "PAYLOAD_TOO_LARGE",
  "error": "Request body exceeds the maximum allowed size."
}
```

## Outros erros

A tabela acima não é exaustiva. Alguns erros são retornados sem um código listado, e as mensagens podem variar conforme o modelo e o endpoint, então baseie sua lógica no status HTTP e não no texto da mensagem. Erros que você pode encontrar e que não estão na tabela:

| Status HTTP | Quando ocorre |
| --- | --- |
| 400 | Uma imagem de entrada em uma requisição de chat ou Responses está em um formato não suportado |
| 400 | A voz solicitada não está disponível para o modelo de text-to-speech |
| 403 | A requisição vem de um endereço IP que não está na allowlist da chave de API |
| 403 | O modelo solicitado não é permitido pela configuração de privacidade da chave de API |
| 403 | O acesso ao modelo solicitado é restrito. Entre em contato com support@venice.ai |
| 409 | Um resultado de vídeo, música ou voice changer ainda está sendo enviado quando você tenta recuperá-lo. Tente novamente em instantes |
| 410 | O endpoint foi descontinuado |
| 422 | O áudio é longo ou curto demais (clonagem de voz, voice changer e jobs de áudio) |
| 422 | A imagem de entrada de uma requisição de vídeo tem uma proporção entre largura e altura fora do intervalo aceito pelo modelo |
| 422 | A entrada de uma requisição de vídeo foi bloqueada pela moderação de conteúdo |
| 500 | A geração de vídeo ou de voice changer falhou |
| 502 | A síntese de fala falhou no provedor upstream, ou um vídeo gerado não pôde ser recuperado. Tente a requisição novamente |
