Quando ocorre um erro, a API Venice retorna um código de status HTTP e uma mensagem descritiva. Alguns erros também incluem campos adicionais, como status de reembolso, modelos sugeridos para nova tentativa, detalhes de validação ou IDs de requisição.

## Formato da resposta de erro

A maioria dos erros retorna um campo `error` com uma mensagem legível por humanos:

```json
{
  "error": "Invalid request parameters"
}
```

Alguns endpoints incluem campos adicionais específicos do endpoint. Por exemplo, erros de moderação de vídeo podem incluir se os créditos foram reembolsados:

```json
{
  "error": "Your generation was blocked due to the model provider's content policies. Credits have been refunded.",
  "credits_refunded": true
}
```

Erros de validação podem incluir campos `details` e `issues` com informações de validação por campo:

```json
{
  "error": "Invalid request parameters",
  "details": {
    "_errors": [],
    "field": {
      "_errors": ["Field is required"]
    }
  },
  "issues": []
}
```

Alguns endpoints compatíveis com OpenAI podem retornar objetos de erro no estilo OpenAI para casos específicos, como erros de comprimento de contexto:

```json
{
  "error": {
    "message": "Your request exceeds the model's maximum context. Please reduce your prompt or completion length.",
    "type": "invalid_request_error",
    "param": "messages",
    "code": "context_length_exceeded"
  }
}
```

## Credenciais ausentes

Uma solicitação sem credenciais retorna `402 Payment Required`, e não `401`. A maioria das rotas pagas também aceita [autenticação por carteira x402](/pt-BR/guides/integrations/x402-venice-api), então a resposta é um desafio de pagamento: ela inclui um cabeçalho `PAYMENT-REQUIRED` e um corpo descrevendo as duas formas de autenticação. As rotas de vídeo e de troca de voz enviam o mesmo desafio, mas atualmente aceitam apenas uma chave de API.

```json
{
  "x402Version": 2,
  "error": "Authentication required",
  "accepts": [ ... ],
  "authOptions": {
    "apiKey": {
      "header": "Authorization: Bearer YOUR_API_KEY",
      "getKey": "https://venice.ai/settings/api"
    },
    "x402Wallet": {
      "header": "SIGN-IN-WITH-X",
      "topUp": "POST /api/v1/x402/top-up"
    }
  }
}
```

Se um `402` em uma rota paga surpreender você, geralmente é um cabeçalho de credenciais ausente, e não um problema de cobrança. Um corpo com `x402Version` e `accepts` significa que nada autenticou a solicitação: defina `Authorization: Bearer $VENICE_API_KEY` e tente novamente. O campo `authOptions.apiKey.header` no corpo indica o formato exato do cabeçalho.

Um `402` que diz "Insufficient USD or Diem balance" (`INSUFFICIENT_BALANCE` na tabela abaixo) é diferente: esse é o saldo da conta. Veja [pagamento pelo uso](/pricing#paying-for-usage).

Uma chave presente, mas inválida, retorna `401`.

## Erros de formato da requisição

Esses erros ocorrem durante a leitura do corpo da requisição, antes de qualquer validação específica do endpoint.

| Status HTTP | Mensagem | Causa |
| --- | --- | --- |
| 400 | `'Content-Type' must be 'application/json'` | Um corpo de `POST`, `PUT` ou `PATCH` enviado sem `Content-Type: application/json`. Endpoints que recebem upload de arquivos também aceitam `multipart/form-data` |
| 400 | `Invalid JSON request` | O corpo não é um JSON válido |
| 400 | `Invalid multipart request: malformed part header` | Um corpo `multipart/form-data` que não pode ser interpretado |
| 413 | `Request body exceeds the maximum allowed size.` | O corpo da requisição é grande demais |
| 415 | `Request encoding is not supported` | Um `Content-Encoding` ou charset que a API não consegue decodificar |

Um `Content-Type` incorreto retorna `400`, não `415`. Respostas `413` por limite de tamanho também incluem um campo `code`:

```json
{
  "code": "PAYLOAD_TOO_LARGE",
  "error": "Request body exceeds the maximum allowed size."
}
```

## Códigos de erro

Os códigos desta tabela nomeiam cada erro para referência. A maioria das respostas não os inclui: o corpo traz apenas a mensagem em `error`. As exceções são as respostas `413` e os erros de carteira x402, que adicionam um campo `code`. Decida com base no status HTTP e não compare o texto da mensagem, que pode variar.

| Código de erro | Status HTTP | Mensagem | O que fazer |
| --- | --- | --- | --- |
| `AUTHENTICATION_FAILED` | 401 | Authentication failed | Verifique o cabeçalho `Authorization: Bearer` e se a chave não foi excluída nem expirou. Os endpoints de conta e de gerenciamento de chaves também respondem a uma chave Inference com este código; use uma chave Admin neles. |
| `AUTHENTICATION_FAILED_INACTIVE_KEY` | 401 | Authentication failed - Pro subscription is inactive. Please upgrade your subscription to continue using the API | A conta da chave não pode usar a API. Entre em venice.ai para verificar a conta ou fale com support@venice.ai. |
| `X402_INVALID_SIGN_IN` | 401 | Invalid Sign-in-with-x signature | Assine uma nova prova `SIGN-IN-WITH-X` com o nonce do desafio `402` mais recente. Veja [x402](/pt-BR/guides/integrations/x402-venice-api). |
| `X402_USER_NOT_ALLOWED` | 401 | Wallet user is not allowed to authenticate | A conta Venice da carteira foi banida ou excluída, ou seus créditos pertencem a outro usuário. Use outra carteira. |
| `PRO_ONLY_MODEL` | 401 | This model is only available to Pro users | Use um modelo incluído no seu plano ou faça upgrade para um plano pago. |
| `INSUFFICIENT_BALANCE` | 402 | Insufficient USD or Diem balance to complete request. Visit https://venice.ai/settings/api to add credits. | Adicione créditos ou faça staking de [DIEM](/pt-BR/overview/vvv-diem) e tente novamente. |
| `API_KEY_DIEM_SPEND_LIMIT_EXCEEDED` | 402 | API key DIEM spend limit exceeded. Your account may still have DIEM balance, but this API key has reached its configured DIEM spending limit. | Aumente ou remova o limite de DIEM da chave, ou aguarde a redefinição do período do limite. |
| `API_KEY_USD_SPEND_LIMIT_EXCEEDED` | 402 | API key USD spend limit exceeded. Your account may still have USD balance, but this API key has reached its configured USD spending limit. | Aumente ou remova o limite de USD da chave, ou aguarde a redefinição do período do limite. |
| `UNAUTHORIZED` | 403 | Unauthorized access | Leia a mensagem, que informa o que bloqueou a requisição, como a sua região. |
| `API_ACCESS_DISABLED` | 403 | API access has been disabled for this account. Please contact support@venice.ai | Fale com support@venice.ai. |
| `X402_WALLET_MISMATCH` | 403 | You can only access resources for your own wallet | Solicite o saldo ou as transações da carteira com a qual você entrou. |
| `INVALID_REQUEST` | 400 | Invalid request parameters | Corrija os campos indicados em `details`, `issues` ou na mensagem. |
| `INVALID_MODEL` | 400 | Invalid model specified | Use um modelo compatível com este endpoint. `GET /models` lista os recursos de cada modelo. |
| `REQUEST_ID_NOT_FOUND` | 400 | Request ID is invalid. | Verifique se o ID da fila e o modelo correspondem a um job que você enfileirou. |
| `INVALID_AUDIO_FORMAT` | 400 | Invalid audio format. Supported formats are WAV and MP3. | Converta o áudio para um formato aceito pelo endpoint. |
| `INVALID_VIDEO_FORMAT` | 400 | Invalid video format. Supported formats include MP4, MOV, WebM, MKV, AVI, and others. | Converta o vídeo para um formato compatível, como MP4. |
| `CORRUPTED_IMAGE` | 400 | The image file is corrupted or unreadable | Recodifique a imagem ou envie outro arquivo. |
| `IMAGE_TOO_SMALL` | 400 | Image dimensions are too small | Envie uma imagem maior. |
| `TOO_MANY_TOKENS` | 400 | Your request exceeds the model's maximum context. Please reduce your prompt or completion length. | Encurte as mensagens ou reduza `max_tokens`. `GET /models` lista o tamanho de contexto de cada modelo. |
| `CHARACTER_NOT_FOUND` | 404 | No character could be found from the provided `character_slug` | Use um slug de [`GET /characters`](/pt-BR/api-reference/endpoint/characters/list). |
| `MODEL_NOT_FOUND` | 404 | Specified model not found | Use um ID atual de `GET /models`. Os modelos desativados estão listados em [Descontinuações](/pt-BR/overview/deprecations). |
| `MEDIA_NOT_FOUND` | 404 | Media could not be found. Request may be invalid, expired, or deleted. | O resultado expirou ou foi excluído. Enfileire o job novamente. |
| `PAYLOAD_TOO_LARGE` | 413 | The request payload is too large. Please reduce the size of your request. | Envie um corpo ou arquivo menor. |
| `INVALID_CONTENT_TYPE` | 415 | Invalid request content-type. Returned only by `/image/multi-edit` | Envie `multipart/form-data` ou `application/json`. |
| `VIDEO_DURATION_TOO_LONG` | 422 | Video duration exceeds the maximum allowed. | Use uma duração que o modelo liste em `GET /models?type=video`. |
| `VIDEO_DURATION_TOO_SHORT` | 422 | Video duration is too short. | Use uma duração que o modelo liste em `GET /models?type=video`. |
| `IMAGE_TOO_LARGE` | 422 | Image dimensions exceed the maximum allowed. | Reduza o tamanho da imagem. |
| `CONTENT_POLICY_VIOLATION` | 422 | Your prompt violates the content policy of Venice.ai or the model provider | Altere o prompt ou use outro modelo. As políticas variam por modelo e provedor. |
| `ASR_UPSTREAM_VALIDATION_FAILED` | 422 | The audio could not be processed for transcription. Common causes: zero-length, silent, corrupt, or unsupported-language audio. Please verify the file and retry. | Verifique se o áudio não está vazio, silencioso ou corrompido, e se o idioma dele é compatível. |
| `RATE_LIMIT_EXCEEDED` | 429 | Rate limit exceeded | Aguarde até `x-ratelimit-reset-requests` e tente novamente. Veja [Limites de taxa](/pt-BR/api-reference/rate-limiting). |
| `MODEL_OVERLOADED` | 429 | The model is currently overloaded. Please try again later. | Tente novamente após o cabeçalho `Retry-After` ou troque de modelo. |
| `INFERENCE_FAILED` | 500 | Inference processing failed | Tente novamente com backoff. Requisições com falha contam para o [orçamento de erros](/pt-BR/api-reference/rate-limiting#orçamentos-de-erro). |
| `UPSCALE_FAILED` | 500 | Image upscaling failed | Tente novamente com backoff. |
| `IMAGE_EDIT_ERROR` | 500 | Image edit failed | Tente novamente com backoff. |
| `UNKNOWN_ERROR` | 500 | An unknown error occurred | Tente novamente com backoff. Se continuar acontecendo, fale com support@venice.ai. |
| `TEE_ATTESTATION_FAILED` | 502 | TEE attestation request failed. The Trusted Execution Environment provider may be temporarily unavailable. | Tente novamente mais tarde. |
| `TEE_SIGNATURE_FAILED` | 502 | TEE signature request failed. The Trusted Execution Environment provider may be temporarily unavailable. | Tente novamente mais tarde. |
| `ASR_UPSTREAM_FAILED` | 502 | Audio transcription failed due to a temporary upstream error. Please retry. | Repita a requisição. |
| `MODEL_OFFLINE` | 503 | The model is temporarily offline. Please try again later. | Tente novamente mais tarde ou troque de modelo. |
| `MODEL_AT_CAPACITY` | 503 | The model is at capacity. Please try again later. | Tente novamente mais tarde ou troque de modelo. |
| `REQUEST_TIMEOUT` | 504 | The request took too long to complete and was timed-out. For non-streaming requests, use the streaming API by setting `stream=true`. A streaming chat completion that times out before the model's first chunk reports the failure as an in-band SSE error frame instead. | Defina `stream: true` ou envie uma requisição mais curta. |

## Outros erros

A tabela acima não é exaustiva. Alguns erros são retornados sem um código listado, e as mensagens podem variar conforme o modelo e o endpoint, então baseie sua lógica no status HTTP e não no texto da mensagem. Erros que você pode encontrar e que não estão na tabela:

| Status HTTP | Quando ocorre |
| --- | --- |
| 400 | Uma imagem de entrada em uma requisição de chat ou Responses está em um formato não suportado |
| 400 | A voz solicitada não está disponível para o modelo de text-to-speech |
| 403 | A requisição vem de um endereço IP que não está na allowlist da chave de API |
| 403 | O modelo solicitado não é permitido pela configuração de privacidade da chave de API |
| 403 | O acesso ao modelo solicitado é restrito. Entre em contato com support@venice.ai |
| 409 | Um resultado de vídeo, música ou voice changer ainda está sendo enviado quando você tenta recuperá-lo. Tente novamente em instantes |
| 410 | O endpoint foi descontinuado |
| 422 | O áudio é longo ou curto demais (clonagem de voz, voice changer e jobs de áudio) |
| 422 | A imagem de entrada de uma requisição de vídeo tem uma proporção entre largura e altura fora do intervalo aceito pelo modelo |
| 422 | A entrada de uma requisição de vídeo foi bloqueada pela moderação de conteúdo |
| 500 | A geração de vídeo ou de voice changer falhou |
| 502 | A síntese de fala falhou no provedor upstream, ou um vídeo gerado não pôde ser recuperado. Tente a requisição novamente |
