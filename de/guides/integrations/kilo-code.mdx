[Kilo Code](https://kilo.ai/) ist ein quelloffener KI-Coding-Agent für VS Code und das Terminal. Venice ist als **nativer Provider** verfügbar, sodass Sie Venice-Modelle auswählen können, ohne einen OpenAI-kompatiblen Custom-Endpoint zu konfigurieren.

## Voraussetzungen

- Ein Venice API-Schlüssel von [venice.ai/settings/api](https://venice.ai/settings/api)
- [Kilo Code für VS Code](https://marketplace.visualstudio.com/items?itemName=kilocode.Kilo-Code) und/oder die [Kilo CLI](https://kilo.ai/docs/code-with-ai/platforms/cli)

## Einrichtung

<Tabs>
  <Tab title="VS Code">
    <Steps>
      <Step title="Kilo Code installieren">
        Öffnen Sie in VS Code **Extensions**, suchen Sie nach **Kilo Code** und installieren Sie es aus dem [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=kilocode.Kilo-Code).

        Bevorzugen Sie den **Pre-Release**-Kanal des Marketplace, wenn dies der aktuell empfohlene Build ist — siehe [Kilos Installationsdokumentation](https://kilo.ai/docs/getting-started/installing).
      </Step>

      <Step title="Venice API-Schlüssel abrufen">
        Erzeugen Sie einen Schlüssel unter [venice.ai/settings/api](https://venice.ai/settings/api). Kopieren Sie ihn sofort und bewahren Sie ihn sicher auf.
      </Step>

      <Step title="Venice-Provider hinzufügen">
        Öffnen Sie die Kilo-**Einstellungen** (Zahnrad-Symbol) und wechseln Sie zum Tab **Providers**. Wählen Sie **Venice AI** und fügen Sie Ihren Venice API-Schlüssel ein.

        Die Erweiterung speichert den Provider in Ihrer `kilo.json`-Konfiguration. Sie können diese Datei auch direkt bearbeiten — das Format finden Sie im Tab **CLI**.
      </Step>

      <Step title="Modell auswählen und testen">
        Wählen Sie ein Venice-Modell aus dem Modell-Picker und senden Sie eine kleine Aufgabe wie:

        ```txt
        Review the current file and suggest one safe improvement.
        ```

        Durchsuchen Sie verfügbare IDs im [Textmodell-Katalog](/models/text).
      </Step>
    </Steps>
  </Tab>

  <Tab title="CLI">
    <Steps>
      <Step title="Kilo CLI installieren">
        ```bash
        npm install -g @kilocode/cli
        kilo --version
        ```

        Weitere Installationsoptionen finden Sie in der [Kilo CLI-Dokumentation](https://kilo.ai/docs/code-with-ai/platforms/cli).
      </Step>

      <Step title="Venice API-Schlüssel setzen">
        Exportieren Sie den Schlüssel in der Shell, in der Sie Kilo ausführen:

        ```bash
        export VENICE_API_KEY="your-api-key"
        ```
      </Step>

      <Step title="Venice-Provider konfigurieren">
        Erstellen oder bearbeiten Sie `~/.config/kilo/kilo.json` (global) oder `./kilo.json` (projektbezogen):

        ```json
        {
          "provider": {
            "venice": {
              "env": ["VENICE_API_KEY"]
            }
          },
          "model": "venice/zai-org-glm-5-1"
        }
        ```

        Ersetzen Sie `zai-org-glm-5-1` durch eine beliebige Modell-ID aus dem [Textmodell-Katalog](/models/text). Kilo-Modellreferenzen verwenden das Format `venice/<model-id>`.
      </Step>

      <Step title="Kilo starten">
        Aus Ihrem Projektverzeichnis:

        ```bash
        kilo
        ```

        Wählen Sie ein Venice-Modell aus dem Modell-Picker, falls Sie kein Standard-`model` gesetzt haben, und senden Sie dann einen kurzen Test-Prompt.
      </Step>
    </Steps>
  </Tab>
</Tabs>

## Venice-API verifizieren

Falls sich Kilo nicht verbinden kann, bestätigen Sie den Schlüssel und die Modell-IDs unabhängig:

```bash
curl https://api.venice.ai/api/v1/models \
  -H "Authorization: Bearer $VENICE_API_KEY"
```

Kopieren Sie die `id` eines Modells exakt in Kilo. In der CLI-Konfiguration versehen Sie sie mit dem Präfix `venice/`, zum Beispiel `venice/zai-org-glm-5-1`.

---

## Konfigurationshinweise

- Venice ist ein **nativer** Kilo-Provider. Bevorzugen Sie in den Providers-Einstellungen **Venice AI** gegenüber einem generischen OpenAI-kompatiblen Custom-Endpoint.
- Die Erweiterung und die CLI teilen sich dieselben Konfigurationsdateien (`~/.config/kilo/kilo.json` global oder `./kilo.json` in einem Projekt).
- Einige Venice-Modelle stellen Reasoning-Steuerungen bereit. Kilo mappt unterstützte Reasoning-Effort- und Disable-Thinking-Optionen, wenn das gewählte Modell sie unterstützt.
- Modell-IDs und der Plan-Zugriff können sich ändern. Nutzen Sie den Modell-Picker, den [Textmodell-Katalog](/models/text) oder `GET /models`, um die aktuelle Liste zu erhalten.
- Halten Sie Ihren Venice API-Schlüssel geheim. Fügen Sie ihn nicht in Quelldateien ein und committen Sie ihn nicht in git.

## Fehlerbehebung

<AccordionGroup>
  <Accordion title="Ungültiger API-Schlüssel oder 401">
    Stellen Sie sicher, dass der Schlüssel von [venice.ai/settings/api](https://venice.ai/settings/api) stammt. Verifizieren Sie für die CLI, dass `VENICE_API_KEY` in derselben Umgebung gesetzt ist, in der Kilo gestartet wird. Verbinden Sie in VS Code Venice AI unter **Providers** neu.
  </Accordion>
  <Accordion title="Modell nicht verfügbar">
    Stellen Sie sicher, dass Ihr Venice-Konto Zugriff auf das gewählte Modell hat, kopieren Sie die ID aus dem [Textmodell-Katalog](/models/text) oder `GET /models`, und verwenden Sie für die CLI-Konfiguration die Form `venice/<model-id>`.
  </Accordion>
  <Accordion title="Provider-Einstellungen in der Erweiterung nicht gefunden">
    Aktualisieren Sie auf den aktuell empfohlenen Kilo-Build (einschließlich Pre-Release, wenn dies der dokumentierte Standard ist). Sie können den Provider auch in `kilo.json` setzen, wie im CLI-Tab gezeigt — die Erweiterung liest dieselbe Konfiguration.
  </Accordion>
</AccordionGroup>
