Venice AI ist ein **Drop-in-Ersatz** für OpenAI. Gleiches SDK, gleicher Code – ändern Sie einfach zwei Zeilen. Sie erhalten datenschutzorientierte Inferenz, unzensierte Modelle und wettbewerbsfähige Preise.

## Die 2-Zeilen-Migration

<CodeGroup>
```python Python
# Vorher (OpenAI)
from openai import OpenAI
client = OpenAI()

# Nachher (Venice) – ändern Sie api_key und base_url
from openai import OpenAI
client = OpenAI(
    api_key="your-venice-api-key",           # ← Änderung 1
    base_url="https://api.venice.ai/api/v1",  # ← Änderung 2
)
```

```javascript Node.js
// Vorher (OpenAI)
import OpenAI from "openai";
const client = new OpenAI();

// Nachher (Venice)
import OpenAI from "openai";
const client = new OpenAI({
  apiKey: "your-venice-api-key",
  baseURL: "https://api.venice.ai/api/v1",
});
```

```bash cURL
# Vorher
curl https://api.openai.com/v1/chat/completions ...

# Nachher – ändern Sie einfach die URL und den Schlüssel
curl https://api.venice.ai/api/v1/chat/completions ...
```
</CodeGroup>

Generieren Sie einen Schlüssel unter [venice.ai/settings/api](https://venice.ai/settings/api) oder folgen Sie der [Anleitung zum API-Schlüssel](/guides/getting-started/generating-api-key).

### Umgebungsvariablen

```bash
# Vorher
OPENAI_API_KEY=sk-...
OPENAI_BASE_URL=https://api.openai.com/v1

# Nachher
OPENAI_API_KEY=your-venice-api-key
OPENAI_BASE_URL=https://api.venice.ai/api/v1
```

<Tip>
Viele Bibliotheken und Tools lesen `OPENAI_API_KEY` und `OPENAI_BASE_URL` automatisch. Es reicht möglicherweise schon, diese Umgebungsvariablen zu aktualisieren. Einige Tools verwenden für dieselbe URL weiterhin `OPENAI_API_BASE`.
</Tip>

## Modelle

Übergeben Sie eine Venice-Modell-ID, ein Merkmal wie `default` oder `most_uncensored` oder einen vertrauten OpenAI-Namen. Venice ordnet OpenAI-Namen über das [Compatibility Mapping](/api-reference/endpoint/models/compatibility_mapping) zu. Merkmale (Traits) werden immer auf das aktuelle Modell für diese Rolle aufgelöst – siehe [Modellmerkmale](/api-reference/endpoint/models/traits).

Durchsuchen Sie den aktuellen Katalog unter [Textmodelle](/models/text) und [Preise](/overview/pricing). Eine Schritt-für-Schritt-Anleitung für die erste Anfrage finden Sie im [Schnellstart](/getting-started/quick-start).

## Funktionskompatibilität

| Funktion | OpenAI | Venice | Hinweise |
|---------|--------|--------|-------|
| Chat Completions | ✅ | ✅ | Voll kompatibel |
| Streaming | ✅ | ✅ | Gleiches SSE-Format |
| Function Calling | ✅ | ✅ | Gleicher `tools`-Parameter |
| Structured Output | ✅ | ✅ | Gleiches `response_format` |
| Vision | ✅ | ✅ | Gleiches Content-Array-Format |
| Embeddings | ✅ | ✅ | Gleiche API |
| Bildgenerierung | ✅ | ✅ | OpenAI-kompatibel über `/images/generations` |
| TTS | ✅ | ✅ | Kompatibel |
| STT | ✅ | ✅ | Kompatibel |
| Responses API | ✅ | ✅ | Alpha |
| Assistants API | ✅ | ❌ | Verwenden Sie [Characters](/guides/features/characters) oder [Function Calling](/guides/features/function-calling) |
| Batch API | ✅ | ❌ | Noch nicht verfügbar |
| Fine-tuning | ✅ | ❌ | Nicht verfügbar |

Für native Bildoptionen jenseits des OpenAI-kompatiblen Endpoints siehe [Bildgenerierung](/guides/media/image-generation).

## Venice-exklusive Funktionen

Übergeben Sie Venice-spezifische Optionen über `extra_body` als `venice_parameters`. Die integrierte Websuche ist üblicherweise der erste zusätzliche Parameter:

```python
response = client.chat.completions.create(
    model="default",
    messages=[{"role": "user", "content": "Latest AI news today"}],
    extra_body={
        "venice_parameters": {
            "enable_web_search": "auto"
        }
    },
)
```

Das gleiche Muster deckt Web Scraping, Quellenangaben und [Characters](/guides/features/characters) ab. Wenn ein Client den Request-Body nicht ändern kann, hängen Sie ein [Model-Feature-Suffix](/api-reference/endpoint/chat/model_feature_suffix) wie `default:enable_web_search=auto` an.

Venice bietet neben der OpenAI-kompatiblen Oberfläche außerdem native APIs für [Video](/guides/media/video-generation), [Musik](/guides/media/music-and-sound-effects), [Web-Retrieval](/guides/tools/web-retrieval) und [x402](/guides/integrations/x402-venice-api).

## Unzensierte Modelle

Venices private unzensierte Modelle verfügen über keine Inhaltsfilterung und eignen sich daher für:

- Kreatives Schreiben ohne Guardrails
- Sicherheitsforschung und Red Teaming
- Ehrliche Analysen ohne Refusal-Muster
- Medizinische und juristische Informationen ohne zusätzliche Disclaimer

Verwenden Sie das Merkmal `most_uncensored` oder eine aktuelle Modell-ID eines unzensierten Modells aus [Textmodelle](/models/text).
