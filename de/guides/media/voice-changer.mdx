Voice Changer ist Speech-to-Speech: Er nimmt eine Quelldatei in einer anderen Stimme neu auf und bewahrt dabei Vortrag, Tempo und Timing. Er läuft asynchron und verwendet eigene Endpoints – nicht [`/audio/queue`](/de/api-reference/endpoint/audio/queue) und auch nicht [Text-to-Speech](/de/guides/media/text-to-speech) oder [Voice Cloning](/de/guides/media/voice-cloning).

<Note>
Eine in die Warteschlange gestellte Konvertierung wird sofort berechnet. Speichere die `queue_id` aus der Queue-Antwort, bevor du irgendetwas anderes tust.
</Note>

## So funktioniert es

1. **Quote** – Kalkuliere den Preis für die Länge, die du voraussichtlich sendest
2. **Queue** – Lade die Aufnahme hoch oder übergib eine öffentliche URL
3. **Poll** – Lade die MP3 herunter, sobald Retrieve Audio zurückgibt
4. **Complete** – Lösche die gespeicherten Medien, nachdem die Datei gesichert ist

| Endpoint | Zweck |
|----------|---------|
| [`POST /audio/voice-changer/quote`](/de/api-reference/endpoint/audio/voice-changer/quote) | Konvertierungskosten in USD schätzen |
| [`POST /audio/voice-changer/queue`](/de/api-reference/endpoint/audio/voice-changer/queue) | Speech-to-Speech-Konvertierung starten |
| [`POST /audio/voice-changer/retrieve`](/de/api-reference/endpoint/audio/voice-changer/retrieve) | Job abfragen und konvertiertes Audio herunterladen |
| [`POST /audio/voice-changer/complete`](/de/api-reference/endpoint/audio/voice-changer/complete) | Gespeicherte Medien nach dem Download löschen |

## Voraussetzungen

- Ein Venice-API-Key für Queue, Retrieve und Complete. Quote verwendet den Key nicht.
- Eine Quellaufnahme in einem Container, der in den `accepted_audio_formats` des Modells aufgeführt ist. Venice prüft die binäre Signatur der Datei, der Dateiname entscheidet also nicht über die Annahme.
- Eine Aufnahme, die nicht länger als `max_source_audio_duration_seconds` des Modells und nicht größer als 25 MB ist.
- Für `audio_url` eine öffentlich erreichbare `http`- oder `https`-URL. Venice ruft die Bytes selbst ab und leitet nur diese Bytes an den Provider weiter.

Setze deinen API-Key:

```bash
export VENICE_API_KEY="your-api-key"
```

## Modell auswählen

Voice-Changer-Modelle werden von `GET /models?type=music` mit `model_spec.voice_changer` gleich `true` zurückgegeben. Es gibt keinen Filter `?type=voice-changer`. Durchsuche [Musik- und Soundeffekt-Modelle](/de/models/music) für die aktuelle Liste. In den folgenden Beispielen wird `elevenlabs-voice-changer` verwendet, und `Aria` ist einer der Stimmennamen dieses Modells. Übergib einen Namen aus `voices` oder lasse `voice` weg, um `default_voice` zu verwenden.

```bash
curl "https://api.venice.ai/api/v1/models?type=music" \
  -H "Authorization: Bearer $VENICE_API_KEY" |
  jq '.data[] | select(.model_spec.voice_changer == true) | {
    id,
    voices: .model_spec.voices,
    default_voice: .model_spec.default_voice,
    supports_custom_voice_id: .model_spec.supports_custom_voice_id,
    accepted_audio_formats: .model_spec.accepted_audio_formats,
    max_source_audio_duration_seconds: .model_spec.max_source_audio_duration_seconds,
    supports_background_noise_removal: .model_spec.supports_background_noise_removal,
    supports_seed: .model_spec.supports_seed,
    durations: .model_spec.pricing.durations
  }'
```

Prüfe die Metadaten jedes Modells, bevor du optionale Felder setzt:

| Feld | Verwendung |
|-------|------------|
| `voices` / `default_voice` | Namen der Zielstimmen. Lasse `voice` weg, um die Standardstimme zu verwenden. |
| `supports_custom_voice_id` | Ob `voice` auch eine Provider-Voice-ID akzeptiert |
| `accepted_audio_formats` | Quellcontainer, die Venice akzeptiert |
| `max_source_audio_duration_seconds` | Längste Quellaufnahme, die das Modell akzeptiert |
| `supports_background_noise_removal` | Ob `remove_background_noise` akzeptiert wird |
| `supports_seed` | Ob `seed` akzeptiert wird |
| `pricing.durations` | Preisstufen nach vollen Minuten, jeweils mit `min_seconds`, `max_seconds` und `usd` |

Nicht unterstützte Felder führen zu einer HTTP-`400`-Antwort. Aufnahmen, die länger als `max_source_audio_duration_seconds` sind, werden vor jeder Berechnung mit HTTP `422` abgelehnt. Der Fehler-Body nennt dieses Maximum in der Form `Source audio must be at most N seconds.`

## 1. Kostenvoranschlag einholen

Voice Changer wird nach der Länge der Quellaufnahme abgerechnet, aufgerundet auf die nächste volle Minute. Ein exaktes Vielfaches von 60 Sekunden bleibt in der Stufe dieser Minute. Eine Sekunde darüber fällt in die nächste Stufe. Für `elevenlabs-voice-changer` liefert Quote 0,35 $ für 60 Sekunden und 0,69 $ für 61 Sekunden. Lies `pricing.durations` aus oder rufe Quote für das Modell auf, das du verwendest. Der berechnete Betrag ergibt sich aus der Länge, die Venice beim Einreihen der Aufnahme in die Warteschlange misst.

<Note>
Quote erfordert keine Authentifizierung. Anfragen an Queue, Retrieve und Complete hingegen schon.
</Note>

```bash
curl https://api.venice.ai/api/v1/audio/voice-changer/quote \
  -H "Content-Type: application/json" \
  -d '{
    "model": "elevenlabs-voice-changer",
    "duration_seconds": 60
  }'
```

Die Antwort enthält die geschätzten Kosten in USD und die Dauer, für die der Kostenvoranschlag berechnet wurde:

```json
{
  "quote": 0.35,
  "duration_seconds": 60
}
```

## 2. Konvertierung in die Warteschlange stellen

Übergib die Quellaufnahme auf genau eine von zwei Arten: als Multipart-`file`-Upload oder als `audio_url` in einem JSON-Body. Beides oder keines von beiden anzugeben, wird abgelehnt.

Eine Datei mit einer Videospur wird abgelehnt. Extrahiere das Audio und lade dieses hoch. Wenn du eine URL übergibst, muss sie öffentlich erreichbar sein. Venice ruft die Bytes selbst ab und validiert sie, und die URL wird niemals an den Provider weitergegeben.

Wenn du `curl -F` verwendest, setze `Content-Type` nicht manuell. `curl` fügt den `multipart/form-data`-Header und die erforderliche Boundary hinzu. Sende in einem Multipart-Body `remove_background_noise` als `true` oder `false` und `seed` als Ziffern.

<CodeGroup>
```bash File upload
curl https://api.venice.ai/api/v1/audio/voice-changer/queue \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -F "model=elevenlabs-voice-changer" \
  -F "voice=Aria" \
  -F "file=@./source-recording.mp3"
```

```bash Audio URL
curl https://api.venice.ai/api/v1/audio/voice-changer/queue \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "elevenlabs-voice-changer",
    "voice": "Aria",
    "audio_url": "https://example.com/source-recording.mp3",
    "remove_background_noise": true,
    "seed": 42
  }'
```
</CodeGroup>

`remove_background_noise` und `seed` werden nur akzeptiert, wenn das Modell Unterstützung dafür angibt. Lasse `voice` weg, um `default_voice` zu verwenden. Wenn `supports_custom_voice_id` true ist, kann `voice` statt eines Namens aus `voices` auch eine Provider-Voice-ID sein.

Eine erfolgreiche Anfrage liefert das Modell, eine Queue-ID und die gemessene Länge der Quelle zurück:

```json
{
  "model": "elevenlabs-voice-changer",
  "queue_id": "0190f2c4-9c1e-7a3b-8f42-2c9d5e7a1b34",
  "status": "QUEUED",
  "duration_seconds": 52
}
```

Speichere `model` und `queue_id`. Retrieve und Complete benötigen beide Werte. Vergleiche `duration_seconds` mit deinem Kostenvoranschlag, um die Schätzung mit der abgerechneten Länge abzugleichen.

<Warning>
Queue-Anfragen können nicht sicher wiederholt werden. Eine erfolgreiche Queue-Anfrage wurde bereits berechnet. Wenn du die `queue_id` hast, frage damit Retrieve ab. Wenn die Queue-Antwort nie angekommen ist, hast du keine ID zum Abfragen, und ein erneutes Senden der Aufnahme kann dir ein zweites Mal berechnet werden.
</Warning>

## 3. Status abfragen und herunterladen

Rufe `/audio/voice-changer/retrieve` mit den Werten aus der Queue-Antwort auf. Eine `queue_id` kann 24 Stunden lang abgerufen werden. Eine unbekannte ID, die ID eines anderen Kontos, eine fehlerhaft formatierte ID und eine abgelaufene ID liefern alle HTTP `400` mit `Request ID is invalid.`

```bash
curl https://api.venice.ai/api/v1/audio/voice-changer/retrieve \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "elevenlabs-voice-changer",
    "queue_id": "0190f2c4-9c1e-7a3b-8f42-2c9d5e7a1b34"
  }' \
  --output response.bin
```

Prüfe den `Content-Type` der Antwort:

| Content-Type | Bedeutung | Aktion |
|--------------|---------|--------|
| `application/json` | Konvertierung läuft noch | Zeitangaben lesen, warten und erneut abfragen |
| `audio/mpeg` | Konvertierung abgeschlossen | Binären Body als `.mp3` speichern |

Eine Antwort während der Verarbeitung sieht so aus:

```json
{
  "status": "PROCESSING",
  "average_execution_time": 10000,
  "execution_duration": 4200
}
```

Beide Zeitangaben sind in Millisekunden. Warte die Differenz zwischen `execution_duration` und `average_execution_time` ab, bevor du erneut abfragst. Eine abgeschlossene Antwort enthält außerdem `x-venice-audio-format`, `x-venice-audio-duration` (Sekunden), `x-venice-inference-time` (Sekunden), `x-venice-model-id` und `x-venice-model-name`.

Ein Provider-Fehler und eine Konvertierung, die den Provider nie erreicht (HTTP `504`), liefern `credits_refunded` im Fehler-Body. Die [Retrieve-Voice-Changer-API](/de/api-reference/endpoint/audio/voice-changer/retrieve) beschreibt, wann dieses Flag false ist und was dir der `error`-String nahelegt. Erneutes Abfragen liefert dasselbe Ergebnis erneut.

Setze `delete_media_on_completion` bei Retrieve auf `true`, um gespeicherte Medien im selben Aufruf zu löschen, der das Audio zurückgibt. Das Audio kann danach nicht mehr abgerufen werden. Andernfalls rufe [`POST /audio/voice-changer/complete`](/de/api-reference/endpoint/audio/voice-changer/complete) auf, nachdem die Datei gespeichert ist. Complete kann gefahrlos mehrfach aufgerufen werden.

## Vollständiges Beispiel

Dieses Beispiel kalkuliert stellvertretend eine Minute, lädt eine Datei hoch, fragt den Status ab, bis das Audio eintrifft oder fünf Minuten vergangen sind, und speichert eine MP3. Die Frist von fünf Minuten gilt nur für das Beispiel. Ein Job kann mit der gespeicherten `queue_id` 24 Stunden lang abgefragt werden.

```python
import os
import time
from pathlib import Path

import requests

BASE_URL = "https://api.venice.ai/api/v1"
HEADERS = {"Authorization": f"Bearer {os.environ['VENICE_API_KEY']}"}
MODEL = "elevenlabs-voice-changer"
# Length you expect to send. The charge uses the length Venice measures.
EXPECTED_DURATION_SECONDS = 60

source = Path("source-recording.mp3")

quote = requests.post(
    f"{BASE_URL}/audio/voice-changer/quote",
    json={"model": MODEL, "duration_seconds": EXPECTED_DURATION_SECONDS},
)
quote.raise_for_status()
print(f"Estimated cost: ${quote.json()['quote']:.2f}")

with source.open("rb") as audio:
    queued = requests.post(
        f"{BASE_URL}/audio/voice-changer/queue",
        headers=HEADERS,
        data={"model": MODEL, "voice": "Aria"},
        files={"file": audio},
    )
queued.raise_for_status()
job = queued.json()
print(f"Queued {job['queue_id']} ({job['duration_seconds']}s billed)")

deadline = time.monotonic() + 5 * 60
while time.monotonic() < deadline:
    result = requests.post(
        f"{BASE_URL}/audio/voice-changer/retrieve",
        headers=HEADERS,
        json={"model": job["model"], "queue_id": job["queue_id"]},
    )
    if not result.ok:
        body = result.json()
        print(body.get("error"))
        if "credits_refunded" in body:
            print(f"credits_refunded: {body['credits_refunded']}")
        raise SystemExit(1)

    content_type = result.headers.get("Content-Type", "").split(";")[0].strip()
    if content_type == "audio/mpeg":
        output = Path("converted-audio.mp3")
        output.write_bytes(result.content)
        print(f"Saved {output}")
        break

    status = result.json()
    if status.get("status") != "PROCESSING":
        print(status)
        raise SystemExit(1)

    remaining_ms = status["average_execution_time"] - status["execution_duration"]
    time.sleep(min(max(remaining_ms / 1000, 1), 15))
else:
    raise SystemExit("Still processing. Poll retrieve again with the saved queue_id.")

requests.post(
    f"{BASE_URL}/audio/voice-changer/complete",
    headers=HEADERS,
    json={"model": job["model"], "queue_id": job["queue_id"]},
).raise_for_status()
```


## API-Parameter

### Queue

| Feld | Typ | Erforderlich | Beschreibung |
|---|---|---|---|
| `model` | string | Ja | ID des Voice-Changer-Modells. |
| `file` | file | Eines von `file` oder `audio_url` | Multipart-Upload der Quellaufnahme. Schließt `audio_url` aus. |
| `audio_url` | string | Eines von `file` oder `audio_url` | Öffentliche `http`- oder `https`-URL der Quellaufnahme in einem JSON-Body. Schließt `file` aus. |
| `voice` | string | Nein | Ein Name aus `voices` oder eine Provider-Voice-ID, wenn `supports_custom_voice_id` true ist. Standardwert ist `default_voice`. |
| `remove_background_noise` | boolean | Nein | Hintergrundgeräusche vor der Konvertierung entfernen. Nur senden, wenn das Modell Unterstützung angibt. Multipart akzeptiert `true` oder `false`. |
| `seed` | integer | Nein | Ganzzahl ≥ 0 für ein reproduzierbares Ergebnis. Nur senden, wenn das Modell Unterstützung angibt. |

### Retrieve und Complete

| Feld | Typ | Erforderlich | Standard | Beschreibung |
|---|---|---|---|---|
| `model` | string | Ja | - | `model` aus der Queue-Antwort. |
| `queue_id` | string | Ja | - | `queue_id` aus der Queue-Antwort. |
| `delete_media_on_completion` | boolean | Nein | `false` | Bei Retrieve gespeicherte Medien löschen, wenn dieser Aufruf das Audio zurückgibt. |

## Häufige Fehler

Endgültige Retrieve-Ergebnisse, einschließlich `credits_refunded`, sind in der [Retrieve-Voice-Changer-API](/de/api-reference/endpoint/audio/voice-changer/retrieve) dokumentiert.

| Status | Ursache | Lösung |
|---|---|---|
| `400` | Nicht unterstütztes Feld, unbekannte Stimme, nicht akzeptierter Container, unlesbares Audio, eine Videospur oder eine unbekannte, fremde oder abgelaufene `queue_id` | Prüfe die Modellmetadaten, sende genau eine Quelle und frage mit der `queue_id` ab, die für dein Konto zurückgegeben wurde. |
| `401` | Ungültiger API-Key oder ein Modell, das auf Pro-Nutzer beschränkt ist | Prüfe den Key unter [venice.ai/settings/api](https://venice.ai/settings/api). |
| `402` mit `"error": "Authentication required"` | Kein API-Key gesendet | Sende `Authorization: Bearer $VENICE_API_KEY`. |
| `402` | Unzureichendes Guthaben | Lade dein Venice-Guthaben auf. |
| `413` | Datei größer als 25 MB | Verwende eine kleinere Datei. Wird vor jeder Berechnung abgelehnt. |
| `422` | Länger als `max_source_audio_duration_seconds` | Kürze die Aufnahme. Der Body nennt das Maximum. Wird vor jeder Berechnung abgelehnt. |
| `429` | Rate-Limit überschritten | Versuche es erneut, nachdem das Rate-Limit-Fenster zurückgesetzt wurde. |
| `503` | Modell ausgelastet | Versuche es später erneut. |

## Tipps für die Produktion

- Notiere dir die `queue_id`, bevor du den Rest der Queue-Antwort parst.
- Vergleiche die gemessene `duration_seconds` mit dem Kostenvoranschlag, bevor du die Schätzung als tatsächliche Berechnung betrachtest.
- Lade die Datei hoch oder übergib eine öffentliche URL, die keine Request-Header benötigt.
- Rufe Complete auf, nachdem die MP3 auf dem Datenträger liegt. `delete_media_on_completion: true` bei Retrieve erledigt diese Bereinigung bereits im Download-Aufruf.
