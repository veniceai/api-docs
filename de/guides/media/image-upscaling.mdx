Bild-Upscaling verbessert die Auflösung und visuelle Qualität eines vorhandenen Bildes. Sende ein Bild an `/image/upscale`, wähle einen Skalierungsfaktor und optional eine Kreativitätsstufe, und Venice gibt das verbesserte Bild als Binärdaten zurück.

Verwende Bild-Upscaling, wenn du bereits ein Bild hast und eine höher aufgelöste Ausgabe wünschst. Verwende die [Bilderzeugung](/de/guides/media/image-generation), wenn du ein Bild aus einem Prompt erstellen möchtest, und die [Bildbearbeitung](/de/guides/media/image-editing), wenn du den Bildinhalt ändern möchtest.

## Grundlegende Nutzung

<CodeGroup>
```python Python
import base64
import os
from pathlib import Path

import requests

image_base64 = base64.b64encode(Path("input.jpg").read_bytes()).decode("utf-8")

response = requests.post(
    "https://api.venice.ai/api/v1/image/upscale",
    headers={
        "Authorization": f"Bearer {os.environ['VENICE_API_KEY']}",
        "Content-Type": "application/json",
    },
    json={
        "image": image_base64,
        "scale": 2,
        "creativity": 0.01,
    },
)

response.raise_for_status()
Path("upscaled.png").write_bytes(response.content)
```

```javascript Node.js
import { readFile, writeFile } from "node:fs/promises";

const image = await readFile("input.jpg");

const response = await fetch("https://api.venice.ai/api/v1/image/upscale", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.VENICE_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    image: image.toString("base64"),
    scale: 2,
    creativity: 0.01,
  }),
});

if (!response.ok) {
  throw new Error(await response.text());
}

const output = Buffer.from(await response.arrayBuffer());
await writeFile("upscaled.png", output);
```

```bash cURL
IMAGE_BASE64=$(base64 < input.jpg | tr -d '\n')

curl https://api.venice.ai/api/v1/image/upscale \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d "{
    \"image\": \"$IMAGE_BASE64\",
    \"scale\": 2,
    \"creativity\": 0.01
  }" \
  --output upscaled.png
```
</CodeGroup>

Du kannst eine Datei auch direkt per `multipart/form-data` hochladen, statt sie Base64-kodiert zu senden:

```bash cURL (multipart)
curl https://api.venice.ai/api/v1/image/upscale \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -F "image=@input.jpg" \
  -F "scale=2" \
  -F "creativity=0.01" \
  --output upscaled.png
```

Sende genau einen `image`-Teil pro Anfrage. Hochgeladene Dateien müssen kleiner als 25 MB sein.

## Parameter

| Parameter | Typ | Erforderlich | Beschreibung |
|-----------|------|----------|-------------|
| `image` | string oder Datei | Ja | Quellbild. Sende es Base64-kodiert im JSON oder lade einen Dateiteil per `multipart/form-data` hoch. Muss mindestens 256×256 Pixel groß sein. Datei-Uploads dürfen höchstens 25 MB groß sein; JSON-Bodys sind auf 35 MB begrenzt. |
| `scale` | number | Nein | Skalierungsfaktor zwischen `2` und `4`. Standardwert ist `2`; verwende `2` oder `4` (Zwischenwerte werden akzeptiert und zum 4x-Tarif abgerechnet). Die Ausgabe ist auf 16.777.216 Pixel (4096×4096) begrenzt: Würde die angeforderte Skalierung das Limit überschreiten, reduziert der Server die effektive Skalierung automatisch. Eingaben, die das Limit bereits erreichen oder fast erreichen, werden mit `400` abgelehnt. Verkleinere sie daher vorher. |
| `creativity` | number | Nein | Wie viel Detail und Textur der Upscaler hinzufügt. `0`–`0.02`, Standardwert `0.01`. Höhere Werte fügen mehr hinzu; niedrigere Werte bleiben näher am Original. Werte außerhalb des Bereichs werden auf die nächste Grenze begrenzt. |

<Note>
Die Antwort besteht aus binären Bilddaten, nicht aus JSON. Schreibe den Antwortkörper direkt in eine Datei oder streame ihn in den Speicher.
</Note>

## Tipps zur Eingabe

- Beginne mit dem saubersten Quellbild, das du hast. Upscaling verbessert Details, kann aber nicht vollständig Informationen wiederherstellen, die nicht vorhanden sind.
- Verwende in Produktions-Workflows moderate Skalierungsfaktoren. Sehr große Ausgaben können Latenz und Dateigröße erhöhen.
- Behalte das Originalbild, falls du die Qualität vergleichen oder mit anderen Einstellungen erneut versuchen möchtest.
