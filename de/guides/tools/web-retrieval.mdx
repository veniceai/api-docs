Venice stellt separate APIs zum Auffinden von Webseiten und zum Extrahieren ihrer Inhalte bereit:

- **Web Search** liefert strukturierte Ergebnisse mit Titeln, URLs, Snippets und Datumsangaben.
- **Web Scrape** wandelt eine ausgewählte öffentliche Seite in Markdown um.

Verwenden Sie sie zusammen, wenn Ihre Anwendung vor der Inferenz aktuelles, überprüfbares Ausgangsmaterial benötigt.

## Das Web durchsuchen

Senden Sie eine Anfrage an die Search API:

```bash
curl https://api.venice.ai/api/v1/augment/search \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"query":"latest developments in decentralized AI"}'
```

Jedes Ergebnis hat einen `title`, eine `url`, einen `content`-Auszug und ein `date`, das leer ist, wenn der Anbieter keines liefert:

```json
{
  "query": "latest developments in decentralized AI",
  "results": [
    {
      "title": "What decentralized AI networks shipped this year",
      "url": "https://example.com/decentralized-ai",
      "content": "An extract of the page text that matches the query...",
      "date": "2026-11-20T00:00:00.000Z"
    }
  ]
}
```

Brave ist der Standardanbieter und bietet Zero Data Retention. Google ist ebenfalls verfügbar, wobei Anfragen anonymisiert über Venice geleitet werden, und [Exa](/de/guides/integrations/exa-search) ist mit Zero Data Retention verfügbar. Weitere Informationen zur Anbieterauswahl und zum vollständigen Antwortschema finden Sie in der [Web Search API-Referenz](/api-reference/endpoint/augment/search).

## Einen Anbieter auswählen {#choosing-a-provider}

Jeder Anbieter nimmt dieselbe Anfrage entgegen und kostet pro Suche gleich viel, sodass ein Wechsel nur ein Feld betrifft: Setzen Sie `search_provider` auf `brave`, `google` oder `exa`. `limit` begrenzt die Anzahl der Ergebnisse (Standard 10, bis zu 20), und ein Anbieter kann weniger zurückgeben:

```bash
curl https://api.venice.ai/api/v1/augment/search \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"query":"latest developments in decentralized AI","search_provider":"exa","limit":5}'
```

Der Unterschied liegt darin, was zurückkommt:

| Anbieter | Ergebnisse | Geeignet für |
|---|---|---|
| `brave` (Standard) | Kurze, zur Anfrage passende Auszüge | Nachrichten und alltägliche Suchen sowie Pipelines, die die ausgewählten Seiten scrapen |
| `google` | 5 Ergebnisse, meist der vollständige Seitentext ab dem Seitenanfang, oder nur das Snippet, wenn eine Website Scraping blockiert | Seitentext lesen ohne separaten Scrape |
| `exa` | Kurze, zur Anfrage passende Auszüge und die relevantesten Ergebnisse in unserem Benchmark | Programmier- und Recherchefragen sowie Ergebnisse, die direkt in einen Prompt gehen |

Längere Ergebnisse werden zu Input-Tokens, wenn Sie sie an ein Modell übergeben. Sie kosten also mehr und brauchen länger in der Verarbeitung. Wenn Ergebnisse direkt in einen Prompt gehen, begrenzen Sie, wie viele Sie aufnehmen und wie viel Text jedes beiträgt. Behalten Sie bei `google` die Passagen, die zur Anfrage passen, statt des Anfangs jedes Ergebnisses, der oft aus Navigation oder einem Cookie-Banner besteht.

Wie sich die Anbieter bei Relevanz, Antwortgenauigkeit, Latenz und Token-Kosten unterscheiden, lesen Sie in [Benchmark von Websuche-Anbietern](/de/learn/search-provider-benchmark). Der Artikel verlinkt das Benchmark-Harness, sodass Sie den Vergleich mit Ihren eigenen Fragen wiederholen können.

## Eine Seite scrapen

Nachdem Sie ein Ergebnis ausgewählt haben, senden Sie dessen öffentliche URL an die Scrape API:

```bash
curl https://api.venice.ai/api/v1/augment/scrape \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://example.com/article"}'
```

Der Endpunkt gibt den Seiteninhalt als Markdown in `content` zurück:

```json
{
  "url": "https://example.com/article",
  "content": "# Article title\n\nThe article text as Markdown...",
  "format": "markdown"
}
```

Er fordert zunächst die native Markdown-Darstellung der Seite an, sofern verfügbar, und nutzt andernfalls eine browserbasierte Extraktion.

## Search-to-Scrape-Workflow

<Steps>
  <Step title="Suchen">
    Reichen Sie eine gezielte Anfrage ein und sammeln Sie die strukturierten Ergebnisse.
  </Step>
  <Step title="Quellen auswählen">
    Filtern Sie Ergebnisse nach Relevanz, Domain und Datum, bevor Sie Seiteninhalte abrufen.
  </Step>
  <Step title="Scrapen">
    Extrahieren Sie Markdown nur von den Seiten, die Ihre Anwendung tatsächlich verwenden möchte.
  </Step>
  <Step title="Inhalte verwenden oder speichern">
    Fügen Sie das Markdown in einen Prompt ein, erstellen Sie Embeddings, cachen Sie es oder bewahren Sie Quell-URLs für Zitate auf.
  </Step>
</Steps>

Web Search und Web Scrape haben jeweils ein Limit für Requests pro Minute und Konto. Requests über dem Limit geben `429` zurück. Wiederholen Sie sie mit exponentiellem Backoff und beschränken Sie paralleles Scraping auf einen kleinen Pool.

## Eigenständige Suche oder Modell-Websuche?

Verwenden Sie die eigenständigen APIs, wenn Ihre Anwendung Kontrolle über die Quellenauswahl benötigt oder abgerufene Inhalte wiederverwenden möchte. Aktivieren Sie die Websuche bei einer Modellanfrage, wenn Venice das Retrieval als Teil einer einzelnen Inferenzanfrage übernehmen soll.

| Bedarf | Ansatz |
|---|---|
| Ergebnisse vor der Inferenz prüfen oder filtern | Eigenständige Web Search |
| Eine bestimmte bekannte URL extrahieren | Eigenständiges Web Scrape |
| Abgerufene Inhalte cachen oder wiederverwenden | Eigenständige APIs |
| Das Modell aktuellen Kontext automatisch abrufen lassen | Modell-Websuche |

Für die Websuche durch das Modell setzen Sie `enable_web_search` in `venice_parameters` einer Chat Completion: `"on"` sucht bei jeder Anfrage, und `"auto"` lässt das Modell entscheiden, wann es sucht. Fügen Sie `enable_web_citations: true` hinzu, damit das Modell seine Quellen mit Hochzahlen wie `^1^` zitiert.

```bash
curl https://api.venice.ai/api/v1/chat/completions \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "venice-uncensored-1-2",
    "messages": [{"role": "user", "content": "What happened in decentralized AI this week?"}],
    "venice_parameters": {"enable_web_search": "on", "enable_web_citations": true}
  }'
```

Die Quellen kommen in der Antwort zurück, beim Streaming im ersten Chunk. Die Websuche wird pro Anfrage zusätzlich zum Tokenpreis des Modells berechnet; siehe [Preise für Websuche und Tools](/pricing#web-search-and-tools).

<Warning>
Web Search und Web Scrape sind experimentelle APIs. Ihre Anfrage- und Antwortformate können sich ohne Vorankündigung ändern. Web Scrape akzeptiert nur öffentlich zugängliche Seiten, und Websites, die automatisierten Zugriff blockieren, können abgelehnt werden.
</Warning>
