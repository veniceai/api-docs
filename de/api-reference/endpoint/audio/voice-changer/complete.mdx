Rufen Sie diesen Endpoint auf, nachdem Sie das konvertierte Audio erfolgreich heruntergeladen haben, wenn Venice die zur Anfrage gespeicherten Medien bereinigen soll. Wenn Sie `delete_media_on_completion: true` an [`/audio/voice-changer/retrieve`](/de/api-reference/endpoint/audio/voice-changer/retrieve) übergeben, wird dieselbe Bereinigung inline durchgeführt.

Voice-Changer-Modelle werden auf [`/audio/complete`](/de/api-reference/endpoint/audio/complete) nicht akzeptiert.
