Verwenden Sie diesen Endpoint vor [`/audio/voice-changer/queue`](/de/api-reference/endpoint/audio/voice-changer/queue), um die USD-Kosten für die Konvertierung einer Quellaufnahme mit einer bestimmten Länge zu schätzen. Voice Changer wird nach der Länge der Quellaufnahme abgerechnet, aufgerundet auf die nächste volle Minute. Die Queue-Antwort liefert die gemessene `duration_seconds`, sodass Sie die Schätzung abgleichen können.

Voice-Changer-Modelle werden auf [`/audio/quote`](/de/api-reference/endpoint/audio/quote) nicht akzeptiert.
