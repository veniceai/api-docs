Verwenden Sie die von [`/audio/voice-changer/queue`](/de/api-reference/endpoint/audio/voice-changer/queue) zurückgegebene `queue_id`, um den Konvertierungsstatus zu prüfen. Solange der Job läuft, gibt dieser Endpoint JSON mit `status: "PROCESSING"` zurück; wenn er abgeschlossen ist, wird `audio/mpeg` zurückgegeben. Setzen Sie `delete_media_on_completion` auf `true`, um gespeicherte Medien im selben Aufruf zu bereinigen, oder rufen Sie [`/audio/voice-changer/complete`](/de/api-reference/endpoint/audio/voice-changer/complete) auf, nachdem Sie die Datei heruntergeladen haben.

Voice-Changer-Modelle werden auf [`/audio/retrieve`](/de/api-reference/endpoint/audio/retrieve) nicht akzeptiert.
