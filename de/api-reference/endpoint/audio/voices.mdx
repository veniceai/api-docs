Laden Sie eine Audioprobe hoch, um ein Handle für eine geklonte Stimme zu erstellen. Übergeben Sie es anschließend als `voice` an [`/audio/speech`](/de/api-reference/endpoint/audio/speech), zusammen mit demselben `model`, mit dem es erstellt wurde. Eine Schritt-für-Schritt-Anleitung finden Sie im [Leitfaden zum Klonen von Stimmen](/de/guides/media/voice-cloning).
