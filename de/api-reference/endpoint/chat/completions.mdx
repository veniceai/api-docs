<Info>
  **Venice-spezifische Parameter befinden sich in [`venice_parameters`](#body-venice-parameters).** Dieser Endpunkt ist OpenAI-kompatibel, aber das `venice_parameters`-Objekt schaltet Funktionen frei, die nicht Teil der Standard-OpenAI-API sind. Viele Integratoren übersehen sie:

  - **Websuche und Zitate** — `enable_web_search`, `enable_web_citations`, `enable_web_scraping`
  - **Charakter-Personas** — `character_slug`
  - **Steuerung des System-Prompts** — `include_venice_system_prompt`
  - **Reasoning-Steuerung** — `disable_thinking`, `strip_thinking_response`
  - **Datenschutz** — `enable_e2ee`

  Die vollständige Liste finden Sie im Abschnitt [`venice_parameters`](#body-venice-parameters) weiter unten.
</Info>
