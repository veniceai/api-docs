<Warning>
Dieser Endpunkt wurde am 2026-09-16 eingestellt und gibt jetzt für jede Anfrage `410 Gone` zurück. Verwenden Sie stattdessen den [Abrechnungsnutzungsverlauf](/de/api-reference/endpoint/billing/usage-history).
</Warning>

Der Abrechnungsnutzungsverlauf gibt dieselben Ledger-Einträge mit Cursor-Paginierung zurück. So migrieren Sie:

- Ersetzen Sie `page` und `limit` durch `pageSize` und übergeben Sie den `nextCursor` aus jeder Antwort, um die nächste Seite abzurufen.
- Ersetzen Sie `startDate` und `endDate` durch `startTimestamp` und `endTimestamp`.
