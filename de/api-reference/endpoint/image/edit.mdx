</Info>

## Qualitätsstufen

`/image/edit` akzeptiert keinen Parameter `quality`; wenn Sie ihn senden, erhalten Sie `400`. Edits über diesen Endpoint werden mit der Standardstufe des Modells abgerechnet (`high` für `gpt-image-2-edit`).

Um eine Stufe (`low`, `medium`, `high`) zu wählen, verwenden Sie [`/image/multi-edit`](/api-reference/endpoint/image/multi-edit); dieser Endpoint akzeptiert `quality` bei Modellen, die es unterstützen. Preise pro Stufe (1K/2K/4K × low/medium/high) finden Sie unter `model_spec.pricing.quality` im [Models-Endpoint](/api-reference/endpoint/models/list) und in der [Preisübersicht](/overview/pricing).
