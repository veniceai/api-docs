Wenn die Antwort von `/video/queue` eine `download_url` enthielt, laden Sie die fertige Datei über diese URL herunter (nicht als Binärdaten von diesem Endpoint). Andernfalls liefert dieser Endpoint das Video zurück. Siehe [Private Download-Links](/de/guides/media/video-generation#private-download-links) für Informationen zur Funktionsweise des Links, zu Wiederholungen und zum optionalen `DELETE`.
