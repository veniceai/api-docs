---

Senden Sie eine **YouTube**-Video-URL in `url`. Optional können Sie `response_format` auf `json` (Standard) oder `text` setzen, je nachdem, ob Sie strukturierte Ausgabe oder reinen Transkripttext wünschen.

<Warning>
Dieser Endpunkt akzeptiert ausschließlich YouTube-URLs. Watch-, Share-, Embed-, Live- und Shorts-Links werden auf den Hosts `youtube.com`, `youtu.be` und `youtube-nocookie.com` unterstützt. Jede andere URL — einschließlich eines selbst gehosteten MP4, eines CDN-Links oder eines S3-Objekts — gibt `400` mit *"url must be a valid YouTube video URL"* zurück. Um eigene Medien zu transkribieren, extrahieren Sie die Audiospur und verwenden Sie stattdessen die [Audio Transcriptions API](/api-reference/endpoint/audio/transcriptions).
</Warning>
