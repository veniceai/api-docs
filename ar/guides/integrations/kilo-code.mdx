[Kilo Code](https://kilo.ai/) هو وكيل برمجة مفتوح المصدر بالذكاء الاصطناعي لـ VS Code والـ terminal. يتوفّر Venice كـ **موفّر أصلي**، فيمكنك اختيار نماذج Venice دون تكوين endpoint مخصص متوافق مع OpenAI.

## المتطلبات

- مفتاح Venice API من [venice.ai/settings/api](https://venice.ai/settings/api)
- [Kilo Code لـ VS Code](https://marketplace.visualstudio.com/items?itemName=kilocode.Kilo-Code) و/أو [Kilo CLI](https://kilo.ai/docs/code-with-ai/platforms/cli)

## الإعداد

<Tabs>
  <Tab title="VS Code">
    <Steps>
      <Step title="ثبّت Kilo Code">
        في VS Code، افتح **Extensions**، وابحث عن **Kilo Code**، ثم ثبّته من [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=kilocode.Kilo-Code).

        فضّل قناة **Pre-Release** من الـ Marketplace عندما تكون هي الإصدار الموصى به حاليًا — راجع [وثائق تثبيت Kilo](https://kilo.ai/docs/getting-started/installing).
      </Step>

      <Step title="احصل على مفتاح Venice API">
        أنشئ مفتاحًا من [venice.ai/settings/api](https://venice.ai/settings/api). انسخه فورًا وخزّنه بأمان.
      </Step>

      <Step title="أضف موفّر Venice">
        افتح **Settings** الخاصة بـ Kilo (أيقونة الترس) وانتقل إلى تبويب **Providers**. اختر **Venice AI** والصق مفتاح Venice API الخاص بك.

        تخزّن الإضافة الموفّر في ملف إعدادات `kilo.json` لديك. يمكنك أيضًا تحرير هذا الملف مباشرة — راجع تبويب **CLI** لمعرفة التنسيق.
      </Step>

      <Step title="اختر نموذجًا واختبره">
        اختر نموذج Venice من مُنتقي النماذج، ثم أرسل مهمة صغيرة مثل:

        ```txt
        Review the current file and suggest one safe improvement.
        ```

        تصفّح المعرّفات المتاحة في [كتالوج النماذج النصية](/models/text).
      </Step>
    </Steps>
  </Tab>

  <Tab title="CLI">
    <Steps>
      <Step title="ثبّت Kilo CLI">
        ```bash
        npm install -g @kilocode/cli
        kilo --version
        ```

        راجع [وثائق Kilo CLI](https://kilo.ai/docs/code-with-ai/platforms/cli) للاطلاع على خيارات التثبيت الأخرى.
      </Step>

      <Step title="عيّن مفتاح Venice API">
        صدّر المفتاح في الـ shell الذي تشغّل فيه Kilo:

        ```bash
        export VENICE_API_KEY="your-api-key"
        ```
      </Step>

      <Step title="اضبط موفّر Venice">
        أنشئ أو حرّر `~/.config/kilo/kilo.json` (عام) أو `./kilo.json` (للمشروع):

        ```json
        {
          "provider": {
            "venice": {
              "env": ["VENICE_API_KEY"]
            }
          },
          "model": "venice/zai-org-glm-5-1"
        }
        ```

        استبدل `zai-org-glm-5-1` بأي معرّف نموذج من [كتالوج النماذج النصية](/models/text). تستخدم مراجع نماذج Kilo تنسيق `venice/<model-id>`.
      </Step>

      <Step title="شغّل Kilo">
        من مجلد مشروعك:

        ```bash
        kilo
        ```

        اختر نموذج Venice من مُنتقي النماذج إذا لم تضبط `model` افتراضيًا، ثم أرسل مطالبة اختبار قصيرة.
      </Step>
    </Steps>
  </Tab>
</Tabs>

## التحقق من Venice API

إذا لم يتمكن Kilo من الاتصال، فأكّد المفتاح ومعرّفات النماذج بشكل مستقل:

```bash
curl https://api.venice.ai/api/v1/models \
  -H "Authorization: Bearer $VENICE_API_KEY"
```

انسخ `id` النموذج تمامًا إلى Kilo. في إعدادات CLI، أضف البادئة `venice/`، على سبيل المثال `venice/zai-org-glm-5-1`.

## ملاحظات التكوين

- Venice موفّر **أصلي** في Kilo. فضّل **Venice AI** في إعدادات Providers على endpoint مخصص عام متوافق مع OpenAI.
- تتشارك الإضافة و CLI نفس ملفات الإعدادات (`~/.config/kilo/kilo.json` عالميًا، أو `./kilo.json` في المشروع).
- تعرض بعض نماذج Venice عناصر تحكم بالاستدلال. يربط Kilo خيارات جهد الاستدلال وتعطيل التفكير المدعومة عندما يدعمها النموذج المحدد.
- قد تتغيّر معرّفات النماذج والوصول حسب الخطة. استخدم مُنتقي النماذج، أو [كتالوج النماذج النصية](/models/text)، أو `GET /models` للحصول على القائمة الحالية.
- احتفظ بمفتاح Venice API خاصًا. لا تلصقه في ملفات المصدر ولا تلتزم به في git.

## استكشاف الأخطاء وإصلاحها

<AccordionGroup>
  <Accordion title="مفتاح API غير صالح أو خطأ 401">
    تأكّد من أن المفتاح مأخوذ من [venice.ai/settings/api](https://venice.ai/settings/api). بالنسبة إلى CLI، تحقّق من ضبط `VENICE_API_KEY` في نفس البيئة التي تشغّل منها Kilo. في VS Code، أعد الاتصال بـ Venice AI ضمن **Providers**.
  </Accordion>
  <Accordion title="النموذج غير متاح">
    تأكّد من أن حساب Venice الخاص بك يمتلك وصولًا إلى النموذج المحدد، وانسخ المعرّف من [كتالوج النماذج النصية](/models/text) أو `GET /models`، ولإعدادات CLI استخدم صيغة `venice/<model-id>`.
  </Accordion>
  <Accordion title="لم يتم العثور على إعدادات الموفّر في الإضافة">
    حدّث إلى إصدار Kilo الموصى به حاليًا (بما في ذلك Pre-Release عندما يكون هو الافتراضي الموثّق). يمكنك أيضًا ضبط الموفّر في `kilo.json` كما هو موضّح في تبويب CLI — تقرأ الإضافة الإعدادات نفسها.
  </Accordion>
</AccordionGroup>
