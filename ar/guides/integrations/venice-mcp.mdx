[خادم Venice MCP](https://github.com/veniceai/venice-mcp-server) هو خادم [Model Context Protocol](https://modelcontextprotocol.io/) الرسمي لـ Venice. يكشف Venice API (الدردشة، الصور، الفيديو، الصوت، الموسيقى، embeddings، web augment، الشخصيات، crypto RPC، وتصديق TEE) إلى جانب عمليات الحساب (الفوترة ومفاتيح API) كـ **45 أداة** يمكن لأي وكيل متوافق مع MCP استدعاؤها.

## البدء السريع

<Steps>
  <Step title="احصل على مفتاح Venice API">
    أنشئ واحدًا من [venice.ai/settings/api](https://venice.ai/settings/api?utm_source=venice-api-documentation). انظر [دليل مفتاح API](/ar/guides/getting-started/generating-api-key) للحصول على تعليمات خطوة بخطوة.
  </Step>

  <Step title="أضف Venice إلى تكوين مضيف MCP">
    ضع هذا في ملف تكوين مضيف MCP الخاص بك:

    ```json
    {
      "mcpServers": {
        "venice": {
          "command": "npx",
          "args": ["-y", "@veniceai/mcp-server@0.3.0"],
          "env": { "VENICE_API_KEY": "<your-venice-api-key>" }
        }
      }
    }
    ```

    مسارات التكوين الشائعة:

    | المضيف | المسار |
    |---|---|
    | Claude Desktop (macOS) | `~/Library/Application Support/Claude/claude_desktop_config.json` |
    | Claude Desktop (Windows) | `%APPDATA%\Claude\claude_desktop_config.json` |
    | Cursor | `~/.cursor/mcp.json` |
    | LM Studio | `mcp.json` (من إعدادات MCP في التطبيق) |
  </Step>

  <Step title="أعد تشغيل مضيف MCP">
    أصبح لدى وكيلك الآن أدوات الدردشة والصور والفيديو والموسيقى و TTS و ASR و 39 أداة Venice إضافية.
  </Step>
</Steps>

<Note>
معظم مضيفي MCP يمررون فقط متغيرات البيئة المُدرجة **بشكل صريح** في كتلة `env`. لا تُورَّث متغيرات env على مستوى النظام. إذا رأيت أخطاء 402 مع مفتاح API مضبوط، تحقق مرتين من أن `VENICE_API_KEY` داخل `env` في التكوين الخاص بك.
</Note>

## ما الذي تحصل عليه

**45 أداة** تغطي كل صيغ Venice بالإضافة إلى عمليات الحساب، و**3 موارد** (`venice://models`, `venice://styles`, `venice://voices`)، و**3 قوالب prompt** (بحث غير خاضع للرقابة، كتابة إبداعية NSFW، مستكشف أنماط الصور).

تعلن كل أداة عن تعليقات توضيحية صريحة `readOnlyHint` و`destructiveHint` و`idempotentHint` و`openWorldHint`، بحيث يمكن للمضيفين تشغيل عمليات البحث دون مطالبة المستخدم وطلب التأكيد قبل أي إجراء مدمّر، مثل تنظيف الوسائط أو ترحيل معاملة عملات مشفرة.

### الدردشة و embeddings

| الأداة | الوصف |
|---|---|
| `venice_chat` | إكمال دردشة متوافق مع OpenAI ضد كتالوج LLM الكامل لـ Venice، مع كتل النص/الصورة/الصوت/الفيديو/الملفات، والمخرجات المهيكلة، وأدوات الدوال، والتخزين المؤقت للمطالبات، وعناصر التحكم في الاستدلال. الاستدعاءات بنص عادي وبدون بث. |
| `venice_responses` | واجهة [Responses API](/ar/guides/features/responses-api) تجريبية (Beta) عديمة الحالة ومتوافقة مع OpenAI، مع إدخال النص/الصورة وعناصر التحكم في الاستدلال. لا تكشف هذه الأداة حقول استدعاء الأدوات، ولا تدعم نماذج E2EE. |
| `venice_embeddings` | حساب embeddings لإدخال نصي. |
| `venice_chat_with_character` | دردش مع شخصية Venice بواسطة slug. |

|---|---|

| الأداة | الوصف |

## التكوين

يتم تكوين الخادم بالكامل عبر متغيرات البيئة.

### النماذج والطلبات

| متغير البيئة | الافتراضي | ملاحظات |
|---|---|---|
| `VENICE_API_KEY` | _(لا شيء)_ | مفتاح Venice API الخاص بك. الإعداد الأبسط. |
| `VENICE_DEFAULT_CHAT_MODEL` | `deepseek-v4-flash-0731` | |
| `VENICE_DEFAULT_IMAGE_MODEL` | `flux-2-pro` | |
| `VENICE_DEFAULT_TTS_MODEL` | `tts-kokoro` | |
| `VENICE_DEFAULT_ASR_MODEL` | `openai/whisper-large-v3` | |
| `VENICE_DISABLE_NSFW` | `0` | اضبط على `1` لإزالة ملاحظات قدرة NSFW من أوصاف الأدوات. |
| `VENICE_HTTP_TIMEOUT_MS` | `60000` | |
| `VENICE_SIWX_TOKEN` | _(لا شيء)_ | رمز مصادقة وضع محفظة x402. انظر [x402 أدناه](#وضع-محفظة-x402). |

إذا تم تعيين كل من `VENICE_API_KEY` و `VENICE_SIWX_TOKEN`، يفوز مفتاح API في معظم الاستدعاءات؛ انظر [تغطية أوضاع المصادقة](#تغطية-أوضاع-المصادقة) لمعرفة الاستثناءات.

### حدود حجم الاستجابة

تُخزَّن الوسائط المُولَّدة مؤقتًا وتُضمَّن في نتيجة MCP بترميز base64، لذا لكل صيغة حد أقصى بالبايت.

| متغير البيئة | الافتراضي | ينطبق على |
|---|---|---|
| `VENICE_MAX_IMAGE_RESPONSE_BYTES` | `33554432` (32 MiB) | `venice_image_generate`, `venice_image_edit`, `venice_image_multi_edit`, `venice_image_upscale`, `venice_image_remove_bg` |
| `VENICE_MAX_VIDEO_RESPONSE_BYTES` | `26214400` (25 MiB) | `venice_video_status` |
| `VENICE_MAX_AUDIO_RESPONSE_BYTES` | `33554432` (32 MiB) | `venice_tts`, `venice_music_status` |

تُتجاهل نتيجة الصورة أو TTS التي تتجاوز الحجم مع ظهور خطأ. أما نتيجة الفيديو أو الموسيقى التي تتجاوز الحجم فتبقى في قائمة الانتظار، لذا يمكنك استدعاء أداة الحالة مرة أخرى بمعرّف قائمة الانتظار نفسه بعد رفع الحد.

### خادم HTTP

ذو صلة فقط في [نشر Streamable HTTP](#الاستضافة-الذاتية-streamable-http).

| متغير البيئة | الافتراضي | ملاحظات |
|---|---|---|
| `PORT` | `3333` | منفذ مستمع HTTP. |
| `VENICE_MCP_HOST` | `127.0.0.1` | عنوان الربط. اضبطه على `0.0.0.0` للإتاحة عبر الشبكة المحلية أو الحاوية. |
| `VENICE_MCP_AUTH_TOKEN` | _(لا شيء)_ | رمز Bearer لـ `/mcp`. مطلوب عند الربط خارج loopback، وفي هذه الحالة يجب ألا يقل عن 16 حرفًا. بمجرد تعيينه، يُفرض على loopback أيضًا. |
| `VENICE_MCP_ALLOW_UNAUTHENTICATED_HTTP` | `0` | منفذ هروب لإتاحة HTTP دون مصادقة. استخدمه فقط خلف وكيل موثوق يطبّق المصادقة. |
| `VENICE_MCP_MAX_SESSIONS` | `100` | الحد الأقصى لجلسات Streamable HTTP النشطة. |
| `VENICE_MCP_SESSION_TTL_MS` | `1800000` | مدة بقاء الجلسة الخاملة قبل تنظيفها. |

## سلوك توليد الوسائط

- **يمكن أن تكون الوسائط المكتملة بايتات أو عنوان URL.** تعيد مهام الفيديو والموسيقى موارد MP4/صوت مُضمَّنة، أو JSON يحتوي على `download_url` يُعاد كرابط مورد. نزّل هذا الرابط أولًا، ثم استدعِ `venice_video_complete` أو `venice_music_complete`؛ لا يُطبَّق تنظيف الوسائط أبدًا على نتيجة `download_url` لأن الرابط يتوقف عن العمل بمجرد حذف الملف.
- **بعض النماذج تعيد عنوان URL فقط وقت الإضافة إلى قائمة الانتظار.** بالنسبة لنماذج VPS وGrok Imagine Private، احتفظ بـ `download_url` الذي تعيده `venice_video_generate` ومرّره إلى `venice_video_status`؛ فعملية الاسترجاع بحالة `COMPLETED` دون عنوان URL مضمّن تعطي رابطًا صالحًا للاستخدام.
- **يُبلَغ عن تحسين المطالبة.** عند تطبيق `enhance_prompt`، تتضمن نتائج توليد الصور وتحريرها والتحرير المتعدد المطالبة المفكوكة الترميز من URL التي أعادتها Venice.
- **تُحتسب تكلفة تقسيم صفحات ASR مرة واحدة.** النصوص التي تتجاوز 8,000 حرف، أو التي تحتوي على طوابع زمنية أكثر مما تتسع له صفحة واحدة (200 لكل مصفوفة افتراضيًا، وحتى 500 مع `timestamp_limit`)، تعيد `result_handle` مع الصفحة الأولى. اطلب الصفحات اللاحقة باستخدام هذا المُعرِّف. تبقى المُعرِّفات في الذاكرة لكل جلسة MCP لمدة 10 دقائق، ويُحتفظ فقط بأحدث 16 منها.
- **موافقة Seedance ليست تجاوزًا للسياسة.** قد ترفض نماذج Seedance العامة الحالية الوسائط التي تحتوي على أشخاص يمكن التعرف عليهم رفضًا قاطعًا. عند إعادة استجابة `needs_consent`، فإن علامات `consents.seedance` الثلاث هي إقرارات قانونية: اضبطها على `true` فقط بعد أن يؤكد المستخدم كل بيان صراحةً.

## وضع محفظة x402

تدعم Venice المصادقة برمز [Sign-In-With-X wallet](/ar/guides/integrations/x402-venice-api) المدعوم برصيد USDC المدفوع مسبقًا على Base أو Solana، بالإضافة إلى التدفق العادي لمفتاح API. لا يلزم بريد إلكتروني أو هاتف أو KYC: محفظتك هي الهوية الوحيدة.

```json
{
  "mcpServers": {
    "venice": {
      "command": "npx",
      "args": ["-y", "@veniceai/mcp-server@0.3.0"],
      "env": { "VENICE_SIWX_TOKEN": "<base64 Sign-In-With-X payload>" }
    }
  }
}
```

يقوم خادم MCP بإعادة توجيه `VENICE_SIWX_TOKEN` في ترويسة `SIGN-IN-WITH-X` في كل استدعاء لـ Venice API. لا يرى الخادم أبدًا مفتاحك الخاص. توقيع المحفظة وتفويضات شحن USDC تحدث في محفظتك الخاصة.

| التدفق | ما الذي يحدث |
|---|---|
| **إعداد لمرة واحدة** | وقّع رسالة Sign-In-With-X في محفظتك → ينتج رمز SIWX (base64 JSON). |
| **الشحن** | `POST /api/v1/x402/top-up` يعيد 402 + متطلبات الدفع. وقّع دفعة USDC لأحد خيارات Base أو Solana المعادة، أعد الإرسال، وستضيف Venice الرصيد إلى حسابك. |
| **كل استدعاء استدلال** | يرسل خادم MCP `SIGN-IN-WITH-X: <SIWX>`؛ تخصم Venice من رصيدك المدفوع مسبقًا. |

الحد الأدنى للشحن **\$5 USD**. الحد الأدنى للرصيد لاستدعاء الاستدلال **\$0.10**. بمجرد الشحن، تكون الاستدعاءات أقل من 100 مللي ثانية لأن التسوية تحدث خارج السلسلة في حساب ائتمان سريع.

<Tip>
المحافظ المرتبطة بحساب Venice مع DIEM المُربط تستهلك من رصيد الـ staking بدلًا من اعتمادات USDC، لذا لا يلزم شحن.
</Tip>

لا تقبل Venice ترويسات الدفع على مسارات الاستدلال، لذا لا يرسل هذا الخادم أيًا منها أبدًا. تخص `PAYMENT-SIGNATURE` المسار `/x402/top-up` فقط، وتكتشف أداة مساعدة الشحن المتطلبات دون إرسال أي دفعة.

### تغطية أوضاع المصادقة

تقبل بعض نقاط النهاية وضع مصادقة واحدًا فقط:

| الأداة | مفتاح API | x402 |
|---|---|---|
| الاستدلال، الوسائط، web augment، crypto RPC، الدردشة مع الشخصيات | ✓ | ✓ |
| `venice_list_characters`, `venice_get_character`, `venice_character_reviews` | ✓ | ✗ |
| `venice_billing_*`, `venice_list_api_keys`, `venice_get_api_key`, `venice_api_key_rate_limit_logs` | ✓ (مسؤول) | ✗ |
| `venice_api_key_rate_limits` | ✓ (أي مفتاح) | ✗ |
| `venice_x402_balance`, `venice_x402_transactions` | ✗ | ✓ |
| `venice_x402_top_up_info` | ✓ | ✓ |

عند تعيين بيانات الاعتماد كلتيهما، يُستخدم مفتاح API لكل استدعاء يتطلب مصادقة باستثناء `venice_x402_balance` و`venice_x402_transactions`، اللتين ترسلان دائمًا رمز المحفظة.

## الاستضافة الذاتية (Streamable HTTP)

لعمليات النشر الجماعية أو لمساحات العمل، شغّل خادم MCP عبر HTTP بدلًا من stdio:

```bash
docker run -p 3333:3333 \
  -e VENICE_API_KEY=<your-venice-api-key> \
  -e VENICE_MCP_AUTH_TOKEN=<choose-a-long-random-token> \
  ghcr.io/veniceai/venice-mcp-server:latest
```

الخادم الآن متاح على `http://localhost:3333/mcp`. يجب أن يرسل عملاء HTTP `Authorization: Bearer <VENICE_MCP_AUTH_TOKEN>` وينبغي أن ينشئوا جلسات جديدة دون ترويسة `mcp-session-id`، ثم يعيدوا استخدام معرّف الجلسة الصادر عن الخادم.

<Warning>
`/mcp` هي نقطة نهاية لتنفيذ أدوات مدعومة بالاعتمادات: يمكن للمتصلين إنفاق مفتاح Venice API المُكوَّن أو رصيد x402. عندما يرتبط وضع HTTP خارج loopback، يفشل بدء التشغيل ما لم يتم تعيين `VENICE_MCP_AUTH_TOKEN`، أو تعيين `VENICE_MCP_ALLOW_UNAUTHENTICATED_HTTP=1` خلف وكيل موثوق يطبّق المصادقة. للإنتاج، ثبّت إصدار حزمة npm بشكل صريح بدلًا من الاعتماد على `latest`.
</Warning>
