[خادم Venice MCP](https://github.com/veniceai/venice-mcp-server) هو خادم [Model Context Protocol](https://modelcontextprotocol.io/) الرسمي لـ Venice. يكشف Venice API (الدردشة، الصور، الفيديو، الصوت، الموسيقى، embeddings، web augment، الشخصيات، RPC للعملات المشفرة، وإثبات TEE) إضافةً إلى عمليات الحساب (الفوترة ومفاتيح API) كـ **45 أداة** يمكن لأي وكيل متوافق مع MCP استدعاؤها.

## البدء السريع

<Steps>
  <Step title="احصل على مفتاح Venice API">
    أنشئ واحدًا من [venice.ai/settings/api](https://venice.ai/settings/api?utm_source=venice-api-documentation). راجع [دليل مفتاح API](/guides/getting-started/generating-api-key) للخطوات التفصيلية.
  </Step>

  <Step title="أضف Venice إلى تكوين مضيف MCP">
    ألصق هذا في ملف تكوين مضيف MCP:

    ```json
    {
      "mcpServers": {
        "venice": {
          "command": "npx",
          "args": ["-y", "@veniceai/mcp-server@0.3.0"],
          "env": { "VENICE_API_KEY": "<your-venice-api-key>" }
        }
      }
    }
    ```

    مسارات التكوين الشائعة:

    | المضيف | المسار |
    |---|---|
    | Claude Desktop (macOS) | `~/Library/Application Support/Claude/claude_desktop_config.json` |
    | Claude Desktop (Windows) | `%APPDATA%\Claude\claude_desktop_config.json` |
    | Cursor | `~/.cursor/mcp.json` |
    | LM Studio | `mcp.json` (من إعدادات MCP في التطبيق) |
  </Step>

  <Step title="أعد تشغيل مضيف MCP">
    أصبح لدى وكيلك الآن الدردشة والصور والفيديو والموسيقى وTTS وASR والفوترة ومفاتيح API و39 أداة Venice أخرى.
  </Step>
</Steps>

<Note>
معظم مضيفات MCP تمرر فقط متغيرات البيئة **المذكورة صراحةً** في كتلة `env`. لا تُورَّث متغيرات النظام. إذا ظهرت أخطاء 402 مع وجود مفتاح API، فتأكد من أن `VENICE_API_KEY` داخل `env` في تكوينك.
</Note>

## ما الذي تحصل عليه

**45 أداة** تغطي كل صيغ Venice إضافة إلى عمليات الحساب، و**3 موارد** (`venice://models`, `venice://styles`, `venice://voices`)، و**3 قوالب prompt** (بحث دون رقابة، كتابة إبداعية NSFW، مستكشف أنماط الصور).

كل أداة تعلن تعليقات صريحة `readOnlyHint` و`destructiveHint` و`idempotentHint` و`openWorldHint`، بحيث يمكن للمضيفات تنفيذ الاستعلامات دون سؤال، وطلب التأكيد قبل أي إجراء مدمّر مثل حذف الوسائط أو تمرير معاملة مشفّرة.

### الدردشة و embeddings

| الأداة | الوصف |
|---|---|
| `venice_chat` | إكمال دردشة متوافق مع OpenAI على كتالوج LLM الكامل في Venice، مع كتل نص/صورة/صوت/فيديو/ملف، ومخرجات مُهيكلة، وfunction tools، وتخزين prompt مؤقت، وتحكم في التفكير. الاستدعاءات نصية صريحة وغير متدفقة. |
| `venice_responses` | واجهة Responses بألفا وبدون حالة ومتوافقة مع OpenAI، مع إدخال نص/صورة وتحكم في التفكير. لا تدعم النماذج القادرة على E2EE ولا حقول الأدوات. |
| `venice_embeddings` | حساب embeddings للنص. |
| `venice_chat_with_character` | الدردشة مع شخصية Venice عبر slug. |

### الصور

| `venice_image_edit` | تحرير صورة بواسطة prompt. |
| `venice_image_multi_edit` | تحرير حتى 8 صور معًا باستخدام prompt واحد (تركيب / توسيع). |
| `venice_image_upscale` | تكبير الصورة من 2 إلى 4×، مع تحكم في `creativity`. |
| `venice_image_remove_bg` | إزالة خلفية الصورة. |
| `venice_image_styles` | عرض قوالب أنماط الصور. |

### الفيديو

| الأداة | الوصف |
|---|---|

| `venice_voice_clone` | عرض الأصوات الحية حسب النموذج، أو استنساخ صوت من رابط عينة (يُرجع مقبض `vv_<id>` لاستخدامه مع `venice_tts`). |

### إثبات TEE

| الأداة | الوصف |
|---|---|
| `venice_tee_attestation` | الحصول على أدلة إثبات العتاد (quote من Intel TDX، وأدلة NVIDIA الاختيارية، ومفتاح التوقيع) لنموذج نصي يدعم TEE، باستخدام nonce خاص بك بحجم 32 بايت. |

<Warning>
كلتا أداتَي TEE تعيدان أدلة المزوّد فقط: لا تتحققان منها ولا تشفّران الدردشة. تحقق بنفسك من nonce المُعاد ووضع التصحيح وربط مفتاح التوقيع قبل الوثوق بنموذج TEE، واستخدم `venice_chat` (لا `venice_responses` أبدًا) مع نماذج TEE. يرفض هذا الخادم `enable_e2ee`.
</Warning>

| الأداة | الوصف |
|---|---|
| `venice_crypto_networks` | عرض معرّفات الشبكات الحية التي يقبلها وكيل RPC. |

## التكوين

يُكوَّن الخادم بالكامل عبر متغيرات البيئة.

### النماذج والطلبات

| المتغير | الافتراضي | ملاحظات |
|---|---|---|
| `VENICE_API_KEY` | _(لا شيء)_ | مفتاح Venice API الخاص بك. أبسط إعداد. |
| `VENICE_DEFAULT_CHAT_MODEL` | `deepseek-v4-flash-0731` | |
| `VENICE_DEFAULT_IMAGE_MODEL` | `flux-2-pro` | |
| `VENICE_DEFAULT_TTS_MODEL` | `tts-kokoro` | |
| `VENICE_DEFAULT_ASR_MODEL` | `openai/whisper-large-v3` | |
| `VENICE_DISABLE_NSFW` | `0` | اضبطه على `1` لإزالة ملاحظات قدرة NSFW من أوصاف الأدوات. |
| `VENICE_HTTP_TIMEOUT_MS` | `60000` | |
| `VENICE_SIWX_TOKEN` | _(لا شيء)_ | رمز مصادقة وضع محفظة x402. انظر [x402 أدناه](#وضع-محفظة-x402). |

إذا تم تعيين `VENICE_API_KEY` و`VENICE_SIWX_TOKEN` معًا، يفوز مفتاح API.

### حدود حجم الاستجابة

تُخزَّن الوسائط المولَّدة مؤقتًا وتُضمَّن بترميز base64 في نتيجة MCP، لذا لكل صيغة سقف بالبايت.

| المتغير | الافتراضي | ينطبق على |
|---|---|---|
| `VENICE_MAX_IMAGE_RESPONSE_BYTES` | `33554432` (32 MiB) | `venice_image_generate`، `venice_image_edit`، `venice_image_multi_edit`، `venice_image_upscale`، `venice_image_remove_bg` |
| `VENICE_MAX_VIDEO_RESPONSE_BYTES` | `26214400` (25 MiB) | `venice_video_status` |
| `VENICE_MAX_AUDIO_RESPONSE_BYTES` | `33554432` (32 MiB) | `venice_tts`، `venice_music_status` |

تُهمَل النتيجة الصورية أو الصوتية (TTS) الكبيرة جدًا مع خطأ. أما الفيديو أو الموسيقى الكبيرة جدًا فتبقى في قائمة الانتظار، لذا يمكنك استدعاء أداة الحالة مجددًا بنفس queue ID بعد رفع الحد.

### خادم HTTP

ذو صلة فقط في [نشر Streamable HTTP](#الاستضافة-الذاتية-streamable-http).

| المتغير | الافتراضي | ملاحظات |
|---|---|---|
| `PORT` | `3333` | منفذ مستمع HTTP. |
| `VENICE_MCP_HOST` | `127.0.0.1` | عنوان الربط. اضبطه على `0.0.0.0` للكشف على الشبكة المحلية أو الحاوية. |
| `VENICE_MCP_AUTH_TOKEN` | _(لا شيء)_ | رمز bearer يتطلبه `/mcp` عند الربط خارج loopback. |
| `VENICE_MCP_ALLOW_UNAUTHENTICATED_HTTP` | `0` | مخرج طوارئ لـ HTTP مكشوف دون مصادقة. استخدمه فقط خلف وكيل موثوق ومصادَق. |
| `VENICE_MCP_MAX_SESSIONS` | `100` | الحد الأقصى لجلسات Streamable HTTP النشطة. |
| `VENICE_MCP_SESSION_TTL_MS` | `1800000` | عمر الجلسة الخاملة قبل التنظيف. |

## سلوك توليد الوسائط

- **قد تكون الوسائط المكتملة بايتات أو رابطًا.** تُرجع مهام الفيديو والموسيقى موارد MP4/صوت مضمّنة، أو JSON يحتوي `download_url` يعود كـ resource link. نزّل ذلك الرابط أولًا ثم استدعِ `venice_video_complete` أو `venice_music_complete`؛ لا يُطبَّق تنظيف الوسائط أبدًا على نتيجة `download_url` لأن الرابط يتوقف عن العمل بعد حذف الملف.
- **بعض النماذج تُرجع الرابط فقط عند وضع المهمة في الانتظار.** في نماذج VPS وGrok Imagine Private، احفظ `download_url` التي يُرجعها `venice_video_generate` ومرّرها إلى `venice_video_status`؛ فاسترجاع `COMPLETED` دون رابط مضمّن يظل يعطي رابطًا صالحًا.
- **يُعاد تحسين prompt.** عند تطبيق `enhance_prompt`، تتضمن نتائج توليد الصور وتحريرها وتحريرها المتعدد الـ prompt المفكوك من ترميز URL الذي تُرجعه Venice.
- **تُحتسب صفحات ASR مرة واحدة.** التفريغات التي تحتوي طوابع زمنية أو تتجاوز 8000 حرف تُرجع `result_handle` مع الصفحة الأولى. اطلب الصفحات التالية بذلك المقبض. تبقى المقابض في الذاكرة لكل جلسة MCP لمدة 10 دقائق، ولا يُحتفظ إلا بأحدث 16.
- **موافقة Seedance ليست تجاوزًا للسياسة.** قد ترفض نماذج Seedance العامة الحالية تمامًا الوسائط التي تحتوي أشخاصًا يمكن التعرف عليهم. وعند إرجاع استجابة `needs_consent`، فإن أعلام `consents.seedance` الثلاثة إقرارات قانونية: لا تضبطها على `true` إلا بعد أن يؤكد المستخدم صراحةً كل عبارة.

## وضع محفظة x402

تدعم Venice المصادقة بـ[رمز محفظة Sign-In-With-X](/guides/integrations/x402-venice-api) المدعوم برصيد USDC مدفوع مسبقًا على Base أو Solana، إضافةً إلى تدفق مفتاح API المعتاد. بلا بريد إلكتروني أو هاتف أو KYC: محفظتك هي الهوية الوحيدة.

```json
{
  "mcpServers": {
    "venice": {
      "command": "npx",
      "args": ["-y", "@veniceai/mcp-server@0.3.0"],
      "env": { "VENICE_SIWX_TOKEN": "<base64 Sign-In-With-X payload>" }
    }
  }
}
```

يمرر خادم MCP قيمة `VENICE_SIWX_TOKEN` في ترويسة `SIGN-IN-WITH-X` مع كل استدعاء لـ Venice API. لا يرى الخادم مفتاحك الخاص أبدًا. تحدث توقيعات المحفظة وتفويضات تعبئة USDC في محفظتك أنت.

| التدفق | ما يحدث |
|---|---|
| **إعداد لمرة واحدة** | توقّع رسالة Sign-In-With-X في محفظتك → ينتج رمز SIWX (JSON بترميز base64). |
| **التعبئة** | يُرجع `POST /api/v1/x402/top-up` استجابة 402 + متطلبات الدفع. وقّع دفعة USDC لأحد خياري Base أو Solana المُعادين، ثم أعد الإرسال، فتُضيف Venice الرصيد. |
| **كل استدعاء استدلال** | يرسل خادم MCP الترويسة `SIGN-IN-WITH-X: <SIWX>`؛ وتخصم Venice من رصيدك المدفوع مسبقًا. |

الحد الأدنى للتعبئة هو **\$5 USD**. والحد الأدنى للرصيد لاستدعاء الاستدلال هو **\$0.10**. بعد التعبئة تصبح الاستدعاءات أقل من 100 مللي ثانية لأن التسوية تحدث خارج السلسلة على حساب ائتمان سريع.

<Tip>
المحافظ المرتبطة بحساب Venice مع DIEM مُرهون تستهلك من رصيد الرهن بدلًا من ائتمانات USDC، لذا لا حاجة إلى تعبئة.
</Tip>

لا تقبل Venice ترويسات الدفع على مسارات الاستدلال، لذا لا يرسل هذا الخادم أي ترويسة دفع. `PAYMENT-SIGNATURE` يخص `/x402/top-up` فقط، ومساعد التعبئة يكتشف المتطلبات دون إرسال أي دفعة.

### تغطية أوضاع المصادقة

بعض النقاط تقبل وضع مصادقة واحدًا فقط:

| الأداة | مفتاح API | x402 |
|---|---|---|
| الاستدلال، الوسائط، web augment، RPC للعملات المشفرة، الدردشة مع شخصية | ✓ | ✓ |
| `venice_list_characters`، `venice_get_character`، `venice_character_reviews` | ✓ | ✗ |
| `venice_billing_*`، `venice_list_api_keys`، `venice_get_api_key`، `venice_api_key_rate_limit_logs` | ✓ (admin) | ✗ |
| `venice_api_key_rate_limits` | ✓ (أي مفتاح) | ✗ |
| `venice_x402_balance`، `venice_x402_transactions` | ✗ | ✓ |
| `venice_x402_top_up_info` | ✓ | ✓ |

عند تعيين بيانات اعتماد كليهما، يفوز مفتاح API في كل الاستدعاءات، لذا تعمل مساعدات SIWX الحصرية (`venice_x402_balance`، `venice_x402_transactions`) فقط عندما يكون رمز المحفظة هو بيانات اعتمادك الوحيدة.

## الاستضافة الذاتية (Streamable HTTP)

لنشر الفرق أو مساحات العمل، شغّل خادم MCP عبر HTTP بدلًا من stdio:

```bash
docker run -p 3333:3333 \
  -e VENICE_API_KEY=<your-venice-api-key> \
  -e VENICE_MCP_AUTH_TOKEN=<choose-a-long-random-token> \
  ghcr.io/veniceai/venice-mcp-server:latest
```

الخادم متاح الآن على `http://localhost:3333/mcp`. يجب على عملاء HTTP إرسال `Authorization: Bearer <VENICE_MCP_AUTH_TOKEN>`، وإنشاء جلسات جديدة دون ترويسة `mcp-session-id`، ثم إعادة استخدام معرّف الجلسة الذي يصدره الخادم.

<Warning>
`/mcp` هو نقطة تنفيذ أدوات مدعومة ببيانات اعتماد: يمكن للمتصلين إنفاق مفتاح Venice API المُكوَّن أو رصيد x402. عندما يرتبط وضع HTTP خارج loopback، يفشل التشغيل ما لم يُضبط `VENICE_MCP_AUTH_TOKEN`، أو يُضبط `VENICE_MCP_ALLOW_UNAUTHENTICATED_HTTP=1` خلف وكيل مصادَق موثوق. في الإنتاج، ثبّت إصدار حزمة npm صراحةً بدلًا من الاعتماد على `latest`.
</Warning>
