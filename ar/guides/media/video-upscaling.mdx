تتيح لك ترقية دقّة الفيديو تحسين مقاطع الفيديو الحالية إلى دقّات أعلى مع تحسين الجودة البصرية. يستخدم نموذج **Topaz Video Upscale** ترقيةً مدفوعة بالذكاء الاصطناعي لرفع الدقّة بمعامل 2x أو 4x، أو لتطبيق تحسين جودة بنفس الدقّة الأصلية (1x).

## كيف يعمل

تستخدم ترقية الفيديو نفس نظام الطابور غير المتزامن المستخدم في توليد الفيديو:

1. **Queue** — أرسل فيديوك إلى `/video/queue` مع النموذج `topaz-video-upscale`
2. **Poll** — استدعِ `/video/retrieve` مع `model` و`queue_id` المُعاد. أثناء تشغيل المهمة، يُرجع JSON يحتوي على `"status": "PROCESSING"`. عند انتهاء المهمة، يكون جسم الاستجابة هو ملف MP4 المُرقّى (`Content-Type: video/mp4`)، لذا احفظه في ملف. لا يوجد رابط إخراج.
3. **Clean up (optional)** — بعد حفظ الملف، استدعِ `/video/complete` لحذف الإخراج المخزّن

يكتشف الخادم تلقائيًا مدة فيديو الإدخال ومعدل إطاراته وأبعاده من الملف المرفوع. لا تحتاج إلى تقديم هذه القيم — إذ تُحتسب الفوترة من بيانات الفيديو الفعلية.

## معاملات الترقية

| `upscale_factor` | دقّة الإخراج | حالة الاستخدام |
|---|---|---|
| `1` | نفس الإدخال | تحسين جودة فقط (إزالة ضوضاء، تحسين الحدّة) |
| `2` (افتراضي) | أبعاد الإدخال × 2 | ترقية قياسية — إدخال 720p يصبح إخراج 1440p |
| `4` | أبعاد الإدخال × 4 | ترقية قصوى — إدخال 480p يصبح إخراج 1920p |

<Note>
معامل `upscale_factor` يحل محل `resolution` لنماذج الترقية. تمرير `resolution` سيُعيد خطأ. وذلك لأن دقّة الإخراج تعتمد على أبعاد فيديو الإدخال — فترقية `2x` لفيديو 720p تنتج نتيجة مختلفة عن ترقية `2x` لفيديو 480p.
</Note>

## صيغ الإدخال المدعومة

- **الصيغ**: MP4، MOV، WebM
- **طرق الإدخال**: رابط HTTPS أو رابط بيانات `data:video/...;base64,...`
- **أقصى مدة**: 300 ثانية (5 دقائق)

## استخدام API

### إرسال مهمة ترقية إلى الطابور

<CodeGroup>
```bash cURL
curl https://api.venice.ai/api/v1/video/queue \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "topaz-video-upscale",
    "video_url": "https://example.com/input-video.mp4",
    "upscale_factor": 2
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.venice.ai/api/v1/video/queue",
    headers={"Authorization": "Bearer YOUR_API_KEY"},
    json={
        "model": "topaz-video-upscale",
        "video_url": "https://example.com/input-video.mp4",
        "upscale_factor": 2,
    },
)

data = response.json()
queue_id = data["queue_id"]
download_url = data.get("download_url")
print(f"Queued: {queue_id}")
```

```javascript Node.js
const response = await fetch("https://api.venice.ai/api/v1/video/queue", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_KEY",
    "Content-Type": "application/json",
  },

    model: "topaz-video-upscale",

const { queue_id, download_url } = await response.json();
```


### الاستعلام وحفظ النتيجة

<CodeGroup>
```bash cURL
curl https://api.venice.ai/api/v1/video/retrieve \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "topaz-video-upscale", "queue_id": "abc123-def456-..."}' \
  -o upscaled.mp4 \
  -w '%{content_type}\n'
```

```python Python
import time

while True:
    result = requests.post(
        "https://api.venice.ai/api/v1/video/retrieve",
        headers={"Authorization": "Bearer YOUR_API_KEY"},
        json={"model": "topaz-video-upscale", "queue_id": queue_id},
    )
    result.raise_for_status()

    if "video/mp4" in result.headers.get("Content-Type", ""):
        with open("upscaled.mp4", "wb") as f:
            f.write(result.content)
        break

    if result.json().get("status") == "COMPLETED" and download_url:
        with open("upscaled.mp4", "wb") as f:
            f.write(requests.get(download_url).content)
        break

    time.sleep(5)

print("Saved upscaled.mp4")
```

```javascript Node.js
import { writeFile } from "node:fs/promises";

const poll = async (queueId, downloadUrl) => {
  while (true) {
    const res = await fetch("https://api.venice.ai/api/v1/video/retrieve", {
      method: "POST",
      headers: {
        "Authorization": "Bearer YOUR_API_KEY",
        "Content-Type": "application/json",
      },
      body: JSON.stringify({ model: "topaz-video-upscale", queue_id: queueId }),
    });
    if (!res.ok) {
      throw new Error(`${res.status}: ${await res.text()}`);
    }

    if (res.headers.get("Content-Type")?.includes("video/mp4")) {
      await writeFile("upscaled.mp4", Buffer.from(await res.arrayBuffer()));
      return;
    }

    const data = await res.json();
    if (data.status === "COMPLETED" && downloadUrl) {
      const video = await fetch(downloadUrl);
      await writeFile("upscaled.mp4", Buffer.from(await video.arrayBuffer()));
      return;
    }

    await new Promise((r) => setTimeout(r, 5000));
  }
};

await poll(queue_id, download_url);
console.log("Saved upscaled.mp4");
```
</CodeGroup>

النتيجة النهائية للترقية هي جسم الاستجابة نفسه، وليست حقلًا في JSON، لذا تحقّق من `Content-Type` قبل التحليل. يطبع مثال cURL نوع المحتوى لكل استجابة: كرّره حتى يطبع `video/mp4`، وعندها يحتوي `upscaled.mp4` على الفيديو. إذا تضمنت استجابة الطابور `download_url`، فإن retrieve يُرجع بدلًا من ذلك JSON يحتوي على `"status": "COMPLETED"`، وتنزّل الملف من ذلك الرابط. راجع [روابط التنزيل الخاصة](/ar/guides/media/video-generation#روابط-التنزيل-الخاصة).

### التنظيف (اختياري)

بعد حفظ ملف MP4، يمكنك استدعاء `/video/complete` لحذف الإخراج المخزّن. لا يُرجع هذا الاستدعاء الفيديو ولا رابطًا.

```bash
curl https://api.venice.ai/api/v1/video/complete \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "topaz-video-upscale", "queue_id": "abc123-def456-..."}'
```

## معاملات API

| الحقل | النوع | مطلوب | الوصف |
|---|---|---|---|
| `model` | string | **نعم** | يجب أن يكون `topaz-video-upscale` |
| `video_url` | string | **نعم** | رابط فيديو الإدخال أو رابط بيانات. الصيغ المدعومة: MP4، MOV، WebM. |
| `upscale_factor` | number | لا | `1` أو `2` (افتراضي) أو `4`. يتحكم في مُضاعف الترقية. |

### معاملات لا تُستخدم لنماذج الترقية

المعاملات التالية **لا تُقبل** لـ `topaz-video-upscale` وستُعيد خطأ إذا قُدِّمت:

| الحقل | السبب |
|---|---|
| `resolution` | استخدم `upscale_factor` بدلًا منه. دقّة الإخراج تعتمد على أبعاد الإدخال. |
| `prompt` | الترقية لا تستخدم تعليمات نصية. تُعيَّن سلسلة فارغة تلقائيًا. |

كذلك يُتجاهل معامل `duration` — إذ يكتشف الخادم المدة مباشرة من ملف الفيديو لأجل دقّة الفوترة.

## التسعير

يستند التسعير إلى **المدة** و**فئة دقّة الإخراج** و**معدل الإطارات**. تُحدَّد فئة دقّة الإخراج بضرب ارتفاع فيديو الإدخال في معامل الترقية.

### فئات دقّة الإخراج

| الفئة | ارتفاع الإخراج | السعر لكل ثانية |
|---|---|---|
| 720p | ≤ 720 بكسل | ~$0.013 |
| 1080p | 721–1080 بكسل | ~$0.025 |
| 4K | > 1080 بكسل | ~$0.10 |

<Note>
مقاطع الفيديو بمعدلات إطارات أعلى من 48fps تكلّف ضعف السعر لكل ثانية.
</Note>

### أمثلة تسعير

| الإدخال | معامل الترقية | الإخراج | المدة | التكلفة التقديرية |
|---|---|---|---|---|
| 480p، 30fps | 2x | 960p (فئة 1080p) | 10 ث | ~$0.25 |
| 720p، 30fps | 2x | 1440p (فئة 4K) | 10 ث | ~$1.00 |
| 1080p، 30fps | 2x | 2160p (فئة 4K) | 30 ث | ~$3.00 |
| 360p، 24fps | 4x | 1440p (فئة 4K) | 10 ث | ~$1.00 |
| 480p، 60fps | 2x | 960p (فئة 1080p) | 10 ث | ~$0.50 |

استخدم [Video Quote API](/api-reference/endpoint/video/quote) للحصول على التسعير الدقيق قبل إرسال المهمة.

### الحصول على عرض سعر

```bash
curl https://api.venice.ai/api/v1/video/quote \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "topaz-video-upscale",
    "video_url": "https://example.com/input.mp4",
    "upscale_factor": 2
  }'
```

`video_url` **مطلوب** لعروض الأسعار على نماذج رفع الدقة — تجلب نقطة نهاية الاقتباس الملف وتكتشف المدة ومعدل الإطارات والارتفاع من البايتات، فلا حاجة لتزويدها. حذفه يعيد `400` مع *"video_url is required for quotes on this model"*.

تتطلب عروض الأسعار لنماذج رفع الدقة مفتاح API. الطلبات التي لا تتضمنه تُعيد `403`.

مرّر قيمة `upscale_factor` نفسها (`1` أو `2` أو `4`) إلى `/video/quote` التي سترسلها إلى `/video/queue`، كي يطابق عرض السعر المهمة. تقبل نقطة نهاية الاقتباس أيضًا `resolution` (`"2x"` أو `"4x"`) كاسم بديل مُهمَل لنماذج رفع الدقة؛ وإذا أُرسل كلاهما، تكون الأولوية لـ `upscale_factor`.

## استكشاف الأخطاء وإصلاحها

| المشكلة | السبب المرجّح | الإصلاح |
|---|---|---|
| `"Use upscale_factor instead of resolution"` | تم تمرير `resolution` في الطلب | أزِل `resolution` واستخدم `upscale_factor` بدلًا منه |
| تكلفة أعلى من المتوقع | فيديو الإدخال بدقّة عالية أو معدل إطارات عالٍ | تحقّق من أبعاد الإدخال عبر نقطة نهاية الاقتباس. إدخال 720p+ مع ترقية 2x يقع في فئة تسعير 4K. |
| تستغرق المهمة وقتًا طويلًا | فيديو كبير أو طويل | الترقية مكثّفة حسابيًا. مقاطع الفيديو الأطول ومعاملات الترقية الأعلى تستغرق وقتًا أطول تناسبيًا. |
| `"Insufficient balance"` | أرصدة الحساب منخفضة جدًا | أضف رصيدًا من [venice.ai/settings/api](https://venice.ai/settings/api?utm_source=venice-api-documentation) |
