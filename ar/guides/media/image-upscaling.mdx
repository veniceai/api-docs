تُحسّن ترقية الصور دقّةَ الصورة الحالية وجودتها البصرية. أرسل صورة إلى `/image/upscale`، واختر عامل التكبير ومستوى إبداع اختياريًا، ويُعيد Venice الصورة المُحسّنة كبيانات ثنائية.

استخدم ترقية الصور عندما تمتلك بالفعل صورة وتريد مخرجًا بدقّة أعلى. استخدم [توليد الصور](/ar/guides/media/image-generation) عندما تحتاج إلى إنشاء صورة من مطالبة، و[تحرير الصور](/ar/guides/media/image-editing) عندما تحتاج إلى تغيير محتوى الصورة.

## الاستخدام الأساسي

<CodeGroup>
```python Python
import base64
import os
from pathlib import Path

import requests

image_base64 = base64.b64encode(Path("input.jpg").read_bytes()).decode("utf-8")

response = requests.post(
    "https://api.venice.ai/api/v1/image/upscale",
    headers={
        "Authorization": f"Bearer {os.environ['VENICE_API_KEY']}",
        "Content-Type": "application/json",
    },
    json={
        "image": image_base64,
        "scale": 2,
        "creativity": 0.01,
    },
)

response.raise_for_status()
Path("upscaled.png").write_bytes(response.content)
```

```javascript Node.js
import { readFile, writeFile } from "node:fs/promises";

const image = await readFile("input.jpg");

const response = await fetch("https://api.venice.ai/api/v1/image/upscale", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.VENICE_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    image: image.toString("base64"),
    scale: 2,
    creativity: 0.01,
  }),
});

if (!response.ok) {
  throw new Error(await response.text());
}

const output = Buffer.from(await response.arrayBuffer());
await writeFile("upscaled.png", output);
```

```bash cURL
IMAGE_BASE64=$(base64 < input.jpg | tr -d '\n')

curl https://api.venice.ai/api/v1/image/upscale \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d "{
    \"image\": \"$IMAGE_BASE64\",
    \"scale\": 2,
    \"creativity\": 0.01
  }" \
  --output upscaled.png
```
</CodeGroup>

يمكنك أيضًا رفع ملف مباشرةً باستخدام `multipart/form-data` بدلًا من ترميزه بـ base64:

```bash cURL (multipart)
curl https://api.venice.ai/api/v1/image/upscale \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -F "image=@input.jpg" \
  -F "scale=2" \
  -F "creativity=0.01" \
  --output upscaled.png
```

أرسل جزء `image` واحدًا فقط في كل طلب. يجب أن يكون حجم الملفات المرفوعة أقل من 25 ميغابايت.

## المعامِلات

| المعامِل | النوع | مطلوب | الوصف |
|-----------|------|----------|-------------|
| `image` | string أو ملف | نعم | الصورة المصدر. أرسلها بترميز base64 داخل JSON، أو ارفع جزء ملف باستخدام `multipart/form-data`. يجب ألا تقل عن 256×256 بكسل. يجب أن يكون حجم الملفات المرفوعة 25 ميغابايت أو أقل؛ والحد الأقصى لأجسام JSON هو 35 ميغابايت. |
| `scale` | number | لا | عامل الترقية بين `2` و`4`. القيمة الافتراضية `2`؛ استخدم `2` أو `4` (القيم الواقعة بينهما مقبولة وتُحتسب بسعر 4x). الحد الأقصى للمخرجات 16,777,216 بكسل (4096×4096): إذا كان التكبير المطلوب سيتجاوز هذا الحد، يُخفّض الخادم عامل التكبير الفعلي تلقائيًا. تُرفض المدخلات التي تبلغ الحد أو تقترب منه برمز `400`، لذا صغّر حجمها أولًا. |
| `creativity` | number | لا | مقدار التفاصيل والملمس الذي تضيفه أداة الترقية. من `0` إلى `0.02`، والقيمة الافتراضية `0.01`. القيم الأعلى تضيف المزيد؛ والقيم الأدنى تبقى أقرب إلى المصدر. تُقصّ القيم الواقعة خارج النطاق إلى أقرب حد. |

<Note>
الاستجابة هي بيانات صورة ثنائية، وليست JSON. اكتب جسم الاستجابة مباشرة إلى ملف أو دفّقه إلى التخزين.
</Note>

## نصائح المدخلات

- ابدأ بأنقى صورة مصدر تمتلكها. تُحسّن الترقية التفاصيل، لكنها لا تستطيع استعادة معلومات غير موجودة أصلًا بشكل كامل.
- استخدم عوامل تكبير معتدلة لسير العمل الإنتاجي. المخرجات الكبيرة جدًا قد تزيد زمن الاستجابة وحجم الملف.
- احتفظ بالصورة الأصلية إذا كنت بحاجة إلى مقارنة الجودة أو إعادة المحاولة بإعدادات مختلفة.
