توليد الصور في Venice متزامن. أرسل موجّهًا إلى `/image/generate` لتتلقى صورتك في الاستجابة ذاتها، إما بصيغة base64 داخل JSON أو كبيانات ثنائية خام عندما تكون `return_binary` بقيمة `true`.

## نقاط النهاية

| نقطة النهاية | الغرض | متى تستخدمها |
|---|---|---|
| `POST /image/generate` | واجهة Venice الأصلية لتوليد الصور | استخدمها للحصول على الدعم الكامل للميزات |
| `GET /image/styles` | قائمة بالأنماط الجاهزة المتاحة | استخدمها قبل إرسال `style_preset` |
| `POST /images/generations` | واجهة توليد صور متوافقة مع OpenAI | استخدمها عند نقل عملاء صور OpenAI الحاليين |

## الخطوة 1: إرسال طلب توليد

تحديد الأبعاد يعتمد على النموذج. بعض النماذج تقبل `width` و`height` صريحَين، وبعضها يكشف عن `aspect_ratio`، ونماذج فئات الدقة تكشف عن `aspect_ratio` بالإضافة إلى قيم `resolution` مثل `1K` أو `2K` أو `4K`.

<Warning>
لم تعد `qwen-image` و `qwen-image-3` و `qwen-image-3-pro` و `qwen-image-2-1-turbo` و `qwen-image-2-1-pro` تقبل `width` أو `height`. إرسال أي منهما يعيد `400` مع *"`width` and `height` are no longer supported for this model. Use `aspect_ratio` instead."* تحقق من `model_spec.constraints` عبر `GET /models?type=image` قبل اختيار حقول الأبعاد.
</Warning>

**مثال على تحديد الأبعاد بالبكسل:**
```bash
POST https://api.venice.ai/api/v1/image/generate
Authorization: Bearer $VENICE_API_KEY
Content-Type: application/json

{
  "model": "venice-sd35",
  "prompt": "A cinematic photo of a gondola passing through a narrow Venice canal at blue hour, warm window lights reflecting on the water",
  "negative_prompt": "blurry, low quality, distorted anatomy, text, watermark",
  "width": 1024,
  "height": 1024,
  "format": "webp"
}
```

**مثال على تحديد الأبعاد بنسبة العرض إلى الارتفاع:**
```bash
POST https://api.venice.ai/api/v1/image/generate
Authorization: Bearer $VENICE_API_KEY
Content-Type: application/json

{
  "model": "qwen-image-2",
  "prompt": "A cinematic photo of a gondola passing through a narrow Venice canal at blue hour",
  "aspect_ratio": "16:9",
  "format": "webp"
}
```

**مثال على تحديد الأبعاد بفئة الدقة:**
```bash
POST https://api.venice.ai/api/v1/image/generate
Authorization: Bearer $VENICE_API_KEY
Content-Type: application/json

{
  "model": "gpt-image-2",
  "prompt": "A cinematic wide shot of a gondola passing through a narrow Venice canal at blue hour",
  "aspect_ratio": "16:9",
  "resolution": "4K",
  "format": "png"
}
```

ينطبق النمط نفسه على نماذج فئات الدقة الأخرى:

```json
{
  "model": "nano-banana-pro",
  "prompt": "A serene canal in Venice at sunset",
  "aspect_ratio": "16:9",
  "resolution": "2K"
}
```

استخدم [نماذج الصور](/ar/models/image) أو [Models API](/ar/api-reference/endpoint/models/list) للتأكد من حقول الأبعاد التي يقبلها كل نموذج.

**الاستجابة (200):**
```json
{
  "id": "generate-image-1234567890",
  "images": [
    "UklGRiIAAABXRUJQVlA4IBYAAAAwAQCdASoQABAAPm..."
  ],
  "timing": {
    "inferenceDuration": 1840,
    "inferencePreprocessingTime": 22,
    "inferenceQueueTime": 31,
    "total": 1893
  }
}
```

تحتوي المصفوفة `images` على بيانات الصورة مرمّزة بـ base64. فُكّ ترميز أول عنصر لحفظ الصورة أو عرضها. القيمة `timing.total` هي إجمالي مدة الطلب بالملي ثانية.

## الخطوة 2: فكّ ترميز الصورة وحفظها

<CodeGroup>
```python Python
import base64
import os
import requests

response = requests.post(
    "https://api.venice.ai/api/v1/image/generate",
    headers={
        "Authorization": f"Bearer {os.environ['VENICE_API_KEY']}",
        "Content-Type": "application/json",
    },
    json={
        "model": "venice-sd35",
        "prompt": "A cinematic photo of a gondola passing through a narrow Venice canal at blue hour, warm window lights reflecting on the water",
        "width": 1024,
        "height": 1024,
        "format": "webp",
    },
)

data = response.json()
image_bytes = base64.b64decode(data["images"][0])

with open("output.webp", "wb") as f:
    f.write(image_bytes)

print(f"Saved image from request {data['id']}")
```

```javascript Node.js
import fs from "fs";

const response = await fetch("https://api.venice.ai/api/v1/image/generate", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.VENICE_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    model: "venice-sd35",
    prompt: "A cinematic photo of a gondola passing through a narrow Venice canal at blue hour, warm window lights reflecting on the water",
    width: 1024,
    height: 1024,
    format: "webp",
  }),
});

const data = await response.json();
const imageBuffer = Buffer.from(data.images[0], "base64");
fs.writeFileSync("output.webp", imageBuffer);

console.log(`Saved image from request ${data.id}`);
```
</CodeGroup>

## الخطوة 3: إرجاع بيانات ثنائية بدلاً من JSON (اختياري)

إذا أردت أن يكون جسم الاستجابة هو ملف الصورة نفسه، فاضبط `return_binary: true`. هذا مفيد عندما تريد بثّ الصورة أو حفظها مباشرة دون الحاجة إلى فك ترميز base64.

```bash
curl https://api.venice.ai/api/v1/image/generate \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -o output.png \
  -d '{
    "model": "qwen-image-2",
    "prompt": "Minimalist poster of a moonlit Venetian bridge in deep blue tones",
    "format": "png",
    "return_binary": true
  }'
```

عندما تكون `return_binary` بقيمة `true`، يكون جسم الاستجابة بيانات `image/jpeg` أو `image/png` أو `image/webp` خام بحسب `format` الذي طلبته.

<Note>
الحقل `variants` مدعوم فقط عندما تكون `return_binary` بقيمة `false`.
</Note>

## الخطوة 4: عرض أنماط الصور المتاحة (اختياري)

إذا أردت استخدام `style_preset`، فاحضر أولًا الأنماط المتاحة من `/image/styles`:

```bash
curl https://api.venice.ai/api/v1/image/styles
```

نقطة النهاية هذه عامة ولا تتطلب مفتاح API.

**الاستجابة (200):**
```json
{
  "object": "list",
  "data": [
    "3D Model",
    "Analog Film",
    "Anime",
    "Cinematic",
    "Digital Art"
  ]
}
```

أسماء الأنماط موجودة داخل `data`، وليس في المستوى الأعلى — اقرأ `response.data` بدلًا من التكرار على كائن الاستجابة مباشرة.

ثم مرّر إحدى تلك القيم إلى طلب التوليد:

```json
{
  "model": "qwen-image-2",
  "prompt": "A futuristic Venice skyline at sunrise",
  "style_preset": "Cinematic"
}
```

استخدم نقطة نهاية الأنماط عندما تريد أسماء الأنماط الجاهزة الدقيقة بدلًا من تخمينها.

## معاملات الطلب

| المعامل | النوع | مطلوب | الافتراضي | الوصف |
|---|---|---|---|---|
| `model` | string | نعم | - | معرّف النموذج المستخدم في التوليد |
| `prompt` | string | نعم | - | ما المطلوب توليده |
| `negative_prompt` | string | لا | - | ما يجب تجنبه في الصورة |
| `width` | integer | لا | `1024` | عرض الإخراج بالبكسل للنماذج المعتمدة على البكسل مثل `venice-sd35`. ترفضه عائلة Qwen Image — انظر الملاحظة أدناه |
| `height` | integer | لا | `1024` | ارتفاع الإخراج بالبكسل للنماذج المعتمدة على البكسل مثل `venice-sd35`. ترفضه عائلة Qwen Image — انظر الملاحظة أدناه |
| `format` | string | لا | `webp` | صيغة الإخراج: `jpeg` أو `png` أو `webp` |
| `variants` | integer | لا | `1` | عدد الصور المراد توليدها (من `1` إلى `4`)، فقط عندما تكون `return_binary` بقيمة `false`. قد يؤدي الرفض الصريح من سياسة المحتوى لدى المزوّد إلى حذف بعض المتغيرات؛ راجع [النتائج الجزئية للمتغيرات](#النتائج-الجزئية-للمتغيرات) |
| `return_binary` | boolean | لا | `false` | إرجاع بايتات الصورة الخام بدلًا من JSON بصيغة base64 |
| `safe_mode` | boolean | لا | `true` | تشويش المحتوى للبالغين عند التفعيل |
| `seed` | integer | لا | عشوائي | أعد استخدام نفس البذرة (seed) لتكرارات أكثر اتساقًا |
| `cfg_scale` | number | لا | يعتمد على النموذج | القيم الأعلى تدفع النموذج لاتباع الموجّه بدقة أكبر |
| `lora_strength` | integer | لا | - | قوة (`0`-`100`) نماذج LoRA الإضافية التي يستخدمها النموذج. راجع [قوة LoRA](#قوة-lora) |
| `style_preset` | string | لا | - | تطبيق نمط جاهز من [Image Styles](/ar/api-reference/endpoint/image/styles) |
| `style_references` | array | لا | - | صور مرجعية للأنماط توجّه الطابع الجمالي للمخرجات. كل عنصر بالشكل `{ "image": <url or base64>, "strength": <0.1-1> }`. للنماذج المدعومة فقط؛ راجع [مراجع الأنماط](#مراجع-الأنماط) |
| `aspect_ratio` | string | شرطي | - | يستخدم في النماذج التي تدعم تحديد الأبعاد بالنسبة، مثل `qwen-image-2` و`gpt-image-2` و`nano-banana-2` و`nano-banana-pro` |
| `resolution` | string | شرطي | - | يستخدم في النماذج التي تدعم فئات دقة مثل `1K` أو `2K` أو `4K` |
| `enable_web_search` | boolean | شرطي | `false` | يسمح للنماذج المدعومة باستخدام معلومات الويب الحالية؛ يضيف تكلفة إضافية |
| `transparent_background` | boolean | لا | `false` | يُعيد صورة PNG أو WebP بقناة شفافية (alpha) حقيقية. يتطلب نموذجًا يحمل `supportsTransparentBackground: true` وقيمة `format` إما `png` أو `webp`. راجع [صور بخلفية شفافة](/ar/guides/media/transparent-backgrounds) |

التحقق من الصحة يعتمد على النموذج. راجع [نماذج الصور](/ar/models/image) و[Models API](/ar/api-reference/endpoint/models/list) قبل الاعتماد على معامل عبر عدة نماذج.

## خيارات خاصة بكل نموذج

### التوليد بدقة عالية

تدعم بعض نماذج الصور `aspect_ratio` دون فئة `resolution` قابلة للاختيار. على سبيل المثال، يقبل `qwen-image-2` نسبة العرض إلى الارتفاع ويربطها بأبعاد إخراج خاصة بالنموذج:

```json
{
  "model": "qwen-image-2",
  "prompt": "Editorial product photo of a luxury watch on black marble, dramatic studio lighting",
  "aspect_ratio": "16:9"
}
```

تدعم نماذج صور أخرى `aspect_ratio` بالإضافة إلى فئة `resolution`. على سبيل المثال، يدعم كل من `gpt-image-2` و`nano-banana-2` و`nano-banana-pro` الفئات `1K` و`2K` و`4K`:

```json
{
  "model": "gpt-image-2",
  "prompt": "Editorial product photo of a luxury watch on black marble, dramatic studio lighting",
  "aspect_ratio": "16:9",
  "resolution": "4K"
}
```

```json
{
  "model": "nano-banana-2",
  "prompt": "Editorial product photo of a luxury watch on black marble, dramatic studio lighting",
  "aspect_ratio": "16:9",
  "resolution": "2K"
}
```

استخدم [نماذج الصور](/ar/models/image) لمعرفة النماذج التي تدعم دقات أعلى وكيفية تسعيرها.

### قوة LoRA

تطبّق بعض نماذج الصور نماذج LoRA إضافية. يحدد `lora_strength` (integer، من `0` إلى `100`) مدى قوة تطبيقها، ولا يؤثر إلا على النماذج التي تستخدمها.

لا تقبل الـ API ملفات LoRA مخصصة، ولا توجد نقطة نهاية تسرد نماذج LoRA التي يستخدمها النموذج. `lora_strength` هو عنصر التحكم الوحيد في LoRA.

### المحتوى للبالغين والوضع الآمن

يتحكّم `safe_mode` فيما إذا كان المحتوى للبالغين في مخرجات التوليد سيُشوَّش أم لا. قيمته الافتراضية `true`، لذا تعود الصور المصنّفة للبالغين مشوَّشة ما لم ترسل `safe_mode: false`:

```json
{
  "model": "lustify-v8",
  "prompt": "…",
  "safe_mode": false
}
```

الصور المخصّصة للبالغين (NSFW) غير المشوَّشة متاحة لكل مستخدمي API. لا تحتاج إلى اشتراك Pro، ولا يؤثر إعداد فلتر المحتوى الناضج في تطبيق Venice على طلبات الصور المُرسَلة عبر API.

بعض نماذج الصور مصمّمة خصيصًا للتوليد الموجّه للبالغين / غير الخاضع للرقابة، وتتلاءم جيدًا مع `safe_mode: false`. من الأمثلة المدرجة في صفحة التسعير: `lustify-sdxl` و`lustify-v7` و`lustify-v8`. راجع [نماذج الصور](/ar/models/image) و[التسعير](/ar/overview/pricing) للاطلاع على القائمة الحالية وتكاليف كل نموذج.

بالنسبة لتحرير الصور الموجودة، فإن نموذج التحرير الافتراضي هو `firered-image-edit`. تختلف سياسات المحتوى حسب نموذج التحرير؛ إذا كنت بحاجة إلى تحرير غير خاضع للرقابة، فاستخدم `qwen-edit-uncensored` عبر [تحرير الصور](/ar/guides/media/image-editing).

عندما يكون `safe_mode` مفعّلًا ويُعيد النموذج مخرجات مشوَّشة أو خاضعة للتعديل، افحص ترويستَي الاستجابة `x-venice-is-blurred` و`x-venice-is-content-violation` إذا كنت بحاجة إلى اكتشاف ذلك برمجيًا.

<Note>
هل تستخدم تطبيقًا تابعًا لجهة خارجية؟ تبقى صور البالغين مشوَّشة ما لم يُرسل التطبيق `safe_mode: false`، أو `moderation: "low"` على نقطة النهاية المتوافقة مع OpenAI (انظر أدناه).
</Note>

### الأنماط الجاهزة (Style Presets)

إذا كان النموذج المختار يدعم ذلك، فإن `style_preset` يتيح لك توجيه المخرجات دون إعادة كتابة الموجّه بأكمله. يمكنك جلب أسماء الأنماط الصالحة من [Image Styles](/ar/api-reference/endpoint/image/styles):

```json
{
  "model": "qwen-image-2",
  "prompt": "A futuristic Venice skyline at sunrise",
  "style_preset": "3D Model"
}
```

راجع [Image Styles](/ar/api-reference/endpoint/image/styles) للاطلاع على قائمة الأنماط الحالية.

### مراجع الأنماط

يذهب `style_references` خطوة أبعد من `style_preset`: فبدلًا من نمط جاهز مسمّى، يوجّه التوليد بناءً على صورة مرجعية واحدة أو أكثر. يحتوي كل عنصر على `image` وقيمة `strength` اختيارية:

```json
{
  "model": "krea-v2-large",
  "prompt": "A quiet Venetian courtyard at golden hour",
  "style_references": [
    {
      "image": "https://example.com/reference-painting.png",
      "strength": 0.5
    }
  ]
}
```

| الحقل | النوع | مطلوب | الوصف |
|---|---|---|---|
| `image` | string | نعم | الصورة المرجعية كعنوان URL يبدأ بـ `http://` أو `https://`، أو سلسلة base64، أو data URI بصيغة base64. يجب أن تكون صورة نقطية (JPEG أو PNG أو WebP أو HEIF أو HEIC أو AVIF)، ولا يمكن أن تكون SVG، ويجب أن يقل حجمها عن 8 MB |
| `strength` | number | لا | مدى قوة توجيه المرجع للمخرجات، من `0.1` إلى `1`. القيمة الافتراضية `0.5`. تتجاهله النماذج التي تكون فيها `supportsStyleReferenceStrength` بقيمة `false` |

يختلف الدعم من نموذج لآخر. تحقّق من `GET /models?type=image`:

- تكون `model_spec.supportsStyleReferences` بقيمة `true` فقط في النماذج التي تقبل هذا الحقل.
- تمثّل `model_spec.constraints.maxStyleReferences` عدد العناصر التي يقبلها النموذج.
- تخبرك `model_spec.constraints.supportsStyleReferenceStrength` بما إذا كان لـ `strength` أي تأثير.

```bash
curl -s "https://api.venice.ai/api/v1/models?type=image" \
  | jq -r '.data[] | select(.model_spec.supportsStyleReferences == true) | "\(.id) max=\(.model_spec.constraints.maxStyleReferences)"'
```

يؤدي إرسال `style_references` إلى نموذج لا يدعمه إلى إرجاع `400`، وكذلك تجاوز الحد الأقصى لذلك النموذج أو إرسال مرجع تالف أو يتعذّر الوصول إليه أو يتجاوز الحجم المسموح. تفرض بعض النماذج رسومًا لمراجع الأنماط عن كل صورة مُرجَعة إضافةً إلى السعر الأساسي للصورة، ومنها مثلًا Krea v2 Large وKrea v2 Medium. لا تُحتسب هذه الرسوم إلا على الصور التي تُرجَع فعلًا. راجع [نماذج الصور](/ar/models/image) للاطلاع على الأسعار الأساسية لكل صورة.

### النتائج الجزئية للمتغيرات

عندما تكون قيمة `variants` أكبر من `1`، قد ترفض سياسة المحتوى لدى المزوّد بعض المتغيرات بينما تنجح البقية. في هذه الحالة تظل نقطة النهاية تُرجع `200` لكن بعدد صور أقل مما طلبت:

- عند حذف متغير واحد أو أكثر، يتضمن جسم JSON الحقل `content_policy_violation_count`، وهو عدد المتغيرات المحذوفة.
- تحمل ترويسة الاستجابة `x-venice-content-violation-count` العدد نفسه.
- تصف `x-venice-is-content-violation` و`x-venice-is-blurred` الصور التي أُرجعت.

إذا رُفضت جميع المتغيرات المطلوبة، فلن تُرجَع أي صور ويفشل الطلب برمز `422` بدلًا من ذلك. لا تفترض أن `len(images) == variants`؛ قارن طول المصفوفة بقيمة `variants`، وتحقّق من `content_policy_violation_count` عند وجوده.

## نقطة النهاية المتوافقة مع OpenAI

إذا كنت تستخدم بالفعل حِزم OpenAI للصور أو لديك تكاملات قائمة مع DALL-E، فإن Venice تدعم أيضًا `POST /images/generations`. توفّر صيغة طلب أبسط ولكن بميزات أقل من نقطة نهاية Venice الأصلية.

**الطلب:**
```json
{
  "model": "z-image-turbo",
  "prompt": "A clean isometric illustration of an AI control room",
  "size": "1024x1024",
  "response_format": "b64_json"
}
```

ينطبق `size` فقط على النماذج المحدَّدة الأبعاد بالبكسل، وهي التي تملك قيمة `widthHeightDivisor` أكبر من `1` في `model_spec.constraints` عبر `GET /models?type=image`. أما معظم النماذج، بما فيها `qwen-image-2`، فتحدّد أبعاد الإخراج بنسبة العرض إلى الارتفاع والدقة بدلًا من ذلك وتتجاهل `size`.

تُقبل بعض معاملات OpenAI لضمان التوافق مع حِزم SDK لكنها تُتجاهل (والمعامل `n` يقتصر على `1`):

| المعامل | السلوك على `/images/generations` |
|---|---|
| `quality` | يُقبل ويُتجاهل. تعتمد الفوترة على فئة الجودة الافتراضية للنموذج |
| `style` | يُقبل ويُتجاهل |
| `output_compression` | يُقبل ويُتجاهل |
| `user` | يُقبل ثم يُهمل، وليس اسمًا بديلًا لـ `anon_user_id` |
| `n` | القيمة `1` فقط مدعومة؛ أما القيم الأخرى فيرفضها التحقق من الصحة |

لا يتوفر التحكم في الفئات على هذا المسار: لا يوجد حقل `resolution` أو `aspect_ratio`، ولا يمكن لـ `quality` رفع التكلفة أو خفضها. بالنسبة إلى نماذج GPT Image ذات الفئات، استخدم نقطة النهاية الأصلية `/image/generate` عندما تحتاج إلى اختيار `quality` أو `resolution` أو `aspect_ratio`.

استخدم المسار المتوافق مع OpenAI لتسريع عمليات الانتقال. واستخدم `/image/generate` عندما تحتاج إلى خيارات خاصة بـ Venice مثل `cfg_scale` أو `style_preset` أو `style_references` أو `variants` أو الاستجابات الثنائية.

### التحكّم في تشويش المحتوى للبالغين على `/images/generations`

لا تقبل نقطة النهاية المتوافقة مع OpenAI المعامل `safe_mode`. إرساله يُعيد `400` مع الرسالة `Unrecognized key(s) in object: 'safe_mode'`. استخدم بدلًا منه معامل `moderation` على طريقة OpenAI:

| القيمة | السلوك |
|---|---|
| `auto` (الافتراضي) | يشوّش المحتوى للبالغين، مثل `safe_mode: true` |
| `low` | يُعيد المخرجات دون تشويش، مثل `safe_mode: false` |

```json
{
  "model": "lustify-v8",
  "prompt": "…",
  "size": "1024x1024",
  "response_format": "b64_json",
  "moderation": "low"
}
```

يعمل `safe_mode` فقط على نقطة النهاية الأصلية `POST /image/generate`. ويعمل `moderation` فقط على نقطة النهاية المتوافقة مع OpenAI `POST /images/generations`.

ينطبق التقسيم نفسه على الشفافية: تستخدم `/image/generate` المعامل `transparent_background: true`، بينما تستخدم `/images/generations` المعامل `background: "transparent"` على طريقة OpenAI. ويتطلب كلاهما صيغة إخراج `png` أو `webp` ونموذجًا يحمل `supportsTransparentBackground: true`. راجع [صور بخلفية شفافة](/ar/guides/media/transparent-backgrounds).

## نصائح للموجّهات (Prompting)

1. ابدأ بالموضوع، ثم أضف الوسيلة والإضاءة والتركيب والمزاج.
2. ضع التفاصيل التي يجب تجنبها في `negative_prompt` بدلًا من إثقال الموجّه الرئيسي.
3. أعد استخدام `seed` أثناء التكرار حتى تتمكن من مقارنة تغييرات الموجّه دون تغيير التركيبة بالكامل.
4. اجعل تحديد الأبعاد متوافقًا مع النموذج. بعض النماذج تستخدم `width`/`height`، والبعض يستخدم `aspect_ratio`، أما نماذج فئات الدقة فتستخدم `aspect_ratio` بالإضافة إلى `resolution`.
5. استخدم `variants` أثناء الاستكشاف، ثم عُد إلى مخرج واحد بمجرد تحديد الاتجاه.

## الأخطاء

| الحالة | المعنى | الإجراء |
|---|---|---|
| `400` | معاملات الطلب غير صالحة | تحقّق من أسماء الحقول وأنواعها والقيود الخاصة بالنموذج |
| `401` | فشل المصادقة أو يتطلب النموذج فئة وصول أعلى | تحقّق من مفتاح API وصلاحية الوصول للنموذج |
| `402` | الرصيد غير كافٍ | أضف رصيدًا عبر [venice.ai/settings/api](https://venice.ai/settings/api?utm_source=venice-api-documentation) |
| `404` | نموذج غير معروف | تحقّق من معرّف النموذج مقابل `GET /models?type=image` |
| `415` | نوع المحتوى غير صالح | أرسل JSON مع `Content-Type: application/json` |
| `422` | انتهاك سياسة المحتوى | رفض المزوّد الموجّه أو الصورة صراحةً. عدّل الموجّه أو بدّل النموذج. يتضمن جسم الاستجابة `error` وقيمة منطقية `retryable`، وقد يتضمن أيضًا `suggested_prompt` و`recommended_model` |
| `429` | تجاوز حد المعدّل أو النموذج محمّل بأقصى طاقته | أعد المحاولة مع تأخير تصاعدي؛ افحص ترويسة `Retry-After` |
| `500` | فشل في معالجة الاستدلال | أعد إرسال الطلب |
| `503` | النموذج بكامل طاقته | أعد المحاولة بعد تأخير قصير |

<Note>
عند تفعيل `safe_mode` (أو عندما تكون قيمة `moderation` هي `auto`)، افحص ترويسات الاستجابة مثل `x-venice-is-blurred` و`x-venice-is-content-violation` إذا كنت بحاجة إلى اكتشاف نتائج الإشراف برمجيًا.
</Note>
