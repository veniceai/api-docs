مُغيّر الصوت هو speech-to-speech: يُعيد تسجيل ملف مصدر بصوتٍ مختلف مع الحفاظ على الأداء والإيقاع والتوقيت. وهو غير متزامن ويستخدم نقاط النهاية الخاصة به، فهو ليس [`/audio/queue`](/ar/api-reference/endpoint/audio/queue)، وليس [تحويل النص إلى كلام](/ar/guides/media/text-to-speech) أو [استنساخ الصوت](/ar/guides/media/voice-cloning).

<Note>
تُخصم تكلفة عملية التحويل الموضوعة في قائمة الانتظار فورًا. احفظ `queue_id` من استجابة قائمة الانتظار قبل أن تفعل أي شيء آخر.
</Note>

## آلية العمل

1. **عرض السعر** - احسب سعر المدة التي تتوقع إرسالها
2. **قائمة الانتظار** - ارفع التسجيل، أو مرّر عنوان URL عامًا
3. **الاستعلام الدوري** - نزّل ملف MP3 عندما يُعيد الاسترجاع الصوت
4. **الإكمال** - احذف الوسائط المُخزَّنة بعد حفظ الملف

| نقطة النهاية | الغرض |
|----------|---------|
| [`POST /audio/voice-changer/quote`](/ar/api-reference/endpoint/audio/voice-changer/quote) | تقدير تكلفة التحويل بالدولار الأمريكي |
| [`POST /audio/voice-changer/queue`](/ar/api-reference/endpoint/audio/voice-changer/queue) | بدء تحويل speech-to-speech |
| [`POST /audio/voice-changer/retrieve`](/ar/api-reference/endpoint/audio/voice-changer/retrieve) | الاستعلام الدوري عن المهمة وتنزيل الصوت المُحوَّل |
| [`POST /audio/voice-changer/complete`](/ar/api-reference/endpoint/audio/voice-changer/complete) | حذف الوسائط المُخزَّنة بعد تنزيلها |

## المتطلبات الأساسية

- مفتاح Venice API لطلبات قائمة الانتظار والاسترجاع والإكمال. لا يستخدم عرض السعر المفتاح.
- تسجيل مصدر بحاوية مُدرجة في `accepted_audio_formats` الخاصة بالنموذج. تتحقق Venice من التوقيع الثنائي للملف، لذا لا يُحدِّد اسم الملف قبوله.
- تسجيل لا يتجاوز طوله `max_source_audio_duration_seconds` الخاص بالنموذج، ولا يزيد حجمه على 25 ميغابايت.
- بالنسبة إلى `audio_url`، عنوان URL من نوع `http` أو `https` يمكن الوصول إليه علنًا. تجلب Venice البايتات بنفسها وتمرر تلك البايتات فقط إلى المزوّد.

عيّن مفتاح API الخاص بك:

```bash
export VENICE_API_KEY="your-api-key"
```

## اختيار نموذج

تُعاد نماذج تغيير الصوت من `GET /models?type=music` مع تعيين `model_spec.voice_changer` على `true`. لا يوجد فلتر `?type=voice-changer`. تصفَّح [نماذج الموسيقى والمؤثرات الصوتية](/ar/models/music) للاطلاع على القائمة الحالية. تستخدم الأمثلة أدناه `elevenlabs-voice-changer`، و`Aria` هو أحد أسماء الأصوات لهذا النموذج. مرّر اسمًا من `voices`، أو احذف `voice` لاستخدام `default_voice`.

```bash
curl "https://api.venice.ai/api/v1/models?type=music" \
  -H "Authorization: Bearer $VENICE_API_KEY" |
  jq '.data[] | select(.model_spec.voice_changer == true) | {
    id,
    voices: .model_spec.voices,
    default_voice: .model_spec.default_voice,
    supports_custom_voice_id: .model_spec.supports_custom_voice_id,
    accepted_audio_formats: .model_spec.accepted_audio_formats,
    max_source_audio_duration_seconds: .model_spec.max_source_audio_duration_seconds,
    supports_background_noise_removal: .model_spec.supports_background_noise_removal,
    supports_seed: .model_spec.supports_seed,
    durations: .model_spec.pricing.durations
  }'
```

راجع بيانات كل نموذج التعريفية قبل تعيين الحقول الاختيارية:

| الحقل | استخدامه لـ |
|-------|------------|
| `voices` / `default_voice` | أسماء الأصوات المستهدفة. احذف `voice` لاستخدام الافتراضي. |
| `supports_custom_voice_id` | ما إذا كان `voice` يقبل أيضًا Voice ID من المزوّد |
| `accepted_audio_formats` | حاويات المصدر التي تقبلها Venice |
| `max_source_audio_duration_seconds` | أطول تسجيل مصدر يقبله النموذج |
| `supports_background_noise_removal` | ما إذا كان `remove_background_noise` مقبولًا |
| `supports_seed` | ما إذا كان `seed` مقبولًا |
| `pricing.durations` | مستويات السعر بالدقيقة الكاملة، ولكل منها `min_seconds` و`max_seconds` و`usd` |

الحقول غير المدعومة تؤدي إلى استجابة HTTP `400`. التسجيلات التي تتجاوز `max_source_audio_duration_seconds` تُرفض بالحالة HTTP `422` قبل أي خصم. يُبلّغ جسم الخطأ عن هذا الحد الأقصى بالصيغة `Source audio must be at most N seconds.`

## 1. احصل على عرض سعر

تُحتسب فوترة مُغيّر الصوت من طول التسجيل المصدر، مقربًا لأعلى إلى الدقيقة الكاملة التالية. المضاعف الدقيق لـ 60 ثانية يبقى في مستوى تلك الدقيقة، وثانية واحدة بعده تنقله إلى المستوى التالي. بالنسبة إلى `elevenlabs-voice-changer`، يُعيد عرض السعر 0.35 دولار لمدة 60 ثانية و0.69 دولار لمدة 61 ثانية. اقرأ `pricing.durations` أو استدعِ عرض السعر للنموذج الذي تستخدمه. يُحتسب المبلغ المخصوم من المدة التي تقيسها Venice عند وضع التسجيل في قائمة الانتظار.

<Note>
لا يتطلب عرض السعر مصادقة، لكن طلبات قائمة الانتظار والاسترجاع والإكمال تتطلبها.
</Note>

```bash
curl https://api.venice.ai/api/v1/audio/voice-changer/quote \
  -H "Content-Type: application/json" \
  -d '{
    "model": "elevenlabs-voice-changer",
    "duration_seconds": 60
  }'
```

تحتوي الاستجابة على التكلفة المقدَّرة بالدولار الأمريكي والمدة التي حُسب عليها عرض السعر:

```json
{
  "quote": 0.35,
  "duration_seconds": 60
}
```

## 2. ضع عملية التحويل في قائمة الانتظار

قدّم التسجيل المصدر بإحدى طريقتين فقط: كرفع `file` عبر multipart، أو كـ `audio_url` في جسم JSON. تقديم الاثنين معًا، أو عدم تقديم أيٍّ منهما، يؤدي إلى الرفض.

يُرفض الملف الذي يحتوي على مسار فيديو. استخرج الصوت وارفعه بدلًا من ذلك. عندما تُمرّر عنوان URL، يجب أن يكون قابلًا للوصول علنًا. تجلب Venice البايتات وتتحقق منها بنفسها، ولا يُمرَّر عنوان URL إلى المزوّد أبدًا.

عند استخدام `curl -F`، لا تعيّن `Content-Type` يدويًا. يضيف `curl` ترويسة `multipart/form-data` والحدّ الفاصل المطلوب. في جسم multipart، أرسل `remove_background_noise` بالقيمة `true` أو `false`، و`seed` كأرقام.

<CodeGroup>
```bash File upload
curl https://api.venice.ai/api/v1/audio/voice-changer/queue \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -F "model=elevenlabs-voice-changer" \
  -F "voice=Aria" \
  -F "file=@./source-recording.mp3"
```

```bash Audio URL
curl https://api.venice.ai/api/v1/audio/voice-changer/queue \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "elevenlabs-voice-changer",
    "voice": "Aria",
    "audio_url": "https://example.com/source-recording.mp3",
    "remove_background_noise": true,
    "seed": 42
  }'
```
</CodeGroup>

لا يُقبل `remove_background_noise` و`seed` إلا عندما يُبلّغ النموذج بدعمهما. احذف `voice` لاستخدام `default_voice`. عندما تكون قيمة `supports_custom_voice_id` هي true، يمكن أن يكون `voice` معرّف Voice ID من المزوّد بدلًا من اسم من `voices`.

يُعيد الطلب الناجح النموذج، ومعرّف قائمة الانتظار، وطول المصدر المقاس:

```json
{
  "model": "elevenlabs-voice-changer",
  "queue_id": "0190f2c4-9c1e-7a3b-8f42-2c9d5e7a1b34",
  "status": "QUEUED",
  "duration_seconds": 52
}
```

احفظ `model` و`queue_id`؛ فالاسترجاع والإكمال يتطلبانهما. قارن `duration_seconds` بعرض السعر لمطابقة التقدير مع الطول الذي جرت فوترته.

<Warning>
ليس من الآمن إعادة محاولة قائمة الانتظار. طلب قائمة الانتظار الناجح تكون تكلفته قد خُصمت بالفعل. إذا كان لديك `queue_id`، فاستعلم به عبر الاسترجاع. أما إذا لم تصل استجابة قائمة الانتظار أبدًا، فليس لديك معرّف للاستعلام به، وقد يؤدي إرسال التسجيل مرة أخرى إلى خصم التكلفة مرة ثانية.
</Warning>

## 3. الاستعلام الدوري والتنزيل

استدعِ `/audio/voice-changer/retrieve` بالقيم المُستلمة من استجابة قائمة الانتظار. يمكن استرجاع `queue_id` لمدة 24 ساعة. المعرّف غير المعروف، أو معرّف حساب آخر، أو المعرّف المشوّه، أو المعرّف منتهي الصلاحية، كلها تُعيد HTTP `400` مع `Request ID is invalid.`

```bash
curl https://api.venice.ai/api/v1/audio/voice-changer/retrieve \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "elevenlabs-voice-changer",
    "queue_id": "0190f2c4-9c1e-7a3b-8f42-2c9d5e7a1b34"
  }' \
  --output response.bin
```

افحص `Content-Type` في الاستجابة:

| Content-Type | المعنى | الإجراء |
|--------------|---------|--------|
| `application/json` | لا يزال التحويل قيد المعالجة | اقرأ حقول التوقيت، وانتظر، ثم استعلم مرة أخرى |
| `audio/mpeg` | اكتمل التحويل | احفظ الجسم الثنائي بامتداد `.mp3` |

تبدو استجابة المعالجة كما يلي:

```json
{
  "status": "PROCESSING",
  "average_execution_time": 10000,
  "execution_duration": 4200
}
```

كلا قيمتَي التوقيت بالميلي ثانية. انتظر مدة الفرق بين `execution_duration` و`average_execution_time` قبل الاستعلام مرة أخرى. تتضمن الاستجابة المكتملة أيضًا `x-venice-audio-format` و`x-venice-audio-duration` (بالثواني) و`x-venice-inference-time` (بالثواني) و`x-venice-model-id` و`x-venice-model-name`.

يُعيد إخفاق المزوّد، وكذلك التحويل الذي لا يصل إلى المزوّد أبدًا (HTTP `504`)، الحقل `credits_refunded` في جسم الخطأ. توضح [واجهة برمجة تطبيقات استرجاع تغيير الصوت](/ar/api-reference/endpoint/audio/voice-changer/retrieve) متى تكون قيمة هذه العلامة false وما الذي ترشدك إليه سلسلة `error`. الاستعلام الدوري مرة أخرى يعيد النتيجة نفسها.

عيّن `delete_media_on_completion` على `true` في الاسترجاع لحذف الوسائط المُخزَّنة في الاستدعاء نفسه الذي يُعيد الصوت. لا يمكن استرجاع الصوت مرة أخرى بعد ذلك. وإلا فاستدعِ [`POST /audio/voice-changer/complete`](/ar/api-reference/endpoint/audio/voice-changer/complete) بعد حفظ الملف. استدعاء الإكمال آمن لأكثر من مرة.

## مثال كامل

يطلب هذا المثال عرض سعر لمدة تقديرية قدرها دقيقة واحدة، ويرفع ملفًا، ويستعلم دوريًا إلى أن يصل الصوت أو تمر خمس دقائق، ثم يحفظ ملف MP3. مهلة الدقائق الخمس مخصّصة للمثال فقط؛ إذ يمكن الاستعلام عن المهمة لمدة 24 ساعة باستخدام `queue_id` المحفوظ.

```python
import os
import time
from pathlib import Path

import requests

BASE_URL = "https://api.venice.ai/api/v1"
HEADERS = {"Authorization": f"Bearer {os.environ['VENICE_API_KEY']}"}
MODEL = "elevenlabs-voice-changer"
# Length you expect to send. The charge uses the length Venice measures.
EXPECTED_DURATION_SECONDS = 60

source = Path("source-recording.mp3")

quote = requests.post(
    f"{BASE_URL}/audio/voice-changer/quote",
    json={"model": MODEL, "duration_seconds": EXPECTED_DURATION_SECONDS},
)
quote.raise_for_status()
print(f"Estimated cost: ${quote.json()['quote']:.2f}")

with source.open("rb") as audio:
    queued = requests.post(
        f"{BASE_URL}/audio/voice-changer/queue",
        headers=HEADERS,
        data={"model": MODEL, "voice": "Aria"},
        files={"file": audio},
    )
queued.raise_for_status()
job = queued.json()
print(f"Queued {job['queue_id']} ({job['duration_seconds']}s billed)")

deadline = time.monotonic() + 5 * 60
while time.monotonic() < deadline:
    result = requests.post(
        f"{BASE_URL}/audio/voice-changer/retrieve",
        headers=HEADERS,
        json={"model": job["model"], "queue_id": job["queue_id"]},
    )
    if not result.ok:
        body = result.json()
        print(body.get("error"))
        if "credits_refunded" in body:
            print(f"credits_refunded: {body['credits_refunded']}")
        raise SystemExit(1)

    content_type = result.headers.get("Content-Type", "").split(";")[0].strip()
    if content_type == "audio/mpeg":
        output = Path("converted-audio.mp3")
        output.write_bytes(result.content)
        print(f"Saved {output}")
        break

    status = result.json()
    if status.get("status") != "PROCESSING":
        print(status)
        raise SystemExit(1)

    remaining_ms = status["average_execution_time"] - status["execution_duration"]
    time.sleep(min(max(remaining_ms / 1000, 1), 15))
else:
    raise SystemExit("Still processing. Poll retrieve again with the saved queue_id.")

requests.post(
    f"{BASE_URL}/audio/voice-changer/complete",
    headers=HEADERS,
    json={"model": job["model"], "queue_id": job["queue_id"]},
).raise_for_status()
```

## معاملات API

### قائمة الانتظار

| الحقل | النوع | مطلوب | الوصف |
|---|---|---|---|
| `model` | string | نعم | معرّف نموذج تغيير الصوت. |
| `file` | file | أحد `file` أو `audio_url` | رفع التسجيل المصدر عبر multipart. لا يُستخدم مع `audio_url`. |
| `audio_url` | string | أحد `file` أو `audio_url` | عنوان URL عام من نوع `http` أو `https` للتسجيل المصدر، في جسم JSON. لا يُستخدم مع `file`. |
| `voice` | string | لا | اسم من `voices`، أو Voice ID من المزوّد عندما تكون قيمة `supports_custom_voice_id` هي true. القيمة الافتراضية `default_voice`. |
| `remove_background_noise` | boolean | لا | إزالة ضوضاء الخلفية قبل التحويل. أرسله فقط عندما يُبلّغ النموذج بدعمه. يقبل multipart القيمة `true` أو `false`. |
| `seed` | integer | لا | عدد صحيح ≥ 0 لنتيجة قابلة للتكرار. أرسله فقط عندما يُبلّغ النموذج بدعمه. |

### الاسترجاع والإكمال

| الحقل | النوع | مطلوب | الافتراضي | الوصف |
|---|---|---|---|---|
| `model` | string | نعم | - | `model` من استجابة قائمة الانتظار. |
| `queue_id` | string | نعم | - | `queue_id` من استجابة قائمة الانتظار. |
| `delete_media_on_completion` | boolean | لا | `false` | في الاسترجاع، احذف الوسائط المُخزَّنة عندما يُعيد هذا الاستدعاء الصوت. |

## الأخطاء الشائعة

النتائج النهائية للاسترجاع، بما فيها `credits_refunded`، موثّقة في [واجهة برمجة تطبيقات استرجاع تغيير الصوت](/ar/api-reference/endpoint/audio/voice-changer/retrieve).

| الحالة | السبب | الحل |
|---|---|---|
| `400` | حقل غير مدعوم، أو صوت غير معروف، أو حاوية غير مقبولة، أو صوت غير قابل للقراءة، أو مسار فيديو، أو `queue_id` غير معروف أو تابع لحساب آخر أو منتهي الصلاحية | راجع البيانات التعريفية للنموذج، وأرسل مصدرًا واحدًا، واستعلم باستخدام `queue_id` المُعاد لحسابك. |
| `401` | مفتاح API غير صالح، أو نموذج مقتصر على مستخدمي Pro | تحقق من المفتاح على [venice.ai/settings/api](https://venice.ai/settings/api). |
| `402` مع `"error": "Authentication required"` | لم يُرسَل مفتاح API | أرسل `Authorization: Bearer $VENICE_API_KEY`. |
| `402` | رصيد غير كافٍ | اشحن رصيدك في Venice. |
| `413` | ملف أكبر من 25 ميغابايت | استخدم ملفًا أصغر. يُرفض قبل أي خصم. |
| `422` | أطول من `max_source_audio_duration_seconds` | قصّر التسجيل. يُبلّغ الجسم عن الحد الأقصى. يُرفض قبل أي خصم. |
| `429` | تجاوز حد المعدل | أعد المحاولة بعد إعادة تعيين نافذة حد المعدل. |
| `503` | النموذج بلغ طاقته القصوى | حاول مرة أخرى لاحقًا. |

## نصائح للإنتاج

- دوّن `queue_id` قبل تحليل بقية استجابة قائمة الانتظار.
- قارن `duration_seconds` المقاس بعرض السعر قبل أن تعدّ التقدير هو المبلغ المخصوم.
- ارفع الملف، أو مرّر عنوان URL عامًا لا يحتاج إلى ترويسات طلب.
- استدعِ الإكمال بعد حفظ ملف MP3 على القرص. يؤدي `delete_media_on_completion: true` في الاسترجاع عملية التنظيف هذه ضمن استدعاء التنزيل.
