Seedance هي عائلة فيديو رائدة متعددة الوسائط على Venice لتوليد الفيديو المدفوع بالنص والصور والمراجع. تشترك **Seedance 2.0** (بالإضافة إلى Fast) و **Seedance 2.5** في نموذج توجيه الـ prompt نفسه في R2V: نقطة نهاية واحدة للمرجع إلى الفيديو تتعامل مع **أربعة تدفقات مميزة** (Reference و Edit و Extend و Stitch) — يُستنتَج التدفق من **شكل الـ prompt الخاص بك**.

يغطي هذا الدليل المتغيرات، والتدفقات الأربعة، و**سياسة وسائط واجهة برمجة التطبيقات العامة**، و**حدود الوسائط المتعددة الخاصة بكل عائلة**، ومعدل بت الإخراج، ووضع المسودة في Seedance 2.5، والتسعير، وأمثلة `curl`.

<Warning>
**الوسائط التي تحتوي على أشخاص غير مدعومة على واجهة Seedance API العامة.** لا تستخدم نماذج `*-basic` العامة إثباتات موافقة (`consents.seedance` / `needs_consent`). قد يتم رفض مثل هذه المدخلات من الطبقات الأعلى كخطأ سياسة محتوى أو خطأ من المزوّد. استخدم تطبيق Venice أو Studio للحصول على مجموعة ميزات Seedance الكاملة.
</Warning>

## المتغيرات {#variants}

| Model ID | المتغير | دقات الإخراج | ملاحظات |
|---|---|---|---|
| `seedance-2-0-text-to-video-basic` | T2V | 480p / 720p / 1080p / **4k** | Prompt نصي فقط |
| `seedance-2-0-image-to-video-basic` | I2V | 480p / 720p / 1080p / **4k** | تثبيت أول إطار (وبشكل اختياري آخر إطار) |
| `seedance-2-0-reference-to-video-basic` | R2V | 480p / 720p / 1080p / **4k** | حتى 9 صور مرجعية + 3 فيديوهات مرجعية + 3 مصادر صوت مرجعية. يشغّل Reference / Edit / Extend / Stitch |
| `seedance-2-0-fast-text-to-video-basic` | Fast T2V | 480p / 720p | مستوى أسرع بجودة أقل (بدون 1080p / 4k) |
| `seedance-2-0-fast-image-to-video-basic` | Fast I2V | 480p / 720p | مستوى أسرع بجودة أقل (بدون 1080p / 4k) |
| `seedance-2-0-fast-reference-to-video-basic` | Fast R2V | 480p / 720p | مستوى أسرع بجودة أقل (بدون 1080p / 4k)؛ نفس مجموعة التدفقات |
| `seedance-2-5-text-to-video-basic` | T2V | 480p / 720p / 1080p | إخراج حتى 30 ثانية؛ صوت أصلي |
| `seedance-2-5-image-to-video-basic` | I2V | 480p / 720p / 1080p | إخراج حتى 30 ثانية؛ تثبيت أول إطار (وبشكل اختياري آخر إطار) |
| `seedance-2-5-reference-to-video-basic` | R2V | 480p / 720p / 1080p | حتى 30 صورة + 10 فيديوهات + 10 مصادر صوت؛ نفس تدفقات Reference / Edit / Extend / Stitch |

جميع المتغيرات غير متزامنة. أرسل عبر `POST /api/v1/video/queue`، ثم استعلم `POST /api/v1/video/retrieve` حتى يصبح جسم الاستجابة `video/mp4`. راجع [توليد الفيديو](/guides/media/video-generation) لتدفق قائمة الانتظار العام.

مرّر `resolution` كواحدة من: `480p` أو `720p` أو `1080p` أو `4k` (أحرف صغيرة). تقبل Seedance **2.0** (غير Fast) الأربعة جميعًا؛ بينما تقبل **2.5** القيم `480p` / `720p` / `1080p`؛ وتقبل **2.0 Fast** القيمتين `480p` / `720p` فقط. اكتشف معرفات النماذج الحية وقدراتها عبر `GET /models?type=video` — لا تُشفّر التوفر بشكل ثابت.

## معدل بت الإخراج {#output-bitrate}

يمكنك ضبط معدل بت ترميز الإخراج على كل نموذج Seedance **2.0** عام (بما في ذلك Fast) و **2.5**. مرّر `bitrate_mode` على `/video/queue` بنفسك — لا يختار Venice ذلك تلقائيًا.

| القيمة | السلوك |
|---|---|
| `standard` | معدل البت الافتراضي. مثل حذف الحقل تمامًا. |
| `high` | ترميز بجودة أعلى وملف أكبر. |

هذا خيار ترميز خاص بقائمة الانتظار فقط: لا يغيّر السعر ولا تكلفة الرموز، ولا يقبل `/video/quote` الحقل `bitrate_mode`. عائلات الفيديو الأخرى (Wan و Kling و LTX وما إلى ذلك) لا تدعم هذا الحقل.

## نموذج "نموذج واحد، أربعة تدفقات" {#the-“one-model-four-workflows”-model}

تستخدم متغيرات المرجع إلى الفيديو (`seedance-2-0-reference-to-video-basic`، وشقيقها Fast، و `seedance-2-5-reference-to-video-basic`) نمط توجيه الـ prompt نفسه. **يستنتج النموذج المهمة من بادئة الـ prompt وشكل مدخلاتك.** لا يوجد حقل `task` أو `workflow` — بناء الـ prompt هو التوجيه.

| التدفق | ما الذي يفعله | بادئة الـ prompt | المدخلات |
|---|---|---|---|
| **Reference** | توليد فيديو جديد باستخدام الملفات المرجعية المرفوعة كمصادر للموضوع / الحركة / الأسلوب / الصوت | `Refer to ... in <Image\|Video\|Audio N> to generate ...` | نص + مرجع صورة أو فيديو واحد على الأقل، بالإضافة إلى مصادر صوت اختيارية (تختلف الأعداد حسب العائلة — راجع الحدود) |
| **Edit** | تعديل فيديو مدخل واحد مع الحفاظ على الباقي | `Strictly edit <Video 1>, changing its ...` | فيديو مدخل واحد + نص (الصور تثبيت اختياري) |
| **Extend** | تمديد للأمام / للخلف لمقطع واحد | `Extend <Video 1>, generate ...` | فيديو مدخل واحد + نص |
| **Stitch** | دمج المقاطع المدخلة مع انتقالات مولّدة تلقائيًا | `<Video 1> + <transition description> + followed by <Video 2> + ...` | فيديوهات مدخلة متعددة + نص (تختلف حدود عدد المقاطع / المدة حسب العائلة) |

**بناء الـ prompt قياسي وحساس لحالة الأحرف**: أقواس زاوية، حرف أول كبير، مسافة واحدة قبل الرقم — `<Video 1>` و `<Image 1>` و `<Audio 1>`.

## أنماط التدفقات {#workflow-patterns}

### تدفق Reference {#reference-workflow}

استخدم الملفات المرجعية المرفوعة كـ**مصادر** — الموضوع، المشهد، الحركة، الأسلوب، جرس الصوت — لتوليد فيديو جديد كليًا.

**أنماط الـ prompt القياسية**:

```
Refer to <Subject N> in <Image N> to generate ...
Refer to the [action | camera scene | style | sound effect] in <Video N> to generate ...
Refer to the [tone | timbre] in <Audio N> to generate ...
```

**أمثلة**:

- `Refer to <Subject 1> in <Image 1> to generate a 5-second clip of the same character riding a horse through snow.`
- `Refer to the camera scene in <Video 1> to generate a similar establishing shot of a futuristic city at dawn.`
- `Refer to <Subject 1> in <Image 1> and use the timbre in <Audio 1> for the narrator describing the scene.` (يجب إقران مصادر الصوت بمرجع صورة أو فيديو واحد على الأقل — يُرفض الصوت وحده)

### تدفق Edit {#edit-workflow}

عدّل فيديو مدخل واحد. **يتم الحفاظ على كل ما لم يُذكر صراحةً في الـ prompt.** استخدم هذا عندما تريد تغييرًا موضعيًا (استبدال الموضوع، تغيير الطقس / اللون، إضافة / إزالة عنصر) بدلًا من فيديو جديد كليًا.

**نمط الـ prompt القياسي**:

```
Strictly edit <Video 1>, changing its [original feature] to [new feature] ...
```

**أنماط فرعية لتحكم أدق**:

```
Add Elements:
  At [timestamp / timing] and [spatial location] of <Video 1>, add [description of intended element].

Remove Elements:
  Remove [element to be deleted] from <Video 1>, keeping the rest of the video content unchanged.

Modify Elements:
  Replace [description of element to be changed] in <Video 1> with [description of intended element].
```

**أمثلة**:

- `Strictly edit <Video 1>, changing its weather from sunny to a heavy rainstorm.`
- `Add snacks such as fried chicken and pizza to the countertop in <Video 1>.`
- `Remove the red car from <Video 1>, keeping the rest of the video content unchanged.`
- `Replace the perfume featured in <Video 1> with the face cream from <Image 1>, with all original motions and camera work preserved.`

المثال الأخير يجمع بين Edit ومرجع صورة — قانوني تمامًا، حيث يستخدم النموذج `<Image 1>` كمصدر بصري للاستبدال.

### نسبة العرض إلى الارتفاع والمدة المتطابقة مع المصدر {#source-matched-aspect-ratio-and-duration}

بالنسبة لتدفقات **edit / extend** في المرجع إلى الفيديو من Seedance، يمكنك أن تطلب من الإخراج أن يتبع المقطع المصدر بدلًا من اختيار نسبة أو مدة ثابتة:

| الحقل | القيم | السلوك |
| --- | --- | --- |
| `aspect_ratio` | `adaptive` أو `auto` | تتطابق نسبة العرض إلى الارتفاع للإخراج مع الفيديو المصدر (Seedance 2.0 و 2.5 R2V) |
| `duration` | `-1` أو `auto` | تتطابق مدة الإخراج مع الفيديو المصدر (Seedance **2.5** R2V edit؛ يجب أن يكون المصدر بين 4 و 30 ثانية) |

المتطلبات:

- **Queue:** أي قيمة متطابقة مع المصدر تتطلب `reference_video_urls`.
- **Quote:** أي قيمة متطابقة مع المصدر تتطلب `reference_video_total_duration`. تُحاسَب المدة المتطابقة مع المصدر بـ `ceil(reference_video_total_duration)` ثانية.
- النسبة والمدة مستقلتان — يمكنك مطابقة إحداهما دون الأخرى.
- بالنسبة لـ **extend**، فضّل `duration` ثابتة (المدة التي تريد توليدها) واختياريًا `aspect_ratio: "adaptive"`. `duration` المتطابقة مع المصدر مخصصة لمهام edit من نوع "نفس مدة المصدر".

### `omni_reference_task_type` (Seedance 2.5 R2V) {#omni_reference_task_type-seedance-2-5-r2v}

يصنّف BytePlus مهام المرجع متعدد الوسائط في Seedance 2.5 على أنها **reference** أو **edit** أو **extend** بناءً على الـ prompt. يمكنك اختياريًا توجيه ذلك التصنيف مسبقًا في `/video/queue` عبر:

| القيمة | المعنى |
| --- | --- |
| `auto` | ترك BytePlus يصنّف بناءً على الـ prompt |
| `reference` | توليد مرجعي متعدد الوسائط (مقطع جديد موجَّه بالمصادر) |
| `edit` | تحرير مقطع موجود (يُقرن بـ `duration: "auto"` / `"-1"` وعادةً `aspect_ratio: "adaptive"`) |
| `extend` | تمديد مقطع موجود (`duration` ثابتة تحدد المدة المراد توليدها؛ عادةً `aspect_ratio: "adaptive"`) |

يُقبل الاسمان المستعاران `editing`→`edit` و `extension`→`extend`. عند حذف القيمة، تستنتجها Venice من الـ prompt إذا كانت `reference_video_urls` موجودة. يجب أن يظل الـ prompt متطابقًا مع النوع المختار — فأي تعارض قد يفشل بشكل غير متزامن.

### تدفق Extend {#extend-workflow}

استمرار مقطع واحد للأمام أو للخلف زمنيًا. **افتراضيًا تُعيد Seedance المحتوى الجديد فقط** — وليس المدخل الأصلي متسلسلًا مع الامتداد. هذا بحكم التصميم، لضمان استمرارية الانتقال؛ إذا كنت تريد الحفاظ على مقطع المدخل بجانب الامتداد، فاذكر ذلك صراحةً:

```
Extend <Video 1>, generate [description of extended content]
Extend <Video 1> backward, [description of extended content]
Extend <Video 1>, start with <Video 1>, then [description of extended content]      ← preserves input at start
Extend <Video 1> backward, [description], and then end with <Video 1>               ← preserves input at end
```

معالجة الانتقال: يستخرج النموذج تلقائيًا إطارات الانتقال للمزج السلس، ولا يُعاد توليد المقاطع الأصلية من فيديو المدخل.

**أمثلة**:

- `Extend <Video 1>, generate a dramatic chase scene through narrow alleys at dusk.`
- `Extend <Video 1> backward, the same character walking toward the camera before the original shot begins.`
- `Extend <Video 1>, start with <Video 1>, then the camera pulls back to reveal a vast landscape.`

### تدفق Stitch (إتمام المسار) {#stitch-workflow-track-completion}

اربط المقاطع المدخلة بانتقالات مولّدة بالذكاء الاصطناعي. احترم حدود المدة المُجمّعة وعدد المقاطع **الخاصة بكل عائلة** في [حدود الإدخال متعدد الوسائط](#حدود-الإدخال-متعدد-الوسائط) (Seedance 2.0: ≤3 مقاطع / ≤15 ثانية مجموع؛ Seedance 2.5: حدود فيديو أعلى).

**نمط الـ prompt القياسي**:

```
<Video 1> + [transition description] + followed by <Video 2> [+ [transition description] + followed by <Video 3>]
```

**أمثلة**:

- `<Video 1> + a smooth seamless cut + followed by <Video 2>`
- `<Video 1>. The moment a leaf falls to the ground, it sets off a special effect of golden particles. A gust of wind blows by, leading into <Video 2>.`
- `<Video 1> + a wisp of smoke transforms into a flock of birds + followed by <Video 2> + a slow dolly-in + followed by <Video 3>`

يقتطع النموذج تلقائيًا المقاطع الرابطة عند نقاط الالتقاء لضمان الاستمرارية.

## صيغة الـ prompt الشاملة {#universal-prompt-formula}

عبر التدفقات الأربعة جميعًا، الصيغة الموصى بها للتأليف هي:

```
Subject + Motion + Environment (Optional)
       + Camera Movement / Cut (Optional)
       + Aesthetic Description (Optional)
       + Audio (Optional)
```

- **Subject + Motion**: الأساس المنطقي — حدّد "مَن" يؤدي "أي فعل"
- **Environment + Aesthetics**: خلفية مكانية، إضاءة، أسلوب بصري
- **Camera**: نوع اللقطة أو الحركة الصريحة
- **Audio**: مؤثرات صوت محيطية أو توجيه صوتي للحصول على إخراج غامر

طبقة هذه الصيغة فوق بادئة تدفق (على سبيل المثال، `Strictly edit <Video 1>, changing its <subject + motion + environment + ...>`) تنتج مخرجات بأعلى جودة.

## حدود الإدخال متعدد الوسائط {#multimodal-input-limits}

القيم أدناه هي ما يقبله Venice API. تُرفض الطلبات خارج هذه النطاقات في طبقة الـ schema بخطأ 400 قبل الوصول إلى الاستدلال.

**تستخدم Seedance 2.0 و Seedance 2.5 حدودًا مختلفة.** تحقق دائمًا من العمود الخاص بعائلة النموذج التي تستدعيها.

### الحدود الدنيا المشتركة للوسائط {#shared-media-floors}

| القيد | القيمة |
|---|---|
| طرق إدخال الصورة / الفيديو / الصوت | URL (`http://`, `https://`) أو Base64 data URL |
| صيغ الصور | `.jpeg`, `.png`, `.webp`, `.bmp`, `.tiff`, `.gif`, `.heic`, `.heif` |
| نسبة العرض إلى الارتفاع للصورة (W / H) | حصريًا `(0.4, 2.5)` |
| الحد الأدنى لجانب الصورة | ≥ 300 بكسل |
| صيغ الفيديو | `.mp4`, `.mov` |
| برامج ترميز الفيديو | H.264 / AVC، H.265 / HEVC |
| برامج ترميز الصوت (في الحاوية) | AAC، MP3 |
| صيغ الصوت (الصوت المرجعي) | `.wav`, `.mp3` |
| حجم الفيديو لكل مقطع | ≤ 50 MB |
| حجم الصوت لكل مقطع | ≤ 15 MB |
| صور I2V للإطار الأول | 1 |
| I2V الإطار الأول + الأخير | 2 |

### مقارنة العائلات {#family-comparison}

| القيد | Seedance 2.0 (+ Fast) | Seedance 2.5 |
|---|---|---|
| مدة الإخراج | 4–15 ثانية | 4–30 ثانية (افتراضي 10) |
| دقات الإخراج | 480p / 720p / 1080p / **4k** (Fast: 480p / 720p فقط) | 480p / 720p / 1080p |
| معدل بت الإخراج (`bitrate_mode`) | `standard` (افتراضي) أو `high` | `standard` (افتراضي) أو `high` |
| صور R2V المرجعية | 1–9 | 1–30 |
| الحد الأقصى لبايتات صورة R2V المرجعية | (حدود الطلب المشتركة) | ≤ 30 MB لكل صورة |
| فيديوهات R2V المرجعية | ≤ 3 | ≤ 10 |
| المدة لكل فيديو مرجعي | `[2, 15]` ثانية | `[2, 30]` ثانية |
| المدة المُجمّعة للفيديو المرجعي | ≤ 15 ثانية | ≤ 30 ثانية |
| مقاطع R2V الصوتية المرجعية | ≤ 3 | ≤ 10 |
| المدة لكل صوت مرجعي | `[2, 15]` ثانية | `[2, 30]` ثانية |
| المدة المُجمّعة للصوت المرجعي | ≤ 15 ثانية | ≤ 30 ثانية |

الصوت المرجعي مدعوم على متغيرات R2V فقط. تُمرَّر كل إدخال إلى النموذج كعنصر محتوى بـ `role: "reference_audio"` يُخاطبه الـ prompt بـ `<Audio 1>` و `<Audio 2>` … — يستخدم النموذج كل مقطع لجرس الصوت أو المؤثرات الصوتية أو الموسيقى الخلفية بناءً على كيفية صياغة الـ prompt له. حقل `audio_url` المفرد القديم يُطابق نفس شكل المحتوى وأصبح الآن مكافئًا لتمرير `reference_audio_urls` بعنصر واحد.

<Warning>
**لا يمكن أن يكون `reference_audio_urls` هو مدخل المرجع الوحيد.** يتطلب النموذج مرجع صورة أو فيديو واحدًا على الأقل بجانب أي مصدر صوت. اقرن `reference_audio_urls` بـ `reference_image_urls` أو `reference_video_urls` — تُرفض الطلبات الصوتية فقط، وكذلك الطلبات التي تقرن الصوت بـ `image_url` أو `video_url` فقط.
</Warning>

### حجم الطلب {#request-size}

تقبل نقطة نهاية قائمة الانتظار أجسام JSON حتى **35 MB**. عناوين URL المضمّنة للبيانات (data URLs) للفيديوهات الكبيرة يمكن أن تتجاوز هذا الحد — بالنسبة لتدفق Stitch متعدد المقاطع بشكل خاص، فضّل عناوين URL على base64 المضمّن.

## وضع المسودة (Seedance 2.5) {#draft-mode-seedance-25}

يمكن لنماذج Seedance 2.5 التي تدعم وضع المسودة، مثل `seedance-2-5-text-to-video-basic`، إنشاء مسودة بدقة 480p ثم ترقيتها لاحقًا إلى 1080p. المسودة والترقية إلى HD طلبان منفصلان ويُحاسَب عليهما بشكل منفصل. استدعِ `POST /api/v1/video/quote` للحصول على سعر كل منهما قبل إدراجه في قائمة الانتظار.

يؤدي إرسال `draft` إلى أي نموذج آخر إلى إرجاع 400 *"This model does not support draft"*. ويؤدي إرسال `draft_task_id` إلى أي نموذج آخر إلى إرجاع 400 *"This model does not support draft_task_id"*.

### إنشاء مسودة {#create-a-draft}

عيّن `draft: true` في `POST /api/v1/video/queue` أو `POST /api/v1/video/quote`. القيمة الافتراضية لـ `resolution` هي `480p`. أي قيمة أخرى تُرجع 400 *"Draft mode requires resolution 480p"*. مسودة مدتها 5 ثوانٍ بنسبة 16:9 أبعادها 854×480.

احصل على عرض سعر المسودة:

```bash
curl -X POST https://api.venice.ai/api/v1/video/quote \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-2-5-text-to-video-basic",
    "duration": "5s",
    "aspect_ratio": "16:9",
    "draft": true
  }'
```

أدرِج المسودة في قائمة الانتظار:

```bash
curl -X POST https://api.venice.ai/api/v1/video/queue \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-2-5-text-to-video-basic",
    "prompt": "A slow aerial push over misty mountains at sunrise, clouds parting, cinematic widescreen framing.",
    "duration": "5s",
    "aspect_ratio": "16:9",
    "draft": true
  }'
```

تتضمن استجابة قائمة الانتظار، واستجابة retrieve أثناء كون الحالة `PROCESSING`، هذه الحقول. `draft_task_id` هو `queue_id` الخاص بالمسودة.

| الحقل | المعنى |
|---|---|
| `is_draft` | `true` للمسودة |
| `draft_task_id` | مرّر هذه القيمة كـ `draft_task_id` في طلب قائمة انتظار لاحق لترقية المسودة |
| `draft_expires_at` | طابع زمني بتنسيق ISO. يمكن ترقية المسودة خلال 7 أيام من إنشائها |
| `can_upgrade_to_hd` | `true` بعد اكتمال المسودة وقبل انتهاء نافذة الأيام السبعة. `false` في استجابة قائمة الانتظار وأثناء استمرار تشغيل المسودة |

استرجع المسودة أثناء تشغيلها:

```bash
curl -X POST https://api.venice.ai/api/v1/video/retrieve \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-2-5-text-to-video-basic",
    "queue_id": "123e4567-e89b-12d3-a456-426614174000"
  }'
```

```json
{
  "status": "PROCESSING",
  "is_draft": true,
  "draft_task_id": "123e4567-e89b-12d3-a456-426614174000",
  "draft_expires_at": "2026-11-18T02:00:00.000Z",
  "can_upgrade_to_hd": false
}
```

تتضمن الاستجابة أيضًا `average_execution_time` و`execution_duration`، كما في أي استجابة retrieve أخرى. `draft_expires_at` هو بعد 7 أيام من إنشاء المسودة. عندما يتحول جسم الاستجابة إلى `video/mp4`، تُرسَل قيم المسودة نفسها كترويسات استجابة: `x-venice-is-draft` و`x-venice-draft-task-id` و`x-venice-draft-expires-at` و`x-venice-can-upgrade-to-hd`. في تلك الاستجابة المكتملة، تكون قيمة `x-venice-can-upgrade-to-hd` هي `true` حتى `draft_expires_at`.

تُحفظ وسائط المسودة حتى انتهاء نافذة الترقية إلى HD، حتى عندما تكون قيمة `delete_media_on_completion` هي `true`.

### ترقية المسودة إلى 1080p {#upgrade-the-draft-to-1080p}

أرسل طلب `POST /api/v1/video/queue` جديدًا مع تعيين `draft_task_id` إلى `queue_id` الخاص بالمسودة. يجب أن تكون المسودة ملكك، وعلى النموذج نفسه، وضمن نافذة الأيام السبعة. القيمة الافتراضية لـ `resolution` هي `1080p`. أي قيمة أخرى تُرجع 400 *"Draft HD upgrade requires resolution 1080p"*.

الحقلان `duration` و`aspect_ratio` اختياريان في الترقية. تتبع البذرة والمدة ونسبة العرض إلى الارتفاع والصوت المسودة. يُتجاهَل أي `duration` أو `aspect_ratio` لا يطابق المسودة، وتُستخدم قيم المسودة. تُتجاهَل مدخلات الوسائط في طلب الترقية. لا يزال `prompt` مطلوبًا. يمكن ترقية المسودة نفسها أكثر من مرة ضمن النافذة. لا ترسل `draft` و`draft_task_id` معًا.

احصل على عرض سعر الترقية إلى HD. يتطلب عرض السعر هذا المصادقة:

```bash
curl -X POST https://api.venice.ai/api/v1/video/quote \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-2-5-text-to-video-basic",
    "draft_task_id": "123e4567-e89b-12d3-a456-426614174000"
  }'
```

أدرِج الترقية في قائمة الانتظار:

```bash
curl -X POST https://api.venice.ai/api/v1/video/queue \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-2-5-text-to-video-basic",
    "prompt": "A slow aerial push over misty mountains at sunrise, clouds parting, cinematic widescreen framing.",
    "draft_task_id": "123e4567-e89b-12d3-a456-426614174000"
  }'
```

لا يُحاسَب على طلب مسودة أو ترقية مرفوض.

## استكشاف الأخطاء وإصلاحها {#troubleshooting}

### `At least one reference is required for this model` {#at-least-one-reference-is-required-for-this-model}

يجب أن تتضمن طلبات المرجع إلى الفيديو واحدًا على الأقل من `reference_image_urls` أو `reference_video_urls` أو `image_references`. التوليد النصي البحت ليس تدفق R2V صالحًا — استخدم معرف نموذج نص إلى فيديو بدلًا من ذلك. `reference_audio_urls` وحده ليس كافيًا (راجع قسم الصوت أعلاه). لاحظ أن `video_references` **غير** مقبول على Seedance — فهو خاص بالنماذج التي تدعم صوتًا لكل مرجع على حدة، وتمريره يعيد *"This model does not support per-reference video entities"*.

### الكثير جدًا من الفيديوهات / الصور المرجعية {#too-many-reference-videos-/-images}

تحدّ Seedance **2.0** R2V بـ**9 صور** و**3 فيديوهات**. ترفع Seedance **2.5** تلك الحدود إلى **30 صورة** و**10 فيديوهات**. إذا تجاوزت حد العائلة، قلّص المدخلات أو ادمج أولًا خارج الاتصال.

### أخطاء المدة / المدة المُجمّعة {#duration-/-aggregate-duration-errors}

- **2.0:** فيديو / صوت مرجعي لكل مقطع `[2, 15]` ثانية؛ فيديو / صوت مُجمّع ≤ 15 ثانية؛ إخراج 4–15 ثانية.
- **2.5:** فيديو / صوت مرجعي لكل مقطع `[2, 30]` ثانية؛ فيديو / صوت مُجمّع ≤ 30 ثانية؛ إخراج 4–30 ثانية.
- **المدة المتطابقة مع المصدر** (`-1` / `auto` في Seedance 2.5): يجب أن يكون المقطع المصدر بين 4 و 30 ثانية، ويُطلب `reference_video_urls` (queue) أو `reference_video_total_duration` (quote).

قلّص المقاطع من جانب العميل قبل الإرسال.

### الـ prompt يوجّه إلى التدفق الخطأ {#prompt-routes-to-the-wrong-workflow}

يُستنتَج التدفق من بناء الـ prompt. حالات التوجيه الخاطئ الشائعة:

- تريد **Extend** لكنك تكتب `Refer to ...` → يعامل النموذج فيديوك كـ*مصدر*، وليس كخلفية للاستمرار
- تريد **Stitch** لكنك تكتب `Refer to ...` → يختار النموذج واحدًا كمصدر، ويتجاهل الآخرين
- تريد **Edit** لكنك تكتب `Generate a video based on <Video 1>` → غامض؛ قد يعود النموذج افتراضيًا إلى Reference

استخدم البادئات القياسية كما هي مكتوبة تمامًا: `Strictly edit <Video 1>, ...`، `Extend <Video 1>, ...`، `<Video 1> + ... + followed by <Video 2>`.

### الوسائط التي تحتوي على أشخاص غير مدعومة {#unsupported-person-bearing-media}

لا تُشغّل نماذج Seedance API العامة تدفق إثبات موافقة (`consents.seedance` / `needs_consent`). قد تفشل الوسائط التي تحتوي على أشخاص يمكن اكتشافهم بخطأ سياسة محتوى أو خطأ من المزوّد. استخدم تطبيق Venice أو Studio بدلًا من ذلك.

### عرض السعر لا يطابق المبلغ المُدرَج في قائمة الانتظار {#quote-doesn’t-match-the-queued-amount}

إذا أدرجت فيديو مرجعيًا ولكنك لم تمرّر `reference_video_total_duration` إلى `/video/quote`، فقد يختلف عرض السعر عن المبلغ المُدرَج في قائمة الانتظار. مرّر دائمًا `reference_video_total_duration` (مجموع مدد جميع المقاطع المرجعية بالثواني) عندما تكون الفيديوهات المرجعية موجودة.

### وضع المسودة {#draft-mode}

تُرجع هذه الطلبات 400 ولا يُحاسَب عليها. راجع [وضع المسودة (Seedance 2.5)](#draft-mode-seedance-25).

- `draft` على نموذج لا يدعمه: *"This model does not support draft"*
- `draft_task_id` على نموذج لا يدعمه: *"This model does not support draft_task_id"*
- `draft` و`draft_task_id` معًا: *"draft cannot be combined with draft_task_id"*
- `draft_task_id` ليس UUID: *"draft_task_id must be a valid queue_id"*
- معرّف غير معروف أو غير متاح: *"Draft queue id was not found or is no longer available."*
- queue id ليس مسودة Seedance 2.5: *"Only a Seedance 2.5 draft can be upgraded to HD."*
- نموذج مختلف عن نموذج المسودة: *"Draft HD upgrade must use the same model as the draft."*
- المسودة لا تزال قيد الإنشاء: *"Draft has not finished generating. Wait until it completes, then upgrade to HD."*
- المسودة لم يقبلها المزوّد بعد: *"Draft is still submitting. Wait until the draft task is accepted before upgrading."*
- أقدم من 7 أيام: *"Draft expired. Draft task IDs are valid for 7 days from creation."*
- `resolution` للمسودة غير `480p`: *"Draft mode requires resolution 480p"*
- `resolution` للترقية غير `1080p`: *"Draft HD upgrade requires resolution 1080p"*
