يُعدّ Venice AI **بديلاً جاهزاً (drop-in)** لـ OpenAI. نفس SDK ونفس الكود — ما عليك سوى تغيير سطرين. احصل على استدلال يعطي الأولوية للخصوصية، ونماذج بدون رقابة، وتسعير تنافسي.

## الانتقال في سطرين

<CodeGroup>
```python Python
# قبل (OpenAI)
from openai import OpenAI
client = OpenAI()

# بعد (Venice) — غيّر api_key و base_url
from openai import OpenAI
client = OpenAI(
    api_key="your-venice-api-key",           # ← التغيير 1
    base_url="https://api.venice.ai/api/v1",  # ← التغيير 2
)
```

```javascript Node.js
// قبل (OpenAI)
import OpenAI from "openai";
const client = new OpenAI();

// بعد (Venice)
import OpenAI from "openai";
const client = new OpenAI({
  apiKey: "your-venice-api-key",
  baseURL: "https://api.venice.ai/api/v1",
});
```

```bash cURL
# قبل
curl https://api.openai.com/v1/chat/completions ...

# بعد — فقط غيّر عنوان URL والمفتاح
curl https://api.venice.ai/api/v1/chat/completions ...
```
</CodeGroup>

أنشئ مفتاحاً من [venice.ai/settings/api](https://venice.ai/settings/api) أو اتّبع [دليل مفتاح API](/guides/getting-started/generating-api-key).

### متغيرات البيئة

```bash
# قبل
OPENAI_API_KEY=sk-...
OPENAI_BASE_URL=https://api.openai.com/v1

# بعد
OPENAI_API_KEY=your-venice-api-key
OPENAI_BASE_URL=https://api.venice.ai/api/v1
```

<Tip>
تقرأ كثير من المكتبات والأدوات المتغيرين `OPENAI_API_KEY` و`OPENAI_BASE_URL` تلقائياً. قد يكفي تحديث متغيرات البيئة هذه فقط. لا تزال بعض الأدوات تستخدم `OPENAI_API_BASE` للإشارة إلى نفس عنوان URL.
</Tip>

## النماذج

مرّر معرّف نموذج Venice، أو سمة (trait) مثل `default` أو `most_uncensored`، أو اسماً مألوفاً بأسلوب OpenAI. تقوم Venice بربط أسماء OpenAI عبر [ربط التوافق](/api-reference/endpoint/models/compatibility_mapping). أما السمات فتُحلّ دائماً إلى النموذج الحالي الذي يؤدي هذا الدور — انظر [سمات النماذج](/api-reference/endpoint/models/traits).

تصفّح الكتالوج الحيّ في [نماذج النصوص](/models/text) و[التسعير](/overview/pricing). لجولة إرشادية عبر أول طلب، راجع [البدء السريع](/getting-started/quick-start).

## ميزات حصرية لـ Venice

مرّر الخيارات الخاصة بـ Venice عبر `extra_body` بوصفها `venice_parameters`. البحث المدمج على الويب هو عادةً أول إضافة تحتاجها:

```python
response = client.chat.completions.create(
    model="default",
    messages=[{"role": "user", "content": "Latest AI news today"}],
    extra_body={
        "venice_parameters": {
            "enable_web_search": "auto"
        }
    },
)
```

يغطي النمط نفسه الزحف على الويب (web scraping) والاقتباسات و[الشخصيات](/guides/features/characters). إذا كان العميل لا يستطيع تغيير جسم الطلب، أضف [لاحقة ميزة النموذج](/api-reference/endpoint/chat/model_feature_suffix) مثل `default:enable_web_search=auto`.

كما تمتلك Venice واجهات API أصلية لـ[الفيديو](/guides/media/video-generation) و[الموسيقى](/guides/media/music-and-sound-effects) و[استرجاع الويب](/guides/tools/web-retrieval) و[x402](/guides/integrations/x402-venice-api) إلى جانب الواجهة المتوافقة مع OpenAI.

## النماذج بدون رقابة

نماذج Venice الخاصة بدون رقابة لا تطبّق أي تصفية للمحتوى، مما يجعلها مناسبة لـ:

- الكتابة الإبداعية بدون قيود
- أبحاث الأمن والاختبار الهجومي (red teaming)
- التحليل الصادق بدون أنماط الرفض
- المعلومات الطبية والقانونية بدون إخلاءات مسؤولية إضافية

استخدم السمة `most_uncensored` أو معرّف نموذج حالي بدون رقابة من [نماذج النصوص](/models/text).
