إذا حذفت معامل الاستعلام `type`، فستتضمن الاستجابة نماذج النصوص فقط. مرّر `type=all` لإرجاع كتالوج النماذج الكامل.

## قراءة إدخال نموذج {#reading-a-model-entry}

أرسل `id` الخاص بالنموذج كمعامل `model`. معظم ما تُرشّح عليه موجود تحت `model_spec`:

| الحقل | ما يخبرك به |
| --- | --- |
| `type` | نقطة النهاية التي يخدمها النموذج: `text` لإكمالات الدردشة، أو `image` و`video` و`tts` و`asr` و`embedding` وغيرها |
| `model_spec.capabilities` | ما يدعمه نموذج النص، مثل `supportsFunctionCalling` و`supportsVision` و`supportsReasoning` و`supportsResponseSchema` و`supportsWebSearch` و`supportsE2EE` |
| `model_spec.availableContextTokens` | نافذة السياق بالتوكنات |
| `model_spec.pricing` | الأسعار بالدولار الأمريكي وDIEM: لكل 1M توكن لنماذج النص، ولكل وحدة لنماذج الوسائط |
| `model_spec.privacy` | `private` أو `anonymized`. نماذج E2EE وTEE تكون `private` وتضبط `supportsE2EE` أو `supportsTeeAttestation` |
| `model_spec.constraints` | قيم المعاملات التي يقبلها النموذج، مثل نسب الأبعاد ومدد الفيديو ومستويات الجودة |
| `model_spec.traits` | الأدوار التي يشغلها النموذج، مثل `default` أو `fastest` |
| `model_spec.deprecation` | يظهر عندما يكون النموذج قيد الإيقاف، مع تاريخ إزالته و`replacementModelId` الخاص به عند وجوده |

لاختيار نموذج حسب الدور بدلًا من المعرّف، استدعِ [`GET /models/traits`](/ar/api-reference/endpoint/models/traits). لتصفح النماذج ومقارنتها، راجع صفحات [النماذج](/ar/models/overview).

## التسعير حسب مستوى الجودة

لنماذج الصور التي تقبل معامل `quality` الاختياري، تكشف الاستجابة عن مصفوفة أسعار لكل جودة ضمن `model_spec.pricing.quality`. كل مفتاح من المستوى الأعلى هو مستوى دقة (`1K` أو `2K` أو `4K`)، وكل مفتاح متداخل هو مستوى جودة (`low` أو `medium` أو `high`) يحمل سعره الخاص بـ `usd` و `diem`:

```json
"pricing": {
  "resolutions": {
    "1K": { "usd": 0.27, "diem": 0.27 },
    "2K": { "usd": 0.51, "diem": 0.51 },
    "4K": { "usd": 0.84, "diem": 0.84 }
  },
  "quality": {
    "1K": {
      "low":    { "usd": 0.02, "diem": 0.02 },
      "medium": { "usd": 0.07, "diem": 0.07 },
      "high":   { "usd": 0.26, "diem": 0.26 }
    },
    "2K": {
      "low":    { "usd": 0.03, "diem": 0.03 },
      "medium": { "usd": 0.13, "diem": 0.13 },
      "high":   { "usd": 0.50, "diem": 0.50 }
    },
    "4K": {
      "low":    { "usd": 0.05, "diem": 0.05 },
      "medium": { "usd": 0.21, "diem": 0.21 },
      "high":   { "usd": 0.83, "diem": 0.83 }
    }
  }
}
```

`pricing.resolutions` هو الجدول القديم لكل صورة المُحتفَظ به للتوافق الخلفي. `pricing.quality` هو مصفوفة لكل (الدقة، الجودة) تنطبق متى كان المعامل `quality` مدعومًا. يتم الاحتفاظ بكلا الحقلين في الاستجابة حتى يتمكن العملاء من اكتشاف دعم الجودة وإظهار المصفوفة في واجهات المستخدم الخاصة بهم.
