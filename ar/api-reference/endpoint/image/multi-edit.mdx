## حدود الصور المدخلة

يعتمد الحد الأقصى لعدد الصور المدخلة على النموذج. اقرأ `model_spec.constraints.maxInputImages` من [`GET /models?type=inpaint`](/ar/api-reference/endpoint/models/list). عند غياب هذا الحقل، يكون الحد 3، أو 1 عندما تكون قيمة `combineImages` هي `false`.

## مستويات الجودة

تقبل بعض نماذج التحرير المتعدد معاملًا اختياريًا `quality` (`low` أو `medium` أو `high`) يوازن بين دقة الصورة المرئية والتكلفة. النماذج التي تُدرج `qualities` في `model_spec.constraints` من [`GET /models?type=inpaint`](/ar/api-reference/endpoint/models/list) تقبل تلك القيم فقط، وبعضها يدعم مجموعة فرعية فقط مثل `low` و `medium`. تتجاهل النماذج الأخرى المعامل.

```json
{
  "modelId": "gpt-image-2-edit",
  "images": ["iVBORw0KGgo...", "iVBORw0KGgo..."],
  "prompt": "blend the two scenes into one cinematic frame",
  "resolution": "2K",
  "quality": "medium"
}
```

عند حذف `quality`، يستخدم النموذج مستواه الافتراضي (`high` لـ `gpt-image-2-edit`). توجد الأسعار لكل مستوى (1K/2K/4K × low/medium/high) ضمن `model_spec.pricing.quality` في [endpoint النماذج](/ar/api-reference/endpoint/models/list) ومذكورة في [نظرة عامة على التسعير](/ar/overview/pricing).

<Info>
التسعير المُدرِك للجودة هو الإعداد الافتراضي لجميع مستدعي API و SDK — لا يلزم header للموافقة. يتم احتساب الطلبات التي تحذف `quality` بالسعر الافتراضي للنموذج (`high` لـ `gpt-image-2-edit`).
</Info>
