## حفظ الصورة المعدّلة {#save-the-edited-image}

جسم الاستجابة هو الصورة المعدّلة نفسها وليس JSON، لذا اكتبه في ملف بدلًا من تحليله:

```bash
curl https://api.venice.ai/api/v1/image/edit \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "Turn the scene into a snowy winter evening", "image": "https://venice.ai/samples/gpt-image-2-6-flare/hero.webp"}' \
  --output edited.png
```

يقبل `image` أيضًا سلسلة base64 أو رفع ملف multipart. يشرح [دليل تحرير الصور](/ar/guides/media/image-editing) التحرير بعدة صور وإزالة الخلفية واختيار النموذج.

## مستويات الجودة

لا يقبل `/image/edit` المعامل `quality`، وإرساله يُعيد `400`. تُحتسب عمليات التحرير على هذا الـ endpoint بالمستوى الافتراضي للنموذج (`high` لـ `gpt-image-2-edit`).

لاختيار مستوى (`low` أو `medium` أو `high`)، استخدم [`/image/multi-edit`](/ar/api-reference/endpoint/image/multi-edit)، الذي يقبل `quality` على النماذج التي تدعمه. توجد الأسعار لكل مستوى (1K/2K/4K × low/medium/high) ضمن `model_spec.pricing.quality` في [endpoint النماذج](/ar/api-reference/endpoint/models/list) ومذكورة في [نماذج الصور](/ar/models/image).
