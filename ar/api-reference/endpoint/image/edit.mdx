<Info>
**التسعير:** يختلف تسعير تحرير الصور حسب النموذج. النموذج الافتراضي (`qwen-edit`) هو **$0.04 لكل عملية تحرير**. راجع [endpoint النماذج](/api-reference/endpoint/models/list) لجميع نماذج التحرير المتاحة وتسعيرها.
</Info>

## مستويات الجودة

لا يقبل `/image/edit` المعامل `quality`، وإرساله يُعيد `400`. تُحتسب عمليات التحرير على هذا الـ endpoint بالمستوى الافتراضي للنموذج (`high` لـ `gpt-image-2-edit`).

لاختيار مستوى (`low` أو `medium` أو `high`)، استخدم [`/image/multi-edit`](/api-reference/endpoint/image/multi-edit)، الذي يقبل `quality` على النماذج التي تدعمه. توجد الأسعار لكل مستوى (1K/2K/4K × low/medium/high) ضمن `model_spec.pricing.quality` في [endpoint النماذج](/api-reference/endpoint/models/list) ومذكورة في [نظرة عامة على التسعير](/overview/pricing).
