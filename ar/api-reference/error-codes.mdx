عند حدوث خطأ، تُعيد Venice API رمز حالة HTTP ورسالة وصفية. تتضمن بعض الأخطاء أيضًا حقولًا إضافية، مثل حالة الاسترداد، أو النماذج المقترحة لإعادة المحاولة، أو تفاصيل التحقق، أو معرّفات الطلب.

## صيغة استجابة الخطأ

تُعيد معظم الأخطاء حقل `error` مع رسالة قابلة للقراءة من قِبَل الإنسان:

```json
{
  "error": "Invalid request parameters"
}
```

تتضمن بعض endpoints حقولًا إضافية خاصة بالـ endpoint. على سبيل المثال، يمكن أن تتضمن أخطاء التحكم بمحتوى الفيديو ما إذا تم استرداد الاعتمادات:

```json
{
  "error": "Your generation was blocked due to the model provider's content policies. Credits have been refunded.",
  "credits_refunded": true
}
```

قد تتضمن أخطاء التحقق حقلي `details` و `issues` مع معلومات التحقق على مستوى الحقل:

```json
{
  "error": "Invalid request parameters",
  "details": {
    "_errors": [],
    "field": {
      "_errors": ["Field is required"]
    }
  },
  "issues": []
}
```

قد تُعيد بعض endpoints المتوافقة مع OpenAI كائنات أخطاء بأسلوب OpenAI لحالات محددة، مثل أخطاء طول السياق:

```json
{
  "error": {
    "message": "Your request exceeds the model's maximum context. Please reduce your prompt or completion length.",
    "type": "invalid_request_error",
    "param": "messages",
    "code": "context_length_exceeded"
  }
}
```

## بيانات الاعتماد المفقودة

يُرجع الطلب الذي لا يتضمن بيانات اعتماد `402 Payment Required`، وليس `401`. تقبل كل المسارات المدفوعة أيضًا [مصادقة المحفظة عبر x402](/ar/guides/integrations/x402-venice-api)، لذا تكون الاستجابة تحدّيًا للدفع: فهي تتضمن ترويسة `PAYMENT-REQUIRED` ونصًا يصف طريقتي المصادقة.

```json
{
  "x402Version": 2,
  "error": "Authentication required",
  "accepts": [ ... ],
  "authOptions": {
    "apiKey": {
      "header": "Authorization: Bearer YOUR_API_KEY",
      "getKey": "https://venice.ai/settings/api"
    },
    "x402Wallet": {
      "header": "SIGN-IN-WITH-X",
      "topUp": "POST /api/v1/x402/top-up"
    }
  }
}
```

إذا كنت تقصد استخدام مفتاح API، فتحقق من تعيين ترويسة `Authorization: Bearer`. يُرجع المفتاح الموجود ولكن غير الصالح `401`.

## أخطاء تنسيق الطلب

تصدر هذه الأخطاء عند قراءة جسم الطلب، قبل تشغيل أي تحقق خاص بنقطة النهاية.

| حالة HTTP | الرسالة | السبب |
| --- | --- | --- |
| 400 | `'Content-Type' must be 'application/json'` | جسم طلب `POST` أو `PUT` أو `PATCH` أُرسل دون `Content-Type: application/json`. تقبل نقاط النهاية التي تستقبل رفع الملفات أيضًا `multipart/form-data` |
| 400 | `Invalid JSON request` | الجسم ليس JSON صالحًا |
| 400 | `Invalid multipart request: malformed part header` | جسم `multipart/form-data` يتعذّر تحليله |
| 413 | `Request body exceeds the maximum allowed size.` | جسم الطلب كبير جدًا |
| 415 | `Request encoding is not supported` | قيمة `Content-Encoding` أو ترميز أحرف (charset) لا تستطيع الواجهة فك ترميزه |

تُرجع قيمة `Content-Type` الخاطئة `400`، وليس `415`. تتضمن استجابات `413` الخاصة بحدّ الحجم أيضًا الحقل `code`:

```json
{
  "code": "PAYLOAD_TOO_LARGE",
  "error": "Request body exceeds the maximum allowed size."
}
```

## أخطاء أخرى

الجدول أعلاه ليس شاملًا. تُرجَع بعض الأخطاء دون رمز مدرج، وقد تختلف الرسائل حسب النموذج ونقطة النهاية، لذا اعتمد في التفريع على حالة HTTP بدلًا من نص الرسالة. أخطاء قد تواجهها وليست في الجدول:

| حالة HTTP | متى يحدث |
| --- | --- |
| 400 | صورة مُدخلة في طلب chat أو Responses بتنسيق غير مدعوم |
| 400 | الصوت المطلوب غير متاح لنموذج تحويل النص إلى كلام |
| 403 | الطلب صادر من عنوان IP غير موجود في قائمة السماح الخاصة بمفتاح API |
| 403 | النموذج المطلوب غير مسموح به وفق إعداد الخصوصية لمفتاح API |
| 403 | الوصول إلى النموذج المطلوب مقيّد. تواصل مع support@venice.ai |
| 409 | نتيجة فيديو أو موسيقى أو مغيّر صوت لا تزال قيد الرفع عند استرجاعها. أعد المحاولة بعد قليل |
| 410 | تم إيقاف نقطة النهاية |
| 422 | الصوت طويل جدًا أو قصير جدًا (استنساخ الصوت، ومغيّر الصوت، ومهام الصوت) |
| 422 | نسبة العرض إلى الارتفاع للصورة المُدخلة في طلب فيديو خارج النطاق الذي يقبله النموذج |
| 422 | تم حظر مُدخل طلب فيديو بواسطة الإشراف على المحتوى |
| 500 | فشل توليد الفيديو أو مغيّر الصوت |
| 502 | فشل تركيب الكلام في المصدر (upstream)، أو تعذّر استرجاع فيديو مُولَّد. أعد إرسال الطلب |
