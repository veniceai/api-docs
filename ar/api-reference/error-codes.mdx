عند حدوث خطأ، تُعيد Venice API رمز حالة HTTP ورسالة وصفية. تتضمن بعض الأخطاء أيضًا حقولًا إضافية، مثل حالة الاسترداد، أو النماذج المقترحة لإعادة المحاولة، أو تفاصيل التحقق، أو معرّفات الطلب.

## صيغة استجابة الخطأ

تُعيد معظم الأخطاء حقل `error` مع رسالة قابلة للقراءة من قِبَل الإنسان:

```json
{
  "error": "Invalid request parameters"
}
```

تتضمن بعض endpoints حقولًا إضافية خاصة بالـ endpoint. على سبيل المثال، يمكن أن تتضمن أخطاء التحكم بمحتوى الفيديو ما إذا تم استرداد الاعتمادات:

```json
{
  "error": "Your generation was blocked due to the model provider's content policies. Credits have been refunded.",
  "credits_refunded": true
}
```

قد تتضمن أخطاء التحقق حقلي `details` و `issues` مع معلومات التحقق على مستوى الحقل:

```json
{
  "error": "Invalid request parameters",
  "details": {
    "_errors": [],
    "field": {
      "_errors": ["Field is required"]
    }
  },
  "issues": []
}
```

قد تُعيد بعض endpoints المتوافقة مع OpenAI كائنات أخطاء بأسلوب OpenAI لحالات محددة، مثل أخطاء طول السياق:

```json
{
  "error": {
    "message": "Your request exceeds the model's maximum context. Please reduce your prompt or completion length.",
    "type": "invalid_request_error",
    "param": "messages",
    "code": "context_length_exceeded"
  }
}
```

## بيانات الاعتماد المفقودة

يُرجع الطلب الذي لا يتضمن بيانات اعتماد `402 Payment Required`، وليس `401`. تقبل معظم المسارات المدفوعة أيضًا [مصادقة المحفظة عبر x402](/ar/guides/integrations/x402-venice-api)، لذا تكون الاستجابة تحدّيًا للدفع: فهي تتضمن ترويسة `PAYMENT-REQUIRED` ونصًا يصف طريقتي المصادقة. ترسل مسارات الفيديو ومغيّر الصوت التحدّي نفسه، لكنها لا تقبل حاليًا إلا مفتاح API.

```json
{
  "x402Version": 2,
  "error": "Authentication required",
  "accepts": [ ... ],
  "authOptions": {
    "apiKey": {
      "header": "Authorization: Bearer YOUR_API_KEY",
      "getKey": "https://venice.ai/settings/api"
    },
    "x402Wallet": {
      "header": "SIGN-IN-WITH-X",
      "topUp": "POST /api/v1/x402/top-up"
    }
  }
}
```

إذا فاجأك `402` على مسار مدفوع، فالسبب عادةً ترويسة بيانات اعتماد مفقودة وليس مشكلة في الفوترة. يعني النص الذي يحتوي على `x402Version` و`accepts` أن شيئاً لم يصادق الطلب: عيّن `Authorization: Bearer $VENICE_API_KEY` وأعد المحاولة. يوضح الحقل `authOptions.apiKey.header` في النص شكل الترويسة بالضبط.

أما `402` الذي يقول "Insufficient USD or Diem balance" (`INSUFFICIENT_BALANCE` في الجدول أدناه) فمختلف: سببه رصيد الحساب. راجع [الدفع مقابل الاستخدام](/pricing#paying-for-usage).

يُرجع المفتاح الموجود ولكن غير الصالح `401`.

## أخطاء تنسيق الطلب

تصدر هذه الأخطاء عند قراءة جسم الطلب، قبل تشغيل أي تحقق خاص بنقطة النهاية.

| حالة HTTP | الرسالة | السبب |
| --- | --- | --- |
| 400 | `'Content-Type' must be 'application/json'` | جسم طلب `POST` أو `PUT` أو `PATCH` أُرسل دون `Content-Type: application/json`. تقبل نقاط النهاية التي تستقبل رفع الملفات أيضًا `multipart/form-data` |
| 400 | `Invalid JSON request` | الجسم ليس JSON صالحًا |
| 400 | `Invalid multipart request: malformed part header` | جسم `multipart/form-data` يتعذّر تحليله |
| 413 | `Request body exceeds the maximum allowed size.` | جسم الطلب كبير جدًا |
| 415 | `Request encoding is not supported` | قيمة `Content-Encoding` أو ترميز أحرف (charset) لا تستطيع الواجهة فك ترميزه |

تُرجع قيمة `Content-Type` الخاطئة `400`، وليس `415`. تتضمن استجابات `413` الخاصة بحدّ الحجم أيضًا الحقل `code`:

```json
{
  "code": "PAYLOAD_TOO_LARGE",
  "error": "Request body exceeds the maximum allowed size."
}
```

## رموز الأخطاء

تُسمّي الرموز في هذا الجدول كل خطأ للرجوع إليه. لا تتضمنها معظم الاستجابات: يحمل النص الأساسي الرسالة فقط في `error`. الاستثناءات هي استجابات `413` وأخطاء محفظة x402، التي تضيف الحقل `code`. اعتمد في منطقك على حالة HTTP، ولا تطابق نص الرسالة لأنه قد يتغيّر.

| رمز الخطأ | حالة HTTP | الرسالة | ما الذي يجب فعله |
| --- | --- | --- | --- |
| `AUTHENTICATION_FAILED` | 401 | Authentication failed | تحقّق من الترويسة `Authorization: Bearer` ومن أن المفتاح لم يُحذف ولم تنتهِ صلاحيته. تُجيب نقاط نهاية الحساب وإدارة المفاتيح أيضًا بهذا الرمز على مفتاح Inference، لذا استخدم مفتاح Admin هناك. |
| `AUTHENTICATION_FAILED_INACTIVE_KEY` | 401 | Authentication failed - Pro subscription is inactive. Please upgrade your subscription to continue using the API | لا يمكن لحساب المفتاح استخدام API. سجّل الدخول إلى venice.ai للتحقق من الحساب، أو تواصل مع support@venice.ai. |
| `X402_INVALID_SIGN_IN` | 401 | Invalid Sign-in-with-x signature | وقّع إثبات `SIGN-IN-WITH-X` جديدًا باستخدام الـ nonce من أحدث تحدٍّ `402`. راجع [x402](/ar/guides/integrations/x402-venice-api). |
| `X402_USER_NOT_ALLOWED` | 401 | Wallet user is not allowed to authenticate | حساب Venice الخاص بالمحفظة محظور أو محذوف، أو أن أرصدتها تخص مستخدمًا آخر. استخدم محفظة مختلفة. |
| `PRO_ONLY_MODEL` | 401 | This model is only available to Pro users | استخدم نموذجًا تتضمنه خطتك، أو قم بالترقية إلى خطة مدفوعة. |
| `INSUFFICIENT_BALANCE` | 402 | Insufficient USD or Diem balance to complete request. Visit https://venice.ai/settings/api to add credits. | أضف رصيدًا أو قم بتخزين [DIEM](/ar/overview/vvv-diem)، ثم أعد المحاولة. |
| `API_KEY_DIEM_SPEND_LIMIT_EXCEEDED` | 402 | API key DIEM spend limit exceeded. Your account may still have DIEM balance, but this API key has reached its configured DIEM spending limit. | ارفع حد DIEM للمفتاح أو أزله، أو انتظر إعادة ضبط فترة الحد. |
| `API_KEY_USD_SPEND_LIMIT_EXCEEDED` | 402 | API key USD spend limit exceeded. Your account may still have USD balance, but this API key has reached its configured USD spending limit. | ارفع حد USD للمفتاح أو أزله، أو انتظر إعادة ضبط فترة الحد. |
| `UNAUTHORIZED` | 403 | Unauthorized access | اقرأ الرسالة، فهي تذكر ما الذي حظر الطلب، مثل منطقتك. |
| `API_ACCESS_DISABLED` | 403 | API access has been disabled for this account. Please contact support@venice.ai | تواصل مع support@venice.ai. |
| `X402_WALLET_MISMATCH` | 403 | You can only access resources for your own wallet | اطلب رصيد أو معاملات المحفظة التي سجّلت الدخول بها. |
| `INVALID_REQUEST` | 400 | Invalid request parameters | صحّح الحقول المذكورة في `details` أو `issues` أو في الرسالة. |
| `INVALID_MODEL` | 400 | Invalid model specified | استخدم نموذجًا يدعم نقطة النهاية هذه. يسرد `GET /models` قدرات كل نموذج. |
| `REQUEST_ID_NOT_FOUND` | 400 | Request ID is invalid. | تحقّق من أن معرّف قائمة الانتظار والنموذج يطابقان مهمة أضفتها إلى قائمة الانتظار. |
| `INVALID_AUDIO_FORMAT` | 400 | Invalid audio format. Supported formats are WAV and MP3. | حوّل الصوت إلى تنسيق تقبله نقطة النهاية. |
| `INVALID_VIDEO_FORMAT` | 400 | Invalid video format. Supported formats include MP4, MOV, WebM, MKV, AVI, and others. | حوّل الفيديو إلى تنسيق مدعوم مثل MP4. |
| `CORRUPTED_IMAGE` | 400 | The image file is corrupted or unreadable | أعد ترميز الصورة أو أرسل ملفًا مختلفًا. |
| `IMAGE_TOO_SMALL` | 400 | Image dimensions are too small | أرسل صورة أكبر. |
| `TOO_MANY_TOKENS` | 400 | Your request exceeds the model's maximum context. Please reduce your prompt or completion length. | اختصر الرسائل أو خفّض `max_tokens`. يسرد `GET /models` حجم السياق لكل نموذج. |
| `CHARACTER_NOT_FOUND` | 404 | No character could be found from the provided `character_slug` | استخدم slug من [`GET /characters`](/ar/api-reference/endpoint/characters/list). |
| `MODEL_NOT_FOUND` | 404 | Specified model not found | استخدم معرّفًا حاليًا من `GET /models`. النماذج المتوقفة مدرجة في [الإيقاف](/ar/overview/deprecations). |
| `MEDIA_NOT_FOUND` | 404 | Media could not be found. Request may be invalid, expired, or deleted. | انتهت صلاحية النتيجة أو حُذفت. أضف المهمة إلى قائمة الانتظار مرة أخرى. |
| `PAYLOAD_TOO_LARGE` | 413 | The request payload is too large. Please reduce the size of your request. | أرسل نصًا أساسيًا أو ملفًا أصغر. |
| `INVALID_CONTENT_TYPE` | 415 | Invalid request content-type. Returned only by `/image/multi-edit` | أرسل `multipart/form-data` أو `application/json`. |
| `VIDEO_DURATION_TOO_LONG` | 422 | Video duration exceeds the maximum allowed. | استخدم مدة يسردها النموذج في `GET /models?type=video`. |
| `VIDEO_DURATION_TOO_SHORT` | 422 | Video duration is too short. | استخدم مدة يسردها النموذج في `GET /models?type=video`. |
| `IMAGE_TOO_LARGE` | 422 | Image dimensions exceed the maximum allowed. | صغّر أبعاد الصورة. |
| `CONTENT_POLICY_VIOLATION` | 422 | Your prompt violates the content policy of Venice.ai or the model provider | غيّر الموجّه أو استخدم نموذجًا آخر. تختلف السياسات حسب النموذج والمزوّد. |
| `ASR_UPSTREAM_VALIDATION_FAILED` | 422 | The audio could not be processed for transcription. Common causes: zero-length, silent, corrupt, or unsupported-language audio. Please verify the file and retry. | تحقّق من أن الصوت ليس فارغًا أو صامتًا أو تالفًا، وأن لغته مدعومة. |
| `RATE_LIMIT_EXCEEDED` | 429 | Rate limit exceeded | انتظر حتى `x-ratelimit-reset-requests`، ثم أعد المحاولة. راجع [حدود المعدل](/ar/api-reference/rate-limiting). |
| `MODEL_OVERLOADED` | 429 | The model is currently overloaded. Please try again later. | أعد المحاولة بعد المدة في الترويسة `Retry-After`، أو بدّل النموذج. |
| `INFERENCE_FAILED` | 500 | Inference processing failed | أعد المحاولة مع التراجع التدريجي. تُحتسب الطلبات الفاشلة ضمن [ميزانية الأخطاء](/ar/api-reference/rate-limiting#ميزانيات-الأخطاء). |
| `UPSCALE_FAILED` | 500 | Image upscaling failed | أعد المحاولة مع التراجع التدريجي. |
| `IMAGE_EDIT_ERROR` | 500 | Image edit failed | أعد المحاولة مع التراجع التدريجي. |
| `UNKNOWN_ERROR` | 500 | An unknown error occurred | أعد المحاولة مع التراجع التدريجي. إذا استمر الخطأ، تواصل مع support@venice.ai. |
| `TEE_ATTESTATION_FAILED` | 502 | TEE attestation request failed. The Trusted Execution Environment provider may be temporarily unavailable. | أعد المحاولة لاحقًا. |
| `TEE_SIGNATURE_FAILED` | 502 | TEE signature request failed. The Trusted Execution Environment provider may be temporarily unavailable. | أعد المحاولة لاحقًا. |
| `ASR_UPSTREAM_FAILED` | 502 | Audio transcription failed due to a temporary upstream error. Please retry. | أعد إرسال الطلب. |
| `MODEL_OFFLINE` | 503 | The model is temporarily offline. Please try again later. | أعد المحاولة لاحقًا أو بدّل النموذج. |
| `MODEL_AT_CAPACITY` | 503 | The model is at capacity. Please try again later. | أعد المحاولة لاحقًا أو بدّل النموذج. |
| `REQUEST_TIMEOUT` | 504 | The request took too long to complete and was timed-out. For non-streaming requests, use the streaming API by setting `stream=true`. A streaming chat completion that times out before the model's first chunk reports the failure as an in-band SSE error frame instead. | عيّن `stream: true`، أو أرسل طلبًا أقصر. |

## أخطاء أخرى

الجدول أعلاه ليس شاملًا. تُرجَع بعض الأخطاء دون رمز مدرج، وقد تختلف الرسائل حسب النموذج ونقطة النهاية، لذا اعتمد في التفريع على حالة HTTP بدلًا من نص الرسالة. أخطاء قد تواجهها وليست في الجدول:

| حالة HTTP | متى يحدث |
| --- | --- |
| 400 | صورة مُدخلة في طلب chat أو Responses بتنسيق غير مدعوم |
| 400 | الصوت المطلوب غير متاح لنموذج تحويل النص إلى كلام |
| 403 | الطلب صادر من عنوان IP غير موجود في قائمة السماح الخاصة بمفتاح API |
| 403 | النموذج المطلوب غير مسموح به وفق إعداد الخصوصية لمفتاح API |
| 403 | الوصول إلى النموذج المطلوب مقيّد. تواصل مع support@venice.ai |
| 409 | نتيجة فيديو أو موسيقى أو مغيّر صوت لا تزال قيد الرفع عند استرجاعها. أعد المحاولة بعد قليل |
| 410 | تم إيقاف نقطة النهاية |
| 422 | الصوت طويل جدًا أو قصير جدًا (استنساخ الصوت، ومغيّر الصوت، ومهام الصوت) |
| 422 | نسبة العرض إلى الارتفاع للصورة المُدخلة في طلب فيديو خارج النطاق الذي يقبله النموذج |
| 422 | تم حظر مُدخل طلب فيديو بواسطة الإشراف على المحتوى |
| 500 | فشل توليد الفيديو أو مغيّر الصوت |
| 502 | فشل تركيب الكلام في المصدر (upstream)، أو تعذّر استرجاع فيديو مُولَّد. أعد إرسال الطلب |
