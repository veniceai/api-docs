## How to use the Nano Banana 2 Lite API

Send requests to `POST https://api.venice.ai/api/v1/image/generate` with `"model": "nano-banana-2-lite"` and your API key.

```bash
curl https://api.venice.ai/api/v1/image/generate \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
```

### What is the Nano Banana 2 Lite model ID?

Use `nano-banana-2-lite` as the `model` parameter. Other variants: `nano-banana-2-lite-edit` (Edit).

### Is the Nano Banana 2 Lite API private?

Nano Banana 2 Lite is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.
