# Nano Banana Pro API

## How to use the Nano Banana Pro API

Send requests to `POST https://api.venice.ai/api/v1/image/generate` with `"model": "nano-banana-pro"` and your API key.

```bash
curl https://api.venice.ai/api/v1/image/generate \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "nano-banana-pro",
    "prompt": "A retro travel poster with the bold headline \"VENICE\" in large condensed serif type, sunset color palette",
    "resolution": "1K",
    "aspect_ratio": "1:1"
  }'
```

## Nano Banana Pro API FAQ

### How much does the Nano Banana Pro API cost?

$0.18 at 1K, $0.23 at 2K and $0.35 at 4K per image. Editing costs $0.18 per edit. Prices are in USD and can be paid in DIEM at parity.

### What is the Nano Banana Pro model ID?

Use `nano-banana-pro` as the `model` parameter. Other variants: `nano-banana-pro-edit` (Edit).

### Is the Nano Banana Pro API private?

Nano Banana Pro is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.

### What resolutions does Nano Banana Pro support?

Resolutions: 1K, 2K, 4K. Aspect ratios: 1:1, 3:2, 16:9, 21:9, 9:16, 2:3, 3:4, 4:5. Prompts up to 32,768 characters.

### Which endpoint does the Nano Banana Pro API use?

Call `POST /image/generate`. `/images/generations` is also supported.
