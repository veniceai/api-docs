## How to use the Gradium TTS API

Send requests to `POST https://api.venice.ai/api/v1/audio/speech` with `"model": "tts-gradium-v1"` and your API key.

```bash
curl https://api.venice.ai/api/v1/audio/speech \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "tts-gradium-v1",
    "input": "Private AI for everyone.",
    "voice": "Alice",
    "response_format": "mp3"
  }' --output speech.mp3
```

## Gradium TTS API FAQ

### How much does the Gradium TTS API cost?

$47.50 per 1M characters of input text, about $0.039 per minute of generated speech. Prices are in USD and can be paid in DIEM at parity.

### What is the Gradium TTS model ID?

Use `tts-gradium-v1` as the `model` parameter.

### Is the Gradium TTS API private?

Gradium TTS is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.

### How many voices does Gradium TTS have?

12 voices, for example `Alice`, `Davi`, `Elise`. Output formats: wav, pcm, opus.

### Which endpoint does the Gradium TTS API use?

Call `POST /audio/speech`.
