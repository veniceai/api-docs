## How to use the Ovi API

Send requests to `POST https://api.venice.ai/api/v1/video/queue` with `"model": "ovi-image-to-video"` and your API key.

```bash
# 1. Queue the job (returns a queue_id)
curl https://api.venice.ai/api/v1/video/queue \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "ovi-image-to-video",
    "prompt": "Slow aerial drone shot over a misty mountain valley at golden hour",
    "duration": "5s",
    "image_url": "https://example.com/first-frame.jpg"
  }'

# 2. Poll until the MP4 is ready
curl https://api.venice.ai/api/v1/video/retrieve \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "model": "ovi-image-to-video", "queue_id": "<queue_id>" }' --output video.mp4
```

## Ovi API FAQ

### How much does the Ovi API cost?

From $0.044 to $0.044 per second of video, depending on resolution, duration and audio. A 5-second  clip with audio costs $0.22. Call `POST /video/quote` for the exact price before queueing. Prices are in USD and can be paid in DIEM at parity.

### What is the Ovi model ID?

Use `ovi-image-to-video` as the `model` parameter.

### Is the Ovi API private?

Ovi is private: requests run on infrastructure Venice controls with zero data retention, and prompts and outputs are never stored or used for training.

### What resolutions and durations does Ovi support?

Durations: 5s. Audio: always generated.

### Which endpoint does the Ovi API use?

Queue a job with `POST /video/queue`, then poll `/video/retrieve` for the result.
