## How to use the Veo 3.1 Fast API

Send requests to `POST https://api.venice.ai/api/v1/video/queue` with `"model": "veo3.1-fast-text-to-video"` and your API key.

```bash
# 1. Queue the job (returns a queue_id)
curl https://api.venice.ai/api/v1/video/queue \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "veo3.1-fast-text-to-video",
    "prompt": "Slow aerial drone shot over a misty mountain valley at golden hour",
    "duration": "4s",
    "resolution": "720p",
    "aspect_ratio": "16:9",
    "audio": true
  }'

# 2. Poll until the MP4 is ready
curl https://api.venice.ai/api/v1/video/retrieve \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "model": "veo3.1-fast-text-to-video", "queue_id": "<queue_id>" }' --output video.mp4
```

## Veo 3.1 Fast API FAQ

### How much does the Veo 3.1 Fast API cost?

From $0.11 to $0.39 per second of video, depending on resolution, duration and audio. A 4-second 720p clip costs $0.44. Call `POST /video/quote` for the exact price before queueing. Prices are in USD and can be paid in DIEM at parity.

### What is the Veo 3.1 Fast model ID?

Use `veo3.1-fast-text-to-video` as the `model` parameter. Other variants: `veo3.1-fast-image-to-video` (Image to video).

### Is the Veo 3.1 Fast API private?

Veo 3.1 Fast is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.

### What resolutions and durations does Veo 3.1 Fast support?

Resolutions: 720p, 1080p, 4K. Durations: 4s, 6s, 8s. Aspect ratios: 16:9, 9:16. Audio: optional, with `"audio": true`.

### Which endpoint does the Veo 3.1 Fast API use?

Queue a job with `POST /video/queue`, then poll `/video/retrieve` for the result.
