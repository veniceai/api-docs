## How to use the GPT-5.6 Terra API

Send requests to `POST https://api.venice.ai/api/v1/responses` with `"model": "openai-gpt-56-terra"` and your API key.

```bash
curl https://api.venice.ai/api/v1/responses \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai-gpt-56-terra",
    "input": "Explain TEE attestation in two sentences.",
    "reasoning": { "effort": "high" }
  }'
```
