## How to use the Kling 2.6 Pro API

Send requests to `POST https://api.venice.ai/api/v1/video/queue` with `"model": "kling-2.6-pro-text-to-video"` and your API key.

```bash
# 1. Queue the job (returns a queue_id)
curl https://api.venice.ai/api/v1/video/queue \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kling-2.6-pro-text-to-video",
    "prompt": "Slow aerial drone shot over a misty mountain valley at golden hour",
    "duration": "5s",
    "aspect_ratio": "16:9",
    "audio": true
  }'

# 2. Poll until the MP4 is ready
curl https://api.venice.ai/api/v1/video/retrieve \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "model": "kling-2.6-pro-text-to-video", "queue_id": "<queue_id>" }' --output video.mp4
```

## Kling 2.6 Pro API FAQ

### How much does the Kling 2.6 Pro API cost?

From $0.077 to $0.15 per second of video, depending on resolution, duration and audio. A 5-second  clip costs $0.39. Call `POST /video/quote` for the exact price before queueing. Prices are in USD and can be paid in DIEM at parity.

### What is the Kling 2.6 Pro model ID?

Use `kling-2.6-pro-text-to-video` as the `model` parameter. Other variants: `kling-2.6-pro-image-to-video` (Image to video).

### Is the Kling 2.6 Pro API private?

Kling 2.6 Pro is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.

### What resolutions and durations does Kling 2.6 Pro support?

Durations: 5s, 10s. Aspect ratios: 16:9, 9:16, 1:1. Audio: optional, with `"audio": true`.

### Which endpoint does the Kling 2.6 Pro API use?

Queue a job with `POST /video/queue`, then poll `/video/retrieve` for the result.
