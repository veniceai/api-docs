Send requests to `POST https://api.venice.ai/api/v1/chat/completions` with `"model": "kimi-k3-1-pro"` and your API key.


## Kimi K3.1 Pro API FAQ

### How much does the Kimi K3.1 Pro API cost?

$3.00 per 1M input tokens and $15.00 per 1M output tokens, with cached input at $0.30 per 1M. Prices are in USD and can be paid in DIEM at parity.

### What is the Kimi K3.1 Pro model ID?

Use `kimi-k3-1-pro` as the `model` parameter.

### Is the Kimi K3.1 Pro API private?

Kimi K3.1 Pro is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.

### What is the context window of Kimi K3.1 Pro?

1M tokens of context, with up to 128K output tokens per response.

### What does Kimi K3.1 Pro support?

Kimi K3.1 Pro supports function calling, structured outputs, reasoning, image input, web search and prompt caching. Reasoning effort is adjustable with `reasoning_effort`: none, low, high and max (default max).

### Which endpoint does the Kimi K3.1 Pro API use?

Call `POST /chat/completions`. `/responses` (Alpha) is also supported.
