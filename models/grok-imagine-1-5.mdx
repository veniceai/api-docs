## How to use the Grok Imagine 1.5 API

Send requests to `POST https://api.venice.ai/api/v1/video/queue` with `"model": "grok-imagine-1-5-text-to-video-private"` and your API key.

```bash
# 1. Queue the job (returns a queue_id)
curl https://api.venice.ai/api/v1/video/queue \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "grok-imagine-1-5-text-to-video-private",
    "prompt": "Slow aerial drone shot over a misty mountain valley at golden hour",
    "duration": "5s",
    "resolution": "720p",
    "aspect_ratio": "16:9"
  }'

# 2. Poll until the MP4 is ready
curl https://api.venice.ai/api/v1/video/retrieve \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "model": "grok-imagine-1-5-text-to-video-private", "queue_id": "<queue_id>" }' --output video.mp4
```

### What is the Grok Imagine 1.5 model ID?

Use `grok-imagine-1-5-text-to-video-private` as the `model` parameter. Other variants: `grok-imagine-1-5-image-to-video-private` (Image to video), `grok-imagine-1-5-reference-to-video-private` (Reference to video).

### Is the Grok Imagine 1.5 API private?

Grok Imagine 1.5 is private: requests run on infrastructure Venice controls with zero data retention, and prompts and outputs are never stored or used for training.
