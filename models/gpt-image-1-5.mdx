# GPT Image 1.5 API

GPT Image 1.5 is an image generation and image editing model by OpenAI, available on the Venice API as `gpt-image-1-5`. Requests are anonymized, so the provider never sees your identity.

## How to use the GPT Image 1.5 API

Send requests to `POST https://api.venice.ai/api/v1/image/generate` with `"model": "gpt-image-1-5"` and your API key.

```bash
curl https://api.venice.ai/api/v1/image/generate \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-1-5",
    "prompt": "A retro travel poster with the bold headline \"VENICE\" in large condensed serif type, sunset color palette",
    "aspect_ratio": "1:1"
  }'
```

## GPT Image 1.5 API FAQ

### How much does the GPT Image 1.5 API cost?

$0.26 per image. Editing costs $0.31 per edit. Prices are in USD and can be paid in DIEM at parity.

### What is the GPT Image 1.5 model ID?

Use `gpt-image-1-5` as the `model` parameter. Other variants: `gpt-image-1-5-edit` (Edit).

### Is the GPT Image 1.5 API private?

GPT Image 1.5 is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.

### What resolutions does GPT Image 1.5 support?

Aspect ratios: 1:1, 3:2, 2:3. Prompts up to 5,000 characters.

### Which endpoint does the GPT Image 1.5 API use?

Call `POST /image/generate`. `/images/generations` is also supported.
