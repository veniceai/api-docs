## How to use the Grok Imagine 2.0 API

Send requests to `POST https://api.venice.ai/api/v1/image/generate` with `"model": "grok-imagine-image-2-0"` and your API key.

```bash
curl https://api.venice.ai/api/v1/image/generate \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "grok-imagine-image-2-0",
    "prompt": "A retro travel poster with the bold headline \"VENICE\" in large condensed serif type, sunset color palette",

    "aspect_ratio": "1:1"
  }'
```

### Is the Grok Imagine 2.0 API private?
