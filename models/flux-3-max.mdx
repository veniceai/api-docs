## How to use the Flux 3 Max API

Send requests to `POST https://api.venice.ai/api/v1/video/queue` with `"model": "flux-3-max-text-to-video"` and your API key.

```bash
# 1. Queue the job (returns a queue_id)
curl https://api.venice.ai/api/v1/video/queue \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "flux-3-max-text-to-video",
    "prompt": "Slow aerial drone shot over a misty mountain valley at golden hour",
    "duration": "5s",
    "resolution": "720p",
    "aspect_ratio": "auto"
  }'

# 2. Poll until the MP4 is ready
curl https://api.venice.ai/api/v1/video/retrieve \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "model": "flux-3-max-text-to-video", "queue_id": "<queue_id>" }' --output video.mp4
```

## Flux 3 Max API FAQ

### How much does the Flux 3 Max API cost?

From $0.064 to $0.11 per second of video, depending on resolution, duration and audio. A 5-second 720p clip with audio costs $0.32. Call `POST /video/quote` for the exact price before queueing. Prices are in USD and can be paid in DIEM at parity.

### What is the Flux 3 Max model ID?

Use `flux-3-max-text-to-video` as the `model` parameter. Other variants: `flux-3-max-image-to-video` (Image to video).

### Is the Flux 3 Max API private?

Flux 3 Max is private: requests run on infrastructure Venice controls with zero data retention, and prompts and outputs are never stored or used for training.

### What resolutions and durations does Flux 3 Max support?

Resolutions: 720p, 1080p. Durations: 5s, 6s, 7s, 8s, 9s, 10s, 11s, 12s, 13s, 14s, 15s, 16s, 17s, 18s, 19s, 20s. Aspect ratios: auto, 21:9, 2:1, 16:9, 4:3, 1:1, 3:4, 9:16. Audio: always generated.

### Which endpoint does the Flux 3 Max API use?

Queue a job with `POST /video/queue`, then poll `/video/retrieve` for the result.
