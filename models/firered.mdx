## How to use the FireRed API

Send requests to `POST https://api.venice.ai/api/v1/image/edit` with `"model": "firered-image-edit"` and your API key.

```bash
curl https://api.venice.ai/api/v1/image/edit \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "firered-image-edit",
    "image": "<base64-encoded image>",
    "prompt": "Make it a rainy night scene"
  }' --output result.png
```
