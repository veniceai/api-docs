## How to use the Longcat Distilled API

Send requests to `POST https://api.venice.ai/api/v1/video/queue` with `"model": "longcat-distilled-text-to-video"` and your API key.

```bash
# 1. Queue the job (returns a queue_id)
curl https://api.venice.ai/api/v1/video/queue \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "longcat-distilled-text-to-video",
    "prompt": "Slow aerial drone shot over a misty mountain valley at golden hour",
    "duration": "5s",
    "resolution": "720p",
    "aspect_ratio": "16:9"
  }'

# 2. Poll until the MP4 is ready
curl https://api.venice.ai/api/v1/video/retrieve \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "model": "longcat-distilled-text-to-video", "queue_id": "<queue_id>" }' --output video.mp4
```

## Longcat Distilled API FAQ

### How much does the Longcat Distilled API cost?

From $0.018 to $0.018 per second of video, depending on resolution, duration and audio. A 5-second 720p clip costs $0.09. Call `POST /video/quote` for the exact price before queueing. Prices are in USD and can be paid in DIEM at parity.

### What is the Longcat Distilled model ID?

Use `longcat-distilled-text-to-video` as the `model` parameter. Other variants: `longcat-distilled-image-to-video` (Image to video).

### Is the Longcat Distilled API private?

Longcat Distilled is private: requests run on infrastructure Venice controls with zero data retention, and prompts and outputs are never stored or used for training.

### What resolutions and durations does Longcat Distilled support?

Resolutions: 720p. Durations: 5s, 10s, 15s, 20s, 30s. Aspect ratios: 16:9, 9:16, 1:1. Audio: none.

### Which endpoint does the Longcat Distilled API use?

Queue a job with `POST /video/queue`, then poll `/video/retrieve` for the result.
