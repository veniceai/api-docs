## How to use the MiniMax Speech-02 HD API

Send requests to `POST https://api.venice.ai/api/v1/audio/speech` with `"model": "tts-minimax-speech-02-hd"` and your API key.

```bash
curl https://api.venice.ai/api/v1/audio/speech \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "tts-minimax-speech-02-hd",
    "input": "Private AI for everyone.",
    "voice": "CalmWoman",
    "response_format": "mp3"
  }' --output speech.mp3
```
