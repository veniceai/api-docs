## How to use the Kling V3 Turbo Standard API

Send requests to `POST https://api.venice.ai/api/v1/video/queue` with `"model": "kling-v3-turbo-standard-text-to-video"` and your API key.

```bash
# 1. Queue the job (returns a queue_id)
curl https://api.venice.ai/api/v1/video/queue \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kling-v3-turbo-standard-text-to-video",
    "prompt": "Slow aerial drone shot over a misty mountain valley at golden hour",
    "duration": "5s",
    "aspect_ratio": "16:9"
  }'

# 2. Poll until the MP4 is ready
curl https://api.venice.ai/api/v1/video/retrieve \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "model": "kling-v3-turbo-standard-text-to-video", "queue_id": "<queue_id>" }' --output video.mp4
```

## Kling V3 Turbo Standard API FAQ

### How much does the Kling V3 Turbo Standard API cost?

From $0.12 to $0.12 per second of video, depending on resolution, duration and audio. A 5-second  clip costs $0.62. Call `POST /video/quote` for the exact price before queueing. Prices are in USD and can be paid in DIEM at parity.

### What is the Kling V3 Turbo Standard model ID?

Use `kling-v3-turbo-standard-text-to-video` as the `model` parameter. Other variants: `kling-v3-turbo-standard-image-to-video` (Image to video).

### Is the Kling V3 Turbo Standard API private?

Kling V3 Turbo Standard is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.

### What resolutions and durations does Kling V3 Turbo Standard support?

Durations: 3s, 4s, 5s, 6s, 7s, 8s, 9s, 10s, 11s, 12s, 13s, 14s, 15s. Aspect ratios: 16:9, 9:16, 1:1. Audio: none.

### Which endpoint does the Kling V3 Turbo Standard API use?
