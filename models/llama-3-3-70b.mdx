Use `llama-3.3-70b` as the `model` parameter.

### Is the Llama 3.3 70B API private?

Llama 3.3 70B is private: requests run on infrastructure Venice controls with zero data retention, and prompts and outputs are never stored or used for training.

125K tokens of context, with up to 4K output tokens per response.

### What does Llama 3.3 70B support?

Llama 3.3 70B supports function calling and web search.
