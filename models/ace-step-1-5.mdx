## How to use the ACE-Step 1.5 API

Send requests to `POST https://api.venice.ai/api/v1/audio/queue` with `"model": "ace-step-15"` and your API key.

```bash
# 1. Queue the job
curl https://api.venice.ai/api/v1/audio/queue \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "ace-step-15",
    "prompt": "Warm lo-fi hip hop beat with soft piano and vinyl crackle",
    "duration_seconds": 30
  }'

# 2. Retrieve when ready

  -H "Authorization: Bearer $VENICE_API_KEY" \

  -d '{ "model": "ace-step-15", "queue_id": "<queue_id>" }' --output audio.mp3
```
