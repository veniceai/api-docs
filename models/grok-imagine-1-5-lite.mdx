## How to use the Grok Imagine 1.5 Lite API

Send requests to `POST https://api.venice.ai/api/v1/video/queue` with `"model": "grok-imagine-1-5-lite-text-to-video"` and your API key.

```bash
# 1. Queue the job (returns a queue_id)
curl https://api.venice.ai/api/v1/video/queue \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "grok-imagine-1-5-lite-text-to-video",
    "prompt": "Slow aerial drone shot over a misty mountain valley at golden hour",
    "duration": "5s",
    "resolution": "720p",
    "aspect_ratio": "16:9"
  }'

# 2. Poll until the MP4 is ready
curl https://api.venice.ai/api/v1/video/retrieve \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "model": "grok-imagine-1-5-lite-text-to-video", "queue_id": "<queue_id>" }' --output video.mp4
```
