Send requests to `POST https://api.venice.ai/api/v1/responses` with `"model": "openai-gpt-61-sol-ultrafast"` and your API key.

```bash
curl https://api.venice.ai/api/v1/responses \
  -H "Authorization: Bearer $VENICE_API_KEY" \
```
