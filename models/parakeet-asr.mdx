## How to use the Parakeet ASR API

Send requests to `POST https://api.venice.ai/api/v1/audio/transcriptions` with `"model": "nvidia/parakeet-tdt-0.6b-v3"` and your API key.

```bash
curl https://api.venice.ai/api/v1/audio/transcriptions \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -F model=nvidia/parakeet-tdt-0.6b-v3 \
  -F file=@meeting.mp3
```
