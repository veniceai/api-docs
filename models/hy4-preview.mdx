# Hy4 Preview API

Hy4 Preview is a large language model by Hy4, available on the Venice API as `hy4-preview`. It runs privately, with zero data retention.

Hy4 Preview is a 770B-parameter Mixture-of-Experts flagship model from the Tencent Hy team, with 49B parameters active per token and a 1M-token context window. It is post-trained for software engineering, office and data analysis, game development, and scientific research, with strong long-horizon reasoning, tool use, and agentic performance.

## How to use the Hy4 Preview API

Send requests to `POST https://api.venice.ai/api/v1/chat/completions` with `"model": "hy4-preview"` and your API key.

```bash
curl https://api.venice.ai/api/v1/chat/completions \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "hy4-preview",
    "messages": [{ "role": "user", "content": "Explain TEE attestation in two sentences." }],
    "reasoning_effort": "high"
  }'
```

## Hy4 Preview API FAQ

### How much does the Hy4 Preview API cost?

$1.04 per 1M input tokens and $3.13 per 1M output tokens, with cached input at $0.052 per 1M. Prices are in USD and can be paid in DIEM at parity.

### What is the Hy4 Preview model ID?

Use `hy4-preview` as the `model` parameter.

### Is the Hy4 Preview API private?

Hy4 Preview is private: zero data retention is enforced by contract, so prompts and outputs are processed for inference only and not retained after the request completes.

### What is the context window of Hy4 Preview?

1M tokens of context, with up to 64K output tokens per response.

### What does Hy4 Preview support?

Hy4 Preview supports function calling, structured outputs, reasoning, web search and prompt caching. Reasoning effort is adjustable with `reasoning_effort`: none, low and high (default high).

### Which endpoint does the Hy4 Preview API use?

Call `POST /chat/completions`. `/responses` (Alpha) is also supported.
