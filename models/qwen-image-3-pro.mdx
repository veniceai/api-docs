Send requests to `POST https://api.venice.ai/api/v1/image/generate` with `"model": "qwen-image-3-pro"` and your API key.

```bash
curl https://api.venice.ai/api/v1/image/generate \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \

```

### How much does the Qwen Image 3 Pro API cost?

$0.05 at 1K and $0.09 at 2K per image. Editing costs $0.05 per edit. Prices are in USD and can be paid in DIEM at parity.

### What is the Qwen Image 3 Pro model ID?

Use `qwen-image-3-pro` as the `model` parameter. Other variants: `qwen-image-3-pro-edit` (Edit).

### Is the Qwen Image 3 Pro API private?

Qwen Image 3 Pro is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.
