## How to use the GPT-5.6 Terra Pro API

Send requests to `POST https://api.venice.ai/api/v1/responses` with `"model": "openai-gpt-56-terra-pro"` and your API key.

```bash
curl https://api.venice.ai/api/v1/responses \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai-gpt-56-terra-pro",
    "input": "Explain TEE attestation in two sentences.",
    "reasoning": { "effort": "medium" }
  }'
```

## GPT-5.6 Terra Pro API FAQ

### How much does the GPT-5.6 Terra Pro API cost?

$2.50 per 1M input tokens and $15.00 per 1M output tokens, with cached input at $0.25 per 1M. Prices are in USD and can be paid in DIEM at parity.

### What is the GPT-5.6 Terra Pro model ID?

Use `openai-gpt-56-terra-pro` as the `model` parameter.

### Is the GPT-5.6 Terra Pro API private?

GPT-5.6 Terra Pro is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.

### What is the context window of GPT-5.6 Terra Pro?

1M tokens of context, with up to 125K output tokens per response.

### What does GPT-5.6 Terra Pro support?

GPT-5.6 Terra Pro supports function calling, structured outputs, reasoning, image input, web search and prompt caching. Reasoning effort is adjustable with `reasoning_effort`: low, medium, high, xhigh and max (default medium).

### Which endpoint does the GPT-5.6 Terra Pro API use?

Call `POST /responses`. `/chat/completions` is also supported. Pro and Codex models are Responses-native upstream. Use /responses for typed reasoning, tool-call and message items; /chat/completions stays fully supported.
