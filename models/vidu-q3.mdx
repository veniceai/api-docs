## How to use the Vidu Q3 API

Send requests to `POST https://api.venice.ai/api/v1/video/queue` with `"model": "vidu-q3-text-to-video"` and your API key.

```bash
# 1. Queue the job (returns a queue_id)
curl https://api.venice.ai/api/v1/video/queue \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "vidu-q3-text-to-video",
    "prompt": "Slow aerial drone shot over a misty mountain valley at golden hour",
    "duration": "5s",
    "resolution": "720p",
    "aspect_ratio": "16:9",
    "audio": true
  }'

# 2. Poll until the MP4 is ready
curl https://api.venice.ai/api/v1/video/retrieve \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "model": "vidu-q3-text-to-video", "queue_id": "<queue_id>" }' --output video.mp4
```

## Vidu Q3 API FAQ

### How much does the Vidu Q3 API cost?

From $0.089 to $0.20 per second of video, depending on resolution, duration and audio. A 5-second 720p clip costs $0.97. Call `POST /video/quote` for the exact price before queueing. Prices are in USD and can be paid in DIEM at parity.

### What is the Vidu Q3 model ID?

Use `vidu-q3-text-to-video` as the `model` parameter. Other variants: `vidu-q3-image-to-video` (Image to video).

### Is the Vidu Q3 API private?

Vidu Q3 is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.

### What resolutions and durations does Vidu Q3 support?

Resolutions: 360p, 540p, 720p, 1080p. Durations: 3s, 5s, 8s, 10s, 12s, 14s, 16s. Aspect ratios: 16:9, 9:16, 4:3, 3:4, 1:1. Audio: optional, with `"audio": true`.

### Which endpoint does the Vidu Q3 API use?

Queue a job with `POST /video/queue`, then poll `/video/retrieve` for the result.
