## How to use the MMAudio V2 API

Send requests to `POST https://api.venice.ai/api/v1/audio/queue` with `"model": "mmaudio-v2-text-to-audio"` and your API key.

```bash
# 1. Queue the job
curl https://api.venice.ai/api/v1/audio/queue \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mmaudio-v2-text-to-audio",
    "prompt": "Heavy wooden door creaking open in a stone hallway",
    "duration_seconds": 5
  }'

# 2. Retrieve when ready
curl https://api.venice.ai/api/v1/audio/retrieve \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "model": "mmaudio-v2-text-to-audio", "queue_id": "<queue_id>" }' --output audio.mp3
```
