# GPT-5.2 API

GPT-5.2 is a large language model by OpenAI, available on the Venice API as `openai-gpt-52`. Requests are anonymized, so the provider never sees your identity.

GPT-5.2 is the latest frontier-grade model in the GPT-5 series, offering stronger agentic and long context performance compared to GPT-5.1. It uses adaptive reasoning to allocate computation dynamically, responding quickly to simple queries while spending more depth on complex tasks.

## How to use the GPT-5.2 API

Send requests to `POST https://api.venice.ai/api/v1/responses` with `"model": "openai-gpt-52"` and your API key.

```bash
curl https://api.venice.ai/api/v1/responses \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai-gpt-52",
    "input": "Explain TEE attestation in two sentences.",
    "reasoning": { "effort": "high" }
  }'
```

## GPT-5.2 API FAQ

### How much does the GPT-5.2 API cost?

$2.19 per 1M input tokens and $17.50 per 1M output tokens, with cached input at $0.22 per 1M. Prices are in USD and can be paid in DIEM at parity.

### What is the GPT-5.2 model ID?

Use `openai-gpt-52` as the `model` parameter.

### Is the GPT-5.2 API private?

GPT-5.2 is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.

### What is the context window of GPT-5.2?

250K tokens of context, with up to 64K output tokens per response.

### What does GPT-5.2 support?

GPT-5.2 supports function calling, structured outputs, reasoning, web search and prompt caching. Reasoning effort is adjustable with `reasoning_effort`: none, low, medium, high and xhigh (default high).

### Which endpoint does the GPT-5.2 API use?

Call `POST /responses`. `/chat/completions` is also supported. OpenAI reasoning models are designed around the Responses API: reasoning, tool calls and messages come back as typed output items. Venice's /responses endpoint is in alpha.
