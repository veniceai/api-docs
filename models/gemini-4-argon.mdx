## How to use the Gemini 4 Argon API

Send requests to `POST https://api.venice.ai/api/v1/chat/completions` with `"model": "gemini-4-argon"` and your API key.

```bash
curl https://api.venice.ai/api/v1/chat/completions \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gemini-4-argon",
    "messages": [{ "role": "user", "content": "Explain TEE attestation in two sentences." }]
  }'
```

## Gemini 4 Argon API FAQ

### How much does the Gemini 4 Argon API cost?

$2.50 per 1M input tokens and $12.50 per 1M output tokens, with cached input at $0.13 per 1M. Prices are in USD and can be paid in DIEM at parity.

### What is the Gemini 4 Argon model ID?

Use `gemini-4-argon` as the `model` parameter.

### Is the Gemini 4 Argon API private?

Gemini 4 Argon is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.

### What is the context window of Gemini 4 Argon?

1M tokens of context, with up to 64K output tokens per response.

### What does Gemini 4 Argon support?

Gemini 4 Argon supports function calling, structured outputs, reasoning, image input, web search and prompt caching.

### Which endpoint does the Gemini 4 Argon API use?

Call `POST /chat/completions`. `/responses` (Alpha) is also supported.
