## How to use the MiniMax H3 Enhanced API

Send requests to `POST https://api.venice.ai/api/v1/video/queue` with `"model": "minimax-h3-enhanced-text-to-video"` and your API key.

```bash
# 1. Queue the job (returns a queue_id)
curl https://api.venice.ai/api/v1/video/queue \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "minimax-h3-enhanced-text-to-video",
    "prompt": "Slow aerial drone shot over a misty mountain valley at golden hour",
    "duration": "5s",
    "resolution": "768P",
    "aspect_ratio": "16:9"
  }'

# 2. Poll until the MP4 is ready
curl https://api.venice.ai/api/v1/video/retrieve \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "model": "minimax-h3-enhanced-text-to-video", "queue_id": "<queue_id>" }' --output video.mp4
```

## MiniMax H3 Enhanced API FAQ

### How much does the MiniMax H3 Enhanced API cost?

From $0.10 to $0.16 per second of video, depending on resolution, duration and audio. A 5-second 768p clip with audio costs $0.50. Call `POST /video/quote` for the exact price before queueing. Prices are in USD and can be paid in DIEM at parity.

### What is the MiniMax H3 Enhanced model ID?

Use `minimax-h3-enhanced-text-to-video` as the `model` parameter. Other variants: `minimax-h3-enhanced-reference-to-video` (Reference to video).

### Is the MiniMax H3 Enhanced API private?

MiniMax H3 Enhanced is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.

### What resolutions and durations does MiniMax H3 Enhanced support?

Resolutions: 768p, 2K. Durations: 5s, 6s, 7s, 8s, 9s, 10s, 11s, 12s, 13s, 14s, 15s. Aspect ratios: 16:9, 21:9, 4:3, 1:1, 3:4, 9:16. Audio: always generated.

### Which endpoint does the MiniMax H3 Enhanced API use?
