## How to use the Wan 2.2 Enhanced API

Send requests to `POST https://api.venice.ai/api/v1/video/queue` with `"model": "wan-2-2-enhanced-image-to-video"` and your API key.

```bash
# 1. Queue the job (returns a queue_id)
curl https://api.venice.ai/api/v1/video/queue \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "wan-2-2-enhanced-image-to-video",
    "prompt": "Slow aerial drone shot over a misty mountain valley at golden hour",
    "duration": "5s",
    "resolution": "720p",
    "image_url": "https://example.com/first-frame.jpg"
  }'

# 2. Poll until the MP4 is ready
curl https://api.venice.ai/api/v1/video/retrieve \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "model": "wan-2-2-enhanced-image-to-video", "queue_id": "<queue_id>" }' --output video.mp4
```
