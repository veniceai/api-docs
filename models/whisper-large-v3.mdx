## How to use the Whisper Large V3 API

Send requests to `POST https://api.venice.ai/api/v1/audio/transcriptions` with `"model": "openai/whisper-large-v3"` and your API key.

```bash
curl https://api.venice.ai/api/v1/audio/transcriptions \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -F model=openai/whisper-large-v3 \
  -F file=@meeting.mp3
```
