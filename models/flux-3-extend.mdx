## How to use the Flux 3 Extend API

Send requests to `POST https://api.venice.ai/api/v1/video/queue` with `"model": "flux-3-extend-video"` and your API key.

```bash
# 1. Queue the job (returns a queue_id)
curl https://api.venice.ai/api/v1/video/queue \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "flux-3-extend-video",
    "prompt": "Slow aerial drone shot over a misty mountain valley at golden hour",
    "duration": "5s",
    "resolution": "720p",
    "aspect_ratio": "auto",
    "video_url": "https://example.com/source.mp4"
  }'

# 2. Poll until the MP4 is ready
curl https://api.venice.ai/api/v1/video/retrieve \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "model": "flux-3-extend-video", "queue_id": "<queue_id>" }' --output video.mp4
```

## Flux 3 Extend API FAQ

### How much does the Flux 3 Extend API cost?

Price depends on the input video. Call `POST /video/quote` for the exact price before queueing. Prices are in USD and can be paid in DIEM at parity.

### What is the Flux 3 Extend model ID?

Use `flux-3-extend-video` as the `model` parameter.

### Is the Flux 3 Extend API private?

Flux 3 Extend is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.

### What resolutions and durations does Flux 3 Extend support?

Resolutions: 720p, 1080p, 1440p, 4K. Durations: 5s, 10s, 15s, 20s. Aspect ratios: auto, 21:9, 16:9, 4:3, 1:1, 3:4, 9:16, 9:21. Audio: always generated.

### Which endpoint does the Flux 3 Extend API use?

Queue a job with `POST /video/queue`, then poll `/video/retrieve` for the result.
