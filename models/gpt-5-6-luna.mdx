## How to use the GPT-5.6 Luna API

Send requests to `POST https://api.venice.ai/api/v1/responses` with `"model": "openai-gpt-56-luna"` and your API key.

```bash
curl https://api.venice.ai/api/v1/responses \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai-gpt-56-luna",
    "input": "Explain TEE attestation in two sentences.",
    "reasoning": { "effort": "high" }
  }'
```

### How much does the GPT-5.6 Luna API cost?

### What is the GPT-5.6 Luna model ID?

Use `openai-gpt-56-luna` as the `model` parameter.

### Is the GPT-5.6 Luna API private?

GPT-5.6 Luna is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.

### What is the context window of GPT-5.6 Luna?

1M tokens of context, with up to 128K output tokens per response.

### What does GPT-5.6 Luna support?

GPT-5.6 Luna supports function calling, structured outputs, reasoning, image input, web search and prompt caching. Reasoning effort is adjustable with `reasoning_effort`: none, low, medium, high, xhigh and max (default high).

### Which endpoint does the GPT-5.6 Luna API use?
