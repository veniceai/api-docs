# GPT-6.1 Terra API

GPT-6.1 Terra is a large language model by OpenAI, available on the Venice API as `openai-gpt-61-terra`. Requests are anonymized, so the provider never sees your identity.

## How to use the GPT-6.1 Terra API

Send requests to `POST https://api.venice.ai/api/v1/responses` with `"model": "openai-gpt-61-terra"` and your API key.

```bash
curl https://api.venice.ai/api/v1/responses \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai-gpt-61-terra",
    "input": "Explain TEE attestation in two sentences.",
    "reasoning": { "effort": "high" }
  }'
```

### Is the GPT-6.1 Terra API private?

GPT-6.1 Terra is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.

### What is the context window of GPT-6.1 Terra?

### What does GPT-6.1 Terra support?
