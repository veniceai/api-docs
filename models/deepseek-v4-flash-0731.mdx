
### What is the DeepSeek V4 Flash 0731 model ID?

Use `deepseek-v4-flash-0731` as the `model` parameter. Other variants: `deepseek-v4-flash-0731-fast` (Fast).

### Is the DeepSeek V4 Flash 0731 API private?

DeepSeek V4 Flash 0731 is private: zero data retention is enforced by contract, so prompts and outputs are processed for inference only and not retained after the request completes.

### What is the context window of DeepSeek V4 Flash 0731?
