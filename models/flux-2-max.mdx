## How to use the Flux 2 Max API

Send requests to `POST https://api.venice.ai/api/v1/image/generate` with `"model": "flux-2-max"` and your API key.

```bash
curl https://api.venice.ai/api/v1/image/generate \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "flux-2-max",
    "prompt": "A retro travel poster with the bold headline \"VENICE\" in large condensed serif type, sunset color palette",
    "aspect_ratio": "auto"
  }'
```

## Flux 2 Max API FAQ

### How much does the Flux 2 Max API cost?

$0.09 per image. Editing costs $0.12 per edit. Prices are in USD and can be paid in DIEM at parity.

### What is the Flux 2 Max model ID?

Use `flux-2-max` as the `model` parameter. Other variants: `flux-2-max-edit` (Edit).

### Is the Flux 2 Max API private?

Flux 2 Max is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.

### What resolutions does Flux 2 Max support?

Aspect ratios: 1:1, 3:2, 16:9, 21:9, 9:16, 2:3, 3:4, 4:5. Prompts up to 3,000 characters.

### Which endpoint does the Flux 2 Max API use?
