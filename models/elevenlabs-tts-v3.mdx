## How to use the ElevenLabs TTS v3 API

Send requests to `POST https://api.venice.ai/api/v1/audio/queue` with `"model": "elevenlabs-tts-v3"` and your API key.

```bash
# 1. Queue the job
curl https://api.venice.ai/api/v1/audio/queue \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "elevenlabs-tts-v3",
    "prompt": "Private AI for everyone."
  }'

# 2. Retrieve when ready
curl https://api.venice.ai/api/v1/audio/retrieve \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "model": "elevenlabs-tts-v3", "queue_id": "<queue_id>" }' --output audio.mp3
```
