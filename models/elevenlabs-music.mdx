## How to use the ElevenLabs Music API

Send requests to `POST https://api.venice.ai/api/v1/audio/queue` with `"model": "elevenlabs-music"` and your API key.

```bash
# 1. Queue the job
curl https://api.venice.ai/api/v1/audio/queue \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "elevenlabs-music",
    "prompt": "Warm lo-fi hip hop beat with soft piano and vinyl crackle",
    "duration_seconds": 30
  }'

# 2. Retrieve when ready
curl https://api.venice.ai/api/v1/audio/retrieve \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "model": "elevenlabs-music", "queue_id": "<queue_id>" }' --output audio.mp3
```
