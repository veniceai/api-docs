## How to use the Upscaler API

Send requests to `POST https://api.venice.ai/api/v1/image/upscale` with `"model": "upscaler"` and your API key.

```bash
curl https://api.venice.ai/api/v1/image/upscale \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "upscaler",
    "image": "<base64-encoded image>",
    "scale": 2
  }' --output result.png
```
