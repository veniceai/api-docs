Send requests to `POST https://api.venice.ai/api/v1/chat/completions` with `"model": "grok-build-0-1"` and your API key.

```bash

  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{

  }'
```

## Grok Build 0.1 API FAQ

### How much does the Grok Build 0.1 API cost?

$1.00 per 1M input tokens and $2.00 per 1M output tokens, with cached input at $0.20 per 1M. Prices are in USD and can be paid in DIEM at parity.

### What is the Grok Build 0.1 model ID?

Use `grok-build-0-1` as the `model` parameter.

### Is the Grok Build 0.1 API private?

Grok Build 0.1 is private: requests run on infrastructure Venice controls with zero data retention, and prompts and outputs are never stored or used for training.

### What is the context window of Grok Build 0.1?

250K tokens of context, with up to 64K output tokens per response.

### What does Grok Build 0.1 support?

Grok Build 0.1 supports function calling, structured outputs, reasoning, image input, web search and prompt caching.

### Which endpoint does the Grok Build 0.1 API use?

Call `POST /chat/completions`. `/responses` (Alpha) is also supported.
