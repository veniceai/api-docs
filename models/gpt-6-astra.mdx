## How to use the GPT-6 Astra API

Send requests to `POST https://api.venice.ai/api/v1/responses` with `"model": "openai-gpt-6-astra"` and your API key.

```bash
curl https://api.venice.ai/api/v1/responses \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai-gpt-6-astra",
    "input": "Explain TEE attestation in two sentences.",
    "reasoning": { "effort": "high" }
  }'
```

### Is the GPT-6 Astra API private?

GPT-6 Astra is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.

### What is the context window of GPT-6 Astra?
