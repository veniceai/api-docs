## How to use the Kling 4.0 API

Send requests to `POST https://api.venice.ai/api/v1/video/queue` with `"model": "kling-v4-text-to-video"` and your API key.

```bash
# 1. Queue the job (returns a queue_id)
curl https://api.venice.ai/api/v1/video/queue \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kling-v4-text-to-video",
    "prompt": "Slow aerial drone shot over a misty mountain valley at golden hour",
    "duration": "5s",
    "resolution": "720p",
    "aspect_ratio": "16:9"
  }'

# 2. Poll until the MP4 is ready
curl https://api.venice.ai/api/v1/video/retrieve \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "model": "kling-v4-text-to-video", "queue_id": "<queue_id>" }' --output video.mp4
```

## Kling 4.0 API FAQ

### How much does the Kling 4.0 API cost?

From $0.20 to $0.29 per second of video, depending on resolution, duration and audio. A 5-second 720p clip with audio costs $0.98. Call `POST /video/quote` for the exact price before queueing. Prices are in USD and can be paid in DIEM at parity.

### What is the Kling 4.0 model ID?

Use `kling-v4-text-to-video` as the `model` parameter. Other variants: `kling-v4-image-to-video` (Image to video), `kling-v4-reference-to-video` (Reference to video).

### Is the Kling 4.0 API private?

Kling 4.0 is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.

### What resolutions and durations does Kling 4.0 support?

Resolutions: 720p, 1080p. Durations: 3s, 4s, 5s, 6s, 7s, 8s, 9s, 10s, 11s, 12s, 13s, 14s, 15s, 16s, 17s, 18s, 19s, 20s, 21s, 22s, 23s, 24s, 25s, 26s, 27s, 28s, 29s, 30s. Aspect ratios: 16:9, 9:16, 1:1, 21:9. Audio: always generated.

### Which endpoint does the Kling 4.0 API use?

Queue a job with `POST /video/queue`, then poll `/video/retrieve` for the result.
