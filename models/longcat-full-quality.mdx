## How to use the Longcat Full Quality API

Send requests to `POST https://api.venice.ai/api/v1/video/queue` with `"model": "longcat-text-to-video"` and your API key.

```bash
# 1. Queue the job (returns a queue_id)
curl https://api.venice.ai/api/v1/video/queue \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "longcat-text-to-video",
    "prompt": "Slow aerial drone shot over a misty mountain valley at golden hour",
    "duration": "5s",
    "resolution": "720p",
    "aspect_ratio": "16:9"
  }'

# 2. Poll until the MP4 is ready
curl https://api.venice.ai/api/v1/video/retrieve \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "model": "longcat-text-to-video", "queue_id": "<queue_id>" }' --output video.mp4
```

## Longcat Full Quality API FAQ

### How much does the Longcat Full Quality API cost?

From $0.051 to $0.051 per second of video, depending on resolution, duration and audio. A 5-second 720p clip costs $0.25. Call `POST /video/quote` for the exact price before queueing. Prices are in USD and can be paid in DIEM at parity.

### What is the Longcat Full Quality model ID?

Use `longcat-text-to-video` as the `model` parameter. Other variants: `longcat-image-to-video` (Image to video).

### Is the Longcat Full Quality API private?

Longcat Full Quality is private: requests run on infrastructure Venice controls with zero data retention, and prompts and outputs are never stored or used for training.

### What resolutions and durations does Longcat Full Quality support?

Resolutions: 720p. Durations: 5s, 10s, 15s, 20s, 30s. Aspect ratios: 16:9, 9:16, 1:1. Audio: none.

### Which endpoint does the Longcat Full Quality API use?

Queue a job with `POST /video/queue`, then poll `/video/retrieve` for the result.
