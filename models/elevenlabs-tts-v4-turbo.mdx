## How to use the ElevenLabs TTS v4 Turbo API

Send requests to `POST https://api.venice.ai/api/v1/audio/queue` with `"model": "elevenlabs-tts-v4-turbo"` and your API key.

```bash

  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
```
