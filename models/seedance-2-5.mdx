## How to use the Seedance 2.5 API

Send requests to `POST https://api.venice.ai/api/v1/video/queue` with `"model": "seedance-2-5-text-to-video-basic"` and your API key.

```bash
# 1. Queue the job (returns a queue_id)
curl https://api.venice.ai/api/v1/video/queue \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-2-5-text-to-video-basic",
    "prompt": "Slow aerial drone shot over a misty mountain valley at golden hour",
    "duration": "5s",
    "resolution": "720p",
    "aspect_ratio": "21:9",
    "audio": true
  }'

# 2. Poll until the MP4 is ready
curl https://api.venice.ai/api/v1/video/retrieve \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "model": "seedance-2-5-text-to-video-basic", "queue_id": "<queue_id>" }' --output video.mp4
```

## Seedance 2.5 API FAQ

### How much does the Seedance 2.5 API cost?

From $0.13 to $0.72 per second of video, depending on resolution, duration and audio. A 5-second 720p clip costs $1.45. Call `POST /video/quote` for the exact price before queueing. Prices are in USD and can be paid in DIEM at parity.

### What is the Seedance 2.5 model ID?

Use `seedance-2-5-text-to-video-basic` as the `model` parameter. Other variants: `seedance-2-5-image-to-video-basic` (Image to video), `seedance-2-5-reference-to-video-basic` (Reference to video).

### Is the Seedance 2.5 API private?

Seedance 2.5 is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.

### What resolutions and durations does Seedance 2.5 support?

Resolutions: 1080p, 720p, 480p. Durations: 4s, 5s, 6s, 7s, 8s, 9s, 10s, 11s, 12s, 13s, 14s, 15s, 16s, 17s, 18s, 19s, 20s, 21s, 22s, 23s, 24s, 25s, 26s, 27s, 28s, 29s, 30s. Aspect ratios: 21:9, 16:9, 4:3, 1:1, 3:4, 9:16. Audio: optional, with `"audio": true`.

### Which endpoint does the Seedance 2.5 API use?

Queue a job with `POST /video/queue`, then poll `/video/retrieve` for the result.
