# Mercury 3 API

Mercury 3 is a large language model by Inception, available on the Venice API as `mercury-3`. Requests are anonymized, so the provider never sees your identity.

Mercury 3 is Inception's most capable diffusion-based reasoning model, generating over 1,000 tokens per second with a 1M-token context window, tunable reasoning, tool calling, and structured output support.

## How to use the Mercury 3 API

Send requests to `POST https://api.venice.ai/api/v1/chat/completions` with `"model": "mercury-3"` and your API key.

```bash
curl https://api.venice.ai/api/v1/chat/completions \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mercury-3",
    "messages": [{ "role": "user", "content": "Explain TEE attestation in two sentences." }],
    "reasoning_effort": "high"
  }'
```

## Mercury 3 API FAQ

### How much does the Mercury 3 API cost?

$0.10 per 1M input tokens and $0.35 per 1M output tokens, with cached input at $0.01 per 1M. Prices are in USD and can be paid in DIEM at parity.

### What is the Mercury 3 model ID?

Use `mercury-3` as the `model` parameter.

### Is the Mercury 3 API private?

Mercury 3 is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.

### What is the context window of Mercury 3?

1M tokens of context, with up to 128K output tokens per response.

### What does Mercury 3 support?

Mercury 3 supports function calling, structured outputs, reasoning, web search and prompt caching. Reasoning effort is adjustable with `reasoning_effort`: none, low, medium and high (default high).

### Which endpoint does the Mercury 3 API use?

Call `POST /chat/completions`. `/responses` (Alpha) is also supported.
