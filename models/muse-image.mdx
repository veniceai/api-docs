## How to use the Muse Image API

Send requests to `POST https://api.venice.ai/api/v1/image/generate` with `"model": "muse-image"` and your API key.

```bash
curl https://api.venice.ai/api/v1/image/generate \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "muse-image",
    "prompt": "A retro travel poster with the bold headline \"VENICE\" in large condensed serif type, sunset color palette",
    "aspect_ratio": "1:1"
  }'
```

## Muse Image API FAQ

### How much does the Muse Image API cost?

$0.02 per image. Editing costs $0.02 per edit. Prices are in USD and can be paid in DIEM at parity.

### What is the Muse Image model ID?

Use `muse-image` as the `model` parameter. Other variants: `muse-image-edit` (Edit).

### Is the Muse Image API private?

Muse Image is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.

### What resolutions does Muse Image support?

Aspect ratios: 1:1, 3:2, 16:9, 21:9, 9:16, 2:3, 3:4. Prompts up to 10,000 characters.

### Which endpoint does the Muse Image API use?

Call `POST /image/generate`. `/images/generations` is also supported.
