## How to use the Seedance 2.0 Fast API

Send requests to `POST https://api.venice.ai/api/v1/video/queue` with `"model": "seedance-2-0-fast-text-to-video-basic"` and your API key.

```bash
# 1. Queue the job (returns a queue_id)
curl https://api.venice.ai/api/v1/video/queue \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-2-0-fast-text-to-video-basic",
    "prompt": "Slow aerial drone shot over a misty mountain valley at golden hour",
    "duration": "5s",
    "resolution": "720p",
    "aspect_ratio": "21:9",
    "audio": true
  }'

# 2. Poll until the MP4 is ready
curl https://api.venice.ai/api/v1/video/retrieve \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "model": "seedance-2-0-fast-text-to-video-basic", "queue_id": "<queue_id>" }' --output video.mp4
```

## Seedance 2.0 Fast API FAQ

### What is the Seedance 2.0 Fast model ID?

Use `seedance-2-0-fast-text-to-video-basic` as the `model` parameter. Other variants: `seedance-2-0-fast-image-to-video-basic` (Image to video), `seedance-2-0-fast-reference-to-video-basic` (Reference to video).

### Is the Seedance 2.0 Fast API private?

Seedance 2.0 Fast is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.

### What resolutions and durations does Seedance 2.0 Fast support?
