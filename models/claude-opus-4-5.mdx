### How much does the Claude Opus 4.5 API cost?

### What is the Claude Opus 4.5 model ID?

Use `claude-opus-4-5` as the `model` parameter.

### Is the Claude Opus 4.5 API private?

Claude Opus 4.5 is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.

### What is the context window of Claude Opus 4.5?

Claude Opus 4.5 supports function calling, structured outputs, reasoning, image input, web search and prompt caching.
