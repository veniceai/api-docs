## How to use the GPT-5.4 Mini API

Send requests to `POST https://api.venice.ai/api/v1/responses` with `"model": "openai-gpt-54-mini"` and your API key.

```bash
curl https://api.venice.ai/api/v1/responses \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai-gpt-54-mini",
    "input": "Explain TEE attestation in two sentences.",
    "reasoning": { "effort": "high" }
  }'
```

## GPT-5.4 Mini API FAQ

### How much does the GPT-5.4 Mini API cost?

$0.75 per 1M input tokens and $4.50 per 1M output tokens, with cached input at $0.075 per 1M. Prices are in USD and can be paid in DIEM at parity.

### What is the GPT-5.4 Mini model ID?

Use `openai-gpt-54-mini` as the `model` parameter.

### Is the GPT-5.4 Mini API private?

GPT-5.4 Mini is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.

### What is the context window of GPT-5.4 Mini?

400K tokens of context, with up to 125K output tokens per response.

### What does GPT-5.4 Mini support?

GPT-5.4 Mini supports function calling, structured outputs, reasoning, image input, web search and prompt caching. Reasoning effort is adjustable with `reasoning_effort`: none, low, medium, high and xhigh (default high).

### Which endpoint does the GPT-5.4 Mini API use?

Call `POST /responses`. `/chat/completions` is also supported. OpenAI reasoning models are designed around the Responses API: reasoning, tool calls and messages come back as typed output items. Venice's /responses endpoint is in alpha.
