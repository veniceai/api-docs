## MiniMax M3.1 Flash API FAQ

### How much does the MiniMax M3.1 Flash API cost?

$0.19 per 1M input tokens and $0.75 per 1M output tokens, with cached input at $0.019 per 1M. Prices are in USD and can be paid in DIEM at parity.

### What is the MiniMax M3.1 Flash model ID?

Use `minimax-m3-1-flash` as the `model` parameter.

### Is the MiniMax M3.1 Flash API private?

MiniMax M3.1 Flash is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.

### What is the context window of MiniMax M3.1 Flash?

1M tokens of context, with up to 128K output tokens per response.

### What does MiniMax M3.1 Flash support?

MiniMax M3.1 Flash supports function calling, reasoning, image input, web search and prompt caching. Reasoning effort is adjustable with `reasoning_effort`: low, medium, high, xhigh and max (default max).

### Which endpoint does the MiniMax M3.1 Flash API use?
