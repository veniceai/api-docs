## How to use the BGE-M3 API

Send requests to `POST https://api.venice.ai/api/v1/embeddings` with `"model": "text-embedding-bge-m3"` and your API key.

```bash
curl https://api.venice.ai/api/v1/embeddings \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "text-embedding-bge-m3",
    "input": "Private AI for everyone."
  }'
```
