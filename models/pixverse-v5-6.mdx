## How to use the PixVerse v5.6 API

Send requests to `POST https://api.venice.ai/api/v1/video/queue` with `"model": "pixverse-v5.6-text-to-video"` and your API key.

```bash
# 1. Queue the job (returns a queue_id)
curl https://api.venice.ai/api/v1/video/queue \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "pixverse-v5.6-text-to-video",
    "prompt": "Slow aerial drone shot over a misty mountain valley at golden hour",
    "duration": "5s",
    "resolution": "720p",
    "aspect_ratio": "16:9",
    "audio": true
  }'

# 2. Poll until the MP4 is ready
curl https://api.venice.ai/api/v1/video/retrieve \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "model": "pixverse-v5.6-text-to-video", "queue_id": "<queue_id>" }' --output video.mp4
```

## PixVerse v5.6 API FAQ

### How much does the PixVerse v5.6 API cost?

From $0.10 to $0.43 per second of video, depending on resolution, duration and audio. A 5-second 720p clip costs $0.57. Call `POST /video/quote` for the exact price before queueing. Prices are in USD and can be paid in DIEM at parity.

### What is the PixVerse v5.6 model ID?

Use `pixverse-v5.6-text-to-video` as the `model` parameter. Other variants: `pixverse-v5.6-image-to-video` (Image to video), `pixverse-v5.6-transition` (Transition).

### Is the PixVerse v5.6 API private?

PixVerse v5.6 is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.

### What resolutions and durations does PixVerse v5.6 support?

Resolutions: 360p, 540p, 720p, 1080p. Durations: 5s, 8s. Aspect ratios: 16:9, 9:16, 1:1, 4:3, 3:4. Audio: optional, with `"audio": true`.

### Which endpoint does the PixVerse v5.6 API use?
