## How to use the Gemini 3.1 Flash TTS API

Send requests to `POST https://api.venice.ai/api/v1/audio/speech` with `"model": "tts-gemini-3-1-flash"` and your API key.

```bash
curl https://api.venice.ai/api/v1/audio/speech \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "tts-gemini-3-1-flash",
    "input": "Private AI for everyone.",
    "voice": "Achernar",
    "response_format": "mp3"
  }' --output speech.mp3
```
