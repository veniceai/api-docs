## How to use the Qwen Image API

Send requests to `POST https://api.venice.ai/api/v1/image/generate` with `"model": "qwen-image"` and your API key.

```bash
curl https://api.venice.ai/api/v1/image/generate \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "qwen-image",
    "prompt": "A retro travel poster with the bold headline \"VENICE\" in large condensed serif type, sunset color palette",
    "aspect_ratio": "1:1"
  }'
```
