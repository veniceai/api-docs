## How to use the ElevenLabs Voice Changer API

Send requests to `POST https://api.venice.ai/api/v1/audio/queue` with `"model": "elevenlabs-voice-changer"` and your API key.

```bash
# 1. Queue the job
curl https://api.venice.ai/api/v1/audio/queue \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "elevenlabs-voice-changer",
    "prompt": "Warm lo-fi hip hop beat with soft piano and vinyl crackle"
  }'

# 2. Retrieve when ready
curl https://api.venice.ai/api/v1/audio/retrieve \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "model": "elevenlabs-voice-changer", "queue_id": "<queue_id>" }' --output audio.mp3
```
