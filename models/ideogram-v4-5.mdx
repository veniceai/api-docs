## How to use the Ideogram V4.5 API

Send requests to `POST https://api.venice.ai/api/v1/image/generate` with `"model": "ideogram-v4-5"` and your API key.

```bash
curl https://api.venice.ai/api/v1/image/generate \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "ideogram-v4-5",
    "prompt": "A retro travel poster with the bold headline \"VENICE\" in large condensed serif type, sunset color palette",
    "resolution": "1K",
    "aspect_ratio": "1:1"
  }'
```

## Ideogram V4.5 API FAQ

### How much does the Ideogram V4.5 API cost?

$0.26 at 1K and $0.26 at 2K per image. Editing costs $0.26 per edit. Prices are in USD and can be paid in DIEM at parity.

### What is the Ideogram V4.5 model ID?

Use `ideogram-v4-5` as the `model` parameter. Other variants: `ideogram-v4-5-edit` (Edit).

### Is the Ideogram V4.5 API private?

Ideogram V4.5 is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.

### What resolutions does Ideogram V4.5 support?

Resolutions: 1K, 2K. Aspect ratios: 1:1, 3:2, 16:9, 9:16, 2:3, 3:4, 4:5. Prompts up to 10,000 characters.

### Which endpoint does the Ideogram V4.5 API use?

Call `POST /image/generate`. `/images/generations` is also supported.
