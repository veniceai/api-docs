# Muse Wonder API

Muse Wonder is a large language model by Muse, available on the Venice API as `muse-wonder`. Requests are anonymized, so the provider never sees your identity.

Muse Wonder is a frontier reasoning model from Meta for complex personal and professional agentic tasks. It accepts text, images, video, audio, and PDF documents and returns text, with a 1M-token context window. The model plans, delegates to sub-agents, calls tools in parallel, and recovers from errors so long-horizon work can run to completion without step-by-step direction.

## How to use the Muse Wonder API

Send requests to `POST https://api.venice.ai/api/v1/chat/completions` with `"model": "muse-wonder"` and your API key.

```bash
curl https://api.venice.ai/api/v1/chat/completions \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "muse-wonder",
    "messages": [{ "role": "user", "content": "Explain TEE attestation in two sentences." }],
    "reasoning_effort": "high"
  }'
```

## Muse Wonder API FAQ

### How much does the Muse Wonder API cost?

$5.00 per 1M input tokens and $25.00 per 1M output tokens, with cached input at $0.25 per 1M. Prices are in USD and can be paid in DIEM at parity.

### What is the Muse Wonder model ID?

Use `muse-wonder` as the `model` parameter.

### Is the Muse Wonder API private?

Muse Wonder is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.

### What is the context window of Muse Wonder?

1M tokens of context, with up to 128K output tokens per response.

### What does Muse Wonder support?

Muse Wonder supports function calling, structured outputs, reasoning, image input, web search and prompt caching. Reasoning effort is adjustable with `reasoning_effort`: none, low, medium, high and max (default high).

### Which endpoint does the Muse Wonder API use?

Call `POST /chat/completions`. `/responses` (Alpha) is also supported.
