## How to use the Claude Fable 5 API

Send requests to `POST https://api.venice.ai/api/v1/chat/completions` with `"model": "claude-fable-5"` and your API key.

```bash
curl https://api.venice.ai/api/v1/chat/completions \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "claude-fable-5",
    "messages": [{ "role": "user", "content": "Explain TEE attestation in two sentences." }],
    "reasoning_effort": "high"
  }'
```

## Claude Fable 5 API FAQ

### How much does the Claude Fable 5 API cost?

$12.00 per 1M input tokens and $60.00 per 1M output tokens, with cached input at $1.20 per 1M. Prices are in USD and can be paid in DIEM at parity.

### What is the Claude Fable 5 model ID?

Use `claude-fable-5` as the `model` parameter.

### Is the Claude Fable 5 API private?

Claude Fable 5 is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.

### What is the context window of Claude Fable 5?

1M tokens of context, with up to 125K output tokens per response.

### What does Claude Fable 5 support?

Claude Fable 5 supports function calling, structured outputs, reasoning, image input, web search and prompt caching. Reasoning effort is adjustable with `reasoning_effort`: low, medium, high, xhigh and max (default high).

### Which endpoint does the Claude Fable 5 API use?

Call `POST /chat/completions`. `/responses` (Alpha) is also supported.
