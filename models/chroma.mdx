## How to use the Chroma API

Send requests to `POST https://api.venice.ai/api/v1/image/generate` with `"model": "chroma"` and your API key.

```bash
curl https://api.venice.ai/api/v1/image/generate \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "chroma",
    "prompt": "A retro travel poster with the bold headline \"VENICE\" in large condensed serif type, sunset color palette"
  }'
```

## Chroma API FAQ

### How much does the Chroma API cost?

$0.01 per image. Prices are in USD and can be paid in DIEM at parity.

### What is the Chroma model ID?

Use `chroma` as the `model` parameter.

### Is the Chroma API private?

Chroma is private: requests run on infrastructure Venice controls with zero data retention, and prompts and outputs are never stored or used for training.

### What resolutions does Chroma support?

Prompts up to 7,500 characters.

### Which endpoint does the Chroma API use?

Call `POST /image/generate`. `/images/generations` is also supported.
