## Claude Haiku 5.5 API FAQ

### How much does the Claude Haiku 5.5 API cost?

$0.10 per 1M input tokens and $0.50 per 1M output tokens, with cached input at $0.01 per 1M. Prices are in USD and can be paid in DIEM at parity.

### What is the Claude Haiku 5.5 model ID?

Use `claude-haiku-5-5` as the `model` parameter.

### Is the Claude Haiku 5.5 API private?

Claude Haiku 5.5 is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.

### What is the context window of Claude Haiku 5.5?

1M tokens of context, with up to 128K output tokens per response.

### What does Claude Haiku 5.5 support?

Claude Haiku 5.5 supports function calling, structured outputs, reasoning, image input, web search and prompt caching. Reasoning effort is adjustable with `reasoning_effort`: none, low, medium, high, xhigh and max (default medium).
