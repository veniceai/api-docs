## How to use the GPT-5.6 Sol API

Send requests to `POST https://api.venice.ai/api/v1/responses` with `"model": "openai-gpt-56-sol"` and your API key.

```bash
curl https://api.venice.ai/api/v1/responses \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai-gpt-56-sol",
    "input": "Explain TEE attestation in two sentences.",
    "reasoning": { "effort": "high" }
  }'
```

### What is the GPT-5.6 Sol model ID?

### Is the GPT-5.6 Sol API private?

GPT-5.6 Sol is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.

### What is the context window of GPT-5.6 Sol?

### What does GPT-5.6 Sol support?

GPT-5.6 Sol supports function calling, structured outputs, reasoning, image input, web search and prompt caching. Reasoning effort is adjustable with `reasoning_effort`: none, low, medium, high, xhigh and max (default high).

### Which endpoint does the GPT-5.6 Sol API use?
