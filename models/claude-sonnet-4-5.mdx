## How to use the Claude Sonnet 4.5 API

Send requests to `POST https://api.venice.ai/api/v1/chat/completions` with `"model": "claude-sonnet-4-5"` and your API key.

```bash
curl https://api.venice.ai/api/v1/chat/completions \
  -H "Authorization: Bearer $VENICE_API_KEY" \

  -d '{
```

## Claude Sonnet 4.5 API FAQ

### How much does the Claude Sonnet 4.5 API cost?

$3.75 per 1M input tokens and $18.75 per 1M output tokens, with cached input at $0.38 per 1M. Prices are in USD and can be paid in DIEM at parity.

### What is the Claude Sonnet 4.5 model ID?

Use `claude-sonnet-4-5` as the `model` parameter.

### Is the Claude Sonnet 4.5 API private?

Claude Sonnet 4.5 is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.

### What is the context window of Claude Sonnet 4.5?

198K tokens of context, with up to 64K output tokens per response.

### What does Claude Sonnet 4.5 support?

Claude Sonnet 4.5 supports function calling, structured outputs, reasoning, image input, web search and prompt caching.

### Which endpoint does the Claude Sonnet 4.5 API use?

Call `POST /chat/completions`. `/responses` (Alpha) is also supported.
