## How to use the Grok Imagine API

Send requests to `POST https://api.venice.ai/api/v1/image/generate` with `"model": "grok-imagine-image"` and your API key.

```bash
curl https://api.venice.ai/api/v1/image/generate \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "grok-imagine-image",
    "prompt": "A retro travel poster with the bold headline \"VENICE\" in large condensed serif type, sunset color palette",
    "resolution": "1K",
    "aspect_ratio": "1:1"
  }'
```

## Grok Imagine API FAQ

### How much does the Grok Imagine API cost?

$0.03 at 1K and $0.04 at 2K per image. Editing costs $0.03 per edit. Prices are in USD and can be paid in DIEM at parity.

### What is the Grok Imagine model ID?

Use `grok-imagine-image` as the `model` parameter. Other variants: `grok-imagine-edit` (Edit).

### Is the Grok Imagine API private?

Grok Imagine is private: requests run on infrastructure Venice controls with zero data retention, and prompts and outputs are never stored or used for training.

### What resolutions does Grok Imagine support?

Resolutions: 1K, 2K. Aspect ratios: 1:1, 16:9, 9:16, 3:4, 3:2, 2:3. Prompts up to 7,500 characters.

### Which endpoint does the Grok Imagine API use?

Call `POST /image/generate`. `/images/generations` is also supported.
