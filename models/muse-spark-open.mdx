# Muse Spark Open API

Muse Spark Open is a large language model by Muse, available on the Venice API as `muse-spark-open`. It runs privately, with zero data retention.

Muse Spark Open is an open-weight reasoning model from Meta for coding and agentic workflows. It supports tool calling and native image understanding in a single checkpoint, using a sparse Mixture-of-Experts architecture with 816B total / 42B active parameters and a 1M-token context window.

## How to use the Muse Spark Open API

Send requests to `POST https://api.venice.ai/api/v1/chat/completions` with `"model": "muse-spark-open"` and your API key.

```bash
curl https://api.venice.ai/api/v1/chat/completions \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "muse-spark-open",
    "messages": [{ "role": "user", "content": "Explain TEE attestation in two sentences." }],
    "reasoning_effort": "xhigh"
  }'
```

## Muse Spark Open API FAQ

### How much does the Muse Spark Open API cost?

$1.56 per 1M input tokens and $5.31 per 1M output tokens, with cached input at $0.19 per 1M. Prices are in USD and can be paid in DIEM at parity.

### What is the Muse Spark Open model ID?

Use `muse-spark-open` as the `model` parameter.

### Is the Muse Spark Open API private?

Muse Spark Open is private: zero data retention is enforced by contract, so prompts and outputs are processed for inference only and not retained after the request completes.

### What is the context window of Muse Spark Open?

1M tokens of context, with up to 128K output tokens per response.

### What does Muse Spark Open support?

Muse Spark Open supports function calling, structured outputs, reasoning, image input, web search and prompt caching. Reasoning effort is adjustable with `reasoning_effort`: low, medium, high and xhigh (default xhigh).

### Which endpoint does the Muse Spark Open API use?

Call `POST /chat/completions`. `/responses` (Alpha) is also supported.
