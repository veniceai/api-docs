# Claude Sonnet 5 API

Claude Sonnet 5 is a large language model by Anthropic, available on the Venice API as `claude-sonnet-5`. Requests are anonymized, so the provider never sees your identity.

Claude Sonnet 5 is Anthropic's latest Sonnet model, substantially improving on Sonnet 4.6 in coding and agentic work and reaching near-Opus quality on many tasks. It features a 1M token context window, adaptive thinking, and strong document and vision understanding.

## How to use the Claude Sonnet 5 API

Send requests to `POST https://api.venice.ai/api/v1/chat/completions` with `"model": "claude-sonnet-5"` and your API key.

```bash
curl https://api.venice.ai/api/v1/chat/completions \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "claude-sonnet-5",
    "messages": [{ "role": "user", "content": "Explain TEE attestation in two sentences." }],
    "reasoning_effort": "medium"
  }'
```

## Claude Sonnet 5 API FAQ

### How much does the Claude Sonnet 5 API cost?

$2.00 per 1M input tokens and $10.00 per 1M output tokens, with cached input at $0.20 per 1M. Prices are in USD and can be paid in DIEM at parity.

### What is the Claude Sonnet 5 model ID?

Use `claude-sonnet-5` as the `model` parameter.

### Is the Claude Sonnet 5 API private?

Claude Sonnet 5 is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.

### What is the context window of Claude Sonnet 5?

1M tokens of context, with up to 64K output tokens per response.

### What does Claude Sonnet 5 support?

Claude Sonnet 5 supports function calling, structured outputs, reasoning, image input, web search and prompt caching. Reasoning effort is adjustable with `reasoning_effort`: low, medium, high, xhigh and max (default medium).

### Which endpoint does the Claude Sonnet 5 API use?

Call `POST /chat/completions`. `/responses` (Alpha) is also supported.
