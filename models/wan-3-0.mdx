## How to use the Wan 3.0 API

Send requests to `POST https://api.venice.ai/api/v1/video/queue` with `"model": "wan-3-0-text-to-video"` and your API key.

```bash
# 1. Queue the job (returns a queue_id)
curl https://api.venice.ai/api/v1/video/queue \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "wan-3-0-text-to-video",
    "prompt": "Slow aerial drone shot over a misty mountain valley at golden hour",
    "duration": "5s",
    "resolution": "720p",
    "aspect_ratio": "16:9",
    "audio": true
  }'

# 2. Poll until the MP4 is ready
curl https://api.venice.ai/api/v1/video/retrieve \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "model": "wan-3-0-text-to-video", "queue_id": "<queue_id>" }' --output video.mp4
```

## Wan 3.0 API FAQ

### How much does the Wan 3.0 API cost?

From $0.052 to $0.21 per second of video, depending on resolution, duration and audio. A 5-second 720p clip costs $0.52. Call `POST /video/quote` for the exact price before queueing. Prices are in USD and can be paid in DIEM at parity.

### What is the Wan 3.0 model ID?

Use `wan-3-0-text-to-video` as the `model` parameter. Other variants: `wan-3-0-image-to-video` (Image to video), `wan-3-0-reference-to-video` (Reference to video).

### Is the Wan 3.0 API private?

Wan 3.0 is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.

### What resolutions and durations does Wan 3.0 support?

Resolutions: 1080p, 720p, 480p. Durations: 2s, 5s, 10s, 15s, 20s, 25s, 30s. Aspect ratios: 16:9, 9:16, 1:1, 4:3, 3:4. Audio: optional, with `"audio": true`.

### Which endpoint does the Wan 3.0 API use?

Queue a job with `POST /video/queue`, then poll `/video/retrieve` for the result.
