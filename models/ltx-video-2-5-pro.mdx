## How to use the LTX Video 2.5 Pro API

Send requests to `POST https://api.venice.ai/api/v1/video/queue` with `"model": "ltx-2-5-pro-text-to-video"` and your API key.

```bash
# 1. Queue the job (returns a queue_id)
curl https://api.venice.ai/api/v1/video/queue \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "ltx-2-5-pro-text-to-video",
    "prompt": "Slow aerial drone shot over a misty mountain valley at golden hour",
    "duration": "6s",
    "resolution": "720p",
    "aspect_ratio": "16:9",
    "audio": true
  }'

# 2. Poll until the MP4 is ready
curl https://api.venice.ai/api/v1/video/retrieve \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "model": "ltx-2-5-pro-text-to-video", "queue_id": "<queue_id>" }' --output video.mp4
```

## LTX Video 2.5 Pro API FAQ

### How much does the LTX Video 2.5 Pro API cost?

From $0.13 to $0.19 per second of video, depending on resolution, duration and audio. A 6-second 720p clip costs $0.79. Call `POST /video/quote` for the exact price before queueing. Prices are in USD and can be paid in DIEM at parity.

### What is the LTX Video 2.5 Pro model ID?

Use `ltx-2-5-pro-text-to-video` as the `model` parameter. Other variants: `ltx-2-5-pro-image-to-video` (Image to video).

### Is the LTX Video 2.5 Pro API private?

LTX Video 2.5 Pro is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.

### What resolutions and durations does LTX Video 2.5 Pro support?

Resolutions: 720p, 1080p. Durations: 6s, 8s, 10s. Aspect ratios: 16:9, 9:16. Audio: optional, with `"audio": true`.

### Which endpoint does the LTX Video 2.5 Pro API use?

Queue a job with `POST /video/queue`, then poll `/video/retrieve` for the result.
