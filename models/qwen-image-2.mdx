## How to use the Qwen Image 2 API

Send requests to `POST https://api.venice.ai/api/v1/image/generate` with `"model": "qwen-image-2"` and your API key.

```bash
curl https://api.venice.ai/api/v1/image/generate \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "qwen-image-2",
    "prompt": "A retro travel poster with the bold headline \"VENICE\" in large condensed serif type, sunset color palette",
    "aspect_ratio": "1:1"
  }'
```

## Qwen Image 2 API FAQ

### How much does the Qwen Image 2 API cost?

$0.05 per image. Editing costs $0.05 per edit. Prices are in USD and can be paid in DIEM at parity.

### What is the Qwen Image 2 model ID?

Use `qwen-image-2` as the `model` parameter. Other variants: `qwen-image-2-edit` (Edit).

### Is the Qwen Image 2 API private?

Qwen Image 2 is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.

### What resolutions does Qwen Image 2 support?

Aspect ratios: 1:1, 3:2, 16:9, 21:9, 9:16, 2:3, 3:4, 4:5. Prompts up to 10,000 characters.

### Which endpoint does the Qwen Image 2 API use?

Call `POST /image/generate`. `/images/generations` is also supported.
