# GPT-6.1 Sol API

GPT-6.1 Sol is a large language model by OpenAI, available on the Venice API as `openai-gpt-61-sol`. Requests are anonymized, so the provider never sees your identity.

## How to use the GPT-6.1 Sol API

Send requests to `POST https://api.venice.ai/api/v1/responses` with `"model": "openai-gpt-61-sol"` and your API key.

```bash
curl https://api.venice.ai/api/v1/responses \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai-gpt-61-sol",
    "input": "Explain TEE attestation in two sentences.",
    "reasoning": { "effort": "high" }
  }'
```

### What is the GPT-6.1 Sol model ID?

Use `openai-gpt-61-sol` as the `model` parameter.

### Is the GPT-6.1 Sol API private?

GPT-6.1 Sol is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.

### What is the context window of GPT-6.1 Sol?

1.05M tokens of context, with up to 128K output tokens per response.

### What does GPT-6.1 Sol support?

GPT-6.1 Sol supports function calling, structured outputs, reasoning, image input, web search and prompt caching. Reasoning effort is adjustable with `reasoning_effort`: low, medium, high, xhigh and max (default high).

### Which endpoint does the GPT-6.1 Sol API use?
