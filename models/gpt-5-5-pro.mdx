## How to use the GPT-5.5 Pro API

Send requests to `POST https://api.venice.ai/api/v1/responses` with `"model": "openai-gpt-55-pro"` and your API key.

```bash
curl https://api.venice.ai/api/v1/responses \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openai-gpt-55-pro",
    "input": "Explain TEE attestation in two sentences.",
    "reasoning": { "effort": "medium" }
  }'
```

## GPT-5.5 Pro API FAQ

### How much does the GPT-5.5 Pro API cost?

$37.50 per 1M input tokens and $225 per 1M output tokens. Prices are in USD and can be paid in DIEM at parity.

### What is the GPT-5.5 Pro model ID?

Use `openai-gpt-55-pro` as the `model` parameter.

### Is the GPT-5.5 Pro API private?

GPT-5.5 Pro is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.

### What is the context window of GPT-5.5 Pro?

1M tokens of context, with up to 125K output tokens per response.

### What does GPT-5.5 Pro support?

GPT-5.5 Pro supports function calling, structured outputs, reasoning, image input and web search. Reasoning effort is adjustable with `reasoning_effort`: medium, high and xhigh (default medium).

### Which endpoint does the GPT-5.5 Pro API use?

Call `POST /responses`. `/chat/completions` is also supported. Pro and Codex models are Responses-native upstream. Use /responses for typed reasoning, tool-call and message items; /chat/completions stays fully supported.
