Claude Opus 5.5 is a large language model by Anthropic, available on the Venice API as `claude-opus-5-5`. Requests are anonymized, so the provider never sees your identity.

## How to use the Claude Opus 5.5 API

Send requests to `POST https://api.venice.ai/api/v1/chat/completions` with `"model": "claude-opus-5-5"` and your API key.

```bash
curl https://api.venice.ai/api/v1/chat/completions \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "claude-opus-5-5",
    "messages": [{ "role": "user", "content": "Explain TEE attestation in two sentences." }],
    "reasoning_effort": "medium"
  }'
```

## Claude Opus 5.5 API FAQ

### How much does the Claude Opus 5.5 API cost?

$4.80 per 1M input tokens and $24.00 per 1M output tokens, with cached input at $0.24 per 1M. The Fast variant costs $9.60 input and $48.00 output. Prices are in USD and can be paid in DIEM at parity.

### What is the Claude Opus 5.5 model ID?

Use `claude-opus-5-5` as the `model` parameter. Other variants: `claude-opus-5-5-fast` (Fast).

### Is the Claude Opus 5.5 API private?

Claude Opus 5.5 is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.

### What is the context window of Claude Opus 5.5?

1M tokens of context, with up to 125K output tokens per response.

### What does Claude Opus 5.5 support?

Claude Opus 5.5 supports function calling, structured outputs, reasoning, image input, web search and prompt caching. Reasoning effort is adjustable with `reasoning_effort`: low, medium, high, xhigh and max (default medium).

### Which endpoint does the Claude Opus 5.5 API use?

Call `POST /chat/completions`. `/responses` (Alpha) is also supported.
