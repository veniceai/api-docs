## How to use the Seedream V5 Pro API

Send requests to `POST https://api.venice.ai/api/v1/image/generate` with `"model": "seedream-v5-pro"` and your API key.

```bash
curl https://api.venice.ai/api/v1/image/generate \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedream-v5-pro",
    "prompt": "A retro travel poster with the bold headline \"VENICE\" in large condensed serif type, sunset color palette",
    "resolution": "1K",
    "aspect_ratio": "1:1"
  }'
```

## Seedream V5 Pro API FAQ

### How much does the Seedream V5 Pro API cost?

$0.06 at 1K and $0.11 at 2K per image. Editing costs $0.06 per edit. Prices are in USD and can be paid in DIEM at parity.

### What is the Seedream V5 Pro model ID?

Use `seedream-v5-pro` as the `model` parameter. Other variants: `seedream-v5-pro-edit` (Edit).

### Is the Seedream V5 Pro API private?

Seedream V5 Pro is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.

### What resolutions does Seedream V5 Pro support?

Resolutions: 1K, 2K. Aspect ratios: 1:1, 3:2, 16:9, 9:16, 2:3, 3:4, 4:3. Prompts up to 10,000 characters.

### Which endpoint does the Seedream V5 Pro API use?

Call `POST /image/generate`. `/images/generations` is also supported.
