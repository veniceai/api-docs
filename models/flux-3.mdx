## How to use the Flux 3 API

Send requests to `POST https://api.venice.ai/api/v1/video/queue` with `"model": "flux-3-text-to-video"` and your API key.

```bash
# 1. Queue the job (returns a queue_id)
curl https://api.venice.ai/api/v1/video/queue \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "flux-3-text-to-video",
    "prompt": "Slow aerial drone shot over a misty mountain valley at golden hour",
    "duration": "5s",
    "resolution": "720p",
    "aspect_ratio": "auto"
  }'

# 2. Poll until the MP4 is ready
curl https://api.venice.ai/api/v1/video/retrieve \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "model": "flux-3-text-to-video", "queue_id": "<queue_id>" }' --output video.mp4
```

## Flux 3 API FAQ

### How much does the Flux 3 API cost?

From $0.19 to $0.32 per second of video, depending on resolution, duration and audio. A 5-second 720p clip with audio costs $0.94. Call `POST /video/quote` for the exact price before queueing. Prices are in USD and can be paid in DIEM at parity.

### What is the Flux 3 model ID?

Use `flux-3-text-to-video` as the `model` parameter. Other variants: `flux-3-image-to-video` (Image to video), `flux-3-first-last-frame-to-video` (First & last frame).

### Is the Flux 3 API private?

Flux 3 is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.

### What resolutions and durations does Flux 3 support?

Resolutions: 720p, 1080p. Durations: 5s, 10s, 15s, 20s. Aspect ratios: auto, 21:9, 16:9, 4:3, 1:1, 3:4, 9:16, 9:21. Audio: always generated.

### Which endpoint does the Flux 3 API use?

Queue a job with `POST /video/queue`, then poll `/video/retrieve` for the result.
