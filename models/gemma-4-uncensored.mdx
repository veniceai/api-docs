# Gemma 4 Uncensored API

Gemma 4 Uncensored is a large language model by Google, available on the Venice API as `gemma-4-uncensored`. It runs privately, with zero data retention.

### How much does the Gemma 4 Uncensored API cost?

### Is the Gemma 4 Uncensored API private?

Gemma 4 Uncensored is private: zero data retention is enforced by contract, so prompts and outputs are processed for inference only and not retained after the request completes.

### What is the context window of Gemma 4 Uncensored?

Gemma 4 Uncensored supports function calling, structured outputs, image input and web search.
