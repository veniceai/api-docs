## How to use the Aion 3.0 API

Send requests to `POST https://api.venice.ai/api/v1/chat/completions` with `"model": "aion-labs-aion-3-0"` and your API key.

```bash
curl https://api.venice.ai/api/v1/chat/completions \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "aion-labs-aion-3-0",
    "messages": [{ "role": "user", "content": "Explain TEE attestation in two sentences." }]
  }'
```

## Aion 3.0 API FAQ

### How much does the Aion 3.0 API cost?

$3.75 per 1M input tokens and $7.50 per 1M output tokens, with cached input at $0.94 per 1M. Prices are in USD and can be paid in DIEM at parity.

### What is the Aion 3.0 model ID?

Use `aion-labs-aion-3-0` as the `model` parameter.

### Is the Aion 3.0 API private?

Aion 3.0 is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.

### What is the context window of Aion 3.0?

125K tokens of context, with up to 32K output tokens per response.

### What does Aion 3.0 support?

Aion 3.0 supports function calling, structured outputs, reasoning, web search and prompt caching.

### Which endpoint does the Aion 3.0 API use?

Call `POST /chat/completions`. `/responses` (Alpha) is also supported.
