Send requests to `POST https://api.venice.ai/api/v1/chat/completions` with `"model": "claude-sonnet-4-6"` and your API key.


### Is the Claude Sonnet 4.6 API private?

Claude Sonnet 4.6 is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.
