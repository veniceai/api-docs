## How to use the Seedream V5 Lite API

Send requests to `POST https://api.venice.ai/api/v1/image/generate` with `"model": "seedream-v5-lite"` and your API key.

```bash
curl https://api.venice.ai/api/v1/image/generate \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedream-v5-lite",
    "prompt": "A retro travel poster with the bold headline \"VENICE\" in large condensed serif type, sunset color palette",
    "aspect_ratio": "1:1"
  }'
```

## Seedream V5 Lite API FAQ

### How much does the Seedream V5 Lite API cost?

$0.05 per image. Editing costs $0.05 per edit. Prices are in USD and can be paid in DIEM at parity.

### What is the Seedream V5 Lite model ID?

Use `seedream-v5-lite` as the `model` parameter. Other variants: `seedream-v5-lite-edit` (Edit).

### Is the Seedream V5 Lite API private?

Seedream V5 Lite is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.

### What resolutions does Seedream V5 Lite support?

Aspect ratios: 1:1, 3:2, 16:9, 21:9, 9:16, 2:3, 3:4, 4:5, 4:3. Prompts up to 10,000 characters.

### Which endpoint does the Seedream V5 Lite API use?

Call `POST /image/generate`. `/images/generations` is also supported.
