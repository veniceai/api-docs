# GPT Image 2 API

GPT Image 2 is an image generation and image editing model by OpenAI, available on the Venice API as `gpt-image-2`. Requests are anonymized, so the provider never sees your identity.

## How to use the GPT Image 2 API

Send requests to `POST https://api.venice.ai/api/v1/image/generate` with `"model": "gpt-image-2"` and your API key.

```bash
curl https://api.venice.ai/api/v1/image/generate \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "A retro travel poster with the bold headline \"VENICE\" in large condensed serif type, sunset color palette",
    "resolution": "1K",
    "aspect_ratio": "1:1"
  }'
```

## GPT Image 2 API FAQ

### How much does the GPT Image 2 API cost?

$0.27 at 1K, $0.51 at 2K and $0.84 at 4K per image. Editing costs $0.34 per edit. Prices are in USD and can be paid in DIEM at parity.

### What is the GPT Image 2 model ID?

Use `gpt-image-2` as the `model` parameter. Other variants: `gpt-image-2-edit` (Edit).

### Is the GPT Image 2 API private?

GPT Image 2 is anonymized: Venice forwards requests to the provider without your identity, but the provider may retain prompt data, so use a private model for sensitive work.

### What resolutions does GPT Image 2 support?

Resolutions: 1K, 2K, 4K. Aspect ratios: 1:1, 3:2, 16:9, 21:9, 9:16, 2:3, 3:4, 4:5. Prompts up to 10,000 characters.

### Which endpoint does the GPT Image 2 API use?

Call `POST /image/generate`. `/images/generations` is also supported.
