## How to use the MiniMax Music 2.6 API

Send requests to `POST https://api.venice.ai/api/v1/audio/queue` with `"model": "minimax-music-v26"` and your API key.

```bash
# 1. Queue the job
curl https://api.venice.ai/api/v1/audio/queue \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "minimax-music-v26",
    "prompt": "Warm lo-fi hip hop beat with soft piano and vinyl crackle"
  }'

# 2. Retrieve when ready
curl https://api.venice.ai/api/v1/audio/retrieve \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "model": "minimax-music-v26", "queue_id": "<queue_id>" }' --output audio.mp3
```
