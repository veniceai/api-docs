Cuando ocurre un error, la API de Venice devuelve un código de estado HTTP y un mensaje descriptivo. Algunos errores también incluyen campos adicionales, como estado de reembolso, modelos sugeridos para reintentar, detalles de validación o IDs de solicitud.

## Formato de respuesta de error

La mayoría de los errores devuelven un campo `error` con un mensaje legible para humanos:

```json
{
  "error": "Invalid request parameters"
}
```

Algunos endpoints incluyen campos adicionales específicos del endpoint. Por ejemplo, los errores de moderación de vídeo pueden incluir si se reembolsaron los créditos:

```json
{
  "error": "Your generation was blocked due to the model provider's content policies. Credits have been refunded.",
  "credits_refunded": true
}
```

Los errores de validación pueden incluir campos `details` e `issues` con información de validación a nivel de campo:

```json
{
  "error": "Invalid request parameters",
  "details": {
    "_errors": [],
    "field": {
      "_errors": ["Field is required"]
    }
  },
  "issues": []
}
```

Algunos endpoints compatibles con OpenAI pueden devolver objetos de error al estilo de OpenAI para casos específicos, como errores de longitud de contexto:

```json
{
  "error": {
    "message": "Your request exceeds the model's maximum context. Please reduce your prompt or completion length.",
    "type": "invalid_request_error",
    "param": "messages",
    "code": "context_length_exceeded"
  }
}
```

## Credenciales ausentes

Una solicitud sin credenciales devuelve `402 Payment Required`, no `401`. La mayoría de las rutas de pago también aceptan [autenticación con billetera x402](/es/guides/integrations/x402-venice-api), por lo que la respuesta es un desafío de pago: incluye un encabezado `PAYMENT-REQUIRED` y un cuerpo que describe ambas formas de autenticarse. Las rutas de video y de cambio de voz envían el mismo desafío, pero por ahora solo aceptan una clave de API.

```json
{
  "x402Version": 2,
  "error": "Authentication required",
  "accepts": [ ... ],
  "authOptions": {
    "apiKey": {
      "header": "Authorization: Bearer YOUR_API_KEY",
      "getKey": "https://venice.ai/settings/api"
    },
    "x402Wallet": {
      "header": "SIGN-IN-WITH-X",
      "topUp": "POST /api/v1/x402/top-up"
    }
  }
}
```

Si un `402` en una ruta de pago te sorprende, normalmente se debe a que falta el encabezado de credenciales, no a un problema de facturación. Un cuerpo con `x402Version` y `accepts` significa que nada autenticó la solicitud: define `Authorization: Bearer $VENICE_API_KEY` y vuelve a intentarlo. El campo `authOptions.apiKey.header` del cuerpo indica la forma exacta del encabezado.

Un `402` que dice "Insufficient USD or Diem balance" (`INSUFFICIENT_BALANCE` en la tabla de abajo) es distinto: ese se debe al saldo de la cuenta. Consulta [pagar por el uso](/pricing#paying-for-usage).

Una clave presente pero no válida devuelve `401`.

## Errores de formato de la solicitud

Estos errores se producen al leer el cuerpo de la solicitud, antes de que se ejecute cualquier validación específica del endpoint.

| Estado HTTP | Mensaje | Causa |
| --- | --- | --- |
| 400 | `'Content-Type' must be 'application/json'` | Un cuerpo `POST`, `PUT` o `PATCH` enviado sin `Content-Type: application/json`. Los endpoints que aceptan subida de archivos también aceptan `multipart/form-data` |
| 400 | `Invalid JSON request` | El cuerpo no es JSON válido |
| 400 | `Invalid multipart request: malformed part header` | Un cuerpo `multipart/form-data` que no se puede analizar |
| 413 | `Request body exceeds the maximum allowed size.` | El cuerpo de la solicitud es demasiado grande |
| 415 | `Request encoding is not supported` | Un `Content-Encoding` o charset que la API no puede decodificar |

Un `Content-Type` incorrecto devuelve `400`, no `415`. Las respuestas `413` por límite de tamaño también incluyen un campo `code`:

```json
{
  "code": "PAYLOAD_TOO_LARGE",
  "error": "Request body exceeds the maximum allowed size."
}
```

## Códigos de error

Los códigos de esta tabla nombran cada error como referencia. La mayoría de las respuestas no los incluyen: el cuerpo solo trae el mensaje en `error`. Las excepciones son las respuestas `413` y los errores de billetera x402, que añaden un campo `code`. Decide según el estado HTTP y no compares el texto del mensaje, que puede variar.

| Código de error | Estado HTTP | Mensaje | Qué hacer |
| --- | --- | --- | --- |
| `AUTHENTICATION_FAILED` | 401 | Authentication failed | Revisa el encabezado `Authorization: Bearer` y que la clave no se haya eliminado ni haya caducado. Los endpoints de cuenta y de gestión de claves también responden con este código a una clave Inference; usa una clave Admin allí. |
| `AUTHENTICATION_FAILED_INACTIVE_KEY` | 401 | Authentication failed - Pro subscription is inactive. Please upgrade your subscription to continue using the API | La cuenta de la clave no puede usar la API. Inicia sesión en venice.ai para revisar la cuenta o contacta con support@venice.ai. |
| `X402_INVALID_SIGN_IN` | 401 | Invalid Sign-in-with-x signature | Firma una nueva prueba `SIGN-IN-WITH-X` con el nonce del último desafío `402`. Consulta [x402](/es/guides/integrations/x402-venice-api). |
| `X402_USER_NOT_ALLOWED` | 401 | Wallet user is not allowed to authenticate | La cuenta de Venice de la billetera está bloqueada o eliminada, o sus créditos pertenecen a otro usuario. Usa otra billetera. |
| `PRO_ONLY_MODEL` | 401 | This model is only available to Pro users | Usa un modelo incluido en tu plan o cambia a un plan de pago. |
| `INSUFFICIENT_BALANCE` | 402 | Insufficient USD or Diem balance to complete request. Visit https://venice.ai/settings/api to add credits. | Añade créditos o haz staking de [DIEM](/es/overview/vvv-diem) y vuelve a intentarlo. |
| `API_KEY_DIEM_SPEND_LIMIT_EXCEEDED` | 402 | API key DIEM spend limit exceeded. Your account may still have DIEM balance, but this API key has reached its configured DIEM spending limit. | Aumenta o elimina el límite de DIEM de la clave, o espera a que se reinicie su periodo de límite. |
| `API_KEY_USD_SPEND_LIMIT_EXCEEDED` | 402 | API key USD spend limit exceeded. Your account may still have USD balance, but this API key has reached its configured USD spending limit. | Aumenta o elimina el límite de USD de la clave, o espera a que se reinicie su periodo de límite. |
| `UNAUTHORIZED` | 403 | Unauthorized access | Lee el mensaje, que indica qué bloqueó la solicitud, como tu región. |
| `API_ACCESS_DISABLED` | 403 | API access has been disabled for this account. Please contact support@venice.ai | Contacta con support@venice.ai. |
| `X402_WALLET_MISMATCH` | 403 | You can only access resources for your own wallet | Solicita el saldo o las transacciones de la billetera con la que iniciaste sesión. |
| `INVALID_REQUEST` | 400 | Invalid request parameters | Corrige los campos indicados en `details`, `issues` o el mensaje. |
| `INVALID_MODEL` | 400 | Invalid model specified | Usa un modelo compatible con este endpoint. `GET /models` lista las capacidades de cada modelo. |
| `REQUEST_ID_NOT_FOUND` | 400 | Request ID is invalid. | Comprueba que el ID de la cola y el modelo coincidan con un trabajo que hayas encolado. |
| `INVALID_AUDIO_FORMAT` | 400 | Invalid audio format. Supported formats are WAV and MP3. | Convierte el audio a un formato que acepte el endpoint. |
| `INVALID_VIDEO_FORMAT` | 400 | Invalid video format. Supported formats include MP4, MOV, WebM, MKV, AVI, and others. | Convierte el video a un formato compatible, como MP4. |
| `CORRUPTED_IMAGE` | 400 | The image file is corrupted or unreadable | Vuelve a codificar la imagen o envía otro archivo. |
| `IMAGE_TOO_SMALL` | 400 | Image dimensions are too small | Envía una imagen más grande. |
| `TOO_MANY_TOKENS` | 400 | Your request exceeds the model's maximum context. Please reduce your prompt or completion length. | Acorta los mensajes o reduce `max_tokens`. `GET /models` lista el tamaño de contexto de cada modelo. |
| `CHARACTER_NOT_FOUND` | 404 | No character could be found from the provided `character_slug` | Usa un slug de [`GET /characters`](/es/api-reference/endpoint/characters/list). |
| `MODEL_NOT_FOUND` | 404 | Specified model not found | Usa un ID actual de `GET /models`. Los modelos retirados aparecen en [Deprecaciones](/es/overview/deprecations). |
| `MEDIA_NOT_FOUND` | 404 | Media could not be found. Request may be invalid, expired, or deleted. | El resultado caducó o se eliminó. Vuelve a encolar el trabajo. |
| `PAYLOAD_TOO_LARGE` | 413 | The request payload is too large. Please reduce the size of your request. | Envía un cuerpo o archivo más pequeño. |
| `INVALID_CONTENT_TYPE` | 415 | Invalid request content-type. Returned only by `/image/multi-edit` | Envía `multipart/form-data` o `application/json`. |
| `VIDEO_DURATION_TOO_LONG` | 422 | Video duration exceeds the maximum allowed. | Usa una duración que el modelo indique en `GET /models?type=video`. |
| `VIDEO_DURATION_TOO_SHORT` | 422 | Video duration is too short. | Usa una duración que el modelo indique en `GET /models?type=video`. |
| `IMAGE_TOO_LARGE` | 422 | Image dimensions exceed the maximum allowed. | Reduce el tamaño de la imagen. |
| `CONTENT_POLICY_VIOLATION` | 422 | Your prompt violates the content policy of Venice.ai or the model provider | Cambia el prompt o usa otro modelo. Las políticas varían según el modelo y el proveedor. |
| `ASR_UPSTREAM_VALIDATION_FAILED` | 422 | The audio could not be processed for transcription. Common causes: zero-length, silent, corrupt, or unsupported-language audio. Please verify the file and retry. | Comprueba que el audio no esté vacío, en silencio ni dañado, y que su idioma sea compatible. |
| `RATE_LIMIT_EXCEEDED` | 429 | Rate limit exceeded | Espera hasta `x-ratelimit-reset-requests` y vuelve a intentarlo. Consulta [Límites de velocidad](/es/api-reference/rate-limiting). |
| `MODEL_OVERLOADED` | 429 | The model is currently overloaded. Please try again later. | Vuelve a intentarlo tras el encabezado `Retry-After` o cambia de modelo. |
| `INFERENCE_FAILED` | 500 | Inference processing failed | Vuelve a intentarlo con backoff. Las solicitudes fallidas cuentan para el [presupuesto de errores](/es/api-reference/rate-limiting#presupuestos-de-errores). |
| `UPSCALE_FAILED` | 500 | Image upscaling failed | Vuelve a intentarlo con backoff. |
| `IMAGE_EDIT_ERROR` | 500 | Image edit failed | Vuelve a intentarlo con backoff. |
| `UNKNOWN_ERROR` | 500 | An unknown error occurred | Vuelve a intentarlo con backoff. Si sigue ocurriendo, contacta con support@venice.ai. |
| `TEE_ATTESTATION_FAILED` | 502 | TEE attestation request failed. The Trusted Execution Environment provider may be temporarily unavailable. | Vuelve a intentarlo más tarde. |
| `TEE_SIGNATURE_FAILED` | 502 | TEE signature request failed. The Trusted Execution Environment provider may be temporarily unavailable. | Vuelve a intentarlo más tarde. |
| `ASR_UPSTREAM_FAILED` | 502 | Audio transcription failed due to a temporary upstream error. Please retry. | Repite la solicitud. |
| `MODEL_OFFLINE` | 503 | The model is temporarily offline. Please try again later. | Vuelve a intentarlo más tarde o cambia de modelo. |
| `MODEL_AT_CAPACITY` | 503 | The model is at capacity. Please try again later. | Vuelve a intentarlo más tarde o cambia de modelo. |
| `REQUEST_TIMEOUT` | 504 | The request took too long to complete and was timed-out. For non-streaming requests, use the streaming API by setting `stream=true`. A streaming chat completion that times out before the model's first chunk reports the failure as an in-band SSE error frame instead. | Establece `stream: true` o envía una solicitud más corta. |

## Otros errores

La tabla anterior no es exhaustiva. Algunos errores se devuelven sin un código de la lista, y los mensajes pueden variar según el modelo y el endpoint, así que basa tu lógica en el estado HTTP y no en el texto del mensaje. Errores que puedes encontrar y que no están en la tabla:

| Estado HTTP | Cuándo ocurre |
| --- | --- |
| 400 | Una imagen de entrada en una solicitud de chat o de Responses está en un formato no compatible |
| 400 | La voz solicitada no está disponible para el modelo de texto a voz |
| 403 | La solicitud procede de una dirección IP que no está en la lista de permitidas de la clave de API |
| 403 | La configuración de privacidad de la clave de API no permite el modelo solicitado |
| 403 | El acceso al modelo solicitado está restringido. Contacta con support@venice.ai |
| 409 | Un resultado de vídeo, música o cambio de voz aún se está subiendo cuando lo recuperas. Reinténtalo en breve |
| 410 | El endpoint se ha retirado |
| 422 | El audio es demasiado largo o demasiado corto (clonación de voz, cambio de voz y trabajos de audio) |
| 422 | La imagen de entrada de una solicitud de vídeo tiene una relación entre ancho y alto fuera del rango que acepta el modelo |
| 422 | La entrada de una solicitud de vídeo fue bloqueada por la moderación de contenido |
| 500 | Falló la generación de vídeo o de cambio de voz |
| 502 | La síntesis de voz falló en el proveedor, o no se pudo recuperar un vídeo generado. Reintenta la solicitud |
