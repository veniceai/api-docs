Cuando ocurre un error, la API de Venice devuelve un código de estado HTTP y un mensaje descriptivo. Algunos errores también incluyen campos adicionales, como estado de reembolso, modelos sugeridos para reintentar, detalles de validación o IDs de solicitud.

## Formato de respuesta de error

La mayoría de los errores devuelven un campo `error` con un mensaje legible para humanos:

```json
{
  "error": "Invalid request parameters"
}
```

Algunos endpoints incluyen campos adicionales específicos del endpoint. Por ejemplo, los errores de moderación de vídeo pueden incluir si se reembolsaron los créditos:

```json
{
  "error": "Your generation was blocked due to the model provider's content policies. Credits have been refunded.",
  "credits_refunded": true
}
```

Los errores de validación pueden incluir campos `details` e `issues` con información de validación a nivel de campo:

```json
{
  "error": "Invalid request parameters",
  "details": {
    "_errors": [],
    "field": {
      "_errors": ["Field is required"]
    }
  },
  "issues": []
}
```

Algunos endpoints compatibles con OpenAI pueden devolver objetos de error al estilo de OpenAI para casos específicos, como errores de longitud de contexto:

```json
{
  "error": {
    "message": "Your request exceeds the model's maximum context. Please reduce your prompt or completion length.",
    "type": "invalid_request_error",
    "param": "messages",
    "code": "context_length_exceeded"
  }
}
```

## Credenciales ausentes

Una solicitud sin credenciales devuelve `402 Payment Required`, no `401`. Todas las rutas de pago también aceptan [autenticación con billetera x402](/es/guides/integrations/x402-venice-api), por lo que la respuesta es un desafío de pago: incluye un encabezado `PAYMENT-REQUIRED` y un cuerpo que describe ambas formas de autenticarse.

```json
{
  "x402Version": 2,
  "error": "Authentication required",
  "accepts": [ ... ],
  "authOptions": {
    "apiKey": {
      "header": "Authorization: Bearer YOUR_API_KEY",
      "getKey": "https://venice.ai/settings/api"
    },
    "x402Wallet": {
      "header": "SIGN-IN-WITH-X",
      "topUp": "POST /api/v1/x402/top-up"
    }
  }
}
```

Si querías usar una clave de API, comprueba que el encabezado `Authorization: Bearer` esté configurado. Una clave presente pero no válida devuelve `401`.

## Errores de formato de la solicitud

Estos errores se producen al leer el cuerpo de la solicitud, antes de que se ejecute cualquier validación específica del endpoint.

| Estado HTTP | Mensaje | Causa |
| --- | --- | --- |
| 400 | `'Content-Type' must be 'application/json'` | Un cuerpo `POST`, `PUT` o `PATCH` enviado sin `Content-Type: application/json`. Los endpoints que aceptan subida de archivos también aceptan `multipart/form-data` |
| 400 | `Invalid JSON request` | El cuerpo no es JSON válido |
| 400 | `Invalid multipart request: malformed part header` | Un cuerpo `multipart/form-data` que no se puede analizar |
| 413 | `Request body exceeds the maximum allowed size.` | El cuerpo de la solicitud es demasiado grande |
| 415 | `Request encoding is not supported` | Un `Content-Encoding` o charset que la API no puede decodificar |

Un `Content-Type` incorrecto devuelve `400`, no `415`. Las respuestas `413` por límite de tamaño también incluyen un campo `code`:

```json
{
  "code": "PAYLOAD_TOO_LARGE",
  "error": "Request body exceeds the maximum allowed size."
}
```

## Otros errores

La tabla anterior no es exhaustiva. Algunos errores se devuelven sin un código de la lista, y los mensajes pueden variar según el modelo y el endpoint, así que basa tu lógica en el estado HTTP y no en el texto del mensaje. Errores que puedes encontrar y que no están en la tabla:

| Estado HTTP | Cuándo ocurre |
| --- | --- |
| 400 | Una imagen de entrada en una solicitud de chat o de Responses está en un formato no compatible |
| 400 | La voz solicitada no está disponible para el modelo de texto a voz |
| 403 | La solicitud procede de una dirección IP que no está en la lista de permitidas de la clave de API |
| 403 | La configuración de privacidad de la clave de API no permite el modelo solicitado |
| 403 | El acceso al modelo solicitado está restringido. Contacta con support@venice.ai |
| 409 | Un resultado de vídeo, música o cambio de voz aún se está subiendo cuando lo recuperas. Reinténtalo en breve |
| 410 | El endpoint se ha retirado |
| 422 | El audio es demasiado largo o demasiado corto (clonación de voz, cambio de voz y trabajos de audio) |
| 422 | La imagen de entrada de una solicitud de vídeo tiene una relación entre ancho y alto fuera del rango que acepta el modelo |
| 422 | La entrada de una solicitud de vídeo fue bloqueada por la moderación de contenido |
| 500 | Falló la generación de vídeo o de cambio de voz |
| 502 | La síntesis de voz falló en el proveedor, o no se pudo recuperar un vídeo generado. Reintenta la solicitud |
