<Info>
  **Los parámetros específicos de Venice están en [`venice_parameters`](#body-venice-parameters).** Este endpoint es compatible con OpenAI, pero el objeto `venice_parameters` desbloquea funciones que no forman parte de la API estándar de OpenAI, y muchos integradores las pasan por alto:

  - **Búsqueda web y citas** — `enable_web_search`, `enable_web_citations`, `enable_web_scraping`
  - **Personajes** — `character_slug`
  - **Control del prompt del sistema** — `include_venice_system_prompt`
  - **Controles de razonamiento** — `disable_thinking`, `strip_thinking_response`
  - **Privacidad** — `enable_e2ee`

  Consulta la lista completa en la sección [`venice_parameters`](#body-venice-parameters) más abajo.
</Info>
