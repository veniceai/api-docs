## Opciones de tamaño

Los modelos de imagen utilizan parámetros de tamaño específicos del modelo:

- Los modelos basados en píxeles aceptan `width` y `height`, por ejemplo `venice-sd35`.
- Los modelos basados en relación de aspecto aceptan `aspect_ratio`, por ejemplo `qwen-image-2`. La familia Qwen Image — `qwen-image`, `qwen-image-3` y `qwen-image-3-pro` — **rechaza** `width` y `height` con un `400`; usa `aspect_ratio` con esos modelos.
- Los modelos con niveles de resolución aceptan tanto `aspect_ratio` como `resolution`.

Por ejemplo, `gpt-image-2`, `nano-banana-2` y `nano-banana-pro` admiten valores de `resolution` de `1K`, `2K` y `4K`:

```json
{
  "model": "gpt-image-2",
  "prompt": "a cinematic wide shot of Venice at sunset",
  "aspect_ratio": "16:9",
  "resolution": "4K",
  "format": "png"
}
```

El mismo patrón de tamaño por nivel de resolución también se aplica a los modelos Nano Banana:

```json
{
  "model": "nano-banana-pro",
  "prompt": "a serene canal in venice at sunset",
  "aspect_ratio": "16:9",
  "resolution": "2K"
}
```

Para los modelos que aceptan relación de aspecto pero no exponen niveles de resolución, envía `aspect_ratio` sin `resolution`:

```json
{
  "model": "qwen-image-2",
  "prompt": "a serene canal in venice at sunset",
  "aspect_ratio": "16:9"
}
```

Para los modelos que usan dimensiones directas en píxeles, envía `width` y `height` en su lugar:

```json
{
  "model": "venice-sd35",
  "prompt": "a serene canal in venice at sunset",
  "width": 1024,
  "height": 1024
}
```

Consulta [Modelos de imagen](/models/image) o el [endpoint de Models](/api-reference/endpoint/models/list) para conocer las opciones de tamaño admitidas por cada modelo antes de mezclar campos de tamaño entre modelos.

## Niveles de calidad

Algunos modelos aceptan un parámetro opcional `quality` (`low`, `medium`, `high`) que intercambia fidelidad visual por coste. Actualmente lo admite `gpt-image-2`; otros modelos ignoran el parámetro.

```json
{
  "model": "gpt-image-2",
  "prompt": "a cinematic wide shot of Venice at sunset",
  "aspect_ratio": "16:9",
  "resolution": "2K",
  "quality": "medium"
}
```

Cuando omites `quality`, el modelo utiliza su nivel predeterminado (`high` para `gpt-image-2`). El precio depende de la combinación de `resolution` y `quality`: los precios por nivel para `gpt-image-2` (1K/2K/4K × low/medium/high) se exponen en `model_spec.pricing.quality` en el [endpoint de Models](/api-reference/endpoint/models/list) y se listan en la [vista general de precios](/overview/pricing).

<Info>
La facturación según la calidad es la predeterminada para todos los llamadores de la API y del SDK: no se requiere ninguna cabecera de activación. Las solicitudes que omiten `quality` se facturan al nivel predeterminado del modelo (`high` para `gpt-image-2`).
</Info>
