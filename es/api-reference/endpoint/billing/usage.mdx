<Warning>
Este endpoint se retiró el 2026-09-16 y ahora devuelve `410 Gone` para cada solicitud. Usa [Historial de uso de facturación](/es/api-reference/endpoint/billing/usage-history) en su lugar.
</Warning>

Historial de uso de facturación devuelve las mismas entradas del registro con paginación por cursor. Para migrar:

- Reemplaza `page` y `limit` por `pageSize` y pasa el `nextCursor` de cada respuesta para obtener la siguiente página.
- Reemplaza `startDate` y `endDate` por `startTimestamp` y `endTimestamp`.
