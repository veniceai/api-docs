Usa este endpoint antes de [`/audio/voice-changer/queue`](/es/api-reference/endpoint/audio/voice-changer/queue) para estimar el coste en USD de convertir una grabación de origen de una duración determinada. Voice Changer se factura a partir de la duración del origen, redondeada al minuto entero superior. La respuesta de queue devuelve la `duration_seconds` medida para que puedas reconciliar la estimación.

Los modelos de cambiador de voz no se aceptan en [`/audio/quote`](/es/api-reference/endpoint/audio/quote).
