title: 'Clonar voz'
openapi: 'POST /audio/voices'
"og:title": "Voice Cloning | Venice API Docs"
"og:description": "Documentación sobre la API de clonación de voz de Venice."
---

Sube una muestra de audio para crear un identificador de voz clonada y luego pásalo como `voice` a [`/audio/speech`](/es/api-reference/endpoint/audio/speech) con el mismo `model` que usaste para crearlo. Para ver un recorrido paso a paso, consulta la [guía de clonación de voz](/es/guides/media/voice-cloning).
