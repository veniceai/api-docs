Usa este endpoint antes de `/audio/queue` para estimar el coste en USD de una solicitud de generación de audio para el modelo y los parámetros seleccionados. Los modelos de cambiador de voz usan [`/audio/voice-changer/quote`](/es/api-reference/endpoint/audio/voice-changer/quote) en su lugar.
