Llama a `/video/quote` para obtener una estimación de precio y, a continuación, consulta `/video/retrieve` con el `queue_id` devuelto hasta que se complete.

Los modelos privados también devuelven un `download_url` para el vídeo terminado. Es una URL de entrega de corta duración (algunos reintentos están bien si una descarga se interrumpe); consulta la [guía de generación de vídeo](/guides/media/video-generation#private-download-links) para conocer los detalles y el `DELETE` opcional para privacidad.

### Seedance 2.0 y 2.5

Para los modelos `seedance-2-0-*-basic` y `seedance-2-5-*-basic` (text-to-video, image-to-video, reference-to-video, además de las variantes `-fast-*` de Seedance 2.0), consulta la [Guía de Seedance 2.0 y 2.5](/guides/media/seedance-2-0) para el modelo de cuatro flujos de trabajo (Reference / Edit / Extend / Stitch), los valores de `aspect_ratio` / `duration` coincidentes con el origen, los límites multimodales específicos por familia, la política de medios de la API pública y los detalles de precios.

### Política de medios de Seedance pública

Los modelos públicos de Seedance no usan atestación de consentimiento (`consents.seedance` / `needs_consent`). Los medios con personas detectables pueden ser rechazados aguas arriba. Usa la app de Venice o Studio para el conjunto completo de funciones de Seedance. Consulta la [guía de Seedance](/guides/media/seedance-2-0) para más detalles.

### Escalado de vídeo

Para el modelo `topaz-video-upscale`, usa `upscale_factor` (1, 2 o 4) en lugar de `resolution` y proporciona un `video_url`. La duración y los FPS se detectan automáticamente del archivo de vídeo. Consulta la [Guía de escalado de vídeo](/guides/media/video-upscaling) para detalles completos y ejemplos.
