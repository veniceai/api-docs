Si la respuesta de `/video/queue` incluyó un `download_url`, descarga el archivo terminado desde esa URL (no como binario desde este endpoint). En caso contrario, este endpoint devuelve el vídeo. Consulta [Enlaces de descarga privados](/es/guides/media/video-generation#enlaces-de-descarga-privados) para saber cómo funciona el enlace, los reintentos y el `DELETE` opcional.
