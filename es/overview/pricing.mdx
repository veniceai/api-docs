### Cómo se factura el uso de la API

Las solicitudes a la API son de pago por uso a las tarifas de esta página. No existe un nivel de API sin medición. Una cuenta Free puede llamar a la API, y esas solicitudes se facturan a las mismas tarifas.

Venice deduce cada solicitud de pago en este orden: DIEM, luego créditos ganados, luego créditos agrupados, luego USD. Cada saldo vale un dólar por unidad. Consulta [VVV & DIEM](/es/overview/vvv-diem).

Si esos saldos no pueden cubrir la solicitud, la API devuelve `402` con `INSUFFICIENT_BALANCE`. Consulta [Códigos de error](/es/api-reference/error-codes).

Los planes de pago incluyen una asignación mensual de créditos agrupados. La API la gasta en el orden indicado arriba. Las cuentas Free no reciben esta asignación.

| Plan | Asignación mensual |
| --- | --- |
| Pro | $1 |
| Plus | $75 |
| Max | $225 |

Cada modelo tiene su propio precio. La API no agrupa los modelos en niveles de precio básico y premium. Algunos modelos están limitados a los planes de pago (Pro, Plus y Max). Las demás cuentas reciben `401` con `PRO_ONLY_MODEL`.

Las filas marcadas como `Variable` tienen precio por solicitud. Cotiza el trabajo antes de ponerlo en cola. Consulta [Límites de tasa](/es/api-reference/rate-limiting).

Los límites de solicitudes dependen del modelo y de tu nivel Default o Partner, no del precio del modelo. Consulta [Límites de tasa](/es/api-reference/rate-limiting).

### Planes de pago

Los suscriptores Pro, Plus y Max reciben un crédito único de $5 USD en el saldo de la API. Se emite una sola vez, en el saldo en USD, y se gasta a las tarifas de esta página. Las cuentas que se actualizaron haciendo staking de VVV no lo reciben.

Una suscripción de pago no incluye uso gratuito ni ilimitado de la API.
