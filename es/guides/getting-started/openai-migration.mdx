Venice AI es un **sustituto drop-in** para OpenAI. El mismo SDK, el mismo código: solo cambia dos líneas. Obtén inferencia centrada en la privacidad, modelos sin censura y precios competitivos.

## La migración de 2 líneas

<CodeGroup>
```python Python
# Antes (OpenAI)
from openai import OpenAI
client = OpenAI()

# Después (Venice) — cambia api_key y base_url
from openai import OpenAI
client = OpenAI(
    api_key="your-venice-api-key",           # ← Cambio 1
    base_url="https://api.venice.ai/api/v1",  # ← Cambio 2
)
```

```javascript Node.js
// Antes (OpenAI)
import OpenAI from "openai";
const client = new OpenAI();

// Después (Venice)
import OpenAI from "openai";
const client = new OpenAI({
  apiKey: "your-venice-api-key",
  baseURL: "https://api.venice.ai/api/v1",
});
```

```bash cURL
# Antes
curl https://api.openai.com/v1/chat/completions ...

# Después — solo cambia la URL y la clave
curl https://api.venice.ai/api/v1/chat/completions ...
```
</CodeGroup>

Genera una clave desde [venice.ai/settings/api](https://venice.ai/settings/api?utm_source=venice-api-documentation) o sigue la [guía de claves de API](/guides/getting-started/generating-api-key).

### Variables de entorno

```bash
# Antes
OPENAI_API_KEY=sk-...
OPENAI_BASE_URL=https://api.openai.com/v1

# Después
OPENAI_API_KEY=your-venice-api-key
OPENAI_BASE_URL=https://api.venice.ai/api/v1
```

<Tip>
Muchas librerías y herramientas leen `OPENAI_API_KEY` y `OPENAI_BASE_URL` automáticamente. Actualizar estas variables de entorno puede ser todo lo que necesitas. Algunas herramientas todavía usan `OPENAI_API_BASE` para la misma URL.
</Tip>

## Modelos

Pasa un ID de modelo de Venice, un rasgo como `default` o `most_uncensored`, o un nombre familiar al estilo de OpenAI. Venice mapea los nombres de OpenAI mediante el [mapeo de compatibilidad](/api-reference/endpoint/models/compatibility_mapping). Los rasgos siempre se resuelven al modelo actual para ese rol; consulta los [rasgos de modelo](/api-reference/endpoint/models/traits).

Explora el catálogo en vivo en [Modelos de texto](/models/text) y [Precios](/overview/pricing). Para un recorrido por la primera solicitud, consulta la [Guía rápida](/getting-started/quick-start).

## Compatibilidad de funciones

| Función | OpenAI | Venice | Notas |
|---------|--------|--------|-------|
| Chat Completions | ✅ | ✅ | Totalmente compatible |
| Streaming | ✅ | ✅ | Mismo formato SSE |
| Function Calling | ✅ | ✅ | Mismo parámetro `tools` |
| Salida estructurada | ✅ | ✅ | Mismo `response_format` |
| Visión | ✅ | ✅ | Mismo formato de array de contenido |
| Embeddings | ✅ | ✅ | Solo texto; los arreglos de tokens devuelven HTTP 400 |
| Generación de imágenes | ✅ | ✅ | Compatible con OpenAI mediante `/images/generations` |
| Edición de imágenes | ✅ | ❌ | No hay endpoint `/images/edits`; usa el endpoint nativo [`/image/edit`](/guides/media/image-editing) |
| TTS | ✅ | ✅ | Compatible |
| STT | ✅ | ✅ | Compatible |
| Responses API | ✅ | ✅ | Alpha |
| Assistants API | ✅ | ❌ | Usa [Personajes](/guides/features/characters) o [function calling](/guides/features/function-calling) |
| Batch API | ✅ | ❌ | Aún no disponible |
| Fine-tuning | ✅ | ❌ | No disponible |

Para opciones de imagen nativas más allá del endpoint compatible con OpenAI, consulta [Generación de imágenes](/guides/media/image-generation).

## Funciones exclusivas de Venice

Pasa opciones específicas de Venice a través de `extra_body` como `venice_parameters`. La búsqueda web integrada suele ser el primer extra:

```python
response = client.chat.completions.create(
    model="default",
    messages=[{"role": "user", "content": "Últimas noticias de IA hoy"}],
    extra_body={
        "venice_parameters": {
            "enable_web_search": "auto"
        }
    },
)
```

El mismo patrón cubre el web scraping, las citas y los [Personajes](/guides/features/characters). Si un cliente no puede cambiar el cuerpo de la solicitud, añade un [sufijo de función de modelo](/api-reference/endpoint/chat/model_feature_suffix) como `default:enable_web_search=auto`.

Venice también dispone de APIs nativas de [vídeo](/guides/media/video-generation), [música](/guides/media/music-and-sound-effects), [recuperación web](/guides/tools/web-retrieval) y [x402](/guides/integrations/x402-venice-api) junto a la superficie compatible con OpenAI.

## Modelos sin censura

Los modelos privados sin censura de Venice no aplican filtrado de contenido, lo que los hace adecuados para:

- Escritura creativa sin restricciones
- Investigación de seguridad y red teaming
- Análisis honesto sin patrones de rechazo
- Información médica y legal sin descargos de responsabilidad adicionales

Usa el rasgo `most_uncensored` o el ID de un modelo sin censura actual de [Modelos de texto](/models/text).
