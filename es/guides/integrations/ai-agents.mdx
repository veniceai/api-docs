### Proyectos de la comunidad
Las siguientes integraciones han sido creadas por la comunidad para facilitarte el uso de la API de Venice.

- Entradas de blog
  - [Venice AI Discord Bot](https://bobbiebeach.space/blog/venice-ai-discord-bot-full-setup-guide-features/)

- Bibliotecas de software
  - [llm-venice](https://github.com/ar-jan/llm-venice)
  - [SDK PHP no oficial para Venice](https://github.com/georgeglarson/venice-ai-php)


### Aplicaciones compatibles de terceros
- [JanitorAI](https://janitorai.com/)
- [1Claw](https://1claw.xyz), infraestructura segura para agentes de IA; enruta la inferencia privada a Venice mediante el proxy Shroud TEE
- [Msty](https://msty.app)
- [Open WebUI](https://github.com/open-webui/open-webui)
- [Librechat](https://www.librechat.ai/)
- [ScreenSnapAI](https://screensnap.ai/)
