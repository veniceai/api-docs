[Kilo Code](https://kilo.ai/) es un agente de programación con IA de código abierto para VS Code y la terminal. Venice está disponible como **proveedor nativo**, por lo que puedes seleccionar modelos de Venice sin configurar un endpoint personalizado compatible con OpenAI.

## Requisitos previos

- Una API key de Venice desde [venice.ai/settings/api](https://venice.ai/settings/api)
- [Kilo Code para VS Code](https://marketplace.visualstudio.com/items?itemName=kilocode.Kilo-Code) o la [CLI de Kilo](https://kilo.ai/docs/code-with-ai/platforms/cli)

---

## Configuración

<Tabs>
  <Tab title="VS Code">
    <Steps>
      <Step title="Instala Kilo Code">
        En VS Code, abre **Extensions**, busca **Kilo Code** e instálalo desde el [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=kilocode.Kilo-Code).

        Prefiere el canal **Pre-Release** del Marketplace cuando sea la build recomendada actualmente; consulta la [documentación de instalación de Kilo](https://kilo.ai/docs/getting-started/installing).
      </Step>

      <Step title="Obtén tu API key de Venice">
        Genera una clave desde [venice.ai/settings/api](https://venice.ai/settings/api). Cópiala de inmediato y guárdala de forma segura.
      </Step>

      <Step title="Añade el proveedor Venice">
        Abre los **Settings** de Kilo (icono de engranaje) y ve a la pestaña **Providers**. Selecciona **Venice AI** y pega tu API key de Venice.

        La extensión guarda el proveedor en tu archivo de configuración `kilo.json`. También puedes editar ese archivo directamente; consulta la pestaña **CLI** para ver el formato.
      </Step>

      <Step title="Selecciona un modelo y pruébalo">
        Elige un modelo de Venice desde el selector de modelos y luego envía una tarea pequeña como:

        ```txt
        Review the current file and suggest one safe improvement.
        ```

        Explora los IDs disponibles en el [catálogo de modelos de texto](/models/text).
      </Step>
    </Steps>
  </Tab>

  <Tab title="CLI">
    <Steps>
      <Step title="Instala la CLI de Kilo">
        ```bash
        npm install -g @kilocode/cli
        kilo --version
        ```

        Consulta la [documentación de la CLI de Kilo](https://kilo.ai/docs/code-with-ai/platforms/cli) para otras opciones de instalación.
      </Step>

      <Step title="Configura tu API key de Venice">
        Exporta la clave en la shell donde ejecutes Kilo:

        ```bash
        export VENICE_API_KEY="your-api-key"
        ```
      </Step>

      <Step title="Configura el proveedor Venice">
        Crea o edita `~/.config/kilo/kilo.json` (global) o `./kilo.json` (del proyecto):

        ```json
        {
          "provider": {
            "venice": {
              "env": ["VENICE_API_KEY"]
            }
          },
          "model": "venice/zai-org-glm-5-1"
        }
        ```

        Reemplaza `zai-org-glm-5-1` con cualquier ID de modelo del [catálogo de modelos de texto](/models/text). Las referencias de modelo en Kilo usan el formato `venice/<model-id>`.
      </Step>

      <Step title="Inicia Kilo">
        Desde el directorio de tu proyecto:

        ```bash
        kilo
        ```

        Selecciona un modelo de Venice desde el selector si no configuraste un `model` por defecto y luego envía un prompt corto de prueba.
      </Step>
    </Steps>
  </Tab>
</Tabs>

## Verifica la API de Venice

Si Kilo no puede conectarse, confirma la clave y los IDs de modelo de forma independiente:

```bash
curl https://api.venice.ai/api/v1/models \
  -H "Authorization: Bearer $VENICE_API_KEY"
```

Copia el `id` de un modelo exactamente en Kilo. En la configuración de la CLI, anteponle `venice/`, por ejemplo `venice/zai-org-glm-5-1`.

---

## Notas de configuración

- Venice es un proveedor **nativo** de Kilo. Prefiere **Venice AI** en los ajustes de Providers en lugar de un endpoint personalizado genérico compatible con OpenAI.
- La extensión y la CLI comparten los mismos archivos de configuración (`~/.config/kilo/kilo.json` de forma global, o `./kilo.json` en un proyecto).
- Algunos modelos de Venice exponen controles de razonamiento. Kilo mapea las opciones de esfuerzo de razonamiento y de desactivación de thinking cuando el modelo seleccionado las soporta.
- Los IDs de modelo y el acceso según el plan pueden cambiar. Usa el selector de modelos, el [catálogo de modelos de texto](/models/text) o `GET /models` para obtener la lista actual.
- Mantén tu API key de Venice privada. No la pegues en archivos fuente ni la subas a git.

## Solución de problemas

<AccordionGroup>
  <Accordion title="API key no válida o 401">
    Confirma que la clave proviene de [venice.ai/settings/api](https://venice.ai/settings/api). Para la CLI, verifica que `VENICE_API_KEY` esté definida en el mismo entorno que lanza Kilo. En VS Code, vuelve a conectar Venice AI en **Providers**.
  </Accordion>
  <Accordion title="Modelo no disponible">
    Confirma que tu cuenta de Venice tiene acceso al modelo seleccionado, copia el ID desde el [catálogo de modelos de texto](/models/text) o `GET /models` y, para la configuración de la CLI, usa la forma `venice/<model-id>`.
  </Accordion>
  <Accordion title="Ajustes de proveedor no encontrados en la extensión">
    Actualiza a la build recomendada actual de Kilo (incluyendo Pre-Release cuando sea la opción documentada por defecto). También puedes definir el proveedor en `kilo.json` como se muestra en la pestaña de la CLI; la extensión lee la misma configuración.
  </Accordion>
</AccordionGroup>
