[OpenCode](https://opencode.ai/) es un agente de programación con IA para la terminal. OpenCode ya incluye un proveedor de Venice AI, así que te conectas con un solo comando y eliges un modelo del catálogo completo de Venice. No necesitas ningún archivo de configuración.

<Note>
  Esta guía sigue OpenCode 1, que es la versión que instala el instalador estándar. OpenCode 2 también incluye Venice AI, pero sus menús y su formato de configuración nativo son distintos.
</Note>

## Requisitos previos {#prerequisites}

- Una API key de Venice desde [venice.ai/settings/api](https://venice.ai/settings/api?utm_source=venice-api-documentation)
- OpenCode instalado y funcionando en tu máquina

---

## Configuración {#setup}

<Steps>
  <Step title="Conecta Venice AI">
    Inicia OpenCode y ejecuta el comando de conexión:

    ```txt
    /connect
    ```

    Busca **Venice AI** y selecciónalo.

    <Frame as="div">
      <img
        src="/images/guides/opencode/connect-venice.png"
        alt="La paleta /connect de OpenCode filtrada por Venice AI"
      />
    </Frame>
  </Step>

  <Step title="Pega tu API key de Venice">
    Pega la clave en el campo **API key** y pulsa Intro.

    OpenCode guarda la credencial en `~/.local/share/opencode/auth.json`, así que queda disponible en todos los proyectos.
  </Step>

  <Step title="Elige un modelo">
    Ejecuta el comando de modelos y elige un modelo de Venice:

    ```txt
    /models
    ```

    `z-ai-glm-5-3-flash` es una buena opción predeterminada para programar: rápido, económico y con una ventana de contexto de 1M tokens. Consulta [IDs de modelo](#model-ids) para ver otras opciones.

    OpenCode también muestra su propio nivel gratuito alojado con nombres parecidos, por ejemplo **GLM-5.3-Flash Free** de **OpenCode** junto a **GLM 5.3 Flash** de **Venice AI**. El nombre del proveedor en la columna derecha los distingue, y la fila de Venice AI es la que usa tu clave y tus créditos.
  </Step>
</Steps>

Envía una tarea pequeña para confirmar el recorrido completo, por ejemplo:

```txt
Review the current file and suggest one safe improvement.
```

## Fija un modelo predeterminado {#pin-a-default-model}

Después de conectarte, OpenCode puede iniciar las nuevas sesiones con un modelo enrutado como Claude Sonnet 4.6, que cuesta más que los modelos de [IDs de modelo](#model-ids). Para elegir el modelo con el que arranca OpenCode, añádelo a `opencode.json` en la raíz de tu proyecto (o a `~/.config/opencode/opencode.json` para un valor predeterminado global):

```json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "venice/z-ai-glm-5-3-flash",
  "small_model": "venice/z-ai-glm-5-3-flash"
}
```

Las referencias a modelos usan la forma `venice/<model-id>`, y `small_model` define el modelo más barato para las tareas en segundo plano.

## Conectar sin `/connect` {#connect-without-/connect}

El proveedor incluido también lee `VENICE_API_KEY` del entorno. Expórtala antes de iniciar OpenCode y los modelos de Venice AI aparecerán en `/models` sin ejecutar `/connect`:

```bash
export VENICE_API_KEY="your-api-key"
```

En una versión de OpenCode anterior al proveedor incluido, o para fijar la lista de modelos que muestra OpenCode, configura Venice como proveedor compatible con OpenAI en `opencode.json`. Mantén `VENICE_API_KEY` exportada:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "venice/z-ai-glm-5-3-flash",
  "small_model": "venice/z-ai-glm-5-3-flash",
  "provider": {
    "venice": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Venice AI",
      "options": {
        "baseURL": "https://api.venice.ai/api/v1",
        "apiKey": "{env:VENICE_API_KEY}"
      },
      "models": {
        "z-ai-glm-5-3-flash": {
          "name": "GLM 5.3 Flash"
        },
        "kimi-k2-6": {
          "name": "Kimi K2.6"
        },
        "minimax-m25": {
          "name": "MiniMax M2.5"
        }
      }
    }
  }
}
```

Enumera en `models` los modelos que quieras. OpenCode solo muestra las entradas declaradas aquí para este proveedor. En las versiones con el proveedor incluido, la variable de entorno por sí sola ya te da el catálogo completo.

## IDs de modelo {#model-ids}

Algunos modelos de Venice que funcionan bien en un agente de programación. El catálogo cambia, así que usa [`GET /models?type=text`](/es/api-reference/endpoint/models/list) para obtener la lista actual.

| Modelo | ID de Venice |
|-------|-----------|
| GLM 5.3 Flash | `z-ai-glm-5-3-flash` |
| GLM 5.3 | `z-ai-glm-5-3` |
| Kimi K2.6 | `kimi-k2-6` |
| MiniMax M2.5 | `minimax-m25` |
| DeepSeek V4.1 Flash | `deepseek-v4-1-flash` |

Los modelos de pesos abiertos como estos se ejecutan de forma totalmente privada. Los modelos enrutados de Anthropic, OpenAI y Google se ejecutan de forma anonimizada, así que el laboratorio de origen nunca ve tu identidad.

## Notas de configuración {#config-notes}

- Mantén `baseURL` en `https://api.venice.ai/api/v1` en el bloque de proveedor manual. El proveedor incluido ya apunta ahí.
- El ID del proveedor es `venice`, así que las referencias a modelos usan la forma `venice/<model-id>` en ambas opciones.
- Ejecuta `/connect` de nuevo en cualquier momento para reemplazar la clave de Venice guardada.
- Amplía el contexto cuando el modelo lo admita: varios modelos de Venice aceptan 1M tokens.

## Solución de problemas {#troubleshooting}

<AccordionGroup>
  <Accordion title="Venice AI no aparece en /connect">
    Actualiza OpenCode a la última versión 1.x con `opencode upgrade`. El proveedor Venice AI viene con las versiones actuales, así que una instalación antigua puede ofrecer solo la configuración manual descrita arriba.
  </Accordion>
  <Accordion title="API key no válida o 401">
    Confirma que la clave proviene de [venice.ai/settings/api](https://venice.ai/settings/api?utm_source=venice-api-documentation), luego ejecuta `/connect`, selecciona **Venice AI** y pégala de nuevo. Cuando la clave guardada está obsoleta, OpenCode informa de un fallo de autenticación en lugar de llegar a Venice.
  </Accordion>
  <Accordion title="Modelo no disponible">
    Copia el ID exactamente desde [IDs de modelo](#model-ids), el [catálogo de modelos de texto](/es/models/text) o `GET /models`, y confirma que tu cuenta de Venice tiene acceso a él.
  </Accordion>
</AccordionGroup>
