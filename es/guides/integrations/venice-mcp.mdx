El [Venice MCP Server](https://github.com/veniceai/venice-mcp-server) es el servidor oficial de [Model Context Protocol](https://modelcontextprotocol.io/) para Venice. Expone la API de Venice (chat, imagen, vídeo, audio, música, embeddings, web augment, personajes, RPC cripto y atestación TEE) más operaciones de cuenta (facturación y claves de API) como **45 herramientas** que cualquier agente compatible con MCP puede invocar.

## Inicio rápido

<Steps>
  <Step title="Obtén una API key de Venice">
    Genera una en [venice.ai/settings/api](https://venice.ai/settings/api?utm_source=venice-api-documentation). Consulta la [guía de API keys](/guides/getting-started/generating-api-key) para el paso a paso.
  </Step>

  <Step title="Añade Venice a la configuración de tu host MCP">
    Pega esto en el archivo de configuración de tu host MCP:

    ```json
    {
      "mcpServers": {
        "venice": {
          "command": "npx",
          "args": ["-y", "@veniceai/mcp-server@0.3.0"],
          "env": { "VENICE_API_KEY": "<your-venice-api-key>" }
        }
      }
    }
    ```

    Rutas de configuración habituales:

    | Host | Ruta |
    |---|---|
    | Claude Desktop (macOS) | `~/Library/Application Support/Claude/claude_desktop_config.json` |
    | Claude Desktop (Windows) | `%APPDATA%\Claude\claude_desktop_config.json` |
    | Cursor | `~/.cursor/mcp.json` |
    | LM Studio | `mcp.json` (desde los ajustes MCP de la app) |
  </Step>

  <Step title="Reinicia tu host MCP">
    Tu agente ya tiene disponibles chat, imagen, vídeo, música, TTS, ASR, facturación, claves de API y 39 herramientas más de Venice.
  </Step>
</Steps>

<Note>
La mayoría de hosts MCP solo pasan las variables de entorno que están **explícitamente** en el bloque `env`. Las variables de entorno del sistema no se heredan. Si ves errores 402 con una API key configurada, comprueba que `VENICE_API_KEY` esté dentro de `env` en tu configuración.
</Note>

## Qué obtienes

**45 herramientas** que cubren cada modalidad de Venice más operaciones de cuenta, **3 recursos** (`venice://models`, `venice://styles`, `venice://voices`) y **3 plantillas de prompt** (investigación sin censura, escritura creativa NSFW, explorador de estilos de imagen).

Cada herramienta declara anotaciones explícitas `readOnlyHint`, `destructiveHint`, `idempotentHint` y `openWorldHint`, de modo que los hosts pueden ejecutar consultas sin preguntar y pedir confirmación antes de cualquier acción destructiva, como la limpieza de medios o un relay cripto.

### Chat y embeddings

| Herramienta | Descripción |
|---|---|
| `venice_chat` | Chat completion compatible con OpenAI contra el catálogo completo de LLM de Venice, con bloques de texto/imagen/audio/vídeo/archivo, salidas estructuradas, function tools, prompt caching y control de razonamiento. Las llamadas son en texto plano y sin streaming. |
| `venice_responses` | API Responses alfa y sin estado, compatible con OpenAI, con entrada de texto/imagen y control de razonamiento. No admite modelos con E2EE ni campos de tools. |
| `venice_embeddings` | Calcula embeddings para texto. |
| `venice_chat_with_character` | Chatea con un personaje de Venice por slug. |

### Imagen

| Herramienta | Descripción |
|---|---|
| `venice_image_generate` | Genera una imagen (Flux 2, Lustify SDXL, Anime/WAI, Qwen Image, GPT Image, Nano Banana Pro y más), con relación de aspecto o ancho/alto, niveles de calidad, mejora de prompt, referencias de estilo, búsqueda web y variantes. |
| `venice_image_edit` | Edita una imagen con un prompt. |
| `venice_image_multi_edit` | Edita hasta 8 imágenes juntas con un solo prompt (composición / outpainting). |
| `venice_image_upscale` | Escala una imagen de 2 a 4×, con control de `creativity`. |
| `venice_image_remove_bg` | Elimina el fondo de una imagen. |
| `venice_image_styles` | Lista los presets de estilo de imagen. |

### Vídeo

| Herramienta | Descripción |
|---|---|
| `venice_video_generate` | Encola una generación de vídeo (Sora 2, Veo 3.1, Kling, Wan, LTX 2, Seedance, Runway Gen-4 y más) con entradas de imagen, vídeo, audio, referencias y elementos. |
| `venice_video_status` | Consulta el estado de un trabajo de vídeo (`POST /video/retrieve`). |
| `venice_video_complete` | Marca un vídeo completado como descargado; solo borra los medios del servidor cuando Venice lo confirma. |
| `venice_video_quote` | Obtén una cotización de precio antes de encolar. |

### Audio (TTS / ASR)

| Herramienta | Descripción |
|---|---|
| `venice_tts` | Texto a voz con voces clonadas, temperatura y etiquetas de emoción. El streaming se agrupa en un único resultado de audio completo. |
| `venice_asr` | Transcribe audio desde una URL, con marcas de tiempo opcionales por palabra/carácter. Las transcripciones grandes se paginan mediante un handle de sesión. |
| `venice_voice_clone` | Lista las voces en vivo por modelo o clona una voz desde una URL de muestra (devuelve un handle `vv_<id>` para `venice_tts`). |
| `venice_audio_quote` | Obtén una cotización de precio para generación de música. |

### Música

| Herramienta | Descripción |
|---|---|
| `venice_music_generate` | Encola una generación de música (`ace-step-15`, `elevenlabs-music`, `minimax-music-v2/v25/v26`, `stable-audio-25`, `mmaudio-v2-text-to-audio`, `elevenlabs-sound-effects-v2`) con controles de letra, instrumental, loop, voz, idioma, velocidad y duración. |
| `venice_music_status` | Consulta el estado de un trabajo de música. |
| `venice_music_complete` | Marca un trabajo de música completado como descargado. |

### Web augment

| Herramienta | Descripción |
|---|---|
| `venice_web_search` | Busca en la web con Brave (por defecto, Zero Data Retention) o Google (proxied y anonimizado por Venice). |
| `venice_web_scrape` | Scrapea una URL a markdown. |
| `venice_text_parser` | Extrae texto de PDF/DOCX/EPUB/PPTX/XLSX. |

### Catálogo y personajes

| Herramienta | Descripción |
|---|---|
| `venice_list_models` | Recorre el catálogo de modelos en vivo de todos los tipos, con resúmenes compactos, precios y flags de capacidad. |
| `venice_model_details` | Obtén la fila completa de un modelo exacto: restricciones de `model_spec`, capacidades y precios. |
| `venice_model_traits` | Asigna nombres de trait (`default`, `most_uncensored`, …) a los IDs de modelo actuales. |
| `venice_model_compatibility_mapping` | Asigna nombres de modelo compatibles a IDs de modelo de Venice. |
| `venice_list_characters` | Lista personajes públicos de Venice con filtros de búsqueda, etiqueta, modelo y orden. **Solo API key.** |
| `venice_get_character` | Obtén un personaje público por slug. **Solo API key.** |
| `venice_character_reviews` | Lista las reseñas públicas de un personaje, paginadas. **Solo API key.** |

### Atestación TEE

| Herramienta | Descripción |
|---|---|
| `venice_tee_attestation` | Obtén evidencia de atestación de hardware (quote Intel TDX, evidencia NVIDIA opcional, clave de firma) para un modelo de texto con TEE, usando tu propio nonce de 32 bytes. |
| `venice_tee_signature` | Obtén el payload de firma del enclave para el ID de una petición de chat TEE completada. |

<Warning>
Ambas herramientas TEE solo devuelven evidencia del proveedor: no la verifican ni cifran el chat. Verifica tú el nonce devuelto, el estado de modo debug y la vinculación de la clave de firma antes de confiar en un modelo TEE, y usa `venice_chat` (nunca `venice_responses`) para modelos TEE. Este servidor rechaza `enable_e2ee`.
</Warning>

### Cripto

| Herramienta | Descripción |
|---|---|
| `venice_crypto_networks` | Lista los slugs de red en vivo que acepta el proxy RPC. |
| `venice_crypto_rpc` | Hace proxy de una petición JSON-RPC, o un lote de hasta 100, a Ethereum, Base, Arbitrum, Optimism, Polygon, Solana, Starknet, zkSync, Linea, BSC, Avalanche, Blast y más. |

Las transmisiones de transacciones (`eth_sendRawTransaction`, `eth_sendUserOperation`, `sendTransaction` de Solana, escrituras en Starknet) deben enviarse como peticiones individuales con `idempotency_key`, y hay que reutilizar la misma clave al reintentar.

### Facturación (claves admin)

| Herramienta | Descripción |
|---|---|
| `venice_billing_balance` | Disponibilidad actual de USD, DIEM y créditos incluidos. |
| `venice_billing_usage_analytics` | Uso agregado en beta por fecha, modelo y clave de API (lookback o rango personalizado). |
| `venice_billing_usage_history` | Uso detallado con paginación por cursor y salida JSON o CSV. |

<Note>
Las herramientas de facturación requieren una API key **ADMIN**. Las claves de inferencia no pueden llamar a estos endpoints, y el servidor falla localmente en vez de recurrir a un token de monedero. La ruta obsoleta `/billing/usage` no está cubierta.
</Note>

### Claves de API

| Herramienta | Descripción |
|---|---|
| `venice_list_api_keys` | Lista metadatos de claves activas, incluyendo solo los últimos seis caracteres. Solo clave admin. |
| `venice_get_api_key` | Obtén metadatos, uso, saldos y rate limits de una clave por ID. Solo clave admin. |
| `venice_api_key_rate_limits` | Saldos actuales, estado de acceso, tier, caducidad y rate limits por modelo. Clave de inferencia o admin. |
| `venice_api_key_rate_limit_logs` | Los últimos 50 eventos de rate limit superados (experimental). Solo clave admin. |

### Helpers de monedero x402

Solo relevantes si te autenticas con un monedero vía [x402](/guides/integrations/x402-venice-api) en lugar de una API key.

| Herramienta | Descripción |
|---|---|
| `venice_x402_balance` | Consulta el saldo de crédito x402 prepago de una dirección de monedero EVM o Solana. |
| `venice_x402_top_up_info` | Obtén los requisitos de recarga (red, token USDC, receptor, importe mínimo). No acepta argumentos. |
| `venice_x402_transactions` | Lista las recargas y débitos x402 recientes de una dirección de monedero EVM o Solana. |

## Configuración

El servidor se configura íntegramente mediante variables de entorno.

### Modelos y peticiones

| Variable | Por defecto | Notas |
|---|---|---|
| `VENICE_API_KEY` | _(ninguna)_ | Tu API key de Venice. La configuración más sencilla. |
| `VENICE_DEFAULT_CHAT_MODEL` | `deepseek-v4-flash-0731` | |
| `VENICE_DEFAULT_IMAGE_MODEL` | `flux-2-pro` | |
| `VENICE_DEFAULT_TTS_MODEL` | `tts-kokoro` | |
| `VENICE_DEFAULT_ASR_MODEL` | `openai/whisper-large-v3` | |
| `VENICE_DISABLE_NSFW` | `0` | Pon `1` para quitar las notas de capacidad NSFW de las descripciones de herramientas. |
| `VENICE_HTTP_TIMEOUT_MS` | `60000` | |
| `VENICE_SIWX_TOKEN` | _(ninguno)_ | Token de auth en modo monedero x402. Ver [x402 abajo](#modo-monedero-x402). |

Si defines tanto `VENICE_API_KEY` como `VENICE_SIWX_TOKEN`, gana la API key.

### Límites de tamaño de respuesta

Los medios generados se almacenan en búfer y se incrustan en base64 en el resultado MCP, por lo que cada modalidad tiene un techo en bytes.

| Variable | Por defecto | Se aplica a |
|---|---|---|
| `VENICE_MAX_IMAGE_RESPONSE_BYTES` | `33554432` (32 MiB) | `venice_image_generate`, `venice_image_edit`, `venice_image_multi_edit`, `venice_image_upscale`, `venice_image_remove_bg` |
| `VENICE_MAX_VIDEO_RESPONSE_BYTES` | `26214400` (25 MiB) | `venice_video_status` |
| `VENICE_MAX_AUDIO_RESPONSE_BYTES` | `33554432` (32 MiB) | `venice_tts`, `venice_music_status` |

Un resultado de imagen o TTS demasiado grande se descarta con un error. Un vídeo o música demasiado grandes siguen en cola, así que puedes volver a llamar a la herramienta de estado con el mismo queue ID tras subir el límite.

### Servidor HTTP

Solo relevante en el [despliegue Streamable HTTP](#self-hosting-http-en-streaming).

| Variable | Por defecto | Notas |
|---|---|---|
| `PORT` | `3333` | Puerto del listener HTTP. |
| `VENICE_MCP_HOST` | `127.0.0.1` | Dirección de bind. Pon `0.0.0.0` para exponer en LAN o contenedor. |
| `VENICE_MCP_AUTH_TOKEN` | _(ninguno)_ | Token bearer que exige `/mcp` cuando se enlaza fuera de loopback. |
| `VENICE_MCP_ALLOW_UNAUTHENTICATED_HTTP` | `0` | Vía de escape para HTTP expuesto sin autenticación. Úsala solo detrás de un proxy autenticado de confianza. |
| `VENICE_MCP_MAX_SESSIONS` | `100` | Máximo de sesiones Streamable HTTP activas. |
| `VENICE_MCP_SESSION_TTL_MS` | `1800000` | Vida de una sesión inactiva antes de la limpieza. |

## Comportamiento de generación de medios

- **Los medios completados pueden ser bytes o una URL.** Los trabajos de vídeo y música devuelven recursos MP4/audio incrustados, o JSON con una `download_url` que llega como resource link. Descarga ese enlace primero y luego llama a `venice_video_complete` o `venice_music_complete`; la limpieza de medios nunca se aplica a un resultado con `download_url` porque el enlace deja de funcionar al borrar el archivo.
- **Algunos modelos solo devuelven la URL al encolar.** En modelos VPS y Grok Imagine Private, guarda la `download_url` que devuelve `venice_video_generate` y pásala a `venice_video_status`; un retrieve en `COMPLETED` sin URL inline seguirá dando un enlace utilizable.
- **La mejora de prompt se devuelve.** Cuando se aplica `enhance_prompt`, los resultados de generación, edición y multi-edición de imagen incluyen el prompt URL-decodificado que devuelve Venice.
- **La paginación de ASR se cobra una vez.** Las transcripciones con marcas de tiempo o de más de 8000 caracteres devuelven un `result_handle` con la primera página. Pide las páginas siguientes con ese handle. Los handles viven en memoria por sesión MCP durante 10 minutos y solo se conservan los 16 más recientes.
- **El consentimiento de Seedance no es un bypass de política.** Los modelos públicos de Seedance actuales pueden rechazar directamente medios con personas detectables. Cuando se devuelve una respuesta `needs_consent`, los tres flags de `consents.seedance` son atestaciones legales: ponlos en `true` solo después de que el usuario confirme explícitamente cada declaración.

## Modo monedero x402

Venice admite la autenticación con un [token de monedero Sign-In-With-X](/guides/integrations/x402-venice-api) respaldado por crédito USDC prepago en Base o Solana, además del flujo normal con API key. Sin email, teléfono ni KYC: tu monedero es la única identidad.

```json
{
  "mcpServers": {
    "venice": {
      "command": "npx",
      "args": ["-y", "@veniceai/mcp-server@0.3.0"],
      "env": { "VENICE_SIWX_TOKEN": "<base64 Sign-In-With-X payload>" }
    }
  }
}
```

El servidor MCP reenvía `VENICE_SIWX_TOKEN` en la cabecera `SIGN-IN-WITH-X` en cada llamada a la API de Venice. El servidor nunca ve tu clave privada. La firma del monedero y las autorizaciones de recarga de USDC ocurren en tu propio monedero.

| Flujo | Qué ocurre |
|---|---|
| **Configuración inicial** | Firmas un mensaje Sign-In-With-X en tu monedero → produce un token SIWX (JSON en base64). |
| **Recarga** | `POST /api/v1/x402/top-up` devuelve 402 + requisitos de pago. Firma un pago en USDC para una de las opciones Base o Solana devueltas, reenvía y Venice abona el saldo. |
| **Cada llamada de inferencia** | El servidor MCP envía `SIGN-IN-WITH-X: <SIWX>`; Venice debita tu saldo prepago. |

La recarga mínima es de **\$5 USD**. El saldo mínimo para llamar a inferencia es de **\$0.10**. Una vez recargado, las llamadas tardan menos de 100 ms porque la liquidación ocurre off-chain en una cuenta de crédito rápida.

<Tip>
Los monederos vinculados a una cuenta de Venice con DIEM en staking consumen del saldo de staking en lugar de los créditos USDC, así que no necesitan recarga.
</Tip>

Venice no acepta cabeceras de pago en las rutas de inferencia, así que este servidor nunca envía una. `PAYMENT-SIGNATURE` solo pertenece a `/x402/top-up`, y el helper de recarga descubre los requisitos sin enviar ningún pago.

### Cobertura de modos de auth

Algunos endpoints aceptan un solo modo de auth:

| Herramienta | API key | x402 |
|---|---|---|
| Inferencia, medios, web augment, RPC cripto, chat con personaje | ✓ | ✓ |
| `venice_list_characters`, `venice_get_character`, `venice_character_reviews` | ✓ | ✗ |
| `venice_billing_*`, `venice_list_api_keys`, `venice_get_api_key`, `venice_api_key_rate_limit_logs` | ✓ (admin) | ✗ |
| `venice_api_key_rate_limits` | ✓ (cualquier clave) | ✗ |
| `venice_x402_balance`, `venice_x402_transactions` | ✗ | ✓ |
| `venice_x402_top_up_info` | ✓ | ✓ |

Si defines ambas credenciales, la API key gana en todas las llamadas, así que los helpers exclusivos de SIWX (`venice_x402_balance`, `venice_x402_transactions`) solo funcionan cuando el token de monedero es tu única credencial.

## Self-hosting (HTTP en streaming)

Para despliegues de equipo o workspace, ejecuta el servidor MCP por HTTP en lugar de stdio:

```bash
docker run -p 3333:3333 \
  -e VENICE_API_KEY=<your-venice-api-key> \
  -e VENICE_MCP_AUTH_TOKEN=<choose-a-long-random-token> \
  ghcr.io/veniceai/venice-mcp-server:latest
```

El servidor queda disponible en `http://localhost:3333/mcp`. Los clientes HTTP deben enviar `Authorization: Bearer <VENICE_MCP_AUTH_TOKEN>` y crear sesiones nuevas sin la cabecera `mcp-session-id` para luego reutilizar el ID que emite el servidor.

<Warning>
`/mcp` es un endpoint de ejecución de herramientas respaldado por credenciales: quien llame puede gastar la API key configurada de Venice o el saldo x402. Cuando el modo HTTP se enlaza fuera de loopback, el arranque falla salvo que `VENICE_MCP_AUTH_TOKEN` esté definido, o que `VENICE_MCP_ALLOW_UNAUTHENTICATED_HTTP=1` se configure detrás de un proxy autenticado de confianza. En producción, fija la versión del paquete npm explícitamente en lugar de confiar en `latest`.
</Warning>
