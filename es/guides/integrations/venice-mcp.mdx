El [Venice MCP Server](https://github.com/veniceai/venice-mcp-server) es el servidor oficial de [Model Context Protocol](https://modelcontextprotocol.io/) para Venice. Expone la API de Venice (chat, imagen, vídeo, audio, música, embeddings, web augment, characters, RPC cripto y atestación TEE) junto con operaciones de cuenta (facturación y API keys) como **45 herramientas** que cualquier agente compatible con MCP puede invocar.

## Inicio rápido

<Steps>
  <Step title="Obtén una API key de Venice">
    Genera una en [venice.ai/settings/api](https://venice.ai/settings/api?utm_source=venice-api-documentation). Consulta la [guía de API key](/es/guides/getting-started/generating-api-key) para instrucciones paso a paso.
  </Step>

  <Step title="Añade Venice a la configuración de tu host MCP">
    Pega esto en el archivo de configuración de tu host MCP:

    ```json
    {
      "mcpServers": {
        "venice": {
          "command": "npx",
          "args": ["-y", "@veniceai/mcp-server@0.3.0"],
          "env": { "VENICE_API_KEY": "<your-venice-api-key>" }
        }
      }
    }
    ```

    Rutas de configuración comunes:

    | Host | Ruta |
    |---|---|
    | Claude Desktop (macOS) | `~/Library/Application Support/Claude/claude_desktop_config.json` |
    | Claude Desktop (Windows) | `%APPDATA%\Claude\claude_desktop_config.json` |
    | Cursor | `~/.cursor/mcp.json` |
    | LM Studio | `mcp.json` (desde los ajustes de MCP de la app) |
  </Step>

  <Step title="Reinicia tu host MCP">
    Tu agente ahora tiene chat, imagen, vídeo, música, TTS, ASR y 39 herramientas más de Venice disponibles.
  </Step>
</Steps>

<Note>
La mayoría de hosts MCP solo pasan las variables de entorno **listadas explícitamente** en el bloque `env`. Las variables de entorno del sistema no se heredan. Si ves errores 402 con una API key configurada, comprueba que `VENICE_API_KEY` esté dentro de `env` en tu configuración.
</Note>

## Qué obtienes

**45 herramientas** que cubren cada modalidad de Venice más operaciones de cuenta, **3 recursos** (`venice://models`, `venice://styles`, `venice://voices`) y **3 plantillas de prompt** (investigación sin censura, escritura creativa NSFW y explorador de estilos de imagen).

Cada herramienta declara anotaciones explícitas `readOnlyHint`, `destructiveHint`, `idempotentHint` y `openWorldHint`, de modo que los hosts pueden ejecutar consultas sin pedir permiso y solicitar confirmación antes de cualquier acción destructiva, como la limpieza de contenido multimedia o un relay cripto.

### Chat y embeddings

| Tool | Descripción |
|---|---|
| `venice_chat` | Chat completion compatible con OpenAI contra todo el catálogo de LLM de Venice, con bloques de texto/imagen/audio/vídeo/archivo, salidas estructuradas, function tools, caché de prompts y controles de razonamiento. Las llamadas son en texto plano y sin streaming. |
| `venice_responses` | [API Responses](/es/guides/features/responses-api) compatible con OpenAI, en beta y sin estado, con entrada de texto/imagen y controles de razonamiento. Esta herramienta no expone campos de tool calling y no admite modelos E2EE. |
| `venice_embeddings` | Calcula embeddings para una entrada de texto. |
| `venice_chat_with_character` | Chatea con un character de Venice por su slug. |

### Imagen

| Tool | Descripción |
|---|---|
| `venice_image_generate` | Genera una imagen (Flux 2, Lustify SDXL, Anime/WAI, Qwen Image, GPT Image, Nano Banana Pro y más), con relación de aspecto o ancho/alto, niveles de calidad, mejora del prompt, referencias de estilo, búsqueda web y variantes. |
| `venice_image_edit` | Edita una imagen con un prompt. |
| `venice_image_multi_edit` | Edita hasta 8 imágenes juntas con un solo prompt (composición / outpainting). |
| `venice_image_upscale` | Escala una imagen de 2 a 4×, con un control de `creativity`. |
| `venice_image_remove_bg` | Elimina el fondo de una imagen. |
| `venice_image_styles` | Lista los presets de estilo de imagen. |

### Vídeo

| Tool | Descripción |
|---|---|
| `venice_video_generate` | Encola una generación de vídeo (Sora 2, Veo 3.1, Kling, Wan, LTX 2, Seedance, Runway Gen-4 y más) con entradas de imagen, vídeo, audio, referencias y elementos. |
| `venice_video_status` | Comprueba el estado de un trabajo de vídeo en cola (`POST /video/retrieve`). |
| `venice_video_complete` | Marca un vídeo completado como descargado y borra su contenido del servidor. Solo informa del borrado cuando Venice lo confirma. |
| `venice_video_quote` | Obtén una cotización de precio antes de encolar. |

### Audio (TTS / ASR)

| Tool | Descripción |
|---|---|
| `venice_tts` | Texto a voz con voces clonadas, temperatura y etiquetas de emoción. El streaming se almacena en búfer en un único resultado de audio completo. |
| `venice_asr` | Transcribe audio desde una URL, con marcas de tiempo opcionales por palabra o carácter. Las transcripciones grandes se paginan mediante un identificador de sesión. |
| `venice_voice_clone` | Lista las voces disponibles en vivo para cada modelo o clona una voz a partir de la URL de una muestra (devuelve un identificador `vv_<id>` para `venice_tts`). |
| `venice_audio_quote` | Obtén una cotización de precio para generación de música. |

### Música

| Tool | Descripción |
|---|---|
| `venice_music_generate` | Encola generación de música (`ace-step-15`, `elevenlabs-music`, `minimax-music-v2/v25/v26`, `stable-audio-25`, `mmaudio-v2-text-to-audio`, `elevenlabs-sound-effects-v2`) con controles de letra, instrumental, bucle, voz, idioma, velocidad y duración. |
| `venice_music_status` | Comprueba el estado de un trabajo de música en cola. |
| `venice_music_complete` | Marca un trabajo de música completado como descargado. |

### Web augment

| Tool | Descripción |
|---|---|
| `venice_web_search` | Busca en la web con Brave (predeterminado, Zero Data Retention) o Google (a través de un proxy y anonimizado por Venice). |
| `venice_web_scrape` | Raspa una URL convirtiéndola en markdown. |
| `venice_text_parser` | Extrae texto de PDF/DOCX/EPUB/PPTX/XLSX. |

### Catálogo y characters

| Tool | Descripción |
|---|---|
| `venice_list_models` | Pagina el catálogo de modelos en vivo de todos los tipos, con resúmenes compactos, precios e indicadores de capacidades. |
| `venice_model_details` | Obtén la fila completa de un modelo exacto: restricciones de `model_spec`, capacidades y precios. |
| `venice_model_traits` | Asigna nombres de rasgos (`default`, `most_uncensored`, …) a los IDs de modelo actuales. |
| `venice_model_compatibility_mapping` | Asigna nombres de modelos compatibles a IDs de modelo de Venice. |
| `venice_list_characters` | Lista los characters públicos de Venice con filtros de búsqueda, etiqueta, modelo y orden. **Solo con API key.** |
| `venice_get_character` | Obtén un character público por su slug. **Solo con API key.** |
| `venice_character_reviews` | Lista las reseñas públicas paginadas de un character. **Solo con API key.** |

### Atestación TEE

| Tool | Descripción |
|---|---|
| `venice_tee_attestation` | Obtén la evidencia de atestación de hardware (quote de Intel TDX, evidencia opcional de NVIDIA, clave de firma) para un modelo de texto compatible con TEE, usando tu propio nonce de 32 bytes. |
| `venice_tee_signature` | Obtén el payload de firma del enclave para el ID de una solicitud de chat TEE completada. |

<Warning>
Ambas herramientas TEE solo devuelven la evidencia del proveedor: no la verifican y no cifran el chat. Verifica tú mismo el nonce devuelto, el estado del modo de depuración y la vinculación de la clave de firma antes de confiar en un modelo TEE; consulta [Verificación de la atestación TEE](/es/guides/features/tee-e2ee-models#verificación-de-la-atestación-tee). Este servidor rechaza `enable_e2ee`.
</Warning>

### Cripto

| Tool | Descripción |
|---|---|
| `venice_crypto_networks` | Lista los slugs de red en vivo que acepta el proxy RPC. |
| `venice_crypto_rpc` | Hace de proxy de una solicitud JSON-RPC, o de un lote de hasta 100, a Ethereum, Base, Arbitrum, Optimism, Polygon, Solana, Starknet, zkSync, Linea, BSC, Avalanche, Blast y más. |

Las difusiones de transacciones (`eth_sendRawTransaction`, `eth_sendUserOperation`, `sendTransaction` de Solana, escrituras en Starknet) deben enviarse como solicitudes individuales con un `idempotency_key`, y se debe reutilizar la misma clave en los reintentos.

### Facturación (claves de administrador)

| Tool | Descripción |
|---|---|
| `venice_billing_balance` | Disponibilidad actual de USD, DIEM y créditos incluidos. |
| `venice_billing_usage_analytics` | Uso agregado (beta) por fecha, modelo y API key (periodo retrospectivo o rango personalizado). |
| `venice_billing_usage_history` | Uso detallado con paginación por cursor y salida en JSON o CSV. |

<Note>
Las herramientas de facturación requieren una API key de **ADMIN**. Las claves de inferencia no pueden llamar a estos endpoints, y el servidor falla localmente en lugar de recurrir a un token de monedero.
</Note>

### API keys

| Tool | Descripción |
|---|---|
| `venice_list_api_keys` | Lista los metadatos de las claves activas, incluidos solo los últimos seis caracteres. Solo con clave de administrador. |
| `venice_get_api_key` | Obtén los metadatos, el uso, los saldos y los límites de tasa de una clave por su ID. Solo con clave de administrador. |
| `venice_api_key_rate_limits` | Saldos actuales, estado de acceso, nivel, caducidad y límites de tasa por modelo. Clave de inferencia o de administrador. |
| `venice_api_key_rate_limit_logs` | Los últimos 50 eventos de límite de tasa superado (experimental). Solo con clave de administrador. |

### Helpers de monedero x402

Solo relevantes si te autenticas con un monedero mediante [x402](/es/guides/integrations/x402-venice-api) en lugar de una API key.

| Tool | Descripción |
|---|---|
| `venice_x402_balance` | Comprueba el saldo prepago de créditos x402 para una dirección de monedero EVM o Solana. |
| `venice_x402_top_up_info` | Obtén los requisitos de recarga (red, token USDC, receptor, importe mínimo). No recibe argumentos. |
| `venice_x402_transactions` | Lista transacciones recientes de recarga y débito x402 para una dirección de monedero EVM o Solana. |

## Configuración

El servidor se configura completamente mediante variables de entorno.

### Modelos y solicitudes

| Env var | Predeterminado | Notas |
|---|---|---|
| `VENICE_API_KEY` | _(ninguno)_ | Tu API key de Venice. La configuración más simple. |
| `VENICE_DEFAULT_CHAT_MODEL` | `deepseek-v4-flash-0731` | |
| `VENICE_DEFAULT_IMAGE_MODEL` | `flux-2-pro` | |
| `VENICE_DEFAULT_TTS_MODEL` | `tts-kokoro` | |
| `VENICE_DEFAULT_ASR_MODEL` | `openai/whisper-large-v3` | |
| `VENICE_DISABLE_NSFW` | `0` | Establece en `1` para eliminar notas de capacidad NSFW de las descripciones de las tools. |
| `VENICE_HTTP_TIMEOUT_MS` | `60000` | |
| `VENICE_SIWX_TOKEN` | _(ninguno)_ | Token de auth en modo monedero x402. Consulta [x402 más abajo](#modo-monedero-x402). |

Si están establecidos tanto `VENICE_API_KEY` como `VENICE_SIWX_TOKEN`, la API key gana en la mayoría de las llamadas; consulta [Cobertura de modos de autenticación](#cobertura-de-modos-de-autenticación) para ver las excepciones.

### Límites de tamaño de respuesta

El contenido multimedia generado se almacena en búfer y se incrusta en el resultado MCP como base64, por lo que cada modalidad tiene un límite de bytes.

| Env var | Predeterminado | Se aplica a |
|---|---|---|
| `VENICE_MAX_IMAGE_RESPONSE_BYTES` | `33554432` (32 MiB) | `venice_image_generate`, `venice_image_edit`, `venice_image_multi_edit`, `venice_image_upscale`, `venice_image_remove_bg` |
| `VENICE_MAX_VIDEO_RESPONSE_BYTES` | `26214400` (25 MiB) | `venice_video_status` |
| `VENICE_MAX_AUDIO_RESPONSE_BYTES` | `33554432` (32 MiB) | `venice_tts`, `venice_music_status` |

Un resultado de imagen o TTS que supere el límite se descarta con un error. Un resultado de vídeo o música que lo supere permanece en cola, así que puedes volver a llamar a la herramienta de estado con el mismo ID de cola después de aumentar el límite.

### Servidor HTTP

Solo relevante en el [despliegue con HTTP en streaming](#self-hosting-http-en-streaming).

| Env var | Predeterminado | Notas |
|---|---|---|
| `PORT` | `3333` | Puerto de escucha HTTP. |
| `VENICE_MCP_HOST` | `127.0.0.1` | Dirección de enlace. Establécela en `0.0.0.0` para exponerlo en la LAN o en un contenedor. |
| `VENICE_MCP_AUTH_TOKEN` | _(ninguno)_ | Token Bearer para `/mcp`. Obligatorio cuando se enlaza fuera de loopback, en cuyo caso debe tener al menos 16 caracteres. Una vez establecido, también se exige en loopback. |
| `VENICE_MCP_ALLOW_UNAUTHENTICATED_HTTP` | `0` | Vía de escape para exponer HTTP sin autenticación. Úsala solo detrás de un proxy autenticado de confianza. |
| `VENICE_MCP_MAX_SESSIONS` | `100` | Número máximo de sesiones activas de HTTP en streaming. |
| `VENICE_MCP_SESSION_TTL_MS` | `1800000` | Tiempo de vida de una sesión inactiva antes de su limpieza. |

## Comportamiento de la generación multimedia

- **El contenido completado puede ser bytes o una URL.** Los trabajos de vídeo y música devuelven recursos MP4/audio incrustados, o un JSON con un `download_url` que se devuelve como enlace a recurso. Descarga primero ese enlace y después llama a `venice_video_complete` o `venice_music_complete`; la limpieza del contenido nunca se aplica a un resultado con `download_url`, porque el enlace deja de funcionar una vez que se borra el archivo.
- **Algunos modelos solo devuelven una URL al encolar.** Para los modelos VPS y Grok Imagine Private, guarda el `download_url` que devuelve `venice_video_generate` y pásalo a `venice_video_status`; una consulta con estado `COMPLETED` sin URL incluida sigue proporcionando un enlace utilizable.
- **La mejora del prompt se informa en la respuesta.** Cuando se aplica `enhance_prompt`, los resultados de generación, edición y edición múltiple de imágenes incluyen el prompt decodificado de URL que devolvió Venice.
- **La paginación de ASR se cobra una sola vez.** Las transcripciones de más de 8.000 caracteres, o con más marcas de tiempo de las que caben en una página (200 por array de forma predeterminada, hasta 500 con `timestamp_limit`), devuelven un `result_handle` junto con la primera página. Solicita las páginas siguientes con ese identificador. Los identificadores se guardan en memoria por sesión MCP durante 10 minutos, y solo se conservan los 16 más recientes.
- **El consentimiento de Seedance no permite saltarse las políticas.** Los modelos públicos actuales de Seedance pueden rechazar directamente contenido que contenga personas detectables. Cuando se devuelve una respuesta `needs_consent`, los tres indicadores `consents.seedance` son declaraciones legales: establécelos en `true` solo después de que el usuario confirme explícitamente cada declaración.

## Modo monedero x402

Venice admite autenticación con un [token Sign-In-With-X de monedero](/es/guides/integrations/x402-venice-api) respaldado por crédito USDC prepago en Base o Solana, además del flujo normal de API key. No se requiere email, teléfono ni KYC: tu monedero es la única identidad.

```json
{
  "mcpServers": {
    "venice": {
      "command": "npx",
      "args": ["-y", "@veniceai/mcp-server@0.3.0"],
      "env": { "VENICE_SIWX_TOKEN": "<base64 Sign-In-With-X payload>" }
    }
  }
}
```

El servidor MCP reenvía `VENICE_SIWX_TOKEN` en la cabecera `SIGN-IN-WITH-X` en cada llamada a la API de Venice. El servidor nunca ve tu clave privada. La firma del monedero y las autorizaciones de recarga USDC ocurren en tu propio monedero.

| Flujo | Qué ocurre |
|---|---|
| **Configuración única** | Firma un mensaje Sign-In-With-X en tu monedero → produce un token SIWX (JSON en base64). |
| **Recarga** | `POST /api/v1/x402/top-up` devuelve 402 + requisitos de pago. Firma un pago USDC para una de las opciones devueltas de Base o Solana, reenvía y Venice acredita tu saldo. |
| **Cada llamada de inferencia** | El servidor MCP envía `SIGN-IN-WITH-X: <SIWX>`; Venice debita tu saldo prepago. |

La recarga mínima es de **\$5 USD**. El saldo mínimo para llamar a inferencia es de **\$0.10**. Una vez recargado, las llamadas son sub-100 ms porque la liquidación ocurre off-chain en una cuenta de crédito rápida.

<Tip>
Los monederos vinculados a una cuenta de Venice con DIEM en staking consumen del saldo de staking en lugar de los créditos USDC, por lo que no se necesita recarga.
</Tip>

Venice no acepta cabeceras de pago en las rutas de inferencia, así que este servidor nunca envía ninguna. `PAYMENT-SIGNATURE` pertenece únicamente a `/x402/top-up`, y el helper de recarga obtiene los requisitos sin enviar ningún pago.

### Cobertura de modos de autenticación

Algunos endpoints solo aceptan un modo de autenticación:

| Tool | API key | x402 |
|---|---|---|
| Inferencia, multimedia, web augment, RPC cripto, chat con characters | ✓ | ✓ |
| `venice_list_characters`, `venice_get_character`, `venice_character_reviews` | ✓ | ✗ |
| `venice_billing_*`, `venice_list_api_keys`, `venice_get_api_key`, `venice_api_key_rate_limit_logs` | ✓ (admin) | ✗ |
| `venice_api_key_rate_limits` | ✓ (cualquier clave) | ✗ |
| `venice_x402_balance`, `venice_x402_transactions` | ✗ | ✓ |
| `venice_x402_top_up_info` | ✓ | ✓ |

Cuando están establecidas ambas credenciales, se usa la API key en todas las llamadas autenticadas excepto en `venice_x402_balance` y `venice_x402_transactions`, que siempre envían el token de monedero.

## Self-hosting (HTTP en streaming)

Para despliegues de equipo o workspace, ejecuta el servidor MCP sobre HTTP en lugar de stdio:

```bash
docker run -p 3333:3333 \
  -e VENICE_API_KEY=<your-venice-api-key> \
  -e VENICE_MCP_AUTH_TOKEN=<choose-a-long-random-token> \
  ghcr.io/veniceai/venice-mcp-server:latest
```

El servidor está ahora disponible en `http://localhost:3333/mcp`. Los clientes HTTP deben enviar `Authorization: Bearer <VENICE_MCP_AUTH_TOKEN>` y deben crear sesiones nuevas sin la cabecera `mcp-session-id`, y después reutilizar el ID de sesión emitido por el servidor.

<Warning>
`/mcp` es un endpoint de ejecución de tools respaldado por credenciales: los llamadores pueden gastar la API key de Venice configurada o el saldo x402. Cuando el modo HTTP se vincula fuera de loopback, el arranque falla salvo que `VENICE_MCP_AUTH_TOKEN` esté establecido, o que `VENICE_MCP_ALLOW_UNAUTHENTICATED_HTTP=1` esté establecido detrás de un proxy autenticado de confianza. En producción, fija explícitamente la versión del paquete npm en lugar de depender de `latest`.
</Warning>
