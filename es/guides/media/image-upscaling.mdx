El escalado de imágenes mejora la resolución y la calidad visual de una imagen existente. Envía una imagen a `/image/upscale`, elige un factor de escala y un nivel de creatividad opcional, y Venice devolverá la imagen mejorada como datos binarios.

Usa el escalado de imágenes cuando ya tengas una imagen y quieras una salida de mayor resolución. Usa [generación de imágenes](/es/guides/media/image-generation) cuando necesites crear una imagen a partir de un prompt, y [edición de imágenes](/es/guides/media/image-editing) cuando necesites cambiar el contenido de la imagen.

## Uso básico

<CodeGroup>
```python Python
import base64
import os
from pathlib import Path

import requests

image_base64 = base64.b64encode(Path("input.jpg").read_bytes()).decode("utf-8")

response = requests.post(
    "https://api.venice.ai/api/v1/image/upscale",
    headers={
        "Authorization": f"Bearer {os.environ['VENICE_API_KEY']}",
        "Content-Type": "application/json",
    },
    json={
        "image": image_base64,
        "scale": 2,
        "creativity": 0.01,
    },
)

response.raise_for_status()
Path("upscaled.png").write_bytes(response.content)
```

```javascript Node.js
import { readFile, writeFile } from "node:fs/promises";

const image = await readFile("input.jpg");

const response = await fetch("https://api.venice.ai/api/v1/image/upscale", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.VENICE_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    image: image.toString("base64"),
    scale: 2,
    creativity: 0.01,
  }),
});

if (!response.ok) {
  throw new Error(await response.text());
}

const output = Buffer.from(await response.arrayBuffer());
await writeFile("upscaled.png", output);
```

```bash cURL
IMAGE_BASE64=$(base64 < input.jpg | tr -d '\n')

curl https://api.venice.ai/api/v1/image/upscale \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d "{
    \"image\": \"$IMAGE_BASE64\",
    \"scale\": 2,
    \"creativity\": 0.01
  }" \
  --output upscaled.png
```
</CodeGroup>

También puedes subir un archivo directamente con `multipart/form-data` en lugar de codificarlo en base64:

```bash cURL (multipart)
curl https://api.venice.ai/api/v1/image/upscale \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -F "image=@input.jpg" \
  -F "scale=2" \
  -F "creativity=0.01" \
  --output upscaled.png
```

Envía exactamente una parte `image` por solicitud. Los archivos subidos deben pesar menos de 25 MB.

## Parámetros

| Parámetro | Tipo | Requerido | Descripción |
|-----------|------|----------|-------------|
| `image` | string o archivo | Sí | Imagen de origen. Envíala en base64 dentro del JSON o sube una parte de archivo con `multipart/form-data`. Debe tener al menos 256×256 píxeles. Los archivos subidos deben pesar 25 MB o menos; los cuerpos JSON tienen un límite de 35 MB. |
| `scale` | number | No | Factor de escalado entre `2` y `4`. El valor predeterminado es `2`; usa `2` o `4` (se aceptan valores intermedios, que se facturan a la tarifa de 4x). La salida está limitada a 16.777.216 píxeles (4096×4096): si la escala solicitada supera el límite, el servidor reduce automáticamente la escala efectiva. Las entradas que ya están en el límite o cerca de él se rechazan con `400`, así que redúcelas primero. |
| `creativity` | number | No | Cuánto detalle y textura añade el escalador. `0`–`0.02`, valor predeterminado `0.01`. Los valores más altos añaden más; los más bajos se mantienen más cerca del original. Los valores fuera del rango se ajustan al límite más cercano. |

<Note>
La respuesta son datos binarios de imagen, no JSON. Escribe el cuerpo de la respuesta directamente en un archivo o envíalo por stream al almacenamiento.
</Note>

## Consejos de entrada

- Comienza con la imagen de origen más limpia que tengas. El escalado mejora el detalle, pero no puede recuperar por completo la información que no está presente.
- Usa factores de escala moderados para flujos de trabajo en producción. Las salidas muy grandes pueden aumentar la latencia y el tamaño del archivo.
- Conserva la imagen original por si necesitas comparar la calidad o reintentar con distintas configuraciones.
