La edición de imágenes en Venice es síncrona. Envía tu imagen fuente a `/image/edit` o `/image/multi-edit` y el resultado editado vuelve en la misma respuesta como archivo de imagen. Para recortes, `/image/background-remove` devuelve un PNG transparente.

<Warning>
Los endpoints de edición de imagen son experimentales y el comportamiento específico del modelo puede cambiar con el tiempo.
</Warning>

## Endpoints

| Endpoint | Propósito | Mejor para |
|---|---|---|
| `POST /image/edit` | Edita una sola imagen con un prompt | Edits generales e inpainting con prompt |
| `POST /image/multi-edit` | Edita usando múltiples imágenes de referencia (el límite varía según el modelo) | Composición y edits con varias referencias |
| `POST /image/background-remove` | Elimina el fondo de una imagen | Recortes transparentes para productos, retratos y activos |

## Cuándo usar cada endpoint

- Usa `/image/edit` cuando tienes una imagen fuente y quieres cambiar, eliminar o restilizar parte de ella con un prompt.
- Usa `/image/multi-edit` cuando necesitas condicionar la edición con imágenes de referencia adicionales.
- Usa `/image/background-remove` cuando solo quieres un sujeto en primer plano limpio con transparencia.

<Note>
Para inpainting, usa `/image/edit` o `/image/multi-edit`. El antiguo parámetro `inpaint` en `/image/generate` está deprecado.
</Note>

<Tip>
Establece `enhance_prompt: true` en cualquiera de los endpoints de edición para que un mejorador con conciencia visual analice la imagen o imágenes de entrada y reescriba tu instrucción antes de editar. Consulta [Mejora de prompts](/es/guides/media/prompt-enhancement) para conocer el comportamiento, los precios y los detalles de las cabeceras de respuesta.
</Tip>

## Paso 1: edita una sola imagen

La edición de imagen única es el flujo más simple de inpainting. Envía una imagen más un prompt corto como "remove the sign", "change the sky to sunrise" o "replace the background with a studio backdrop".

**Solicitud:**
```bash
POST https://api.venice.ai/api/v1/image/edit
Authorization: Bearer $VENICE_API_KEY
Content-Type: application/json

{
  "model": "firered-image-edit",
  "prompt": "Replace the cloudy sky with a warm sunrise while preserving the buildings and canal",
  "image": "https://example.com/venice-canal.jpg"
}
```

**Respuesta (200):**
El cuerpo de la respuesta es datos binarios de imagen en bruto. Guárdalos directamente en un archivo. El formato es PNG para ediciones 1K y JPEG para ediciones 2K y 4K, o PNG en cualquier resolución cuando `transparent_background` es `true`. Establece `output_format` en `jpeg`, `png` o `webp` para elegirlo explícitamente.

<CodeGroup>
```python Python
import base64
import os
import requests

with open("input.jpg", "rb") as f:
    image_base64 = base64.b64encode(f.read()).decode("utf-8")

response = requests.post(
    "https://api.venice.ai/api/v1/image/edit",
    headers={
        "Authorization": f"Bearer {os.environ['VENICE_API_KEY']}",
        "Content-Type": "application/json",
    },
    json={
        "model": "firered-image-edit",
        "prompt": "Remove the tourist crowd from the square and keep the architecture intact",
        "image": image_base64,
    },
)

with open("edited.png", "wb") as f:
    f.write(response.content)
```

```javascript Node.js
import fs from "fs";

const imageBase64 = fs.readFileSync("input.jpg").toString("base64");

const response = await fetch("https://api.venice.ai/api/v1/image/edit", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.VENICE_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    model: "firered-image-edit",
    prompt: "Remove the tourist crowd from the square and keep the architecture intact",
    image: imageBase64,
  }),
});

const editedImage = Buffer.from(await response.arrayBuffer());
fs.writeFileSync("edited.png", editedImage);
```

```bash cURL
curl https://api.venice.ai/api/v1/image/edit \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -o edited.png \
  -d '{
    "model": "firered-image-edit",
    "prompt": "Colorize this black and white portrait naturally",
    "image": "https://example.com/portrait-bw.jpg"
  }'
```
</CodeGroup>

## Paso 2: usa multi-edit con imágenes de referencia

`/image/multi-edit` acepta múltiples imágenes, y el tope es específico de cada modelo. Lee `model_spec.constraints.maxInputImages` en `GET /models?type=inpaint` para conocer el tope de un modelo concreto. Cuando el campo no está presente, el tope es 3, o 1 cuando `combineImages` es `false`.

La primera imagen es la imagen base. Las imágenes restantes son referencias adicionales que condicionan la edición.

<Note>
El endpoint público no tiene canal de máscara. Las imágenes adicionales actúan como referencias sobre toda la imagen, no como mapas de regiones: no existe el parámetro `mask`, y enviarlo devuelve un `400`. Redacta el prompt con precisión para acotar dónde se aplica la edición.
</Note>

Es la mejor elección cuando quieres:

- combinar una composición existente con una imagen de referencia adicional
- dar al modelo ejemplos del estilo, objeto o textura que se debe aplicar
- restringir la edición más estrechamente de lo que puede hacer un prompt en una sola imagen

**Solicitud JSON:**
```json
{
  "modelId": "firered-image-edit",
  "prompt": "Replace the blank billboard area with a glowing Venice film festival poster while preserving lighting and perspective",
  "images": [
    "https://example.com/street-scene.png",
    "https://example.com/billboard-reference.png"
  ]
}
```

**Solicitud multipart:**
```bash
curl https://api.venice.ai/api/v1/image/multi-edit \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -F "modelId=firered-image-edit" \
  -F "prompt=Replace the blank billboard area with a glowing Venice film festival poster while preserving lighting and perspective" \
  -F "images=@street-scene.png" \
  -F "images=@billboard-reference.png" \
  -o multi-edited.png
```

Al igual que `/image/edit`, el cuerpo de la respuesta es datos de imagen en bruto, y el formato de salida sigue las mismas reglas.

<Note>
`/image/multi-edit` usa actualmente el campo `modelId` en lugar de `model` en el esquema de la solicitud.
</Note>

## Consejos para inpainting

El inpainting basado en prompt funciona mejor cuando la instrucción es corta y local:

- `remove the tree`
- `change the sky to sunset`
- `replace the logo with a blank sign`
- `restore the torn corner of the photo`

Para cambios de escena más amplios, describe lo que debe permanecer igual:

```text
Replace the background with a modern photo studio backdrop while preserving the subject pose, facial features, and clothing.
```

Si la edición sigue afectando al área equivocada, cambia de `/image/edit` a `/image/multi-edit` y proporciona una imagen de referencia adicional que muestre el resultado deseado. Luego describe con precisión el cambio que quieres en el prompt.

## Paso 3: elimina el fondo

Usa `/image/background-remove` cuando quieras el sujeto en primer plano aislado sobre un fondo transparente. Este endpoint devuelve un PNG con transparencia alfa.

**Usando una URL de imagen:**
```bash
curl https://api.venice.ai/api/v1/image/background-remove \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -o cutout.png \
  -d '{
    "image_url": "https://example.com/product-photo.jpg"
  }'
```

**Usando subida de archivo local:**
```bash
curl https://api.venice.ai/api/v1/image/background-remove \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -F "image=@product-photo.jpg" \
  -o cutout.png
```

Usa la eliminación de fondo para:

- fotos de producto de ecommerce
- fotos de perfil y retratos
- activos que planeas colocar sobre un nuevo fondo

Si de todos modos vas a generar o editar la imagen, puedes ahorrarte esta segunda llamada: `/image/generate`, `/image/edit` y `/image/multi-edit` aceptan `transparent_background: true` en los modelos compatibles y devuelven el canal alfa directamente. Consulta [Imágenes con fondo transparente](/es/guides/media/transparent-backgrounds) para ver la comparación.

## Parámetros de la solicitud

### `/image/edit`

| Parámetro | Tipo | Obligatorio | Predeterminado | Descripción |
|---|---|---|---|---|
| `image` | archivo, cadena base64 o URL | Sí | - | Imagen fuente a editar |
| `prompt` | string | Sí | - | Instrucciones de texto para la edición |
| `model` | string | No | `firered-image-edit` | ID del modelo de edición |
| `aspect_ratio` | string | No | predeterminado del modelo | Ratio de salida para los modelos que lo admiten |
| `resolution` | string | No | `1K` | Nivel de resolución de la imagen de salida, como `1K`, `2K` o `4K`. Los valores admitidos varían según el modelo |
| `output_format` | string | No | inferido | `jpeg`, `png` o `webp`. Si se omite, PNG para ediciones 1K y JPEG para ediciones 2K y 4K, o PNG en cualquier resolución cuando `transparent_background` es `true` |
| `enhance_prompt` | boolean | No | `false` | Analiza la imagen de entrada y reescribe la instrucción de edición antes de la inferencia |
| `disable_prompt_optimization_thinking` | boolean | No | predeterminado del modelo | Omite el paso de razonamiento de optimización del prompt del modelo para una generación más rápida. Solo lo admiten los modelos con `supportsOptimizePromptThinking`; los demás lo ignoran |
| `safe_mode` | boolean | No | `true` | Desenfoca el contenido adulto en el resultado editado. Establece en `false` para desactivar el desenfoque. |
| `transparent_background` | boolean | No | `false` | Devuelve la edición con un canal alfa real. Requiere un modelo con `supportsTransparentBackground: true` y `output_format` `png` o `webp` (se infiere PNG si se omite). Consulta [Imágenes con fondo transparente](/es/guides/media/transparent-backgrounds) |
| `modelId` | string | Deprecado | - | Alias deprecado de `model` |

### `/image/multi-edit`

| Parámetro | Tipo | Obligatorio | Predeterminado | Descripción |
|---|---|---|---|---|
| `images` | array de archivos, cadenas base64 o URLs | Sí | - | La primera imagen es la base; el resto son referencias adicionales. El máximo es específico del modelo: consulta `model_spec.constraints.maxInputImages` |
| `prompt` | string | Sí | - | Instrucciones de texto sobre cómo combinar o editar las imágenes |
| `modelId` | string | No | `firered-image-edit` | ID del modelo de edición |
| `resolution` | string | No | `1K` | Nivel de resolución de la imagen de salida, como `1K`, `2K` o `4K`. Los valores admitidos varían según el modelo |
| `quality` | string | No | predeterminado del modelo | `low`, `medium` o `high` en los modelos que incluyen `qualities` en `model_spec.constraints`. Los valores más altos pueden aumentar el coste de la solicitud |
| `output_format` | string | No | inferido | `jpeg`, `png` o `webp`. Mismas reglas de inferencia que `/image/edit` |
| `enhance_prompt` | boolean | No | `false` | Analiza las imágenes de entrada y reescribe la instrucción de edición antes de la inferencia |
| `disable_prompt_optimization_thinking` | boolean | No | predeterminado del modelo | Omite el paso de razonamiento de optimización del prompt del modelo para una generación más rápida. Solo lo admiten los modelos con `supportsOptimizePromptThinking`; los demás lo ignoran |
| `safe_mode` | boolean | No | `true` | Desenfoca el contenido adulto en el resultado editado. Establece en `false` para desactivar el desenfoque. |
| `transparent_background` | boolean | No | `false` | Devuelve el resultado compuesto con un canal alfa real. Mismas reglas de modelo y formato que `/image/edit` |

### `/image/background-remove`

| Parámetro | Tipo | Obligatorio | Descripción |
|---|---|---|---|
| `image` | archivo o cadena base64 | Uno de `image` o `image_url` | Imagen fuente a recortar |
| `image_url` | string | Uno de `image` o `image_url` | URL pública de la imagen a recortar |

<Note>
`/image/background-remove` usa un modelo interno fijo. No acepta un campo `model`. Enviar uno (por ejemplo `"model": "bria-bg-remover"`) devuelve `400` porque `model` no es un campo reconocido.
</Note>

### Contenido adulto y modo seguro

Tanto `/image/edit` como `/image/multi-edit` aceptan `safe_mode` (predeterminado: `true`). Cuando está habilitado, el contenido adulto en la salida editada se difumina, así que envía `safe_mode: false` para recibir la salida sin difuminar:

```json
{
  "model": "qwen-edit-uncensored",
  "prompt": "…",
  "image": "…",
  "safe_mode": false
}
```

La salida para adultos (NSFW) sin difuminar está disponible para todos los usuarios de la API. No necesitas una suscripción Pro, y la configuración del filtro de contenido maduro en la app de Venice no afecta a las solicitudes de imágenes realizadas a través de la API.

Las políticas de contenido varían según el modelo de edición y se aplican independientemente de `safe_mode`. Para edición sin censura, usa `qwen-edit-uncensored`.

La diferencia en el nombre de moderación entre endpoints suele confundir:

| Endpoint | Campo para desactivar el desenfoque |
|---|---|
| `POST /image/edit`, `POST /image/multi-edit` | `safe_mode: false` |
| `POST /image/generate` (generación nativa) | `safe_mode: false` |
| `POST /images/generations` (generación compatible con OpenAI) | `moderation: "low"` |

Pasar `safe_mode` a `/images/generations` devuelve `400` con `Unrecognized key(s) in object: 'safe_mode'`.

## Formatos de entrada admitidos

| Endpoint | Entrada JSON | Entrada multipart | Salida |
|---|---|---|---|
| `/image/edit` | Cadena base64 o URL | Subida de archivo | `image/png`, `image/jpeg` o `image/webp` |
| `/image/multi-edit` | Cadenas base64 o URLs | Subidas de archivo | `image/png`, `image/jpeg` o `image/webp` |
| `/image/background-remove` | Cadena base64 o URL | Subida de archivo | `image/png` |

Para los endpoints de edición, las imágenes deben tener al menos 256×256 píxeles y el número total de píxeles no debe superar 33.177.600 (resolución 8K). Los archivos subidos deben ser de menos de `25MB`.

## Modelos y precios

El modelo de edición predeterminado es `firered-image-edit`, con precio de **$0.04 por edición**. Otros modelos con capacidad de edición pueden tener precios y restricciones diferentes. La mejora de prompts añade **$0.04 por reescritura aplicada** al precio de la edición.

Consulta:

- [Precios de imagen](/es/overview/pricing)
- [API de Models](/es/api-reference/endpoint/models/list) con `type=inpaint`

## Errores

| Estado | Significado | Acción |
|---|---|---|
| `400` | Parámetros de solicitud no válidos | Comprueba el número de imágenes, los nombres de campo y el formato de entrada |
| `401` | Autenticación fallida | Comprueba tu API key |
| `402` | Saldo insuficiente | Añade créditos en [venice.ai/settings/api](https://venice.ai/settings/api?utm_source=venice-api-documentation) |
| `413` | Archivo demasiado grande | Mantén los archivos subidos por debajo de 25 MB |
| `415` | Tipo de contenido no válido (solo `/image/multi-edit`; los demás endpoints devuelven `400`) | Usa JSON o multipart form-data correctamente |
| `422` | Infracción de la política de contenido o imagen de entrada demasiado grande | Ajusta el prompt o reduce las dimensiones de la imagen |
| `429` | Límite de velocidad excedido o modelo sobrecargado | Reintenta con backoff; comprueba la cabecera `Retry-After` |
| `500` | Procesamiento de inferencia fallido | Reintenta la solicitud |
| `503` | Modelo a capacidad máxima | Reintenta tras una breve demora |

<Note>
Algunos modelos de edición tienen políticas de contenido más estrictas que los modelos de generación de imagen. Las solicitudes que infringen la política del modelo seleccionado se rechazan con `422`.
</Note>
