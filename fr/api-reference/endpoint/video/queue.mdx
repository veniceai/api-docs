Appelez `/video/quote` pour obtenir une estimation du prix, puis interrogez `/video/retrieve` avec le `queue_id` renvoyé jusqu'à ce que la génération soit terminée.

Les modèles privés renvoient également un `download_url` pour la vidéo terminée. Il s'agit d'une URL de livraison à durée de vie courte (quelques relances sont acceptables si un téléchargement échoue) ; voir le [guide de génération vidéo](/guides/media/video-generation#private-download-links) pour les détails et la méthode `DELETE` optionnelle pour la confidentialité.

### Seedance 2.0 & 2.5

Pour les modèles `seedance-2-0-*-basic` et `seedance-2-5-*-basic` (text-to-video, image-to-video, reference-to-video, plus les variantes `-fast-*` de Seedance 2.0), voir le [guide Seedance 2.0 & 2.5](/guides/media/seedance-2-0) pour le modèle à quatre workflows (Reference / Edit / Extend / Stitch), les valeurs `aspect_ratio` / `duration` alignées sur la source, les limites multimodales spécifiques à chaque famille, la politique média de l'API publique et les détails de tarification.

### Politique média publique de Seedance

Les modèles Seedance publics n'utilisent pas d'attestation de consentement (`consents.seedance` / `needs_consent`). Les médias contenant des personnes détectables peuvent être rejetés en amont. Utilisez l'application Venice ou Studio pour bénéficier de l'ensemble complet des fonctionnalités Seedance. Voir le [guide Seedance](/guides/media/seedance-2-0) pour plus de détails.

### Agrandissement vidéo

Pour le modèle `topaz-video-upscale`, utilisez `upscale_factor` (1, 2 ou 4) au lieu de `resolution`, et fournissez un `video_url`. La durée et le FPS sont détectés automatiquement à partir du fichier vidéo. Voir le [guide d'agrandissement vidéo](/guides/media/video-upscaling) pour les détails complets et les exemples.
