Si la réponse de `/video/queue` incluait un `download_url`, téléchargez le fichier terminé depuis cette URL (et non en binaire depuis cet endpoint). Sinon, cet endpoint renvoie la vidéo. Voir [Liens de téléchargement privés](/fr/guides/media/video-generation#liens-de-t%C3%A9l%C3%A9chargement-priv%C3%A9s) pour le fonctionnement du lien, les relances et la méthode `DELETE` optionnelle.
