<Warning>
Ce endpoint a été retiré le 2026-09-16 et renvoie désormais `410 Gone` pour chaque requête. Utilisez plutôt l'[historique d'utilisation de la facturation](/fr/api-reference/endpoint/billing/usage-history).
</Warning>

L'historique d'utilisation de la facturation renvoie les mêmes entrées du registre avec une pagination par curseur. Pour migrer :

- Remplacez `page` et `limit` par `pageSize`, puis transmettez le `nextCursor` de chaque réponse pour récupérer la page suivante.
- Remplacez `startDate` et `endDate` par `startTimestamp` et `endTimestamp`.
