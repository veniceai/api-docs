Appelez [`/audio/voice-changer/quote`](/fr/api-reference/endpoint/audio/voice-changer/quote) pour estimer le coût, puis interrogez [`/audio/voice-changer/retrieve`](/fr/api-reference/endpoint/audio/voice-changer/retrieve) avec le `queue_id` renvoyé jusqu'à ce que la conversion soit terminée. Une conversion mise en file d'attente a déjà été facturée. Si cette réponse est perdue, interrogez retrieve plutôt que de la remettre en file d'attente. Si vous conservez les médias convertis après récupération, appelez [`/audio/voice-changer/complete`](/fr/api-reference/endpoint/audio/voice-changer/complete) une fois que vous les avez téléchargés.

Les modèles de changeur de voix ne sont pas acceptés sur [`/audio/queue`](/fr/api-reference/endpoint/audio/queue). Consultez le [guide Changeur de voix](/fr/guides/media/voice-changer) pour un parcours complet.
