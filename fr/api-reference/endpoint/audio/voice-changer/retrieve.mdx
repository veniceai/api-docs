Utilisez le `queue_id` renvoyé par [`/audio/voice-changer/queue`](/fr/api-reference/endpoint/audio/voice-changer/queue) pour vérifier l'état de la conversion. Tant que le travail est en cours d'exécution, cet endpoint renvoie du JSON avec `status: "PROCESSING"` ; lorsqu'il se termine, il renvoie `audio/mpeg`. Définissez `delete_media_on_completion` sur `true` pour nettoyer les médias stockés dans le même appel, ou appelez [`/audio/voice-changer/complete`](/fr/api-reference/endpoint/audio/voice-changer/complete) après avoir téléchargé le fichier.

Les modèles de changeur de voix ne sont pas acceptés sur [`/audio/retrieve`](/fr/api-reference/endpoint/audio/retrieve).
