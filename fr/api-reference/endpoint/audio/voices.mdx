title: 'Cloner une voix'
openapi: 'POST /audio/voices'
"og:title": "Voice Cloning | Venice API Docs"
"og:description": "Documentation de l'API de clonage vocal de Venice."
---

Importez un échantillon audio pour créer un identifiant de voix clonée, puis transmettez-le comme `voice` à [`/audio/speech`](/fr/api-reference/endpoint/audio/speech) avec le même `model` que celui utilisé pour le créer. Pour un tutoriel pas à pas, consultez le [guide du clonage vocal](/fr/guides/media/voice-cloning).
