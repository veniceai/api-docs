Il s'agit d'un endpoint expérimental qui peut être sujet à modification.
</Warning>

<Info>
**Tarification :** Le prix de l'édition d'image varie selon le modèle. Le modèle par défaut (`firered-image-edit`) coûte **0,04 $ par édition**. Voir l'[endpoint Models](/fr/api-reference/endpoint/models/list) pour tous les modèles d'édition disponibles et leur tarification.
</Info>

## Niveaux de qualité

`/image/edit` n'accepte pas de paramètre `quality`, et l'envoyer renvoie `400`. Les éditions sur cet endpoint sont facturées au niveau par défaut du modèle (`high` pour `gpt-image-2-edit`).

Pour choisir un niveau (`low`, `medium`, `high`), utilisez [`/image/multi-edit`](/fr/api-reference/endpoint/image/multi-edit), qui accepte `quality` sur les modèles qui le prennent en charge. Les prix par niveau (1K/2K/4K × low/medium/high) se trouvent sous `model_spec.pricing.quality` dans l'[endpoint Models](/fr/api-reference/endpoint/models/list) et sont listés dans l'[aperçu de la tarification](/fr/overview/pricing).
