</Info>

## Enregistrer l'image modifiée {#save-the-edited-image}

Le corps de la réponse est l'image modifiée elle-même, pas du JSON : écrivez-le donc dans un fichier au lieu de l'analyser :

```bash
curl https://api.venice.ai/api/v1/image/edit \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "Turn the scene into a snowy winter evening", "image": "https://venice.ai/samples/gpt-image-2-6-flare/hero.webp"}' \
  --output edited.png
```

`image` accepte aussi une chaîne base64 ou un envoi de fichier multipart. Le [guide d'édition d'images](/fr/guides/media/image-editing) couvre les modifications multi-images, la suppression d'arrière-plan et le choix d'un modèle.

## Niveaux de qualité

`/image/edit` n'accepte pas de paramètre `quality`, et l'envoyer renvoie `400`. Les éditions sur cet endpoint sont facturées au niveau par défaut du modèle (`high` pour `gpt-image-2-edit`).

Pour choisir un niveau (`low`, `medium`, `high`), utilisez [`/image/multi-edit`](/fr/api-reference/endpoint/image/multi-edit), qui accepte `quality` sur les modèles qui le prennent en charge. Les prix par niveau (1K/2K/4K × low/medium/high) se trouvent sous `model_spec.pricing.quality` dans l'[endpoint Models](/fr/api-reference/endpoint/models/list) et sont listés dans [Modèles d'image](/fr/models/image).
