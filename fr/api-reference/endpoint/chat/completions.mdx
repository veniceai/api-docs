<Info>
  **Les paramètres propres à Venice se trouvent dans [`venice_parameters`](#body-venice-parameters).** Cet endpoint est compatible OpenAI, mais l'objet `venice_parameters` débloque des fonctionnalités qui ne font pas partie de l'API OpenAI standard, et beaucoup d'intégrateurs passent à côté :

  - **Recherche web et citations** — `enable_web_search`, `enable_web_citations`, `enable_web_scraping`
  - **Personas de personnages** — `character_slug`
  - **Contrôle du prompt système** — `include_venice_system_prompt`
  - **Contrôles du raisonnement** — `disable_thinking`, `strip_thinking_response`
  - **Confidentialité** — `enable_e2ee`

  Consultez la liste complète dans la section [`venice_parameters`](#body-venice-parameters) ci-dessous.
</Info>
