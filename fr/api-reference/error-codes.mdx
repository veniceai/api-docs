Lorsqu'une erreur survient, l'API Venice renvoie un code d'état HTTP et un message descriptif. Certaines erreurs incluent également des champs supplémentaires, tels que le statut de remboursement, les modèles de relance suggérés, les détails de validation ou les identifiants de requête.

## Format de la réponse d'erreur

La plupart des erreurs renvoient un champ `error` avec un message lisible par l'humain :

```json
{
  "error": "Invalid request parameters"
}
```

Certains endpoints incluent des champs supplémentaires spécifiques à l'endpoint. Par exemple, les erreurs de modération vidéo peuvent indiquer si les crédits ont été remboursés :

```json
{
  "error": "Your generation was blocked due to the model provider's content policies. Credits have been refunded.",
  "credits_refunded": true
}
```

Les erreurs de validation peuvent inclure des champs `details` et `issues` avec des informations de validation au niveau du champ :

```json
{
  "error": "Invalid request parameters",
  "details": {
    "_errors": [],
    "field": {
      "_errors": ["Field is required"]
    }
  },
  "issues": []
}
```

Certains endpoints compatibles OpenAI peuvent renvoyer des objets d'erreur de style OpenAI pour des cas spécifiques, comme les erreurs de longueur de contexte :

```json
{
  "error": {
    "message": "Your request exceeds the model's maximum context. Please reduce your prompt or completion length.",
    "type": "invalid_request_error",
    "param": "messages",
    "code": "context_length_exceeded"
  }
}
```

## Identifiants manquants

Une requête sans identifiants renvoie `402 Payment Required`, et non `401`. La plupart des routes payantes acceptent également l'[authentification par portefeuille x402](/fr/guides/integrations/x402-venice-api), la réponse est donc une demande de paiement : elle inclut un en-tête `PAYMENT-REQUIRED` et un corps décrivant les deux façons de s'authentifier. Les routes de vidéo et de changement de voix renvoient la même demande, mais n'acceptent actuellement qu'une clé API.

```json
{
  "x402Version": 2,
  "error": "Authentication required",
  "accepts": [ ... ],
  "authOptions": {
    "apiKey": {
      "header": "Authorization: Bearer YOUR_API_KEY",
      "getKey": "https://venice.ai/settings/api"
    },
    "x402Wallet": {
      "header": "SIGN-IN-WITH-X",
      "topUp": "POST /api/v1/x402/top-up"
    }
  }
}
```

Si un `402` sur une route payante vous surprend, il s'agit généralement d'un en-tête d'identifiants manquant plutôt que d'un problème de facturation. Un corps contenant `x402Version` et `accepts` signifie que rien n'a authentifié la requête : définissez `Authorization: Bearer $VENICE_API_KEY` et réessayez. Le champ `authOptions.apiKey.header` du corps indique la forme exacte de l'en-tête.

Un `402` indiquant "Insufficient USD or Diem balance" (`INSUFFICIENT_BALANCE` dans le tableau ci-dessous) est différent : il concerne le solde du compte. Consultez [payer l'utilisation](/pricing#paying-for-usage).

Une clé présente mais invalide renvoie `401`.

## Erreurs de format de requête

Ces erreurs proviennent de la lecture du corps de la requête, avant toute validation propre à l'endpoint.

| Statut HTTP | Message | Cause |
| --- | --- | --- |
| 400 | `'Content-Type' must be 'application/json'` | Un corps `POST`, `PUT` ou `PATCH` envoyé sans `Content-Type: application/json`. Les endpoints qui acceptent des envois de fichiers acceptent aussi `multipart/form-data` |
| 400 | `Invalid JSON request` | Le corps n'est pas du JSON valide |
| 400 | `Invalid multipart request: malformed part header` | Un corps `multipart/form-data` qui ne peut pas être analysé |
| 413 | `Request body exceeds the maximum allowed size.` | Le corps de la requête est trop volumineux |
| 415 | `Request encoding is not supported` | Un `Content-Encoding` ou un jeu de caractères que l'API ne peut pas décoder |

Un mauvais `Content-Type` renvoie `400`, et non `415`. Les réponses `413` liées à la limite de taille incluent aussi un champ `code` :

```json
{
  "code": "PAYLOAD_TOO_LARGE",
  "error": "Request body exceeds the maximum allowed size."
}
```

## Codes d'erreur

Les codes de ce tableau nomment chaque erreur à titre de référence. La plupart des réponses ne les incluent pas : le corps contient uniquement le message dans `error`. Les exceptions sont les réponses `413` et les erreurs de portefeuille x402, qui ajoutent un champ `code`. Basez votre logique sur le statut HTTP et ne comparez pas le texte du message, qui peut varier.

| Code d'erreur | Statut HTTP | Message | Que faire |
| --- | --- | --- | --- |
| `AUTHENTICATION_FAILED` | 401 | Authentication failed | Vérifiez l'en-tête `Authorization: Bearer` et que la clé n'a pas été supprimée ou n'a pas expiré. Les endpoints de gestion du compte et des clés renvoient aussi ce code à une clé Inference ; utilisez-y une clé Admin. |
| `AUTHENTICATION_FAILED_INACTIVE_KEY` | 401 | Authentication failed - Pro subscription is inactive. Please upgrade your subscription to continue using the API | Le compte de la clé ne peut pas utiliser l'API. Connectez-vous sur venice.ai pour vérifier le compte, ou contactez support@venice.ai. |
| `X402_INVALID_SIGN_IN` | 401 | Invalid Sign-in-with-x signature | Signez une nouvelle preuve `SIGN-IN-WITH-X` avec le nonce du dernier challenge `402`. Voir [x402](/fr/guides/integrations/x402-venice-api). |
| `X402_USER_NOT_ALLOWED` | 401 | Wallet user is not allowed to authenticate | Le compte Venice du portefeuille est banni ou supprimé, ou ses crédits appartiennent à un autre utilisateur. Utilisez un autre portefeuille. |
| `PRO_ONLY_MODEL` | 401 | This model is only available to Pro users | Utilisez un modèle inclus dans votre offre, ou passez à une offre payante. |
| `INSUFFICIENT_BALANCE` | 402 | Insufficient USD or Diem balance to complete request. Visit https://venice.ai/settings/api to add credits. | Ajoutez des crédits ou stakez des [DIEM](/fr/overview/vvv-diem), puis réessayez. |
| `API_KEY_DIEM_SPEND_LIMIT_EXCEEDED` | 402 | API key DIEM spend limit exceeded. Your account may still have DIEM balance, but this API key has reached its configured DIEM spending limit. | Augmentez ou supprimez la limite DIEM de la clé, ou attendez la réinitialisation de sa période de limite. |
| `API_KEY_USD_SPEND_LIMIT_EXCEEDED` | 402 | API key USD spend limit exceeded. Your account may still have USD balance, but this API key has reached its configured USD spending limit. | Augmentez ou supprimez la limite USD de la clé, ou attendez la réinitialisation de sa période de limite. |
| `UNAUTHORIZED` | 403 | Unauthorized access | Lisez le message, qui indique ce qui a bloqué la requête, comme votre région. |
| `API_ACCESS_DISABLED` | 403 | API access has been disabled for this account. Please contact support@venice.ai | Contactez support@venice.ai. |
| `X402_WALLET_MISMATCH` | 403 | You can only access resources for your own wallet | Demandez le solde ou les transactions du portefeuille avec lequel vous vous êtes connecté. |
| `INVALID_REQUEST` | 400 | Invalid request parameters | Corrigez les champs indiqués dans `details`, `issues` ou le message. |
| `INVALID_MODEL` | 400 | Invalid model specified | Utilisez un modèle qui prend en charge cet endpoint. `GET /models` liste les capacités de chaque modèle. |
| `REQUEST_ID_NOT_FOUND` | 400 | Request ID is invalid. | Vérifiez que l'ID de file d'attente et le modèle correspondent à une tâche que vous avez mise en file. |
| `INVALID_AUDIO_FORMAT` | 400 | Invalid audio format. Supported formats are WAV and MP3. | Convertissez l'audio dans un format accepté par l'endpoint. |
| `INVALID_VIDEO_FORMAT` | 400 | Invalid video format. Supported formats include MP4, MOV, WebM, MKV, AVI, and others. | Convertissez la vidéo dans un format pris en charge, comme MP4. |
| `CORRUPTED_IMAGE` | 400 | The image file is corrupted or unreadable | Réencodez l'image ou envoyez un autre fichier. |
| `IMAGE_TOO_SMALL` | 400 | Image dimensions are too small | Envoyez une image plus grande. |
| `TOO_MANY_TOKENS` | 400 | Your request exceeds the model's maximum context. Please reduce your prompt or completion length. | Raccourcissez les messages ou baissez `max_tokens`. `GET /models` liste la taille de contexte de chaque modèle. |
| `CHARACTER_NOT_FOUND` | 404 | No character could be found from the provided `character_slug` | Utilisez un slug issu de [`GET /characters`](/fr/api-reference/endpoint/characters/list). |
| `MODEL_NOT_FOUND` | 404 | Specified model not found | Utilisez un ID actuel issu de `GET /models`. Les modèles retirés sont listés dans [Dépréciations](/fr/overview/deprecations). |
| `MEDIA_NOT_FOUND` | 404 | Media could not be found. Request may be invalid, expired, or deleted. | Le résultat a expiré ou a été supprimé. Remettez la tâche en file d'attente. |
| `PAYLOAD_TOO_LARGE` | 413 | The request payload is too large. Please reduce the size of your request. | Envoyez un corps ou un fichier plus petit. |
| `INVALID_CONTENT_TYPE` | 415 | Invalid request content-type. Returned only by `/image/multi-edit` | Envoyez `multipart/form-data` ou `application/json`. |
| `VIDEO_DURATION_TOO_LONG` | 422 | Video duration exceeds the maximum allowed. | Utilisez une durée que le modèle liste dans `GET /models?type=video`. |
| `VIDEO_DURATION_TOO_SHORT` | 422 | Video duration is too short. | Utilisez une durée que le modèle liste dans `GET /models?type=video`. |
| `IMAGE_TOO_LARGE` | 422 | Image dimensions exceed the maximum allowed. | Réduisez la taille de l'image. |
| `CONTENT_POLICY_VIOLATION` | 422 | Your prompt violates the content policy of Venice.ai or the model provider | Modifiez le prompt ou utilisez un autre modèle. Les politiques varient selon le modèle et le fournisseur. |
| `ASR_UPSTREAM_VALIDATION_FAILED` | 422 | The audio could not be processed for transcription. Common causes: zero-length, silent, corrupt, or unsupported-language audio. Please verify the file and retry. | Vérifiez que l'audio n'est ni vide, ni silencieux, ni corrompu, et que sa langue est prise en charge. |
| `RATE_LIMIT_EXCEEDED` | 429 | Rate limit exceeded | Attendez `x-ratelimit-reset-requests`, puis réessayez. Voir [Limites de débit](/fr/api-reference/rate-limiting). |
| `MODEL_OVERLOADED` | 429 | The model is currently overloaded. Please try again later. | Réessayez après le délai de l'en-tête `Retry-After`, ou changez de modèle. |
| `INFERENCE_FAILED` | 500 | Inference processing failed | Réessayez avec un backoff. Les requêtes échouées comptent dans le [budget d'erreurs](/fr/api-reference/rate-limiting#budgets-d’erreurs). |
| `UPSCALE_FAILED` | 500 | Image upscaling failed | Réessayez avec un backoff. |
| `IMAGE_EDIT_ERROR` | 500 | Image edit failed | Réessayez avec un backoff. |
| `UNKNOWN_ERROR` | 500 | An unknown error occurred | Réessayez avec un backoff. Si l'erreur persiste, contactez support@venice.ai. |
| `TEE_ATTESTATION_FAILED` | 502 | TEE attestation request failed. The Trusted Execution Environment provider may be temporarily unavailable. | Réessayez plus tard. |
| `TEE_SIGNATURE_FAILED` | 502 | TEE signature request failed. The Trusted Execution Environment provider may be temporarily unavailable. | Réessayez plus tard. |
| `ASR_UPSTREAM_FAILED` | 502 | Audio transcription failed due to a temporary upstream error. Please retry. | Relancez la requête. |
| `MODEL_OFFLINE` | 503 | The model is temporarily offline. Please try again later. | Réessayez plus tard ou changez de modèle. |
| `MODEL_AT_CAPACITY` | 503 | The model is at capacity. Please try again later. | Réessayez plus tard ou changez de modèle. |
| `REQUEST_TIMEOUT` | 504 | The request took too long to complete and was timed-out. For non-streaming requests, use the streaming API by setting `stream=true`. A streaming chat completion that times out before the model's first chunk reports the failure as an in-band SSE error frame instead. | Définissez `stream: true`, ou envoyez une requête plus courte. |

## Autres erreurs

Le tableau ci-dessus n'est pas exhaustif. Certaines erreurs sont renvoyées sans code répertorié, et les messages peuvent varier selon le modèle et l'endpoint : basez donc votre logique sur le statut HTTP plutôt que sur le texte du message. Erreurs que vous pouvez rencontrer et qui ne figurent pas dans le tableau :

| Statut HTTP | Quand elle se produit |
| --- | --- |
| 400 | Une image en entrée dans une requête de chat ou Responses est dans un format non pris en charge |
| 400 | La voix demandée n'est pas disponible pour le modèle de synthèse vocale |
| 403 | La requête provient d'une adresse IP qui ne figure pas dans la liste d'autorisation de la clé API |
| 403 | Le modèle demandé n'est pas autorisé par le paramètre de confidentialité de la clé API |
| 403 | L'accès au modèle demandé est restreint. Contactez support@venice.ai |
| 409 | Un résultat de vidéo, de musique ou de changement de voix est encore en cours d'envoi lorsque vous le récupérez. Réessayez sous peu |
| 410 | L'endpoint a été retiré |
| 422 | L'audio est trop long ou trop court (clonage de voix, changement de voix et tâches audio) |
| 422 | L'image en entrée d'une requête vidéo a un rapport largeur/hauteur hors de la plage acceptée par le modèle |
| 422 | L'entrée d'une requête vidéo a été bloquée par la modération de contenu |
| 500 | La génération de vidéo ou de changement de voix a échoué |
| 502 | La synthèse vocale a échoué en amont, ou une vidéo générée n'a pas pu être récupérée. Réessayez la requête |
