Lorsqu'une erreur survient, l'API Venice renvoie un code d'état HTTP et un message descriptif. Certaines erreurs incluent également des champs supplémentaires, tels que le statut de remboursement, les modèles de relance suggérés, les détails de validation ou les identifiants de requête.

## Format de la réponse d'erreur

La plupart des erreurs renvoient un champ `error` avec un message lisible par l'humain :

```json
{
  "error": "Invalid request parameters"
}
```

Certains endpoints incluent des champs supplémentaires spécifiques à l'endpoint. Par exemple, les erreurs de modération vidéo peuvent indiquer si les crédits ont été remboursés :

```json
{
  "error": "Your generation was blocked due to the model provider's content policies. Credits have been refunded.",
  "credits_refunded": true
}
```

Les erreurs de validation peuvent inclure des champs `details` et `issues` avec des informations de validation au niveau du champ :

```json
{
  "error": "Invalid request parameters",
  "details": {
    "_errors": [],
    "field": {
      "_errors": ["Field is required"]
    }
  },
  "issues": []
}
```

Certains endpoints compatibles OpenAI peuvent renvoyer des objets d'erreur de style OpenAI pour des cas spécifiques, comme les erreurs de longueur de contexte :

```json
{
  "error": {
    "message": "Your request exceeds the model's maximum context. Please reduce your prompt or completion length.",
    "type": "invalid_request_error",
    "param": "messages",
    "code": "context_length_exceeded"
  }
}
```

## Identifiants manquants

Une requête sans identifiants renvoie `402 Payment Required`, et non `401`. Chaque route payante accepte également l'[authentification par portefeuille x402](/fr/guides/integrations/x402-venice-api), la réponse est donc une demande de paiement : elle inclut un en-tête `PAYMENT-REQUIRED` et un corps décrivant les deux façons de s'authentifier.

```json
{
  "x402Version": 2,
  "error": "Authentication required",
  "accepts": [ ... ],
  "authOptions": {
    "apiKey": {
      "header": "Authorization: Bearer YOUR_API_KEY",
      "getKey": "https://venice.ai/settings/api"
    },
    "x402Wallet": {
      "header": "SIGN-IN-WITH-X",
      "topUp": "POST /api/v1/x402/top-up"
    }
  }
}
```

Si vous vouliez utiliser une clé API, vérifiez que l'en-tête `Authorization: Bearer` est défini. Une clé présente mais invalide renvoie `401`.

## Erreurs de format de requête

Ces erreurs proviennent de la lecture du corps de la requête, avant toute validation propre à l'endpoint.

| Statut HTTP | Message | Cause |
| --- | --- | --- |
| 400 | `'Content-Type' must be 'application/json'` | Un corps `POST`, `PUT` ou `PATCH` envoyé sans `Content-Type: application/json`. Les endpoints qui acceptent des envois de fichiers acceptent aussi `multipart/form-data` |
| 400 | `Invalid JSON request` | Le corps n'est pas du JSON valide |
| 400 | `Invalid multipart request: malformed part header` | Un corps `multipart/form-data` qui ne peut pas être analysé |
| 413 | `Request body exceeds the maximum allowed size.` | Le corps de la requête est trop volumineux |
| 415 | `Request encoding is not supported` | Un `Content-Encoding` ou un jeu de caractères que l'API ne peut pas décoder |

Un mauvais `Content-Type` renvoie `400`, et non `415`. Les réponses `413` liées à la limite de taille incluent aussi un champ `code` :

```json
{
  "code": "PAYLOAD_TOO_LARGE",
  "error": "Request body exceeds the maximum allowed size."
}
```

## Autres erreurs

Le tableau ci-dessus n'est pas exhaustif. Certaines erreurs sont renvoyées sans code répertorié, et les messages peuvent varier selon le modèle et l'endpoint : basez donc votre logique sur le statut HTTP plutôt que sur le texte du message. Erreurs que vous pouvez rencontrer et qui ne figurent pas dans le tableau :

| Statut HTTP | Quand elle se produit |
| --- | --- |
| 400 | Une image en entrée dans une requête de chat ou Responses est dans un format non pris en charge |
| 400 | La voix demandée n'est pas disponible pour le modèle de synthèse vocale |
| 403 | La requête provient d'une adresse IP qui ne figure pas dans la liste d'autorisation de la clé API |
| 403 | Le modèle demandé n'est pas autorisé par le paramètre de confidentialité de la clé API |
| 403 | L'accès au modèle demandé est restreint. Contactez support@venice.ai |
| 409 | Un résultat de vidéo, de musique ou de changement de voix est encore en cours d'envoi lorsque vous le récupérez. Réessayez sous peu |
| 410 | L'endpoint a été retiré |
| 422 | L'audio est trop long ou trop court (clonage de voix, changement de voix et tâches audio) |
| 422 | L'image en entrée d'une requête vidéo a un rapport largeur/hauteur hors de la plage acceptée par le modèle |
| 422 | L'entrée d'une requête vidéo a été bloquée par la modération de contenu |
| 500 | La génération de vidéo ou de changement de voix a échoué |
| 502 | La synthèse vocale a échoué en amont, ou une vidéo générée n'a pas pu être récupérée. Réessayez la requête |
