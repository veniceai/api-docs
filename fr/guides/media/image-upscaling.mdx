L'agrandissement d'image améliore la résolution et la qualité visuelle d'une image existante. Envoyez une image à `/image/upscale`, choisissez un facteur d'échelle et un niveau de créativité facultatif, et Venice retourne l'image améliorée sous forme de données binaires.

Utilisez l'agrandissement d'image lorsque vous disposez déjà d'une image et souhaitez obtenir une sortie de plus haute résolution. Utilisez la [génération d'image](/fr/guides/media/image-generation) lorsque vous devez créer une image à partir d'une invite, et l'[édition d'image](/fr/guides/media/image-editing) lorsque vous devez modifier le contenu de l'image.

## Utilisation de base

<CodeGroup>
```python Python
import base64
import os
from pathlib import Path

import requests

image_base64 = base64.b64encode(Path("input.jpg").read_bytes()).decode("utf-8")

response = requests.post(
    "https://api.venice.ai/api/v1/image/upscale",
    headers={
        "Authorization": f"Bearer {os.environ['VENICE_API_KEY']}",
        "Content-Type": "application/json",
    },
    json={
        "image": image_base64,
        "scale": 2,
        "creativity": 0.01,
    },
)

response.raise_for_status()
Path("upscaled.png").write_bytes(response.content)
```

```javascript Node.js
import { readFile, writeFile } from "node:fs/promises";

const image = await readFile("input.jpg");

const response = await fetch("https://api.venice.ai/api/v1/image/upscale", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.VENICE_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    image: image.toString("base64"),
    scale: 2,
    creativity: 0.01,
  }),
});

if (!response.ok) {
  throw new Error(await response.text());
}

const output = Buffer.from(await response.arrayBuffer());
await writeFile("upscaled.png", output);
```

```bash cURL
IMAGE_BASE64=$(base64 < input.jpg | tr -d '\n')

curl https://api.venice.ai/api/v1/image/upscale \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d "{
    \"image\": \"$IMAGE_BASE64\",
    \"scale\": 2,
    \"creativity\": 0.01
  }" \
  --output upscaled.png
```
</CodeGroup>

Vous pouvez aussi téléverser directement un fichier avec `multipart/form-data` au lieu de l'encoder en base64 :

```bash cURL (multipart)
curl https://api.venice.ai/api/v1/image/upscale \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -F "image=@input.jpg" \
  -F "scale=2" \
  -F "creativity=0.01" \
  --output upscaled.png
```

Envoyez exactement une partie `image` par requête. Les fichiers téléversés doivent faire moins de 25 Mo.

## Paramètres

| Paramètre | Type | Requis | Description |
|-----------|------|--------|-------------|
| `image` | string ou fichier | Oui | Image source. Envoyez-la en base64 dans le JSON, ou téléversez une partie fichier avec `multipart/form-data`. Elle doit faire au moins 256×256 pixels. Les fichiers téléversés doivent faire 25 Mo ou moins ; les corps JSON sont limités à 35 Mo. |
| `scale` | number | Non | Facteur d'agrandissement entre `2` et `4`. La valeur par défaut est `2` ; utilisez `2` ou `4` (les valeurs intermédiaires sont acceptées et facturées au tarif 4x). La sortie est plafonnée à 16 777 216 pixels (4096×4096) : si l'échelle demandée dépasse ce plafond, le serveur réduit automatiquement l'échelle effective. Les entrées déjà au plafond ou proches de celui-ci sont rejetées avec `400`. Réduisez-les donc d'abord. |
| `creativity` | number | Non | Quantité de détails et de texture ajoutée par l'upscaler. `0`–`0.02`, `0.01` par défaut. Des valeurs plus élevées en ajoutent davantage ; des valeurs plus faibles restent plus proches de la source. Les valeurs hors plage sont ramenées à la borne la plus proche. |

<Note>
La réponse est constituée de données d'image binaires, et non de JSON. Écrivez le corps de la réponse directement dans un fichier ou envoyez-le en flux vers le stockage.
</Note>

## Conseils sur l'entrée

- Commencez avec l'image source la plus nette dont vous disposez. L'agrandissement améliore les détails, mais ne peut pas récupérer entièrement les informations absentes.
- Utilisez des facteurs d'échelle modérés pour les flux de production. Des sorties très grandes peuvent augmenter la latence et la taille des fichiers.
- Conservez l'image originale si vous devez comparer la qualité ou réessayer avec d'autres paramètres.
