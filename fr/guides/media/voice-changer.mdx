Voice Changer fait du speech-to-speech. Vous lui fournissez un enregistrement, vous choisissez une voix, et vous récupérez la même interprétation dans cette voix : mêmes mots, mêmes pauses, mêmes accentuations, même durée. Il est fait pour les cas où vous avez déjà une prise que vous souhaitez conserver. Si vous n'avez que du texte, utilisez le [text-to-speech](/fr/guides/media/text-to-speech) ; si vous voulez que votre propre voix soit disponible comme cible, consultez le [clonage vocal](/fr/guides/media/voice-cloning).

La conversion s'exécute de manière asynchrone via quatre endpoints sous `/audio/voice-changer/` : [quote](/fr/api-reference/endpoint/audio/voice-changer/quote) chiffre une durée, [queue](/fr/api-reference/endpoint/audio/voice-changer/queue) soumet l'enregistrement et vous facture, [retrieve](/fr/api-reference/endpoint/audio/voice-changer/retrieve) est interrogé en boucle jusqu'à ce que le MP3 soit prêt, et [complete](/fr/api-reference/endpoint/audio/voice-changer/complete) supprime les médias stockés une fois que vous les avez récupérés. Le fonctionnement est le même que pour les endpoints de musique, mais le chemin est différent et les deux n'acceptent pas les modèles l'un de l'autre.

Les exemples supposent que `VENICE_API_KEY` est définie :

```bash
export VENICE_API_KEY="your-api-key"
```

## Choisir un modèle

Les modèles de changeur de voix se trouvent sous `GET /models?type=music` avec `model_spec.voice_changer` défini sur `true` ; il n'existe pas de filtre de type dédié. Il n'y en a actuellement qu'un seul, `elevenlabs-voice-changer` : il accepte des sources `mp3`, `wav`, `ogg`, `mp4` ou `aac` jusqu'à 300 secondes, propose 20 voix nommées avec `Aria` par défaut, accepte un Voice ID ElevenLabs brut à la place d'un nom, et prend en charge `remove_background_noise` et `seed`. Ces détails peuvent évoluer : lisez-les donc depuis l'API. Cette requête renvoie tout ce dont dépend la suite du guide :

```bash
curl "https://api.venice.ai/api/v1/models?type=music" \
  -H "Authorization: Bearer $VENICE_API_KEY" |
  jq '.data[] | select(.model_spec.voice_changer == true) | {
    id,
    voices: .model_spec.voices,
    default_voice: .model_spec.default_voice,
    supports_custom_voice_id: .model_spec.supports_custom_voice_id,
    accepted_audio_formats: .model_spec.accepted_audio_formats,
    max_source_audio_duration_seconds: .model_spec.max_source_audio_duration_seconds,
    supports_background_noise_removal: .model_spec.supports_background_noise_removal,
    supports_seed: .model_spec.supports_seed,
    durations: .model_spec.pricing.durations
  }'
```

Envoyer un champ que le modèle ne prend pas en charge renvoie une erreur `400`. Un enregistrement plus long que `max_source_audio_duration_seconds` renvoie une erreur `422` avant toute facturation, avec la limite indiquée dans le message.

Il y a une chose que l'API ne vérifie pas au moment de la mise en file d'attente : le nom de la voix. Si vous mettez en file d'attente une `voice` que le modèle ne possède pas, vous obtenez quand même un `200` et un `queue_id` ; le rejet arrive au premier appel à retrieve, avec le remboursement de la facturation. Vous récupérez votre argent, mais vous perdez un aller-retour : vérifiez donc `voices` avant la mise en file d'attente.

## 1. Obtenir un devis

La facturation se base sur la durée de l'enregistrement source, arrondie à la minute entière supérieure. Pour `elevenlabs-voice-changer`, cela représente 0,35 $ jusqu'à 60 secondes, 0,69 $ jusqu'à 120, 1,04 $ jusqu'à 180, 1,38 $ jusqu'à 240 et 1,73 $ jusqu'à 300. Un extrait de 7 secondes coûte autant qu'un extrait de 60 secondes, et 60,5 secondes sont facturées comme deux minutes. Si vous avez de nombreux segments courts, regroupez-les dans un seul fichier qui reste sous une limite de minute plutôt que de mettre chacun en file d'attente séparément. Les paliers proviennent de `pricing.durations` dans `/models`.

Quote accepte un nombre entier de secondes et ne nécessite pas de clé API :

```bash
curl https://api.venice.ai/api/v1/audio/voice-changer/quote \
  -H "Content-Type: application/json" \
  -d '{
    "model": "elevenlabs-voice-changer",
    "duration_seconds": 60
  }'
```

```json
{
  "quote": 0.35,
  "duration_seconds": 60
}
```

Il s'agit d'une estimation. Le montant facturé est calculé à partir de la durée mesurée par Venice lors de la mise en file d'attente de l'enregistrement.

## 2. Mettre la conversion en file d'attente

Envoyez l'enregistrement soit sous forme de téléversement multipart `file`, soit sous forme d'`audio_url` dans un corps JSON, mais pas les deux. Une URL doit être accessible publiquement sans en-têtes ni cookies ; Venice récupère lui-même les octets et ne transmet jamais l'URL au fournisseur. Venice vérifie les octets, pas l'extension : un fichier doit donc réellement correspondre à l'un des conteneurs acceptés, et les fichiers contenant une piste vidéo sont rejetés.

Avec `curl -F`, ne touchez pas à `Content-Type` afin que curl puisse définir la boundary multipart, et envoyez `remove_background_noise` sous la forme `true`/`false` et `seed` sous forme de chiffres.

<CodeGroup>
```bash File upload
curl https://api.venice.ai/api/v1/audio/voice-changer/queue \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -F "model=elevenlabs-voice-changer" \
  -F "voice=George" \
  -F "file=@./source-recording.mp3"
```

```bash Audio URL
curl https://api.venice.ai/api/v1/audio/voice-changer/queue \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "elevenlabs-voice-changer",
    "voice": "George",
    "audio_url": "https://example.com/source-recording.mp3",
    "remove_background_noise": true,
    "seed": 42
  }'
```
</CodeGroup>

La requête multipart ci-dessus est celle qui a produit l'extrait George en haut de la page. Omettez `voice` pour obtenir `default_voice`. Lorsque `supports_custom_voice_id` vaut true, `voice` peut également être un Voice ID de fournisseur ; pour `elevenlabs-voice-changer`, cela signifie n'importe quelle voix ElevenLabs à laquelle vous avez accès, y compris des voix de la bibliothèque qui ne figurent pas dans la liste `voices` de Venice. `remove_background_noise` et `seed` ne sont acceptés que lorsque le modèle indique les prendre en charge.

La réponse vous fournit l'identifiant nécessaire pour toutes les étapes suivantes :

```json
{
  "duration_seconds": 7.008,
  "model": "elevenlabs-voice-changer",
  "queue_id": "01a164db-8652-7fa9-94d6-25754090bd64",
  "status": "QUEUED"
}
```

`duration_seconds` correspond à la durée mesurée par Venice, et au palier sur lequel vous avez été facturé. Si votre devis portait sur 60 et que cette valeur indique 61,2, vous avez payé deux minutes. Conservez `model` et `queue_id` ; retrieve et complete en ont tous deux besoin, et l'ID reste valable 24 heures.

Vous êtes facturé à ce moment-là, et non au retour de l'audio : ne réessayez donc pas une requête queue. Si vous disposez d'un `queue_id`, interrogez retrieve avec celui-ci. Si la réponse n'est jamais arrivée, renvoyer l'enregistrement peut entraîner une double facturation. Queue est limité à 40 requêtes par minute et retrieve à 120 ; les deux renvoient `x-ratelimit-remaining-requests`.

## 3. Interroger et télécharger

Appelez retrieve avec les valeurs de la réponse de queue :

```bash
curl https://api.venice.ai/api/v1/audio/voice-changer/retrieve \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "elevenlabs-voice-changer",
    "queue_id": "0190f2c4-9c1e-7a3b-8f42-2c9d5e7a1b34"
  }' \
  --output response.bin
```

La réponse peut prendre deux formes. Tant que le travail est en cours, vous recevez du JSON :

```json
{
  "status": "PROCESSING",
  "average_execution_time": 10000,
  "execution_duration": 4200
}
```

Une fois le travail terminé, vous recevez `audio/mpeg` et le corps contient le MP3. Aiguillez votre traitement selon le `Content-Type`.

Les deux valeurs sont en millisecondes : la durée habituelle des travaux sur ce modèle, et la durée depuis laquelle le vôtre est en cours. L'écart entre les deux constitue un premier délai d'attente raisonnable, mais la moyenne n'est qu'une indication. Une source de 148 secondes a pris 24 secondes pour une moyenne de 7 : sur des entrées plus longues, `execution_duration` finira donc par dépasser `average_execution_time`. Dans ce cas, revenez à un intervalle fixe de quelques secondes et continuez. Les extraits courts vont dans l'autre sens : l'exemple de 7 secondes est revenu dès la toute première interrogation.

La réponse finale contient `x-venice-audio-duration` (secondes), `x-venice-inference-time`, `x-venice-audio-format`, `x-venice-model-id` et `x-venice-model-name`. La sortie est toujours un MP3 mono à 128 kbit/s et 44,1 kHz, quel que soit le format envoyé. La durée de l'audio doit correspondre à celle de votre source à quelques millisecondes près ; si l'écart est plus important, écoutez le résultat avant de le publier.

### En cas d'échec

Un travail accepté par le fournisseur puis en échec renvoie un statut d'erreur avec `error` et `credits_refunded` dans le corps. `true` signifie que la facturation a été annulée. `false` avec un message se terminant par « please contact support » signifie que le remboursement lui-même a échoué et que la prochaine interrogation réessaiera. Le verdict est enregistré : interroger à nouveau le rejoue.

Un travail qui n'a jamais atteint le fournisseur se présente différemment. Retrieve continue d'indiquer `PROCESSING` pendant jusqu'à 10 minutes, puis renvoie une erreur `504` et vous rembourse : accordez donc au moins ce délai à un travail `PROCESSING` avant de le considérer comme bloqué. L'ensemble des résultats finaux est décrit dans la [référence de retrieve](/fr/api-reference/endpoint/audio/voice-changer/retrieve).

### Nettoyage

Transmettez `delete_media_on_completion: true` à retrieve et les médias stockés sont supprimés dans le même appel qui vous renvoie l'audio. Tout appel ultérieur à retrieve pour cet ID renvoie une erreur `404`. Si vous souhaitez télécharger le fichier plusieurs fois, omettez ce paramètre et appelez [complete](/fr/api-reference/endpoint/audio/voice-changer/complete) lorsque vous avez terminé. Complete renvoie `{"success": true}` et peut être appelé plusieurs fois sans risque.

## Exemple complet

Tout ce qui précède, de bout en bout : vérifier que la voix existe, obtenir un devis, téléverser, interroger jusqu'à l'arrivée de l'audio, l'enregistrer. Le délai maximal est de 12 minutes afin qu'un échec de transmission se traduise par un remboursement plutôt que par un dépassement de délai.

```python
import os
import time
from pathlib import Path

import requests

BASE_URL = "https://api.venice.ai/api/v1"
HEADERS = {"Authorization": f"Bearer {os.environ['VENICE_API_KEY']}"}
MODEL = "elevenlabs-voice-changer"
VOICE = "George"
# Length you expect to send, in whole seconds. The charge uses the length Venice measures.
EXPECTED_DURATION_SECONDS = 60

source = Path("source-recording.mp3")

# Voice names are not validated at queue time, so check before paying for a round trip.
models = requests.get(f"{BASE_URL}/models", params={"type": "music"}, headers=HEADERS)
models.raise_for_status()
spec = next(m["model_spec"] for m in models.json()["data"] if m["id"] == MODEL)
if VOICE not in spec["voices"] and not spec.get("supports_custom_voice_id"):
    raise SystemExit(f"{VOICE!r} is not a voice on {MODEL}: {spec['voices']}")

quote = requests.post(
    f"{BASE_URL}/audio/voice-changer/quote",
    json={"model": MODEL, "duration_seconds": EXPECTED_DURATION_SECONDS},
)
quote.raise_for_status()
print(f"Estimated cost: ${quote.json()['quote']:.2f}")

with source.open("rb") as audio:
    queued = requests.post(
        f"{BASE_URL}/audio/voice-changer/queue",
        headers=HEADERS,
        data={"model": MODEL, "voice": VOICE},
        files={"file": audio},
    )
queued.raise_for_status()
job = queued.json()
print(f"Queued {job['queue_id']} ({job['duration_seconds']:.1f}s billed)")

deadline = time.monotonic() + 12 * 60
while time.monotonic() < deadline:
    result = requests.post(
        f"{BASE_URL}/audio/voice-changer/retrieve",
        headers=HEADERS,
        json={
            "model": job["model"],
            "queue_id": job["queue_id"],
            "delete_media_on_completion": True,
        },
    )

    content_type = result.headers.get("Content-Type", "").split(";")[0].strip()
    if content_type == "audio/mpeg":
        output = Path("converted-audio.mp3")
        output.write_bytes(result.content)
        print(f"Saved {output} ({result.headers.get('x-venice-audio-duration')}s)")
        break

    body = result.json()
    if not result.ok:
        # Terminal failure. credits_refunded tells you whether the charge came back.
        print(f"{result.status_code}: {body.get('error')}")
        print(f"credits_refunded: {body.get('credits_refunded')}")
        raise SystemExit(1)

    if body.get("status") != "PROCESSING":
        print(body)
        raise SystemExit(1)

    # The average is a hint. On long inputs execution_duration overtakes it; fall back to a fixed interval.
    remaining_ms = body["average_execution_time"] - body["execution_duration"]
    time.sleep(5 if remaining_ms <= 0 else min(remaining_ms / 1000, 15))
else:
    raise SystemExit(
        f"Still processing after 12 minutes. Poll retrieve again with queue_id={job['queue_id']}."
    )
```

Il n'y a pas d'appel à complete, car retrieve supprime les médias au passage. Retirez `delete_media_on_completion` et appelez complete vous-même si vous avez besoin du fichier plusieurs fois.

## Paramètres de l'API

### Queue

| Champ | Type | Requis | Description |
|---|---|---|---|
| `model` | string | Oui | ID du modèle de changeur de voix. |
| `file` | file | L'un de `file` ou `audio_url` | Téléversement multipart de l'enregistrement source. Incompatible avec `audio_url`. |
| `audio_url` | string | L'un de `file` ou `audio_url` | URL publique `http` ou `https` de l'enregistrement source, dans un corps JSON. Incompatible avec `file`. |
| `voice` | string | Non | Un nom issu de `voices`, ou un Voice ID de fournisseur lorsque `supports_custom_voice_id` vaut true. Par défaut, `default_voice`. |
| `remove_background_noise` | boolean | Non | Supprime le bruit de fond avant la conversion. À envoyer uniquement lorsque le modèle indique le prendre en charge. En multipart, accepte `true` ou `false`. |
| `seed` | integer | Non | Entier ≥ 0, pour un résultat reproductible. À envoyer uniquement lorsque le modèle indique le prendre en charge. |

### Retrieve et complete

| Champ | Type | Requis | Défaut | Description |
|---|---|---|---|---|
| `model` | string | Oui | - | `model` issu de la réponse de queue. |
| `queue_id` | string | Oui | - | `queue_id` issu de la réponse de queue. |
| `delete_media_on_completion` | boolean | Non | `false` | Sur retrieve, supprime les médias stockés lorsque cet appel renvoie l'audio. |

## Erreurs

| Statut | Endpoint | Corps | Solution |
|---|---|---|---|
| `400` | queue | ``Provide exactly one source recording: the multipart `file` field or `audio_url`.`` | Envoyez `file` ou `audio_url`, pas les deux, ni aucun des deux. |
| `400` | queue | `Source audio must be one of: MP3, WAV, OGG, MP4, AAC.` | Les octets ne correspondent pas à un conteneur pris en charge. Renommer le fichier n'y change rien. |
| `400` | queue | `Upstream returned 404 Not Found` | L'hôte de `audio_url` a renvoyé une erreur. Vérifiez que l'URL est publique et ne nécessite pas d'en-têtes. |
| `400` | retrieve | `The requested voice is not available. Check the Voice ID and try again.` avec `credits_refunded: true` | La `voice` mise en file d'attente n'existe pas. La facturation est remboursée. Vérifiez `voices` avant la mise en file d'attente. |
| `400` | retrieve, complete | `Request ID is invalid.` | ID inconnu, mal formé, appartenant à un autre compte ou datant de plus de 24 heures. Utilisez le `queue_id` de votre propre réponse de queue. |
| `401` | tous | Clé API invalide | Vérifiez la clé sur [venice.ai/settings/api](https://venice.ai/settings/api). |
| `402` | queue, retrieve, complete | `Authentication required` accompagné d'une offre de paiement x402 | Aucun en-tête `Authorization` n'a été envoyé. |
| `402` | queue | Solde insuffisant | Rechargez votre solde Venice. |
| `404` | queue, quote | `Specified model not found: ...` | L'ID du modèle est incorrect. Le corps suggère des correspondances proches. |
| `404` | retrieve | `Media could not be found. Request may be invalid, expired, or deleted.` | Les médias ont déjà été supprimés par complete ou par `delete_media_on_completion`. Rien à rembourser. |
| `413` | queue | Fichier de plus de 25 Mo | Utilisez un fichier plus petit. Rejeté avant toute facturation. |
| `422` | queue | `Source audio must be at most N seconds.` | Raccourcissez l'enregistrement. Rejeté avant toute facturation. |
| `429` | tous | Limite de débit dépassée | Queue autorise 40/min, retrieve 120/min. Patientez puis réessayez. |
| `503` | queue | Modèle à pleine capacité | Réessayez plus tard. |
| `504` | retrieve | `The conversion was never accepted by the provider and can no longer complete.` avec `credits_refunded` | Le travail est resté orphelin lors de la transmission. La facturation est remboursée. Remettez-le en file d'attente. |
