[Kilo Code](https://kilo.ai/) est un agent de codage IA open source pour VS Code et le terminal. Venice est disponible en tant que **fournisseur natif**, ce qui vous permet de sélectionner des modèles Venice sans configurer un endpoint personnalisé compatible OpenAI.

## Prérequis

- Une clé API Venice depuis [venice.ai/settings/api](https://venice.ai/settings/api)
- [Kilo Code pour VS Code](https://marketplace.visualstudio.com/items?itemName=kilocode.Kilo-Code) et/ou le [CLI Kilo](https://kilo.ai/docs/code-with-ai/platforms/cli)

---

## Configuration

<Tabs>
  <Tab title="VS Code">
    <Steps>
      <Step title="Installer Kilo Code">
        Dans VS Code, ouvrez **Extensions**, recherchez **Kilo Code** et installez-le depuis le [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=kilocode.Kilo-Code).

        Préférez le canal **Pre-Release** du Marketplace lorsqu'il correspond à la version actuellement recommandée — voir la [documentation d'installation de Kilo](https://kilo.ai/docs/getting-started/installing).
      </Step>

      <Step title="Obtenir votre clé API Venice">
        Générez une clé depuis [venice.ai/settings/api](https://venice.ai/settings/api). Copiez-la immédiatement et stockez-la de manière sécurisée.
      </Step>

      <Step title="Ajouter le fournisseur Venice">
        Ouvrez les **Paramètres** de Kilo (icône d'engrenage) et allez dans l'onglet **Providers**. Sélectionnez **Venice AI** et collez votre clé API Venice.

        L'extension enregistre le fournisseur dans votre configuration `kilo.json`. Vous pouvez aussi éditer ce fichier directement — voir l'onglet **CLI** pour le format.
      </Step>

      <Step title="Sélectionner un modèle et tester">
        Choisissez un modèle Venice dans le sélecteur de modèles, puis envoyez une petite tâche telle que :

        ```txt
        Review the current file and suggest one safe improvement.
        ```

        Parcourez les ID disponibles dans le [catalogue de modèles de texte](/models/text).
      </Step>
    </Steps>
  </Tab>

  <Tab title="CLI">
    <Steps>
      <Step title="Installer le CLI Kilo">
        ```bash
        npm install -g @kilocode/cli
        kilo --version
        ```

        Consultez la [documentation du CLI Kilo](https://kilo.ai/docs/code-with-ai/platforms/cli) pour les autres options d'installation.
      </Step>

      <Step title="Définir votre clé API Venice">
        Exportez la clé dans le shell où vous exécutez Kilo :

        ```bash
        export VENICE_API_KEY="your-api-key"
        ```
      </Step>

      <Step title="Configurer le fournisseur Venice">
        Créez ou éditez `~/.config/kilo/kilo.json` (global) ou `./kilo.json` (projet) :

        ```json
        {
          "provider": {
            "venice": {
              "env": ["VENICE_API_KEY"]
            }
          },
          "model": "venice/zai-org-glm-5-1"
        }
        ```

        Remplacez `zai-org-glm-5-1` par n'importe quel ID de modèle du [catalogue de modèles de texte](/models/text). Les références de modèles Kilo utilisent le format `venice/<model-id>`.
      </Step>

      <Step title="Démarrer Kilo">
        Depuis le répertoire de votre projet :

        ```bash
        kilo
        ```

        Sélectionnez un modèle Venice dans le sélecteur de modèles si vous n'avez pas défini de `model` par défaut, puis envoyez un court prompt de test.
      </Step>
    </Steps>
  </Tab>
</Tabs>

## Vérifier l'API Venice

Si Kilo ne parvient pas à se connecter, vérifiez indépendamment la clé et les ID de modèles :

```bash
curl https://api.venice.ai/api/v1/models \
  -H "Authorization: Bearer $VENICE_API_KEY"
```

Copiez le `id` d'un modèle exactement dans Kilo. Dans la configuration CLI, préfixez-le par `venice/`, par exemple `venice/zai-org-glm-5-1`.

---

## Notes de configuration

- Venice est un fournisseur **natif** de Kilo. Préférez **Venice AI** dans les paramètres Providers plutôt qu'un endpoint personnalisé générique compatible OpenAI.
- L'extension et le CLI partagent les mêmes fichiers de configuration (`~/.config/kilo/kilo.json` globalement, ou `./kilo.json` dans un projet).
- Certains modèles Venice exposent des contrôles de raisonnement. Kilo mappe les options prises en charge d'effort de raisonnement et de désactivation de la réflexion lorsque le modèle sélectionné les prend en charge.
- Les ID de modèles et l'accès selon le plan peuvent évoluer. Utilisez le sélecteur de modèles, le [catalogue de modèles de texte](/models/text) ou `GET /models` pour obtenir la liste actuelle.
- Gardez votre clé API Venice privée. Ne la collez pas dans des fichiers source et ne la committez pas dans git.

## Dépannage

<AccordionGroup>
  <Accordion title="Clé API invalide ou 401">
    Vérifiez que la clé provient de [venice.ai/settings/api](https://venice.ai/settings/api). Pour le CLI, vérifiez que `VENICE_API_KEY` est définie dans le même environnement que celui qui lance Kilo. Dans VS Code, reconnectez Venice AI sous **Providers**.
  </Accordion>
  <Accordion title="Modèle non disponible">
    Vérifiez que votre compte Venice a accès au modèle sélectionné, copiez l'ID depuis le [catalogue de modèles de texte](/models/text) ou `GET /models`, et pour la configuration CLI utilisez la forme `venice/<model-id>`.
  </Accordion>
  <Accordion title="Paramètres du fournisseur introuvables dans l'extension">
    Mettez à jour vers la version actuellement recommandée de Kilo (y compris Pre-Release lorsque c'est la valeur par défaut documentée). Vous pouvez aussi définir le fournisseur dans `kilo.json` comme indiqué dans l'onglet CLI — l'extension lit la même configuration.
  </Accordion>
</AccordionGroup>
