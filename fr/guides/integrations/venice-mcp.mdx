Le [serveur Venice MCP](https://github.com/veniceai/venice-mcp-server) est le serveur officiel [Model Context Protocol](https://modelcontextprotocol.io/) pour Venice. Il expose l'API Venice (chat, image, vidéo, audio, musique, embeddings, web augment, personnages, RPC crypto et attestation TEE) ainsi que les opérations de compte (facturation et clés API) sous la forme de **45 outils** que tout agent compatible MCP peut appeler.

## Démarrage rapide

<Steps>
  <Step title="Obtenez une clé API Venice">
    Générez-en une depuis [venice.ai/settings/api](https://venice.ai/settings/api?utm_source=venice-api-documentation). Consultez le [guide des clés API](/fr/guides/getting-started/generating-api-key) pour des instructions détaillées.
  </Step>

  <Step title="Ajoutez Venice à la configuration de votre hôte MCP">
    Insérez ceci dans le fichier de configuration de votre hôte MCP :

    ```json
    {
      "mcpServers": {
        "venice": {
          "command": "npx",
          "args": ["-y", "@veniceai/mcp-server@0.3.0"],
          "env": { "VENICE_API_KEY": "<your-venice-api-key>" }
        }
      }
    }
    ```

    Chemins de configuration courants :

    | Hôte | Chemin |
    |---|---|
    | Claude Desktop (macOS) | `~/Library/Application Support/Claude/claude_desktop_config.json` |
    | Claude Desktop (Windows) | `%APPDATA%\Claude\claude_desktop_config.json` |
    | Cursor | `~/.cursor/mcp.json` |
    | LM Studio | `mcp.json` (depuis les paramètres MCP de l'application) |
  </Step>

  <Step title="Redémarrez votre hôte MCP">
    Votre agent dispose désormais des outils chat, image, vidéo, musique, TTS, ASR, et de 39 autres outils Venice.
  </Step>
</Steps>

<Note>
La plupart des hôtes MCP ne transmettent que les variables d'environnement **explicitement listées** dans le bloc `env`. Les variables d'environnement système ne sont pas héritées. Si vous voyez des erreurs 402 alors qu'une clé API est définie, vérifiez que `VENICE_API_KEY` se trouve bien dans `env` dans votre configuration.
</Note>

## Ce que vous obtenez

**45 outils** couvrant chaque modalité Venice ainsi que les opérations de compte, **3 ressources** (`venice://models`, `venice://styles`, `venice://voices`) et **3 modèles de prompts** (recherche non censurée, écriture créative NSFW, exploration de styles d'image).

Chaque outil déclare explicitement les annotations `readOnlyHint`, `destructiveHint`, `idempotentHint` et `openWorldHint`, afin que les hôtes puissent exécuter les consultations sans demander d'autorisation et demander une confirmation avant toute action destructive, comme le nettoyage de médias ou un relais crypto.

### Chat et embeddings

| Outil | Description |
|---|---|
| `venice_chat` | Chat completion compatible OpenAI sur l'ensemble du catalogue LLM de Venice, avec des blocs texte/image/audio/vidéo/fichier, des sorties structurées, des outils de fonction, la mise en cache des prompts et des contrôles de raisonnement. Les appels sont en clair et sans streaming. |
| `venice_responses` | [API Responses](/fr/guides/features/responses-api) compatible OpenAI, en bêta et sans état, avec entrée texte/image et contrôles de raisonnement. Cet outil n'expose pas les champs d'appel d'outils, et les modèles E2EE ne sont pas pris en charge. |
| `venice_embeddings` | Calcule les embeddings pour un texte d'entrée. |
| `venice_chat_with_character` | Discutez avec un personnage Venice via son slug. |

### Image

| Outil | Description |
|---|---|
| `venice_image_generate` | Générez une image (Flux 2, Lustify SDXL, Anime/WAI, Qwen Image, GPT Image, Nano Banana Pro, et plus), avec un ratio d'aspect ou une largeur/hauteur, des niveaux de qualité, l'amélioration du prompt, des références de style, la recherche web et des variantes. |
| `venice_image_edit` | Modifiez une image à partir d'un prompt. |
| `venice_image_multi_edit` | Modifiez jusqu'à 8 images ensemble avec un même prompt (composition / outpainting). |
| `venice_image_upscale` | Mettez à l'échelle une image de 2 à 4×, avec un contrôle `creativity`. |
| `venice_image_remove_bg` | Supprimez l'arrière-plan d'une image. |
| `venice_image_styles` | Listez les presets de style d'image. |

### Vidéo

| Outil | Description |
|---|---|
| `venice_video_generate` | Mettez en file d'attente une génération vidéo (Sora 2, Veo 3.1, Kling, Wan, LTX 2, Seedance, Runway Gen-4, et plus) avec des entrées image, vidéo, audio, de référence et d'éléments. |
| `venice_video_status` | Vérifiez l'état d'une tâche vidéo en file d'attente (`POST /video/retrieve`). |
| `venice_video_complete` | Marquez une vidéo terminée comme téléchargée et supprimez son média côté serveur. La suppression n'est signalée que lorsque Venice la confirme. |
| `venice_video_quote` | Obtenez un devis avant la mise en file d'attente. |

### Audio (TTS / ASR)

| Outil | Description |
|---|---|
| `venice_tts` | Synthèse vocale avec voix clonées, température et balises d'émotion. Le streaming est mis en mémoire tampon dans un seul résultat audio complet. |
| `venice_asr` | Transcrivez de l'audio depuis une URL, avec des horodatages facultatifs par mot ou par caractère. Les transcriptions volumineuses sont paginées via un handle de session. |
| `venice_voice_clone` | Listez les voix disponibles en direct pour un modèle, ou clonez une voix à partir d'une URL d'échantillon (renvoie un handle `vv_<id>` pour `venice_tts`). |
| `venice_audio_quote` | Obtenez un devis pour la génération musicale. |

### Musique

| Outil | Description |
|---|---|
| `venice_music_generate` | Mettez en file d'attente une génération musicale (`ace-step-15`, `elevenlabs-music`, `minimax-music-v2/v25/v26`, `stable-audio-25`, `mmaudio-v2-text-to-audio`, `elevenlabs-sound-effects-v2`) avec des contrôles de paroles, instrumental, boucle, voix, langue, vitesse et durée. |
| `venice_music_status` | Vérifiez l'état d'une tâche musicale en file d'attente. |
| `venice_music_complete` | Marquez une tâche musicale terminée comme téléchargée. |

### Web augment

| Outil | Description |
|---|---|
| `venice_web_search` | Recherchez sur le web avec Brave (par défaut, Zero Data Retention) ou Google (via un proxy et anonymisé par Venice). |
| `venice_web_scrape` | Scrapez une URL en markdown. |
| `venice_text_parser` | Extrayez le texte de PDF/DOCX/EPUB/PPTX/XLSX. |

### Catalogue et personnages

| Outil | Description |
|---|---|
| `venice_list_models` | Parcourez page par page le catalogue de modèles en direct de tous types, avec des résumés compacts, les prix et les indicateurs de capacités. |
| `venice_model_details` | Obtenez la fiche complète d'un modèle précis : contraintes `model_spec`, capacités et tarification. |
| `venice_model_traits` | Associez des noms de traits (`default`, `most_uncensored`, …) aux identifiants de modèles actuels. |
| `venice_model_compatibility_mapping` | Associez des noms de modèles compatibles aux identifiants de modèles Venice. |
| `venice_list_characters` | Listez les personnages Venice publics avec des filtres de recherche, de tag, de modèle et de tri. **Clé API uniquement.** |
| `venice_get_character` | Obtenez un personnage public via son slug. **Clé API uniquement.** |
| `venice_character_reviews` | Listez les avis publics paginés d'un personnage. **Clé API uniquement.** |

### Attestation TEE

| Outil | Description |
|---|---|
| `venice_tee_attestation` | Récupérez les preuves d'attestation matérielle (quote Intel TDX, preuves NVIDIA facultatives, clé de signature) pour un modèle de texte compatible TEE, en utilisant votre propre nonce de 32 octets. |
| `venice_tee_signature` | Récupérez la signature de l'enclave pour l'identifiant d'une requête de chat TEE terminée. |

<Warning>
Les deux outils TEE renvoient uniquement les preuves du fournisseur : ils ne les vérifient pas et ne chiffrent pas le chat. Vérifiez vous-même le nonce renvoyé, l'état du mode debug et la liaison de la clé de signature avant de faire confiance à un modèle TEE ; consultez [Vérifier l'attestation TEE](/fr/guides/features/tee-e2ee-models#vérifier-lattestation-tee). `enable_e2ee` est rejeté par ce serveur.
</Warning>

### Crypto

| Outil | Description |
|---|---|
| `venice_crypto_networks` | Listez les slugs de réseaux acceptés en direct par le proxy RPC. |
| `venice_crypto_rpc` | Servez de proxy pour une requête JSON-RPC, ou un lot de 100 au maximum, vers Ethereum, Base, Arbitrum, Optimism, Polygon, Solana, Starknet, zkSync, Linea, BSC, Avalanche, Blast, et plus. |

Les diffusions de transactions (`eth_sendRawTransaction`, `eth_sendUserOperation`, `sendTransaction` sur Solana, écritures Starknet) doivent être envoyées sous forme de requêtes individuelles avec une `idempotency_key`, et la même clé doit être réutilisée en cas de nouvelle tentative.

### Facturation (clés admin)

| Outil | Description |
|---|---|
| `venice_billing_balance` | Disponibilité actuelle en USD, DIEM et crédits inclus. |
| `venice_billing_usage_analytics` | Utilisation agrégée (bêta) par date, modèle et clé API (période rétrospective ou plage personnalisée). |
| `venice_billing_usage_history` | Utilisation détaillée avec pagination par curseur et sortie JSON ou CSV. |

<Note>
Les outils de facturation nécessitent une clé API **ADMIN**. Les clés d'inférence ne peuvent pas appeler ces endpoints, et le serveur échoue localement au lieu de se rabattre sur un token de wallet.
</Note>

### Clés API

| Outil | Description |
|---|---|
| `venice_list_api_keys` | Listez les métadonnées des clés actives, avec uniquement les six derniers caractères. Clé admin uniquement. |
| `venice_get_api_key` | Obtenez les métadonnées, l'utilisation, les soldes et les limites de débit d'une clé via son identifiant. Clé admin uniquement. |
| `venice_api_key_rate_limits` | Soldes actuels, statut d'accès, niveau, expiration et limites de débit par modèle. Clé d'inférence ou admin. |
| `venice_api_key_rate_limit_logs` | Les 50 derniers dépassements de limite de débit (expérimental). Clé admin uniquement. |

### Helpers wallet x402

Pertinent uniquement si vous vous authentifiez avec un wallet via [x402](/fr/guides/integrations/x402-venice-api) au lieu d'une clé API.

| Outil | Description |
|---|---|
| `venice_x402_balance` | Vérifiez le solde de crédit prépayé x402 pour une adresse de wallet EVM ou Solana. |
| `venice_x402_top_up_info` | Récupérez les exigences de top-up (réseau, token USDC, destinataire, montant minimum). Ne prend aucun argument. |
| `venice_x402_transactions` | Listez les top-ups et débits x402 récents pour une adresse de wallet EVM ou Solana. |

## Configuration

Le serveur se configure entièrement via des variables d'environnement.

### Modèles et requêtes

| Variable d'env. | Défaut | Notes |
|---|---|---|
| `VENICE_API_KEY` | _(aucun)_ | Votre clé API Venice. La configuration la plus simple. |
| `VENICE_DEFAULT_CHAT_MODEL` | `deepseek-v4-flash-0731` | |
| `VENICE_DEFAULT_IMAGE_MODEL` | `flux-2-pro` | |
| `VENICE_DEFAULT_TTS_MODEL` | `tts-kokoro` | |
| `VENICE_DEFAULT_ASR_MODEL` | `openai/whisper-large-v3` | |
| `VENICE_DISABLE_NSFW` | `0` | Définissez à `1` pour retirer les mentions de capacité NSFW des descriptions d'outils. |
| `VENICE_HTTP_TIMEOUT_MS` | `60000` | |
| `VENICE_SIWX_TOKEN` | _(aucun)_ | Token d'authentification en mode wallet x402. Voir [x402 ci-dessous](#mode-wallet-x402). |

Si `VENICE_API_KEY` et `VENICE_SIWX_TOKEN` sont tous deux définis, la clé API prime pour la plupart des appels ; consultez [Couverture des modes d'authentification](#couverture-des-modes-dauthentification) pour les exceptions.

### Limites de taille des réponses

Les médias générés sont mis en mémoire tampon et intégrés au résultat MCP en base64 ; chaque modalité a donc un plafond en octets.

| Variable d'env. | Défaut | S'applique à |
|---|---|---|
| `VENICE_MAX_IMAGE_RESPONSE_BYTES` | `33554432` (32 Mio) | `venice_image_generate`, `venice_image_edit`, `venice_image_multi_edit`, `venice_image_upscale`, `venice_image_remove_bg` |
| `VENICE_MAX_VIDEO_RESPONSE_BYTES` | `26214400` (25 Mio) | `venice_video_status` |
| `VENICE_MAX_AUDIO_RESPONSE_BYTES` | `33554432` (32 Mio) | `venice_tts`, `venice_music_status` |

Un résultat d'image ou de TTS trop volumineux est abandonné avec une erreur. Un résultat vidéo ou musical trop volumineux reste en file d'attente : vous pouvez donc rappeler l'outil d'état avec le même identifiant de file après avoir relevé la limite.

### Serveur HTTP

Pertinent uniquement dans le [déploiement Streamable HTTP](#auto-hébergement-streamable-http).

| Variable d'env. | Défaut | Notes |
|---|---|---|
| `PORT` | `3333` | Port d'écoute HTTP. |
| `VENICE_MCP_HOST` | `127.0.0.1` | Adresse de liaison. Définissez `0.0.0.0` pour une exposition sur le réseau local ou dans un conteneur. |
| `VENICE_MCP_AUTH_TOKEN` | _(aucun)_ | Token Bearer pour `/mcp`. Obligatoire en cas de liaison hors loopback, où il doit comporter au moins 16 caractères. Une fois défini, il est aussi appliqué sur loopback. |
| `VENICE_MCP_ALLOW_UNAUTHENTICATED_HTTP` | `0` | Échappatoire pour exposer un HTTP non authentifié. À utiliser uniquement derrière un proxy authentifié de confiance. |
| `VENICE_MCP_MAX_SESSIONS` | `100` | Nombre maximal de sessions Streamable HTTP actives. |
| `VENICE_MCP_SESSION_TTL_MS` | `1800000` | Durée de vie d'une session inactive avant son nettoyage. |

## Comportement de la génération de médias

- **Les médias terminés peuvent être des octets ou une URL.** Les tâches vidéo et musicales renvoient des ressources MP4/audio intégrées, ou un JSON avec un `download_url` renvoyé sous forme de lien de ressource. Téléchargez d'abord ce lien, puis appelez `venice_video_complete` ou `venice_music_complete` ; le nettoyage des médias n'est jamais appliqué à un résultat `download_url`, car le lien cesse de fonctionner une fois le fichier supprimé.
- **Certains modèles ne renvoient une URL qu'au moment de la mise en file d'attente.** Pour les modèles VPS et Grok Imagine Private, récupérez le `download_url` renvoyé par `venice_video_generate` et transmettez-le à `venice_video_status` ; une récupération `COMPLETED` sans URL intégrée fournit tout de même un lien utilisable.
- **L'amélioration du prompt est signalée en retour.** Lorsque `enhance_prompt` est appliqué, les résultats de génération, de modification et de modification multiple d'images incluent le prompt décodé de l'URL renvoyé par Venice.
- **La pagination ASR n'est facturée qu'une fois.** Les transcriptions de plus de 8 000 caractères, ou comportant plus d'horodatages que ne peut en contenir une page (200 par tableau par défaut, jusqu'à 500 avec `timestamp_limit`), renvoient un `result_handle` avec la première page. Demandez les pages suivantes avec ce handle. Les handles sont conservés en mémoire par session MCP pendant 10 minutes, et seuls les 16 plus récents sont gardés.
- **Le consentement Seedance ne permet pas de contourner les règles.** Les modèles Seedance publics actuels peuvent rejeter purement et simplement les médias contenant des personnes détectables. Lorsqu'une réponse `needs_consent` est renvoyée, les trois indicateurs `consents.seedance` constituent des attestations juridiques : définissez-les à `true` uniquement après que l'utilisateur a explicitement confirmé chaque déclaration.

## Mode wallet x402

Venice prend en charge l'authentification avec un [token wallet Sign-In-With-X](/fr/guides/integrations/x402-venice-api) adossé à du crédit USDC prépayé sur Base ou Solana, en plus du flux classique par clé API. Pas d'e-mail, ni de téléphone, ni de KYC requis : votre wallet est votre seule identité.

```json
{
  "mcpServers": {
    "venice": {
      "command": "npx",
      "args": ["-y", "@veniceai/mcp-server@0.3.0"],
      "env": { "VENICE_SIWX_TOKEN": "<base64 Sign-In-With-X payload>" }
    }
  }
}
```

Le serveur MCP transmet `VENICE_SIWX_TOKEN` dans l'en-tête `SIGN-IN-WITH-X` à chaque appel de l'API Venice. Le serveur ne voit jamais votre clé privée. La signature du wallet et les autorisations de top-up USDC se produisent dans votre propre wallet.

| Flux | Ce qui se passe |
|---|---|
| **Configuration unique** | Signez un message Sign-In-With-X dans votre wallet → produit un token SIWX (JSON base64). |
| **Top-up** | `POST /api/v1/x402/top-up` renvoie 402 + des exigences de paiement. Signez un paiement USDC pour l'une des options Base ou Solana renvoyées, resoumettez, et Venice crédite votre solde. |
| **Chaque appel d'inférence** | Le serveur MCP envoie `SIGN-IN-WITH-X: <SIWX>` ; Venice débite votre solde prépayé. |

Le top-up minimum est de **\$5 USD**. Le solde minimum pour appeler l'inférence est de **\$0.10**. Une fois rechargés, les appels prennent moins de 100 ms car le règlement a lieu hors chaîne sur un compte de crédit rapide.

<Tip>
Les wallets liés à un compte Venice avec du DIEM staké consomment depuis le solde de staking au lieu des crédits USDC, donc aucun top-up n'est nécessaire.
</Tip>

Venice n'accepte pas d'en-têtes de paiement sur les routes d'inférence ; ce serveur n'en envoie donc jamais. `PAYMENT-SIGNATURE` est réservé à `/x402/top-up`, et le helper de top-up découvre les exigences sans soumettre de paiement.

### Couverture des modes d'authentification

Certains endpoints n'acceptent qu'un seul mode d'authentification :

| Outil | Clé API | x402 |
|---|---|---|
| Inférence, médias, web augment, RPC crypto, chat avec personnage | ✓ | ✓ |
| `venice_list_characters`, `venice_get_character`, `venice_character_reviews` | ✓ | ✗ |
| `venice_billing_*`, `venice_list_api_keys`, `venice_get_api_key`, `venice_api_key_rate_limit_logs` | ✓ (admin) | ✗ |
| `venice_api_key_rate_limits` | ✓ (toute clé) | ✗ |
| `venice_x402_balance`, `venice_x402_transactions` | ✗ | ✓ |
| `venice_x402_top_up_info` | ✓ | ✓ |

Lorsque les deux identifiants sont définis, la clé API est utilisée pour chaque appel authentifié, sauf pour `venice_x402_balance` et `venice_x402_transactions`, qui envoient toujours le token de wallet.

## Auto-hébergement (Streamable HTTP)

Pour les déploiements en équipe ou en workspace, exécutez le serveur MCP via HTTP au lieu de stdio :

```bash
docker run -p 3333:3333 \
  -e VENICE_API_KEY=<your-venice-api-key> \
  -e VENICE_MCP_AUTH_TOKEN=<choose-a-long-random-token> \
  ghcr.io/veniceai/venice-mcp-server:latest
```

Le serveur est désormais disponible à l'adresse `http://localhost:3333/mcp`. Les clients HTTP doivent envoyer `Authorization: Bearer <VENICE_MCP_AUTH_TOKEN>` et doivent créer les nouvelles sessions sans en-tête `mcp-session-id`, puis réutiliser l'identifiant de session émis par le serveur.

<Warning>
`/mcp` est un endpoint d'exécution d'outils adossé à des identifiants : les appelants peuvent dépenser la clé API Venice configurée ou le solde x402. Lorsque le mode HTTP s'expose au-delà de loopback, le démarrage échoue sauf si `VENICE_MCP_AUTH_TOKEN` est défini, ou si `VENICE_MCP_ALLOW_UNAUTHENTICATED_HTTP=1` est défini derrière un proxy authentifié de confiance. En production, épinglez explicitement une version du paquet npm plutôt que de vous reposer sur `latest`.
</Warning>
