[OpenCode](https://opencode.ai/) est un agent de programmation IA pour le terminal. OpenCode intègre déjà un fournisseur Venice AI : vous vous connectez en une seule commande et choisissez un modèle dans tout le catalogue Venice. Aucun fichier de configuration n'est nécessaire.

<Note>
  Ce guide suit OpenCode 1, la version installée par l'installateur standard. OpenCode 2 inclut aussi Venice AI, avec quelques libellés différents. Voir [OpenCode 2](#opencode-2).
</Note>

## Prérequis {#prerequisites}

- Une clé API Venice depuis [venice.ai/settings/api](https://venice.ai/settings/api?utm_source=venice-api-documentation)
- OpenCode installé et fonctionnel sur votre machine

---

## Configuration {#setup}

<Steps>
  <Step title="Connecter Venice AI">
    Lancez OpenCode et exécutez la commande de connexion :

    ```txt
    /connect
    ```

    Recherchez **Venice AI** et sélectionnez-le.

    <Frame as="div">
      <img
        src="/images/guides/opencode/connect-venice.png"
        alt="La palette /connect d'OpenCode filtrée sur Venice AI"
      />
    </Frame>
  </Step>

  <Step title="Coller votre clé API Venice">
    Collez la clé dans le champ **API key** et appuyez sur Entrée.

    OpenCode enregistre l'identifiant dans `~/.local/share/opencode/auth.json`, il reste donc disponible dans tous les projets.
  </Step>

  <Step title="Choisir un modèle">
    Exécutez la commande des modèles et choisissez un modèle Venice :

    ```txt
    /models
    ```

    `z-ai-glm-5-3-flash` est un bon choix par défaut pour le code : rapide, peu coûteux et doté d'une fenêtre de contexte de 1M tokens. Consultez [ID de modèles](#model-ids) pour d'autres options.

    OpenCode liste aussi sa propre offre gratuite hébergée sous des noms proches, par exemple **GLM-5.3-Flash Free** d'**OpenCode** à côté de **GLM 5.3 Flash** de **Venice AI**. Le nom du fournisseur dans la colonne de droite permet de les distinguer, et la ligne Venice AI est celle qui utilise votre clé et vos crédits.
  </Step>
</Steps>

Envoyez une petite tâche pour confirmer l'aller-retour, par exemple :

```txt
Review the current file and suggest one safe improvement.
```

## Définir un modèle par défaut {#pin-a-default-model}

Après la connexion, OpenCode peut démarrer les nouvelles sessions sur un modèle routé comme Claude Sonnet 4.6, qui coûte plus cher que les modèles de [ID de modèles](#model-ids). Pour choisir le modèle de démarrage d'OpenCode, ajoutez-le à `opencode.json` à la racine de votre projet (ou à `~/.config/opencode/opencode.json` pour un choix global) :

```json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "venice/z-ai-glm-5-3-flash",
  "small_model": "venice/z-ai-glm-5-3-flash"
}
```

Les références de modèles utilisent la forme `venice/<model-id>`, et `small_model` définit le modèle moins coûteux utilisé pour les tâches en arrière-plan.

## Se connecter sans `/connect` {#connect-without-/connect}

Le fournisseur intégré lit aussi `VENICE_API_KEY` depuis l'environnement. Exportez-la avant de lancer OpenCode et les modèles Venice AI apparaissent dans `/models` sans exécuter `/connect` :

```bash
export VENICE_API_KEY="your-api-key"
```

Sur une version d'OpenCode antérieure au fournisseur intégré, ou pour figer la liste des modèles affichés par OpenCode, configurez Venice comme fournisseur compatible OpenAI dans `opencode.json`. Gardez `VENICE_API_KEY` exportée :

```json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "venice/z-ai-glm-5-3-flash",
  "small_model": "venice/z-ai-glm-5-3-flash",
  "provider": {
    "venice": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Venice AI",
      "options": {
        "baseURL": "https://api.venice.ai/api/v1",
        "apiKey": "{env:VENICE_API_KEY}"
      },
      "models": {
        "z-ai-glm-5-3-flash": {
          "name": "GLM 5.3 Flash"
        },
        "kimi-k2-6": {
          "name": "Kimi K2.6"
        },
        "minimax-m25": {
          "name": "MiniMax M2.5"
        }
      }
    }
  }
}
```

Listez dans `models` les modèles souhaités. OpenCode n'affiche que les entrées déclarées ici pour ce fournisseur. Sur les versions dotées du fournisseur intégré, la variable d'environnement suffit à donner accès à tout le catalogue.

## OpenCode 2 {#opencode-2}

OpenCode 2 est une ligne de versions distincte, avec son propre installateur :

```bash
curl -fsSL https://opencode.ai/v2/install | bash
```

Il intègre un fournisseur Venice AI natif, et la configuration ci-dessus fonctionne avec quelques différences :

- La boîte de dialogue `/connect` s'intitule **Connect an integration**. Recherchez **Venice AI** sous **Services**, puis collez votre clé dans la boîte de dialogue **Connect Venice AI**.
- Exporter `VENICE_API_KEY` avant le lancement active aussi le fournisseur sans `/connect`.
- Sans modèle épinglé, OpenCode 2 peut aussi démarrer sur un modèle routé, comme Claude Fable 5.2.
- Les exemples `opencode.json` de cette page continuent de fonctionner, car OpenCode 2 lit toujours le format de configuration d'OpenCode 1. Dans la configuration native d'OpenCode 2, définissez le modèle d'arrière-plan avec `agents.title.model` au lieu de `small_model`. Consultez le [guide de migration](https://opencode.ai/docs/migrate-v1) d'OpenCode pour le reste du format natif.

## ID de modèles {#model-ids}

Quelques modèles Venice qui fonctionnent bien dans un agent de code. Le catalogue évolue, utilisez donc [`GET /models?type=text`](/fr/api-reference/endpoint/models/list) pour obtenir la liste à jour.

| Modèle | ID Venice |
|-------|-----------|
| GLM 5.3 Flash | `z-ai-glm-5-3-flash` |
| GLM 5.3 | `z-ai-glm-5-3` |
| Kimi K2.6 | `kimi-k2-6` |
| MiniMax M2.5 | `minimax-m25` |
| DeepSeek V4.1 Flash | `deepseek-v4-1-flash` |

Les modèles open-weight comme ceux-ci s'exécutent de manière entièrement privée. Les modèles routés d'Anthropic, d'OpenAI et de Google s'exécutent de manière anonymisée : le laboratoire d'origine ne voit jamais votre identité.

## Notes de configuration {#config-notes}

- Gardez `baseURL` défini sur `https://api.venice.ai/api/v1` dans le bloc de fournisseur manuel. Le fournisseur intégré pointe déjà vers cette adresse.
- L'ID du fournisseur est `venice`, donc les références de modèles utilisent la forme `venice/<model-id>` dans les deux cas.
- Exécutez de nouveau `/connect` à tout moment pour remplacer la clé Venice enregistrée.
- Élargissez le contexte lorsque le modèle le permet : plusieurs modèles Venice acceptent 1M tokens.

## Dépannage {#troubleshooting}

<AccordionGroup>
  <Accordion title="Venice AI n'apparaît pas dans /connect">
    Mettez OpenCode à jour vers la dernière version 1.x avec `opencode upgrade`. Le fournisseur Venice AI est inclus dans les versions actuelles, une installation plus ancienne peut donc ne proposer que la configuration manuelle ci-dessus.
  </Accordion>
  <Accordion title="Clé API invalide ou erreur 401">
    Vérifiez que la clé provient de [venice.ai/settings/api](https://venice.ai/settings/api?utm_source=venice-api-documentation), puis exécutez `/connect`, sélectionnez **Venice AI** et collez-la de nouveau. Lorsque la clé enregistrée est périmée, OpenCode signale un échec d'authentification au lieu d'atteindre Venice.
  </Accordion>
  <Accordion title="Modèle indisponible">
    Copiez l'ID exactement depuis [ID de modèles](#model-ids), le [catalogue des modèles de texte](/fr/models/text) ou `GET /models`, et vérifiez que votre compte Venice y a accès.
  </Accordion>
</AccordionGroup>
