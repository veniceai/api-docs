Le [Venice CLI](https://github.com/veniceai/venice-cli) est l'interface en ligne de commande officielle de Venice. Discutez avec des modèles d'IA, générez des images, convertissez du texte en parole, transcrivez de l'audio, générez de la vidéo, et bien plus encore — le tout depuis votre terminal, avec chiffrement de bout en bout optionnel.

## Démarrage rapide

<Steps>
  <Step title="Installez le CLI">
    Installez-le globalement avec npm :

    ```bash
    npm install -g veniceai-cli
    ```

    Ou exécutez-le sans installation :

    ```bash
    npx veniceai-cli chat 'Hello, world!'
    ```
  </Step>

  <Step title="Obtenez une clé API Venice">
    Générez-en une depuis [venice.ai/settings/api](https://venice.ai/settings/api). Consultez le [guide des clés API](/guides/getting-started/generating-api-key) pour des instructions détaillées.
  </Step>

  <Step title="Configurez votre clé">
    Lancez la configuration interactive et collez votre clé lorsqu'elle vous est demandée, afin qu'elle n'apparaisse jamais dans l'historique de votre shell ni dans la liste des processus :

    ```bash
    venice config init
    ```

    Ou utilisez plutôt une variable d'environnement :

    ```bash
    export VENICE_API_KEY=YOUR_API_KEY
    ```
  </Step>

  <Step title="Commencez à discuter">
    ```bash
    venice chat "What is the meaning of life?"
    ```
  </Step>
</Steps>

<Note>
Nécessite Node.js 18.0.0 ou supérieur. `VENICE_API_KEY` prime sur toute valeur stockée dans le fichier de configuration.
</Note>

## Commandes

| Commande | Rôle |
|---|---|
| `venice chat <prompt>` | Discutez avec n'importe quel modèle texte Venice, avec outils, personnages et streaming |
| `venice search <query>` | Recherche web avec synthèse par IA et citations optionnelles |
| `venice image <prompt>` | Générez une image à partir d'un prompt texte |
| `venice upscale <file>` | Mettez à l'échelle une image existante jusqu'à 4× |
| `venice tts <text>` | Synthèse vocale avec plus de 35 voix |
| `venice transcribe <file>` | Transcription audio avec horodatages optionnels |
| `venice video <subcommand>` | Mettez en file d'attente, interrogez et téléchargez de la vidéo générée par IA |
| `venice embeddings <text>` | Générez des vecteurs d'embedding |
| `venice models` | Listez et filtrez le catalogue de modèles en direct |
| `venice tee <subcommand>` | Récupérez et vérifiez l'attestation TEE |
| `venice config <subcommand>` | Gérez la clé API et les valeurs par défaut |
| `venice history <subcommand>` | Listez, affichez, exportez ou effacez les conversations |
| `venice usage` | Affichez la consommation de tokens dans le temps |
| `venice characters` / `venice voices` | Listez les personas intégrés et les voix TTS |
| `venice completions <shell>` | Générez des complétions shell |

### Chat

```bash
# Basic chat
venice chat "Explain quantum computing in simple terms"

# Use a specific model and system prompt
venice chat -m deepseek-v3.2 -s "You are a helpful coding assistant" "Write fizzbuzz in Python"

# Continue the previous conversation
venice chat --continue "What about the next step?"

# Function calling with built-in tools
venice chat -t calculator,datetime "What's 25 * 4.5, and what day is it?"

# JSON output for scripting
venice chat -f json "List 3 colors" | jq '.content'
```

Options courantes de chat :

| Option | Description |
|---|---|
| `-m, --model <model>` | Modèle à utiliser (par défaut : `kimi-k2-5`) |
| `-s, --system <prompt>` | Prompt système |
| `-c, --character <name>` | Persona de personnage |
| `-t, --tools <tools>` | Liste d'outils intégrés séparés par des virgules |
| `--continue` | Poursuivez la dernière conversation |
| `--web-search` | Activez la recherche web pour des informations actuelles |
| `--no-stream` | Désactivez la sortie en streaming |
| `-f, --format <format>` | Format de sortie (`pretty`, `json`, `markdown`, `raw`) |
| `--e2ee` / `--no-e2ee` | Forcez ou désactivez le chiffrement de bout en bout |
| `--tee-verify` | Affichez les détails de l'attestation TEE |
| `-q, --quiet` | Masquez les messages d'état E2EE/TEE |

### Recherche web

```bash
venice search "Latest developments in fusion energy"
venice search -n 10 --citations "Best practices for TypeScript"
venice search --scrape "Company research on Anthropic"
```

### Génération et upscaling d'images

```bash
# Generate and save an image
venice image -o sunset.png "A serene mountain lake at sunset"

# Custom dimensions and model
venice image -w 1024 -h 768 -m flux-1-dev "Landscape photograph"

# Upscale an existing image 4×
venice upscale photo.jpg -s 4 -o photo_4x.jpg
```

### Synthèse vocale et transcription

```bash
# Speak with a specific voice
venice tts -v bf_emma -o greeting.mp3 "Good morning, everyone!"

# Pipe text in from stdin
echo "Text to speak" | venice tts -o output.mp3

# Transcribe audio with timestamps
venice transcribe -t recording.mp3

# Choose a model and language hint
venice transcribe -m openai/whisper-large-v3 -l es spanish_audio.mp3
```

### Génération vidéo

La génération vidéo est asynchrone (basée sur une file d'attente).

```bash
# Queue a text-to-video generation
venice video generate -m veo3-fast-text-to-video "Cinematic sunset over mountains"

# Image-to-video with a reference image
venice video generate -m wan-2.6-image-to-video -i photo.jpg "The scene comes alive"

# Poll until done, then download
venice video status -w <queue_id>
venice video retrieve <queue_id> -o my_video.mp4

# List available video models
venice video models
```

### Modèles et embeddings

```bash
# List and filter the catalog
venice models -t image
venice models --privacy
venice models --e2ee

# Generate embeddings
venice embeddings -o vectors.json "Text to embed"
```

### Configuration

```bash
# Interactive setup
venice config init

# Set and inspect values
venice config set default_model kimi-k2-5
venice config get default_model
venice config show
venice config path
```

| Clé | Description |
|---|---|
| `api_key` | Votre clé API Venice |
| `default_model` | Modèle de chat par défaut |
| `default_image_model` | Modèle de génération d'images par défaut |
| `default_voice` | Voix TTS par défaut |
| `output_format` | Format de sortie par défaut |
| `show_usage` | Afficher la consommation de tokens après chaque requête |

## Confidentialité : E2EE et TEE

Venice CLI est conçu pour la confidentialité. Il n'envoie aucune télémétrie, stocke votre clé API localement avec des permissions restreintes, et prend en charge les modèles de calcul confidentiel de Venice.

- **Chiffrement de bout en bout (E2EE)** : les messages sont chiffrés côté client et déchiffrés uniquement à l'intérieur du TEE, de sorte que Venice ne peut pas lire vos données. Le CLI active automatiquement l'E2EE lorsqu'un modèle en annonce la capacité, en générant une paire de clés éphémère par session (ECDH + AES-GCM).
- **Attestation TEE** : vérifiez cryptographiquement qu'un modèle s'exécute dans une enclave sécurisée avant d'envoyer des données.

```bash
# Discover confidential-compute models
venice models --e2ee
venice models --tee

# Chat with E2EE (auto-enabled for capable models)
venice chat -m <e2ee-capable-model> "Your private message here"

# TEE-only mode: verify attestation without encryption
venice chat -m <e2ee-capable-model> --no-e2ee "TEE verified, not encrypted"

# Fetch and verify attestation directly
venice tee attestation <model>
venice tee verify <model>
```

<Note>
Le mode E2EE désactive les outils et la recherche web afin de préserver le chiffrement de bout en bout.
</Note>

## Formats de sortie

| Format | Cas d'usage |
|---|---|
| `pretty` | Sortie colorée et formatée pour un usage interactif (par défaut) |
| `json` | JSON lisible par machine pour le scripting et le piping |
| `markdown` | Sortie formatée en Markdown pour la documentation |
| `raw` | Texte brut sans décoration, pour les pipes |

Le CLI détecte automatiquement quand la sortie est redirigée par pipe et bascule sur `raw`.

```bash
venice chat -f json "List items" | jq '.'
venice chat "Generate code" | pbcopy
```
