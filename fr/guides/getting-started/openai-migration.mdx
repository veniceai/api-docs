Venice AI est un **remplacement direct** d'OpenAI. Même SDK, même code — il suffit de changer deux lignes. Bénéficiez d'une inférence axée sur la confidentialité, de modèles non censurés et d'une tarification compétitive.

## La migration en 2 lignes

<CodeGroup>
```python Python
# Avant (OpenAI)
from openai import OpenAI
client = OpenAI()

# Après (Venice) — changez api_key et base_url
from openai import OpenAI
client = OpenAI(
    api_key="your-venice-api-key",           # ← Changement 1
    base_url="https://api.venice.ai/api/v1",  # ← Changement 2
)
```

```javascript Node.js
// Avant (OpenAI)
import OpenAI from "openai";
const client = new OpenAI();

// Après (Venice)
import OpenAI from "openai";
const client = new OpenAI({
  apiKey: "your-venice-api-key",
  baseURL: "https://api.venice.ai/api/v1",
});
```

```bash cURL
# Avant
curl https://api.openai.com/v1/chat/completions ...

# Après — changez simplement l'URL et la clé
curl https://api.venice.ai/api/v1/chat/completions ...
```
</CodeGroup>

Générez une clé depuis [venice.ai/settings/api](https://venice.ai/settings/api?utm_source=venice-api-documentation) ou suivez le [guide de création d'une clé API](/guides/getting-started/generating-api-key).

### Variables d'environnement

```bash
# Avant
OPENAI_API_KEY=sk-...
OPENAI_BASE_URL=https://api.openai.com/v1

# Après
OPENAI_API_KEY=your-venice-api-key
OPENAI_BASE_URL=https://api.venice.ai/api/v1
```

<Tip>
De nombreuses bibliothèques et outils lisent automatiquement `OPENAI_API_KEY` et `OPENAI_BASE_URL`. Mettre à jour ces variables d'environnement peut suffire. Certains outils utilisent encore `OPENAI_API_BASE` pour la même URL.
</Tip>

## Modèles

Transmettez un identifiant de modèle Venice, un trait tel que `default` ou `most_uncensored`, ou un nom familier de style OpenAI. Venice fait correspondre les noms OpenAI grâce à la [table de correspondance](/api-reference/endpoint/models/compatibility_mapping). Les traits se résolvent toujours vers le modèle actuel pour ce rôle — voir les [traits de modèles](/api-reference/endpoint/models/traits).

Parcourez le catalogue en direct sur [Modèles de texte](/models/text) et [Tarification](/overview/pricing). Pour un pas-à-pas d'une première requête, consultez le [Démarrage rapide](/getting-started/quick-start).

## Compatibilité des fonctionnalités

| Fonctionnalité | OpenAI | Venice | Notes |
|---------|--------|--------|-------|
| Chat Completions | ✅ | ✅ | Entièrement compatible |
| Streaming | ✅ | ✅ | Même format SSE |
| Appels de fonction | ✅ | ✅ | Même paramètre `tools` |
| Sortie structurée | ✅ | ✅ | Même `response_format` |
| Vision | ✅ | ✅ | Même format de tableau de contenu |
| Embeddings | ✅ | ✅ | Texte uniquement ; les tableaux de tokens renvoient HTTP 400 |
| Génération d'images | ✅ | ✅ | Compatible OpenAI via `/images/generations` |
| Éditions d'images | ✅ | ❌ | Pas d'endpoint `/images/edits` ; utilisez l'endpoint natif [`/image/edit`](/guides/media/image-editing) |
| TTS | ✅ | ✅ | Compatible |
| STT | ✅ | ✅ | Compatible |
| API Responses | ✅ | ✅ | Alpha |
| API Assistants | ✅ | ❌ | Utilisez les [Characters](/guides/features/characters) ou les [appels de fonction](/guides/features/function-calling) |
| API Batch | ✅ | ❌ | Pas encore disponible |
| Fine-tuning | ✅ | ❌ | Non disponible |

Pour les options d'image natives au-delà de l'endpoint compatible OpenAI, consultez la [Génération d'images](/guides/media/image-generation).

## Fonctionnalités exclusives à Venice

Transmettez les options spécifiques à Venice via `extra_body` en tant que `venice_parameters`. La recherche web intégrée est généralement le premier ajout :

```python
response = client.chat.completions.create(
    model="default",
    messages=[{"role": "user", "content": "Latest AI news today"}],
    extra_body={
        "venice_parameters": {
            "enable_web_search": "auto"
        }
    },
)
```

Le même schéma couvre le web scraping, les citations et les [Characters](/guides/features/characters). Si un client ne peut pas modifier le corps de la requête, ajoutez un [suffixe de fonctionnalité de modèle](/api-reference/endpoint/chat/model_feature_suffix) tel que `default:enable_web_search=auto`.

Venice propose également des APIs natives de [vidéo](/guides/media/video-generation), de [musique](/guides/media/music-and-sound-effects), de [récupération web](/guides/tools/web-retrieval) et [x402](/guides/integrations/x402-venice-api) en parallèle de la surface compatible OpenAI.

## Modèles non censurés

Les modèles privés non censurés de Venice n'appliquent aucun filtrage de contenu, ce qui les rend adaptés à :

- L'écriture créative sans garde-fous
- La recherche en sécurité et le red teaming
- Une analyse honnête sans schémas de refus
- Des informations médicales et juridiques sans avertissements supplémentaires

Utilisez le trait `most_uncensored` ou un identifiant de modèle non censuré actuel depuis [Modèles de texte](/models/text).
