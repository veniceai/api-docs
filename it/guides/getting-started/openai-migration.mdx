Venice AI è un **sostituto drop-in** di OpenAI. Stesso SDK, stesso codice — basta cambiare due righe. Ottieni inferenza privacy-first, modelli non censurati e prezzi competitivi.

## La migrazione in 2 righe

<CodeGroup>
```python Python
# Prima (OpenAI)
from openai import OpenAI
client = OpenAI()

# Dopo (Venice) — cambia api_key e base_url
from openai import OpenAI
client = OpenAI(
    api_key="your-venice-api-key",           # ← Modifica 1
    base_url="https://api.venice.ai/api/v1",  # ← Modifica 2
)
```

```javascript Node.js
// Prima (OpenAI)
import OpenAI from "openai";
const client = new OpenAI();

// Dopo (Venice)
import OpenAI from "openai";
const client = new OpenAI({
  apiKey: "your-venice-api-key",
  baseURL: "https://api.venice.ai/api/v1",
});
```

```bash cURL
# Prima
curl https://api.openai.com/v1/chat/completions ...

# Dopo — basta cambiare la URL e la chiave
curl https://api.venice.ai/api/v1/chat/completions ...
```
</CodeGroup>

Genera una chiave da [venice.ai/settings/api](https://venice.ai/settings/api) oppure segui la [guida alle API key](/guides/getting-started/generating-api-key).

### Variabili d'ambiente

```bash
# Prima
OPENAI_API_KEY=sk-...
OPENAI_BASE_URL=https://api.openai.com/v1

# Dopo
OPENAI_API_KEY=your-venice-api-key
OPENAI_BASE_URL=https://api.venice.ai/api/v1
```

<Tip>
Molte librerie e strumenti leggono automaticamente `OPENAI_API_KEY` e `OPENAI_BASE_URL`. Aggiornare queste variabili d'ambiente potrebbe essere tutto ciò di cui hai bisogno. Alcuni strumenti usano ancora `OPENAI_API_BASE` per lo stesso URL.
</Tip>

## Modelli

Passa un ID di modello Venice, un trait come `default` o `most_uncensored`, oppure un nome familiare in stile OpenAI. Venice mappa i nomi OpenAI tramite il [compatibility mapping](/api-reference/endpoint/models/compatibility_mapping). I trait si risolvono sempre al modello corrente per quel ruolo — vedi [model traits](/api-reference/endpoint/models/traits).

Sfoglia il catalogo aggiornato su [Modelli di testo](/models/text) e [Prezzi](/overview/pricing). Per un walkthrough della prima richiesta, consulta la [Quickstart](/getting-started/quick-start).

## Compatibilità delle funzionalità

| Funzionalità | OpenAI | Venice | Note |
|---------|--------|--------|-------|
| Chat Completions | ✅ | ✅ | Pienamente compatibile |
| Streaming | ✅ | ✅ | Stesso formato SSE |
| Function Calling | ✅ | ✅ | Stesso parametro `tools` |
| Structured Output | ✅ | ✅ | Stesso `response_format` |
| Vision | ✅ | ✅ | Stesso formato per l'array content |
| Embeddings | ✅ | ✅ | Solo testo; gli array di token restituiscono HTTP 400 |
| Generazione di immagini | ✅ | ✅ | OpenAI-compatible tramite `/images/generations` |
| TTS | ✅ | ✅ | Compatibile |
| STT | ✅ | ✅ | Compatibile |
| Responses API | ✅ | ✅ | Alpha |
| Assistants API | ✅ | ❌ | Usa i [Characters](/guides/features/characters) o il [function calling](/guides/features/function-calling) |
| Batch API | ✅ | ❌ | Non ancora disponibile |
| Fine-tuning | ✅ | ❌ | Non disponibile |

Per le opzioni native sulle immagini oltre l'endpoint OpenAI-compatible, consulta [Generazione di immagini](/guides/media/image-generation).

## Funzionalità esclusive di Venice

Passa opzioni specifiche di Venice attraverso `extra_body` come `venice_parameters`. La ricerca web integrata è di solito il primo extra:

```python
response = client.chat.completions.create(
    model="default",
    messages=[{"role": "user", "content": "Ultime notizie di AI oggi"}],
    extra_body={
        "venice_parameters": {
            "enable_web_search": "auto"
        }
    },
)
```

Lo stesso pattern copre web scraping, citazioni e [Characters](/guides/features/characters). Se un client non può modificare il body della richiesta, aggiungi un [suffisso di feature del modello](/api-reference/endpoint/chat/model_feature_suffix) come `default:enable_web_search=auto`.

Venice offre inoltre API native per [video](/guides/media/video-generation), [musica](/guides/media/music-and-sound-effects), [recupero dal web](/guides/tools/web-retrieval) e [x402](/guides/integrations/x402-venice-api), affiancate alla superficie OpenAI-compatible.

## Modelli non censurati

I modelli privati non censurati di Venice non applicano filtri sui contenuti, il che li rende adatti a:

- Scrittura creativa senza guardrail
- Ricerca sulla sicurezza e red teaming
- Analisi oneste senza pattern di rifiuto
- Informazioni mediche e legali senza disclaimer aggiuntivi

Usa il trait `most_uncensored` oppure un ID di modello non censurato attuale da [Modelli di testo](/models/text).
