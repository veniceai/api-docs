L'upscaling delle immagini migliora la risoluzione e la qualità visiva di un'immagine esistente. Invia un'immagine a `/image/upscale`, scegli un fattore di scala e un livello di creatività opzionale, e Venice restituirà l'immagine migliorata come dati binari.

Usa l'upscaling quando hai già un'immagine e vuoi ottenerne una versione a maggiore risoluzione. Usa la [generazione di immagini](/it/guides/media/image-generation) quando devi creare un'immagine da un prompt, e l'[editing di immagini](/it/guides/media/image-editing) quando devi modificare il contenuto di un'immagine.

## Utilizzo di Base

<CodeGroup>
```python Python
import base64
import os
from pathlib import Path

import requests

image_base64 = base64.b64encode(Path("input.jpg").read_bytes()).decode("utf-8")

response = requests.post(
    "https://api.venice.ai/api/v1/image/upscale",
    headers={
        "Authorization": f"Bearer {os.environ['VENICE_API_KEY']}",
        "Content-Type": "application/json",
    },
    json={
        "image": image_base64,
        "scale": 2,
        "creativity": 0.01,
    },
)

response.raise_for_status()
Path("upscaled.png").write_bytes(response.content)
```

```javascript Node.js
import { readFile, writeFile } from "node:fs/promises";

const image = await readFile("input.jpg");

const response = await fetch("https://api.venice.ai/api/v1/image/upscale", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.VENICE_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    image: image.toString("base64"),
    scale: 2,
    creativity: 0.01,
  }),
});

if (!response.ok) {
  throw new Error(await response.text());
}

const output = Buffer.from(await response.arrayBuffer());
await writeFile("upscaled.png", output);
```

```bash cURL
IMAGE_BASE64=$(base64 < input.jpg | tr -d '\n')

curl https://api.venice.ai/api/v1/image/upscale \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d "{
    \"image\": \"$IMAGE_BASE64\",
    \"scale\": 2,
    \"creativity\": 0.01
  }" \
  --output upscaled.png
```
</CodeGroup>

Puoi anche caricare direttamente un file con `multipart/form-data` invece di codificarlo in base64:

```bash cURL (multipart)
curl https://api.venice.ai/api/v1/image/upscale \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -F "image=@input.jpg" \
  -F "scale=2" \
  -F "creativity=0.01" \
  --output upscaled.png
```

Invia esattamente una parte `image` per richiesta. I file caricati devono essere inferiori a 25 MB.

## Parametri

| Parametro | Tipo | Obbligatorio | Descrizione |
|-----------|------|--------------|-------------|
| `image` | string o file | Sì | Immagine sorgente. Inviala in base64 nel JSON oppure carica una parte file con `multipart/form-data`. Deve essere di almeno 256×256 pixel. I file caricati devono essere di 25 MB o meno; i corpi JSON sono limitati a 35 MB. |
| `scale` | number | No | Fattore di upscaling compreso tra `2` e `4`. Il valore predefinito è `2`; usa `2` o `4` (i valori intermedi sono accettati e fatturati alla tariffa 4x). L'output è limitato a 16.777.216 pixel (4096×4096): se la scala richiesta supera il limite, il server riduce automaticamente la scala effettiva. Gli input già pari o vicini al limite vengono rifiutati con `400`, quindi ridimensionali prima. |
| `creativity` | number | No | Quanto dettaglio e quanta texture aggiunge l'upscaler. `0`–`0.02`, predefinito `0.01`. Valori più alti ne aggiungono di più; valori più bassi restano più fedeli all'originale. I valori fuori intervallo vengono riportati al limite più vicino. |

<Note>
La risposta contiene dati binari dell'immagine, non JSON. Scrivi il corpo della risposta direttamente in un file o effettuane lo streaming verso uno storage.
</Note>

## Consigli sull'Input

- Parti dall'immagine sorgente più pulita a tua disposizione. L'upscaling migliora il dettaglio, ma non può recuperare completamente informazioni non presenti.
- Usa fattori di scala moderati nei flussi di produzione. Output molto grandi possono aumentare la latenza e la dimensione dei file.
- Conserva l'immagine originale nel caso in cui debba confrontare la qualità o riprovare con impostazioni diverse.
