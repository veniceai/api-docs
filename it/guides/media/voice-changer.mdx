Il Voice Changer è speech-to-speech: registra di nuovo un file sorgente in una voce diversa preservando intonazione, ritmo e tempistica. È asincrono e usa endpoint dedicati, non [`/audio/queue`](/it/api-reference/endpoint/audio/queue), e nemmeno [text-to-speech](/it/guides/media/text-to-speech) o [voice cloning](/it/guides/media/voice-cloning).

<Note>
Una conversione messa in coda viene addebitata immediatamente. Salva il `queue_id` dalla risposta della coda prima di fare qualsiasi altra cosa.
</Note>

## Come funziona

1. **Quote** - Richiedi un preventivo per la durata che prevedi di inviare
2. **Queue** - Carica la registrazione, oppure passa un URL pubblico
3. **Poll** - Scarica l'MP3 quando retrieve restituisce l'audio
4. **Complete** - Elimina i media memorizzati dopo aver salvato il file

| Endpoint | Scopo |
|----------|---------|
| [`POST /audio/voice-changer/quote`](/it/api-reference/endpoint/audio/voice-changer/quote) | Stima il costo della conversione in USD |
| [`POST /audio/voice-changer/queue`](/it/api-reference/endpoint/audio/voice-changer/queue) | Avvia una conversione speech-to-speech |
| [`POST /audio/voice-changer/retrieve`](/it/api-reference/endpoint/audio/voice-changer/retrieve) | Effettua polling sul job e scarica l'audio convertito |
| [`POST /audio/voice-changer/complete`](/it/api-reference/endpoint/audio/voice-changer/complete) | Elimina i media memorizzati dopo il download |

## Prerequisiti

- Una chiave API Venice per queue, retrieve e complete. L'endpoint quote non usa la chiave.
- Una registrazione sorgente in un contenitore elencato in `accepted_audio_formats` del modello. Venice controlla la firma binaria del file, quindi non è il nome del file a determinarne l'accettazione.
- Una registrazione non più lunga di `max_source_audio_duration_seconds` del modello e non più grande di 25 MB.
- Per `audio_url`, un URL `http` o `https` raggiungibile pubblicamente. Venice scarica i byte da sola e inoltra al provider solo quei byte.

Imposta la tua chiave API:

```bash
export VENICE_API_KEY="your-api-key"
```

## Scegli un modello

I modelli voice-changer sono restituiti da `GET /models?type=music` con `model_spec.voice_changer` impostato su `true`. Non esiste un filtro `?type=voice-changer`. Consulta i [Modelli Musica ed Effetti Sonori](/it/models/music) per l'elenco aggiornato. Gli esempi seguenti usano `elevenlabs-voice-changer`, e `Aria` è uno dei nomi delle voci di quel modello. Passa un nome da `voices`, oppure ometti `voice` per usare `default_voice`.

```bash
curl "https://api.venice.ai/api/v1/models?type=music" \
  -H "Authorization: Bearer $VENICE_API_KEY" |
  jq '.data[] | select(.model_spec.voice_changer == true) | {
    id,
    voices: .model_spec.voices,
    default_voice: .model_spec.default_voice,
    supports_custom_voice_id: .model_spec.supports_custom_voice_id,
    accepted_audio_formats: .model_spec.accepted_audio_formats,
    max_source_audio_duration_seconds: .model_spec.max_source_audio_duration_seconds,
    supports_background_noise_removal: .model_spec.supports_background_noise_removal,
    supports_seed: .model_spec.supports_seed,
    durations: .model_spec.pricing.durations
  }'
```

Controlla i metadati di ciascun modello prima di impostare campi opzionali:

| Campo | Uso |
|-------|------------|
| `voices` / `default_voice` | Nomi delle voci di destinazione. Ometti `voice` per usare quella predefinita. |
| `supports_custom_voice_id` | Indica se `voice` accetta anche un Voice ID del provider |
| `accepted_audio_formats` | Contenitori sorgente accettati da Venice |
| `max_source_audio_duration_seconds` | Registrazione sorgente più lunga accettata dal modello |
| `supports_background_noise_removal` | Indica se `remove_background_noise` è accettato |
| `supports_seed` | Indica se `seed` è accettato |
| `pricing.durations` | Fasce di prezzo per minuti interi, ciascuna con `min_seconds`, `max_seconds` e `usd` |

I campi non supportati generano una risposta HTTP `400`. Le registrazioni più lunghe di `max_source_audio_duration_seconds` vengono rifiutate con HTTP `422` prima di qualsiasi addebito. Il corpo dell'errore riporta tale valore massimo, nella forma `Source audio must be at most N seconds.`

## 1. Ottieni un preventivo

Il Voice Changer viene fatturato in base alla durata della registrazione sorgente, arrotondata per eccesso al minuto intero successivo. Un multiplo esatto di 60 secondi rimane nella fascia di quel minuto. Un secondo in più fa passare alla fascia successiva. Per `elevenlabs-voice-changer`, quote restituisce $0.35 per 60 secondi e $0.69 per 61 secondi. Leggi `pricing.durations` o chiama quote per il modello che stai usando. L'importo addebitato viene calcolato dalla durata misurata da Venice quando la registrazione viene messa in coda.

<Note>
L'endpoint quote non richiede autenticazione, mentre le richieste queue, retrieve e complete sì.
</Note>

```bash
curl https://api.venice.ai/api/v1/audio/voice-changer/quote \
  -H "Content-Type: application/json" \
  -d '{
    "model": "elevenlabs-voice-changer",
    "duration_seconds": 60
  }'
```

La risposta contiene il costo stimato in USD e la durata per cui il preventivo è stato calcolato:

```json
{
  "quote": 0.35,
  "duration_seconds": 60
}
```

## 2. Metti in coda la conversione

Fornisci la registrazione sorgente esattamente in uno di due modi: come upload multipart `file`, oppure come `audio_url` in un corpo JSON. Fornire entrambi, o nessuno dei due, viene rifiutato.

Un file che contiene una traccia video viene rifiutato. Estrai l'audio e carica quello. Quando passi un URL, l'URL deve essere raggiungibile pubblicamente. Venice scarica e valida i byte da sola, e l'URL non viene mai passato al provider.

Quando usi `curl -F`, non impostare manualmente `Content-Type`. `curl` aggiunge l'header `multipart/form-data` e il boundary richiesto. In un corpo multipart, invia `remove_background_noise` come `true` o `false` e `seed` come cifre.

<CodeGroup>
```bash File upload
curl https://api.venice.ai/api/v1/audio/voice-changer/queue \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -F "model=elevenlabs-voice-changer" \
  -F "voice=Aria" \
  -F "file=@./source-recording.mp3"
```

```bash Audio URL
curl https://api.venice.ai/api/v1/audio/voice-changer/queue \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "elevenlabs-voice-changer",
    "voice": "Aria",
    "audio_url": "https://example.com/source-recording.mp3",
    "remove_background_noise": true,
    "seed": 42
  }'
```
</CodeGroup>

`remove_background_noise` e `seed` sono accettati solo quando il modello ne segnala il supporto. Ometti `voice` per usare `default_voice`. Quando `supports_custom_voice_id` è true, `voice` può essere un Voice ID del provider invece di un nome da `voices`.

Una richiesta andata a buon fine restituisce il modello, un ID di coda e la durata misurata della sorgente:

```json
{
  "model": "elevenlabs-voice-changer",
  "queue_id": "0190f2c4-9c1e-7a3b-8f42-2c9d5e7a1b34",
  "status": "QUEUED",
  "duration_seconds": 52
}
```

Salva `model` e `queue_id`. Gli endpoint retrieve e complete li richiedono entrambi. Confronta `duration_seconds` con il tuo preventivo per riconciliare la stima con la durata fatturata.

<Warning>
La coda non è sicura da ritentare. Una richiesta di coda andata a buon fine è già stata addebitata. Se hai il `queue_id`, usalo per effettuare polling su retrieve. Se la risposta della coda non è mai arrivata, non hai un ID su cui effettuare polling, e inviare di nuovo la registrazione può comportare un secondo addebito.
</Warning>

## 3. Effettua polling e scarica

Chiama `/audio/voice-changer/retrieve` con i valori ottenuti dalla risposta della coda. Un `queue_id` può essere recuperato per 24 ore. Un ID sconosciuto, l'ID di un altro account, un ID malformato e un ID scaduto restituiscono tutti HTTP `400` con `Request ID is invalid.`

```bash
curl https://api.venice.ai/api/v1/audio/voice-changer/retrieve \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "elevenlabs-voice-changer",
    "queue_id": "0190f2c4-9c1e-7a3b-8f42-2c9d5e7a1b34"
  }' \
  --output response.bin
```

Controlla il `Content-Type` della risposta:

| Content-Type | Significato | Azione |
|--------------|---------|--------|
| `application/json` | La conversione è ancora in corso | Leggi i campi temporali, attendi ed effettua nuovamente il polling |
| `audio/mpeg` | La conversione è completata | Salva il corpo binario come `.mp3` |

Una risposta di elaborazione in corso appare così:

```json
{
  "status": "PROCESSING",
  "average_execution_time": 10000,
  "execution_duration": 4200
}
```

Entrambi i valori temporali sono in millisecondi. Attendi per l'intervallo tra `execution_duration` e `average_execution_time` prima di effettuare di nuovo il polling. Una risposta completata include anche `x-venice-audio-format`, `x-venice-audio-duration` (secondi), `x-venice-inference-time` (secondi), `x-venice-model-id` e `x-venice-model-name`.

Un errore del provider, così come una conversione che non raggiunge mai il provider (HTTP `504`), restituisce `credits_refunded` nel corpo dell'errore. L'[API Retrieve Voice Changer](/it/api-reference/endpoint/audio/voice-changer/retrieve) descrive quando quel flag è false e cosa ti indica di fare la stringa `error`. Un nuovo polling restituisce lo stesso risultato.

Imposta `delete_media_on_completion` su `true` su retrieve per eliminare i media memorizzati nella stessa chiamata che restituisce l'audio. L'audio non potrà essere recuperato di nuovo in seguito. In alternativa, chiama [`POST /audio/voice-changer/complete`](/it/api-reference/endpoint/audio/voice-changer/complete) dopo aver salvato il file. È sicuro chiamare complete più di una volta.

## Esempio completo

Questo esempio richiede un preventivo per una durata indicativa di un minuto, carica un file, effettua polling finché l'audio non arriva o non trascorrono cinque minuti, e salva un MP3. La scadenza di cinque minuti vale solo per l'esempio. È possibile effettuare polling su un job per 24 ore con il `queue_id` salvato.

```python
import os
import time
from pathlib import Path

import requests

BASE_URL = "https://api.venice.ai/api/v1"
HEADERS = {"Authorization": f"Bearer {os.environ['VENICE_API_KEY']}"}
MODEL = "elevenlabs-voice-changer"
# Length you expect to send. The charge uses the length Venice measures.
EXPECTED_DURATION_SECONDS = 60

source = Path("source-recording.mp3")

quote = requests.post(
    f"{BASE_URL}/audio/voice-changer/quote",
    json={"model": MODEL, "duration_seconds": EXPECTED_DURATION_SECONDS},
)
quote.raise_for_status()
print(f"Estimated cost: ${quote.json()['quote']:.2f}")

with source.open("rb") as audio:
    queued = requests.post(
        f"{BASE_URL}/audio/voice-changer/queue",
        headers=HEADERS,
        data={"model": MODEL, "voice": "Aria"},
        files={"file": audio},
    )
queued.raise_for_status()
job = queued.json()
print(f"Queued {job['queue_id']} ({job['duration_seconds']}s billed)")

deadline = time.monotonic() + 5 * 60
while time.monotonic() < deadline:
    result = requests.post(
        f"{BASE_URL}/audio/voice-changer/retrieve",
        headers=HEADERS,
        json={"model": job["model"], "queue_id": job["queue_id"]},
    )
    if not result.ok:
        body = result.json()
        print(body.get("error"))
        if "credits_refunded" in body:
            print(f"credits_refunded: {body['credits_refunded']}")
        raise SystemExit(1)

    content_type = result.headers.get("Content-Type", "").split(";")[0].strip()
    if content_type == "audio/mpeg":
        output = Path("converted-audio.mp3")
        output.write_bytes(result.content)
        print(f"Saved {output}")
        break

    status = result.json()
    if status.get("status") != "PROCESSING":
        print(status)
        raise SystemExit(1)

    remaining_ms = status["average_execution_time"] - status["execution_duration"]
    time.sleep(min(max(remaining_ms / 1000, 1), 15))
else:
    raise SystemExit("Still processing. Poll retrieve again with the saved queue_id.")

requests.post(
    f"{BASE_URL}/audio/voice-changer/complete",
    headers=HEADERS,
    json={"model": job["model"], "queue_id": job["queue_id"]},
).raise_for_status()
```

## Parametri API

### Queue

| Campo | Tipo | Obbligatorio | Descrizione |
|---|---|---|---|
| `model` | string | Sì | ID del modello voice-changer. |
| `file` | file | Uno tra `file` e `audio_url` | Upload multipart della registrazione sorgente. Si esclude a vicenda con `audio_url`. |
| `audio_url` | string | Uno tra `file` e `audio_url` | URL pubblico `http` o `https` della registrazione sorgente, in un corpo JSON. Si esclude a vicenda con `file`. |
| `voice` | string | No | Un nome da `voices`, oppure un Voice ID del provider quando `supports_custom_voice_id` è true. Il valore predefinito è `default_voice`. |
| `remove_background_noise` | boolean | No | Rimuove il rumore di fondo prima della conversione. Invialo solo quando il modello ne segnala il supporto. Il formato multipart accetta `true` o `false`. |
| `seed` | integer | No | Intero ≥ 0, per un risultato riproducibile. Invialo solo quando il modello ne segnala il supporto. |

### Retrieve e complete

| Campo | Tipo | Obbligatorio | Predefinito | Descrizione |
|---|---|---|---|---|
| `model` | string | Sì | - | `model` dalla risposta della coda. |
| `queue_id` | string | Sì | - | `queue_id` dalla risposta della coda. |
| `delete_media_on_completion` | boolean | No | `false` | Su retrieve, elimina i media memorizzati quando questa chiamata restituisce l'audio. |

## Errori comuni

Gli esiti terminali di retrieve, incluso `credits_refunded`, sono documentati nell'[API Retrieve Voice Changer](/it/api-reference/endpoint/audio/voice-changer/retrieve).

| Stato | Causa | Soluzione |
|---|---|---|
| `400` | Campo non supportato, voce sconosciuta, contenitore non accettato, audio illeggibile, una traccia video, oppure un `queue_id` sconosciuto, di un altro account o scaduto | Controlla i metadati del modello, invia una sola sorgente ed effettua polling con il `queue_id` restituito per il tuo account. |
| `401` | Chiave API non valida, oppure un modello riservato agli utenti Pro | Controlla la chiave su [venice.ai/settings/api](https://venice.ai/settings/api). |
| `402` con `"error": "Authentication required"` | Nessuna chiave API inviata | Invia `Authorization: Bearer $VENICE_API_KEY`. |
| `402` | Saldo insufficiente | Ricarica il tuo saldo Venice. |
| `413` | File più grande di 25 MB | Usa un file più piccolo. Rifiutato prima di qualsiasi addebito. |
| `422` | Durata superiore a `max_source_audio_duration_seconds` | Accorcia la registrazione. Il corpo riporta il valore massimo. Rifiutato prima di qualsiasi addebito. |
| `429` | Limite di frequenza superato | Riprova dopo il reset della finestra del limite di frequenza. |
| `503` | Modello al limite della capacità | Riprova più tardi. |

## Consigli per la produzione

- Annota il `queue_id` prima di analizzare il resto della risposta della coda.
- Confronta il `duration_seconds` misurato con il preventivo prima di considerare la stima come l'addebito effettivo.
- Carica il file, oppure passa un URL pubblico che non richieda header nella richiesta.
- Chiama complete dopo che l'MP3 è stato salvato su disco. `delete_media_on_completion: true` su retrieve esegue questa pulizia nella chiamata di download.
