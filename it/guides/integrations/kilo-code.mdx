[Kilo Code](https://kilo.ai/) è un agente di coding AI open source per VS Code e il terminale. Venice è disponibile come **provider nativo**, quindi puoi selezionare i modelli Venice senza configurare un endpoint personalizzato compatibile con OpenAI.

## Prerequisiti

- Una API key Venice da [venice.ai/settings/api](https://venice.ai/settings/api)
- [Kilo Code per VS Code](https://marketplace.visualstudio.com/items?itemName=kilocode.Kilo-Code) e/o la [CLI di Kilo](https://kilo.ai/docs/code-with-ai/platforms/cli)

---

## Configurazione

<Tabs>
  <Tab title="VS Code">
    <Steps>
      <Step title="Installa Kilo Code">
        In VS Code, apri **Extensions**, cerca **Kilo Code** e installalo dal [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=kilocode.Kilo-Code).

        Preferisci il canale **Pre-Release** del Marketplace quando è la build attualmente consigliata — vedi la [documentazione di installazione di Kilo](https://kilo.ai/docs/getting-started/installing).
      </Step>

      <Step title="Ottieni la tua API key Venice">
        Genera una chiave da [venice.ai/settings/api](https://venice.ai/settings/api). Copiala immediatamente e conservala in modo sicuro.
      </Step>

      <Step title="Aggiungi il provider Venice">
        Apri le **Settings** di Kilo (icona a forma di ingranaggio) e vai alla scheda **Providers**. Seleziona **Venice AI** e incolla la tua API key Venice.

        L'estensione salva il provider nel tuo file di configurazione `kilo.json`. Puoi anche modificare quel file direttamente — vedi la scheda **CLI** per il formato.
      </Step>

      <Step title="Seleziona un modello e testa">
        Scegli un modello Venice dal selettore dei modelli, poi invia un piccolo task come:

        ```txt
        Review the current file and suggest one safe improvement.
        ```

        Sfoglia gli ID disponibili nel [catalogo dei modelli di testo](/models/text).
      </Step>
    </Steps>
  </Tab>

  <Tab title="CLI">
    <Steps>
      <Step title="Installa la CLI di Kilo">
        ```bash
        npm install -g @kilocode/cli
        kilo --version
        ```

        Consulta la [documentazione della CLI di Kilo](https://kilo.ai/docs/code-with-ai/platforms/cli) per altre opzioni di installazione.
      </Step>

      <Step title="Imposta la tua API key Venice">
        Esporta la chiave nella shell in cui esegui Kilo:

        ```bash
        export VENICE_API_KEY="your-api-key"
        ```
      </Step>

      <Step title="Configura il provider Venice">
        Crea o modifica `~/.config/kilo/kilo.json` (globale) o `./kilo.json` (di progetto):

        ```json
        {
          "provider": {
            "venice": {
              "env": ["VENICE_API_KEY"]
            }
          },
          "model": "venice/zai-org-glm-5-1"
        }
        ```

        Sostituisci `zai-org-glm-5-1` con qualsiasi ID modello dal [catalogo dei modelli di testo](/models/text). I riferimenti ai modelli di Kilo usano il formato `venice/<model-id>`.
      </Step>

      <Step title="Avvia Kilo">
        Dalla directory del tuo progetto:

        ```bash
        kilo
        ```

        Seleziona un modello Venice dal selettore dei modelli se non hai impostato un `model` predefinito, poi invia un breve prompt di test.
      </Step>
    </Steps>
  </Tab>
</Tabs>

## Verifica l'API di Venice

Se Kilo non riesce a connettersi, verifica la chiave e gli ID dei modelli in modo indipendente:

```bash
curl https://api.venice.ai/api/v1/models \
  -H "Authorization: Bearer $VENICE_API_KEY"
```

Copia l'`id` di un modello esattamente in Kilo. Nella configurazione CLI, aggiungi il prefisso `venice/`, ad esempio `venice/zai-org-glm-5-1`.

---

## Note di configurazione

- Venice è un provider **nativo** di Kilo. Nelle impostazioni Providers, preferisci **Venice AI** rispetto a un endpoint personalizzato generico compatibile con OpenAI.
- L'estensione e la CLI condividono gli stessi file di configurazione (`~/.config/kilo/kilo.json` globalmente, oppure `./kilo.json` in un progetto).
- Alcuni modelli Venice espongono controlli di reasoning. Kilo mappa le opzioni supportate di reasoning effort e di disable-thinking quando il modello selezionato le supporta.
- Gli ID dei modelli e l'accesso in base al piano possono cambiare. Usa il selettore dei modelli, il [catalogo dei modelli di testo](/models/text) o `GET /models` per l'elenco aggiornato.
- Mantieni privata la tua API key Venice. Non incollarla nei file sorgente e non committarla su git.

## Risoluzione dei problemi

<AccordionGroup>
  <Accordion title="API key non valida o 401">
    Verifica che la chiave provenga da [venice.ai/settings/api](https://venice.ai/settings/api). Per la CLI, controlla che `VENICE_API_KEY` sia impostata nello stesso ambiente che avvia Kilo. In VS Code, riconnetti Venice AI nella sezione **Providers**.
  </Accordion>
  <Accordion title="Modello non disponibile">
    Verifica che il tuo account Venice abbia accesso al modello selezionato, copia l'ID dal [catalogo dei modelli di testo](/models/text) o da `GET /models`, e per la configurazione CLI usa la forma `venice/<model-id>`.
  </Accordion>
  <Accordion title="Impostazioni del provider non trovate nell'estensione">
    Aggiorna alla build di Kilo attualmente consigliata (incluso il canale Pre-Release quando è quello predefinito documentato). Puoi anche impostare il provider in `kilo.json` come mostrato nella scheda CLI — l'estensione legge la stessa configurazione.
  </Accordion>
</AccordionGroup>
