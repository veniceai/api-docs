[OpenCode](https://opencode.ai/) è un agente di programmazione AI per il terminale. OpenCode include già un provider Venice AI, quindi ti colleghi con un solo comando e scegli un modello dall'intero catalogo Venice. Non serve alcun file di configurazione.

<Note>
  Questa guida segue OpenCode 1, la versione configurata dall'installer standard. Anche OpenCode 2 include Venice AI, con alcune etichette diverse. Vedi [OpenCode 2](#opencode-2).
</Note>

## Prerequisiti {#prerequisites}

- Una API key Venice da [venice.ai/settings/api](https://venice.ai/settings/api?utm_source=venice-api-documentation)
- OpenCode installato e funzionante sulla tua macchina

---

## Configurazione {#setup}

<Steps>
  <Step title="Collega Venice AI">
    Avvia OpenCode ed esegui il comando di connessione:

    ```txt
    /connect
    ```

    Cerca **Venice AI** e selezionalo.

    <Frame as="div">
      <img
        src="/images/guides/opencode/connect-venice.png"
        alt="La palette /connect di OpenCode filtrata su Venice AI"
      />
    </Frame>
  </Step>

  <Step title="Incolla la tua API key Venice">
    Incolla la chiave nel campo **API key** e premi Invio.

    OpenCode salva la credenziale in `~/.local/share/opencode/auth.json`, quindi resta disponibile in tutti i progetti.
  </Step>

  <Step title="Scegli un modello">
    Esegui il comando dei modelli e scegli un modello Venice:

    ```txt
    /models
    ```

    `z-ai-glm-5-3-flash` è una buona scelta predefinita per il coding: veloce, economico e con una finestra di contesto da 1M token. Vedi [ID dei modelli](#model-ids) per altre opzioni.

    OpenCode elenca anche il proprio livello gratuito ospitato con nomi simili, ad esempio **GLM-5.3-Flash Free** di **OpenCode** accanto a **GLM 5.3 Flash** di **Venice AI**. Il nome del provider nella colonna di destra li distingue, e la riga di Venice AI è quella che usa la tua chiave e i tuoi crediti.
  </Step>
</Steps>

Invia un piccolo task per verificare l'intero percorso, ad esempio:

```txt
Review the current file and suggest one safe improvement.
```

## Imposta un modello predefinito {#pin-a-default-model}

Dopo la connessione, OpenCode può avviare le nuove sessioni su un modello instradato come Claude Sonnet 4.6, che costa più dei modelli in [ID dei modelli](#model-ids). Per scegliere il modello con cui OpenCode si avvia, aggiungilo a `opencode.json` nella root del progetto (o a `~/.config/opencode/opencode.json` per un valore predefinito globale):

```json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "venice/z-ai-glm-5-3-flash",
  "small_model": "venice/z-ai-glm-5-3-flash"
}
```

I riferimenti ai modelli usano la forma `venice/<model-id>`, e `small_model` imposta il modello più economico per le attività in background.

## Collegarsi senza `/connect` {#connect-without-/connect}

Il provider incluso legge anche `VENICE_API_KEY` dall'ambiente. Esportala prima di avviare OpenCode e i modelli Venice AI compariranno in `/models` senza eseguire `/connect`:

```bash
export VENICE_API_KEY="your-api-key"
```

Su una build di OpenCode precedente al provider incluso, o per fissare l'elenco dei modelli mostrati da OpenCode, configura Venice come provider compatibile con OpenAI in `opencode.json`. Mantieni `VENICE_API_KEY` esportata:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "venice/z-ai-glm-5-3-flash",
  "small_model": "venice/z-ai-glm-5-3-flash",
  "provider": {
    "venice": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Venice AI",
      "options": {
        "baseURL": "https://api.venice.ai/api/v1",
        "apiKey": "{env:VENICE_API_KEY}"
      },
      "models": {
        "z-ai-glm-5-3-flash": {
          "name": "GLM 5.3 Flash"
        },
        "kimi-k2-6": {
          "name": "Kimi K2.6"
        },
        "minimax-m25": {
          "name": "MiniMax M2.5"
        }
      }
    }
  }
}
```

Elenca in `models` i modelli che vuoi. OpenCode mostra solo le voci dichiarate qui per questo provider. Nelle build con il provider incluso, la sola variabile d'ambiente ti dà già l'intero catalogo.

## OpenCode 2 {#opencode-2}

OpenCode 2 è una linea di rilascio separata con un proprio installer:

```bash
curl -fsSL https://opencode.ai/v2/install | bash
```

Include un provider Venice AI nativo, e la configurazione descritta sopra funziona con alcune differenze:

- La finestra di `/connect` si intitola **Connect an integration**. Cerca **Venice AI** in **Services**, poi incolla la tua chiave nella finestra **Connect Venice AI**.
- Esportare `VENICE_API_KEY` prima dell'avvio abilita il provider anche senza `/connect`.
- Senza un modello fissato, OpenCode 2 può anche avviarsi con un modello instradato, come Claude Fable 5.2.
- Gli esempi di `opencode.json` in questa pagina continuano a funzionare, perché OpenCode 2 legge ancora il formato di configurazione di OpenCode 1. Nella configurazione nativa di OpenCode 2, imposta il modello in background con `agents.title.model` invece di `small_model`. Consulta la [guida alla migrazione](https://opencode.ai/docs/migrate-v1) di OpenCode per il resto del formato nativo.

## ID dei modelli {#model-ids}

Alcuni modelli Venice che funzionano bene in un agente di coding. Il catalogo cambia, quindi usa [`GET /models?type=text`](/it/api-reference/endpoint/models/list) per l'elenco aggiornato.

| Modello | ID Venice |
|-------|-----------|
| GLM 5.3 Flash | `z-ai-glm-5-3-flash` |
| GLM 5.3 | `z-ai-glm-5-3` |
| Kimi K2.6 | `kimi-k2-6` |
| MiniMax M2.5 | `minimax-m25` |
| DeepSeek V4.1 Flash | `deepseek-v4-1-flash` |

I modelli open-weight come questi vengono eseguiti in modo completamente privato. I modelli instradati di Anthropic, OpenAI e Google vengono eseguiti in forma anonimizzata, quindi il laboratorio di origine non vede mai la tua identità.

## Note di configurazione {#config-notes}

- Mantieni `baseURL` impostato su `https://api.venice.ai/api/v1` nel blocco del provider manuale. Il provider incluso punta già lì.
- L'ID del provider è `venice`, quindi i riferimenti ai modelli usano la forma `venice/<model-id>` in entrambi i percorsi.
- Esegui di nuovo `/connect` in qualsiasi momento per sostituire la chiave Venice salvata.
- Amplia il contesto quando il modello lo supporta: diversi modelli Venice accettano 1M token.

## Risoluzione dei problemi {#troubleshooting}

<AccordionGroup>
  <Accordion title="Venice AI non compare in /connect">
    Aggiorna OpenCode all'ultima versione 1.x con `opencode upgrade`. Il provider Venice AI è incluso nelle build attuali, quindi un'installazione più vecchia potrebbe offrire solo la configurazione manuale descritta sopra.
  </Accordion>
  <Accordion title="API key non valida o 401">
    Verifica che la chiave provenga da [venice.ai/settings/api](https://venice.ai/settings/api?utm_source=venice-api-documentation), poi esegui `/connect`, seleziona **Venice AI** e incollala di nuovo. Quando la chiave salvata non è più valida, OpenCode segnala un errore di autenticazione invece di raggiungere Venice.
  </Accordion>
  <Accordion title="Modello non disponibile">
    Copia l'ID esattamente da [ID dei modelli](#model-ids), dal [catalogo dei modelli di testo](/it/models/text) o da `GET /models`, e verifica che il tuo account Venice vi abbia accesso.
  </Accordion>
  <Accordion title="Ancora bloccato? Guarda cosa invia l'agente">
    Esegui il [proxy di debug locale](/it/learn/local-debug-proxy) tra OpenCode e Venice per registrare ogni richiesta e risposta, inclusi l'ID del modello, gli strumenti e il corpo di errore che l'agente ha effettivamente inviato, oltre agli ultimi quattro caratteri della chiave usata.
  </Accordion>
</AccordionGroup>
