Quando si verifica un errore, l'API Venice restituisce un codice di stato HTTP e un messaggio descrittivo. Alcuni errori includono anche campi aggiuntivi, come lo stato del rimborso, modelli di retry suggeriti, dettagli di validazione o ID di richiesta.

## Formato della risposta di errore

La maggior parte degli errori restituisce un campo `error` con un messaggio leggibile:

```json
{
  "error": "Invalid request parameters"
}
```

Alcuni endpoint includono campi aggiuntivi specifici dell'endpoint. Ad esempio, gli errori di moderazione video possono indicare se i crediti sono stati rimborsati:

```json
{
  "error": "Your generation was blocked due to the model provider's content policies. Credits have been refunded.",
  "credits_refunded": true
}
```

Gli errori di validazione possono includere i campi `details` e `issues` con informazioni di validazione a livello di campo:

```json
{
  "error": "Invalid request parameters",
  "details": {
    "_errors": [],
    "field": {
      "_errors": ["Field is required"]
    }
  },
  "issues": []
}
```

Alcuni endpoint compatibili con OpenAI possono restituire oggetti di errore in stile OpenAI per casi specifici, come gli errori di lunghezza del contesto:

```json
{
  "error": {
    "message": "Your request exceeds the model's maximum context. Please reduce your prompt or completion length.",
    "type": "invalid_request_error",
    "param": "messages",
    "code": "context_length_exceeded"
  }
}
```

## Credenziali mancanti

Una richiesta senza credenziali restituisce `402 Payment Required`, non `401`. Ogni route a pagamento accetta anche l'[autenticazione tramite wallet x402](/it/guides/integrations/x402-venice-api), quindi la risposta è una richiesta di pagamento: include un header `PAYMENT-REQUIRED` e un body che descrive entrambi i modi per autenticarsi.

```json
{
  "x402Version": 2,
  "error": "Authentication required",
  "accepts": [ ... ],
  "authOptions": {
    "apiKey": {
      "header": "Authorization: Bearer YOUR_API_KEY",
      "getKey": "https://venice.ai/settings/api"
    },
    "x402Wallet": {
      "header": "SIGN-IN-WITH-X",
      "topUp": "POST /api/v1/x402/top-up"
    }
  }
}
```

Se intendevi usare una chiave API, verifica che l'header `Authorization: Bearer` sia impostato. Una chiave presente ma non valida restituisce `401`.

## Errori di formato della richiesta

Questi errori derivano dalla lettura del body della richiesta, prima che venga eseguita qualsiasi validazione specifica dell'endpoint.

| Stato HTTP | Messaggio | Causa |
| --- | --- | --- |
| 400 | `'Content-Type' must be 'application/json'` | Un body `POST`, `PUT` o `PATCH` inviato senza `Content-Type: application/json`. Gli endpoint che accettano upload di file accettano anche `multipart/form-data` |
| 400 | `Invalid JSON request` | Il body non è un JSON valido |
| 400 | `Invalid multipart request: malformed part header` | Un body `multipart/form-data` che non può essere analizzato |
| 413 | `Request body exceeds the maximum allowed size.` | Il body della richiesta è troppo grande |
| 415 | `Request encoding is not supported` | Un `Content-Encoding` o un charset che l'API non riesce a decodificare |

Un `Content-Type` errato restituisce `400`, non `415`. Le risposte `413` per il limite di dimensione includono anche un campo `code`:

```json
{
  "code": "PAYLOAD_TOO_LARGE",
  "error": "Request body exceeds the maximum allowed size."
}
```

## Altri errori

La tabella precedente non è esaustiva. Alcuni errori vengono restituiti senza un codice elencato e i messaggi possono variare in base al modello e all'endpoint, quindi basa la logica sullo stato HTTP anziché sul testo del messaggio. Errori che potresti incontrare e che non sono nella tabella:

| Stato HTTP | Quando si verifica |
| --- | --- |
| 400 | Un'immagine in input in una richiesta chat o Responses è in un formato non supportato |
| 400 | La voce richiesta non è disponibile per il modello text-to-speech |
| 403 | La richiesta proviene da un indirizzo IP che non è nella allowlist della chiave API |
| 403 | Il modello richiesto non è consentito dall'impostazione di privacy della chiave API |
| 403 | L'accesso al modello richiesto è limitato. Contatta support@venice.ai |
| 409 | Un risultato video, musicale o di voice changer è ancora in fase di upload quando lo recuperi. Riprova a breve |
| 410 | L'endpoint è stato dismesso |
| 422 | L'audio è troppo lungo o troppo corto (voice cloning, voice changer e job audio) |
| 422 | L'immagine in input di una richiesta video ha un rapporto larghezza/altezza al di fuori dell'intervallo accettato dal modello |
| 422 | L'input di una richiesta video è stato bloccato dalla moderazione dei contenuti |
| 500 | La generazione video o di voice changer non è riuscita |
| 502 | La sintesi vocale non è riuscita a monte, oppure non è stato possibile recuperare un video generato. Riprova la richiesta |
