Quando si verifica un errore, l'API Venice restituisce un codice di stato HTTP e un messaggio descrittivo. Alcuni errori includono anche campi aggiuntivi, come lo stato del rimborso, modelli di retry suggeriti, dettagli di validazione o ID di richiesta.

## Formato della risposta di errore

La maggior parte degli errori restituisce un campo `error` con un messaggio leggibile:

```json
{
  "error": "Invalid request parameters"
}
```

Alcuni endpoint includono campi aggiuntivi specifici dell'endpoint. Ad esempio, gli errori di moderazione video possono indicare se i crediti sono stati rimborsati:

```json
{
  "error": "Your generation was blocked due to the model provider's content policies. Credits have been refunded.",
  "credits_refunded": true
}
```

Gli errori di validazione possono includere i campi `details` e `issues` con informazioni di validazione a livello di campo:

```json
{
  "error": "Invalid request parameters",
  "details": {
    "_errors": [],
    "field": {
      "_errors": ["Field is required"]
    }
  },
  "issues": []
}
```

Alcuni endpoint compatibili con OpenAI possono restituire oggetti di errore in stile OpenAI per casi specifici, come gli errori di lunghezza del contesto:

```json
{
  "error": {
    "message": "Your request exceeds the model's maximum context. Please reduce your prompt or completion length.",
    "type": "invalid_request_error",
    "param": "messages",
    "code": "context_length_exceeded"
  }
}
```

## Credenziali mancanti

Una richiesta senza credenziali restituisce `402 Payment Required`, non `401`. La maggior parte delle route a pagamento accetta anche l'[autenticazione tramite wallet x402](/it/guides/integrations/x402-venice-api), quindi la risposta è una richiesta di pagamento: include un header `PAYMENT-REQUIRED` e un body che descrive entrambi i modi per autenticarsi. Le route di video e voice changer inviano la stessa richiesta, ma al momento accettano solo una chiave API.

```json
{
  "x402Version": 2,
  "error": "Authentication required",
  "accepts": [ ... ],
  "authOptions": {
    "apiKey": {
      "header": "Authorization: Bearer YOUR_API_KEY",
      "getKey": "https://venice.ai/settings/api"
    },
    "x402Wallet": {
      "header": "SIGN-IN-WITH-X",
      "topUp": "POST /api/v1/x402/top-up"
    }
  }
}
```

Se un `402` su una route a pagamento ti sorprende, di solito è dovuto all'header delle credenziali mancante e non a un problema di fatturazione. Un body con `x402Version` e `accepts` significa che nulla ha autenticato la richiesta: imposta `Authorization: Bearer $VENICE_API_KEY` e riprova. Il campo `authOptions.apiKey.header` nel body indica la forma esatta dell'header.

Un `402` che dice "Insufficient USD or Diem balance" (`INSUFFICIENT_BALANCE` nella tabella qui sotto) è diverso: quello riguarda il saldo dell'account. Vedi [pagare l'utilizzo](/pricing#paying-for-usage).

Una chiave presente ma non valida restituisce `401`.

## Errori di formato della richiesta

Questi errori derivano dalla lettura del body della richiesta, prima che venga eseguita qualsiasi validazione specifica dell'endpoint.

| Stato HTTP | Messaggio | Causa |
| --- | --- | --- |
| 400 | `'Content-Type' must be 'application/json'` | Un body `POST`, `PUT` o `PATCH` inviato senza `Content-Type: application/json`. Gli endpoint che accettano upload di file accettano anche `multipart/form-data` |
| 400 | `Invalid JSON request` | Il body non è un JSON valido |
| 400 | `Invalid multipart request: malformed part header` | Un body `multipart/form-data` che non può essere analizzato |
| 413 | `Request body exceeds the maximum allowed size.` | Il body della richiesta è troppo grande |
| 415 | `Request encoding is not supported` | Un `Content-Encoding` o un charset che l'API non riesce a decodificare |

Un `Content-Type` errato restituisce `400`, non `415`. Le risposte `413` per il limite di dimensione includono anche un campo `code`:

```json
{
  "code": "PAYLOAD_TOO_LARGE",
  "error": "Request body exceeds the maximum allowed size."
}
```

## Codici di errore

I codici in questa tabella danno un nome a ogni errore come riferimento. La maggior parte delle risposte non li include: il corpo contiene solo il messaggio in `error`. Fanno eccezione le risposte `413` e gli errori del wallet x402, che aggiungono un campo `code`. Basa la logica sullo stato HTTP e non confrontare il testo del messaggio, che può variare.

| Codice di errore | Stato HTTP | Messaggio | Cosa fare |
| --- | --- | --- | --- |
| `AUTHENTICATION_FAILED` | 401 | Authentication failed | Controlla l'header `Authorization: Bearer` e che la chiave non sia stata eliminata o non sia scaduta. Anche gli endpoint di gestione dell'account e delle chiavi rispondono con questo codice a una chiave Inference; lì usa una chiave Admin. |
| `AUTHENTICATION_FAILED_INACTIVE_KEY` | 401 | Authentication failed - Pro subscription is inactive. Please upgrade your subscription to continue using the API | L'account della chiave non può usare l'API. Accedi a venice.ai per controllare l'account o contatta support@venice.ai. |
| `X402_INVALID_SIGN_IN` | 401 | Invalid Sign-in-with-x signature | Firma una nuova prova `SIGN-IN-WITH-X` con il nonce dell'ultima challenge `402`. Vedi [x402](/it/guides/integrations/x402-venice-api). |
| `X402_USER_NOT_ALLOWED` | 401 | Wallet user is not allowed to authenticate | L'account Venice del wallet è bannato o eliminato, oppure i suoi crediti appartengono a un altro utente. Usa un wallet diverso. |
| `PRO_ONLY_MODEL` | 401 | This model is only available to Pro users | Usa un modello incluso nel tuo piano o passa a un piano a pagamento. |
| `INSUFFICIENT_BALANCE` | 402 | Insufficient USD or Diem balance to complete request. Visit https://venice.ai/settings/api to add credits. | Aggiungi crediti o fai staking di [DIEM](/it/overview/vvv-diem), poi riprova. |
| `API_KEY_DIEM_SPEND_LIMIT_EXCEEDED` | 402 | API key DIEM spend limit exceeded. Your account may still have DIEM balance, but this API key has reached its configured DIEM spending limit. | Aumenta o rimuovi il limite DIEM della chiave, oppure attendi il reset del suo periodo di limite. |
| `API_KEY_USD_SPEND_LIMIT_EXCEEDED` | 402 | API key USD spend limit exceeded. Your account may still have USD balance, but this API key has reached its configured USD spending limit. | Aumenta o rimuovi il limite USD della chiave, oppure attendi il reset del suo periodo di limite. |
| `UNAUTHORIZED` | 403 | Unauthorized access | Leggi il messaggio, che indica cosa ha bloccato la richiesta, ad esempio la tua regione. |
| `API_ACCESS_DISABLED` | 403 | API access has been disabled for this account. Please contact support@venice.ai | Contatta support@venice.ai. |
| `X402_WALLET_MISMATCH` | 403 | You can only access resources for your own wallet | Richiedi il saldo o le transazioni del wallet con cui hai effettuato l'accesso. |
| `INVALID_REQUEST` | 400 | Invalid request parameters | Correggi i campi indicati in `details`, `issues` o nel messaggio. |
| `INVALID_MODEL` | 400 | Invalid model specified | Usa un modello che supporta questo endpoint. `GET /models` elenca le capacità di ogni modello. |
| `REQUEST_ID_NOT_FOUND` | 400 | Request ID is invalid. | Verifica che l'ID della coda e il modello corrispondano a un job che hai accodato. |
| `INVALID_AUDIO_FORMAT` | 400 | Invalid audio format. Supported formats are WAV and MP3. | Converti l'audio in un formato accettato dall'endpoint. |
| `INVALID_VIDEO_FORMAT` | 400 | Invalid video format. Supported formats include MP4, MOV, WebM, MKV, AVI, and others. | Converti il video in un formato supportato, come MP4. |
| `CORRUPTED_IMAGE` | 400 | The image file is corrupted or unreadable | Ricodifica l'immagine o invia un file diverso. |
| `IMAGE_TOO_SMALL` | 400 | Image dimensions are too small | Invia un'immagine più grande. |
| `TOO_MANY_TOKENS` | 400 | Your request exceeds the model's maximum context. Please reduce your prompt or completion length. | Accorcia i messaggi o riduci `max_tokens`. `GET /models` elenca la dimensione del contesto di ogni modello. |
| `CHARACTER_NOT_FOUND` | 404 | No character could be found from the provided `character_slug` | Usa uno slug da [`GET /characters`](/it/api-reference/endpoint/characters/list). |
| `MODEL_NOT_FOUND` | 404 | Specified model not found | Usa un ID attuale da `GET /models`. I modelli ritirati sono elencati in [Deprecazioni](/it/overview/deprecations). |
| `MEDIA_NOT_FOUND` | 404 | Media could not be found. Request may be invalid, expired, or deleted. | Il risultato è scaduto o è stato eliminato. Accoda di nuovo il job. |
| `PAYLOAD_TOO_LARGE` | 413 | The request payload is too large. Please reduce the size of your request. | Invia un corpo o un file più piccolo. |
| `INVALID_CONTENT_TYPE` | 415 | Invalid request content-type. Returned only by `/image/multi-edit` | Invia `multipart/form-data` o `application/json`. |
| `VIDEO_DURATION_TOO_LONG` | 422 | Video duration exceeds the maximum allowed. | Usa una durata che il modello elenca in `GET /models?type=video`. |
| `VIDEO_DURATION_TOO_SHORT` | 422 | Video duration is too short. | Usa una durata che il modello elenca in `GET /models?type=video`. |
| `IMAGE_TOO_LARGE` | 422 | Image dimensions exceed the maximum allowed. | Riduci le dimensioni dell'immagine. |
| `CONTENT_POLICY_VIOLATION` | 422 | Your prompt violates the content policy of Venice.ai or the model provider | Modifica il prompt o usa un altro modello. Le policy variano in base al modello e al provider. |
| `ASR_UPSTREAM_VALIDATION_FAILED` | 422 | The audio could not be processed for transcription. Common causes: zero-length, silent, corrupt, or unsupported-language audio. Please verify the file and retry. | Verifica che l'audio non sia vuoto, silenzioso o corrotto e che la sua lingua sia supportata. |
| `RATE_LIMIT_EXCEEDED` | 429 | Rate limit exceeded | Attendi fino a `x-ratelimit-reset-requests`, poi riprova. Vedi [Rate limit](/it/api-reference/rate-limiting). |
| `MODEL_OVERLOADED` | 429 | The model is currently overloaded. Please try again later. | Riprova dopo l'header `Retry-After` o cambia modello. |
| `INFERENCE_FAILED` | 500 | Inference processing failed | Riprova con backoff. Le richieste non riuscite contano ai fini del [budget di errore](/it/api-reference/rate-limiting#budget-di-errore). |
| `UPSCALE_FAILED` | 500 | Image upscaling failed | Riprova con backoff. |
| `IMAGE_EDIT_ERROR` | 500 | Image edit failed | Riprova con backoff. |
| `UNKNOWN_ERROR` | 500 | An unknown error occurred | Riprova con backoff. Se il problema persiste, contatta support@venice.ai. |
| `TEE_ATTESTATION_FAILED` | 502 | TEE attestation request failed. The Trusted Execution Environment provider may be temporarily unavailable. | Riprova più tardi. |
| `TEE_SIGNATURE_FAILED` | 502 | TEE signature request failed. The Trusted Execution Environment provider may be temporarily unavailable. | Riprova più tardi. |
| `ASR_UPSTREAM_FAILED` | 502 | Audio transcription failed due to a temporary upstream error. Please retry. | Ripeti la richiesta. |
| `MODEL_OFFLINE` | 503 | The model is temporarily offline. Please try again later. | Riprova più tardi o cambia modello. |
| `MODEL_AT_CAPACITY` | 503 | The model is at capacity. Please try again later. | Riprova più tardi o cambia modello. |
| `REQUEST_TIMEOUT` | 504 | The request took too long to complete and was timed-out. For non-streaming requests, use the streaming API by setting `stream=true`. A streaming chat completion that times out before the model's first chunk reports the failure as an in-band SSE error frame instead. | Imposta `stream: true` o invia una richiesta più breve. |

## Altri errori

La tabella precedente non è esaustiva. Alcuni errori vengono restituiti senza un codice elencato e i messaggi possono variare in base al modello e all'endpoint, quindi basa la logica sullo stato HTTP anziché sul testo del messaggio. Errori che potresti incontrare e che non sono nella tabella:

| Stato HTTP | Quando si verifica |
| --- | --- |
| 400 | Un'immagine in input in una richiesta chat o Responses è in un formato non supportato |
| 400 | La voce richiesta non è disponibile per il modello text-to-speech |
| 403 | La richiesta proviene da un indirizzo IP che non è nella allowlist della chiave API |
| 403 | Il modello richiesto non è consentito dall'impostazione di privacy della chiave API |
| 403 | L'accesso al modello richiesto è limitato. Contatta support@venice.ai |
| 409 | Un risultato video, musicale o di voice changer è ancora in fase di upload quando lo recuperi. Riprova a breve |
| 410 | L'endpoint è stato dismesso |
| 422 | L'audio è troppo lungo o troppo corto (voice cloning, voice changer e job audio) |
| 422 | L'immagine in input di una richiesta video ha un rapporto larghezza/altezza al di fuori dell'intervallo accettato dal modello |
| 422 | L'input di una richiesta video è stato bloccato dalla moderazione dei contenuti |
| 500 | La generazione video o di voice changer non è riuscita |
| 502 | La sintesi vocale non è riuscita a monte, oppure non è stato possibile recuperare un video generato. Riprova la richiesta |
