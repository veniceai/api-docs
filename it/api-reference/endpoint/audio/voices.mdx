Carica un campione audio per creare un identificativo di voce clonata, quindi passalo come `voice` a [`/audio/speech`](/it/api-reference/endpoint/audio/speech) con lo stesso `model` usato per crearlo. Per una procedura dettagliata, consulta la [guida alla clonazione vocale](/it/guides/media/voice-cloning).
