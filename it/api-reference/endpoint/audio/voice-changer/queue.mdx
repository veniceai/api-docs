Chiama [`/audio/voice-changer/quote`](/it/api-reference/endpoint/audio/voice-changer/quote) per stimare il costo, quindi esegui il polling di [`/audio/voice-changer/retrieve`](/it/api-reference/endpoint/audio/voice-changer/retrieve) con il `queue_id` restituito finché la conversione non termina. Una conversione messa in coda è già stata addebitata. Se questa risposta viene persa, esegui il polling di retrieve invece di mettere di nuovo in coda. Se conservi i media convertiti dopo il recupero, chiama [`/audio/voice-changer/complete`](/it/api-reference/endpoint/audio/voice-changer/complete) una volta scaricati.

I modelli voice-changer non sono accettati su [`/audio/queue`](/it/api-reference/endpoint/audio/queue). Consulta la [guida Voice Changer](/it/guides/media/voice-changer) per una panoramica completa.
