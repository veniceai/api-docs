Se la risposta di `/video/queue` includeva un `download_url`, scarica il file finale da quell'URL (non come binario da questo endpoint). Altrimenti, questo endpoint restituisce il video. Consulta [Link di download privati](/it/guides/media/video-generation#link-di-download-privati) per scoprire come funziona il link, i retry e l'eventuale `DELETE`.
