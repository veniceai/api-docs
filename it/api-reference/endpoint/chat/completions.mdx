<Info>
  **I parametri specifici di Venice si trovano in [`venice_parameters`](#body-venice-parameters).** Questo endpoint è compatibile con OpenAI, ma l'oggetto `venice_parameters` sblocca funzionalità che non fanno parte dell'API standard di OpenAI, e molti integratori se le perdono:

  - **Ricerca web e citazioni** — `enable_web_search`, `enable_web_citations`, `enable_web_scraping`
  - **Personaggi** — `character_slug`
  - **Controllo del prompt di sistema** — `include_venice_system_prompt`
  - **Controlli del reasoning** — `disable_thinking`, `strip_thinking_response`
  - **Privacy** — `enable_e2ee`

  Consulta l'elenco completo nella sezione [`venice_parameters`](#body-venice-parameters) qui sotto.
</Info>
