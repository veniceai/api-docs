[OpenCode](https://opencode.ai/) 是一款运行在终端中的 AI 编程智能体。OpenCode 已内置 Venice AI 提供商，因此只需一条命令即可连接，并从完整的 Venice 目录中选择模型。无需任何配置文件。

<Note>
  本指南基于 OpenCode 1，即标准安装程序安装的版本。OpenCode 2 同样包含 Venice AI，只有少量标签变化。请参阅 [OpenCode 2](#opencode-2)。
</Note>

## 前置条件 {#prerequisites}

- 来自 [venice.ai/settings/api](https://venice.ai/settings/api?utm_source=venice-api-documentation) 的 Venice API 密钥
- 已在您的机器上安装并可正常使用的 OpenCode

---

## 设置 {#setup}

<Steps>
  <Step title="连接 Venice AI">
    启动 OpenCode 并运行连接命令：

    ```txt
    /connect
    ```

    搜索 **Venice AI** 并选择它。

    <Frame as="div">
      <img
        src="/images/guides/opencode/connect-venice.png"
        alt="OpenCode 的 /connect 面板筛选出 Venice AI"
      />
    </Frame>
  </Step>

  <Step title="粘贴你的 Venice API 密钥">
    将密钥粘贴到 **API key** 字段中，然后按回车。

    OpenCode 会将凭据保存在 `~/.local/share/opencode/auth.json` 中，因此它在每个项目中都可用。
  </Step>

  <Step title="选择模型">
    运行模型命令并选择一个 Venice 模型：

    ```txt
    /models
    ```

    `z-ai-glm-5-3-flash` 是编程的不错默认选择：速度快、价格低，并具备 1M token 上下文窗口。其他选项请参见 [模型 ID](#model-ids)。

    OpenCode 还会以相似的名称列出其自有的托管免费版本，例如来自 **OpenCode** 的 **GLM-5.3-Flash Free** 与来自 **Venice AI** 的 **GLM 5.3 Flash** 并列显示。右侧列中的提供商名称可用于区分，其中 Venice AI 这一行才会使用你的密钥和额度。
  </Step>
</Steps>

发送一个小任务以确认整个流程正常，例如：

```txt
Review the current file and suggest one safe improvement.
```

## 固定默认模型 {#pin-a-default-model}

连接后，OpenCode 可能会使用路由模型（例如 Claude Sonnet 4.6）启动新会话，其费用高于 [模型 ID](#model-ids) 中的模型。要指定 OpenCode 启动时使用的模型，请将其添加到项目根目录下的 `opencode.json` 中（或添加到 `~/.config/opencode/opencode.json` 作为全局默认值）：

```json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "venice/z-ai-glm-5-3-flash",
  "small_model": "venice/z-ai-glm-5-3-flash"
}
```

模型引用使用 `venice/<model-id>` 格式，`small_model` 用于为后台任务设置更便宜的模型。

## 不使用 `/connect` 连接 {#connect-without-/connect}

内置提供商也会从环境中读取 `VENICE_API_KEY`。在启动 OpenCode 之前导出该变量，无需运行 `/connect`，Venice AI 模型就会出现在 `/models` 中：

```bash
export VENICE_API_KEY="your-api-key"
```

如果你使用的 OpenCode 版本早于内置提供商，或希望固定 OpenCode 显示的模型列表，请在 `opencode.json` 中将 Venice 配置为 OpenAI 兼容提供商。请保持 `VENICE_API_KEY` 已导出：

```json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "venice/z-ai-glm-5-3-flash",
  "small_model": "venice/z-ai-glm-5-3-flash",
  "provider": {
    "venice": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Venice AI",
      "options": {
        "baseURL": "https://api.venice.ai/api/v1",
        "apiKey": "{env:VENICE_API_KEY}"
      },
      "models": {
        "z-ai-glm-5-3-flash": {
          "name": "GLM 5.3 Flash"
        },
        "kimi-k2-6": {
          "name": "Kimi K2.6"
        },
        "minimax-m25": {
          "name": "MiniMax M2.5"
        }
      }
    }
  }
}
```

在 `models` 中列出你需要的模型。OpenCode 只会显示此处为该提供商声明的条目。在包含内置提供商的版本中，仅设置环境变量即可获得完整目录。

## OpenCode 2 {#opencode-2}

OpenCode 2 是一条独立的发布线，有自己的安装程序：

```bash
curl -fsSL https://opencode.ai/v2/install | bash
```

它内置原生的 Venice AI 提供商，上述设置同样适用，但有以下几点不同：

- `/connect` 对话框的标题为 **Connect an integration**。在 **Services** 下搜索 **Venice AI**，然后在 **Connect Venice AI** 对话框中粘贴你的密钥。
- 在启动前导出 `VENICE_API_KEY`，也可以在不使用 `/connect` 的情况下启用该提供商。
- 如果没有固定模型，OpenCode 2 也可能以路由模型启动，例如 Claude Fable 5.2。
- 本页的 `opencode.json` 示例仍然可用，因为 OpenCode 2 仍会读取 OpenCode 1 的配置格式。在 OpenCode 2 的原生配置中，使用 `agents.title.model` 而不是 `small_model` 来设置后台模型。原生格式的其余内容请参阅 OpenCode 的[迁移指南](https://opencode.ai/docs/migrate-v1)。

## 模型 ID {#model-ids}

以下是一些适合在编程智能体中使用的 Venice 模型。目录会不断变化，请使用 [`GET /models?type=text`](/zh/api-reference/endpoint/models/list) 获取最新列表。

| 模型 | Venice ID |
|-------|-----------|
| GLM 5.3 Flash | `z-ai-glm-5-3-flash` |
| GLM 5.3 | `z-ai-glm-5-3` |
| Kimi K2.6 | `kimi-k2-6` |
| MiniMax M2.5 | `minimax-m25` |
| DeepSeek V4.1 Flash | `deepseek-v4-1-flash` |

此类开放权重模型完全以私密方式运行。来自 Anthropic、OpenAI 和 Google 的路由模型以匿名方式运行，因此上游实验室永远不会看到你的身份。

## 配置说明 {#config-notes}

- 在手动提供商配置块中，请保持 `baseURL` 为 `https://api.venice.ai/api/v1`。内置提供商已指向该地址。
- 提供商 ID 为 `venice`，因此在两种方式中模型引用都使用 `venice/<model-id>` 格式。
- 可随时再次运行 `/connect` 以替换已保存的 Venice 密钥。
- 在模型支持时扩大上下文：多个 Venice 模型支持 1M token。

## 故障排查 {#troubleshooting}

<AccordionGroup>
  <Accordion title="/connect 中没有 Venice AI">
    使用 `opencode upgrade` 将 OpenCode 更新到最新的 1.x 版本。当前版本已包含 Venice AI 提供商，较旧的安装可能只提供上文的手动配置方式。
  </Accordion>
  <Accordion title="API 密钥无效或返回 401">
    确认密钥来自 [venice.ai/settings/api](https://venice.ai/settings/api?utm_source=venice-api-documentation)，然后运行 `/connect`，选择 **Venice AI** 并重新粘贴密钥。当已保存的密钥失效时，OpenCode 会报告认证失败，而不会连接到 Venice。
  </Accordion>
  <Accordion title="模型不可用">
    从 [模型 ID](#model-ids)、[文本模型目录](/zh/models/text) 或 `GET /models` 中准确复制 ID，并确认你的 Venice 账户有权访问该模型。
  </Accordion>
  <Accordion title="仍然无法解决？查看智能体发送了什么">
    在 OpenCode 和 Venice 之间运行[本地调试代理](/zh/learn/local-debug-proxy)，记录每个请求和响应，包括智能体实际发送的模型 ID、工具和错误响应体，以及它所用密钥的最后四个字符。
  </Accordion>
</AccordionGroup>
