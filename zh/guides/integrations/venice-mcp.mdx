[Venice MCP Server](https://github.com/veniceai/venice-mcp-server) 是 Venice 的官方 [Model Context Protocol](https://modelcontextprotocol.io/) 服务器。它将 Venice API（聊天、图像、视频、音频、音乐、embeddings、web augment、character、加密货币 RPC 和 TEE 证明）以及账户操作（计费和 API 密钥）作为 **45 个工具**暴露给任何兼容 MCP 的 agent。

</Card>

## 快速入门

<Steps>
  <Step title="获取 Venice API 密钥">
    在 [venice.ai/settings/api](https://venice.ai/settings/api?utm_source=venice-api-documentation) 生成。分步说明见 [API 密钥指南](/guides/getting-started/generating-api-key)。
  </Step>

  <Step title="将 Venice 添加到 MCP 宿主配置">
    把下面的内容粘贴到 MCP 宿主的配置文件中：

    ```json
    {
      "mcpServers": {
        "venice": {
          "command": "npx",
          "args": ["-y", "@veniceai/mcp-server@0.3.0"],
          "env": { "VENICE_API_KEY": "<your-venice-api-key>" }
        }
      }
    }
    ```

    常见配置路径：

    | 宿主 | 路径 |
    |---|---|
    | Claude Desktop (macOS) | `~/Library/Application Support/Claude/claude_desktop_config.json` |
    | Claude Desktop (Windows) | `%APPDATA%\Claude\claude_desktop_config.json` |
    | Cursor | `~/.cursor/mcp.json` |
    | LM Studio | `mcp.json`（在应用的 MCP 设置中） |
  </Step>

  <Step title="重启您的 MCP 宿主">
    您的 agent 现在拥有聊天、图像、视频、音乐、TTS、ASR、计费、API 密钥以及另外 39 个 Venice 工具。
  </Step>
</Steps>

<Note>
大多数 MCP 宿主只会传递 `env` 块中**显式列出**的环境变量，系统级环境变量不会被继承。如果已设置 API 密钥却仍看到 402 错误，请检查配置中的 `env` 里是否有 `VENICE_API_KEY`。
</Note>

## 您将获得

覆盖所有 Venice 模态与账户操作的 **45 个工具**、**3 个资源**（`venice://models`、`venice://styles`、`venice://voices`）和 **3 个提示模板**（无审查研究、NSFW 创意写作、图像风格探索）。

每个工具都声明了明确的 `readOnlyHint`、`destructiveHint`、`idempotentHint` 和 `openWorldHint` 注解，因此宿主可以无需确认地执行查询，并在媒体清理或加密货币中继等破坏性操作前请求确认。

### 聊天与 embeddings

| 工具 | 说明 |
|---|---|
| `venice_chat` | 面向 Venice 完整 LLM 目录的 OpenAI 兼容 chat completion，支持文本/图像/音频/视频/文件块、结构化输出、function tool、提示缓存和推理控制。调用为明文且不流式。 |
| `venice_responses` | Alpha 阶段、无状态的 OpenAI 兼容 Responses API，支持文本/图像输入和推理控制。不支持 E2EE 模型和 tool 字段。 |
| `venice_embeddings` | 为文本计算 embeddings。 |
| `venice_chat_with_character` | 通过 slug 与 Venice character 对话。 |

### 图像

| 工具 | 说明 |
|---|---|
| `venice_image_generate` | 生成图像（Flux 2、Lustify SDXL、Anime/WAI、Qwen Image、GPT Image、Nano Banana Pro 等），支持宽高比或宽/高、质量档位、提示增强、风格参考、联网搜索和变体。 |
| `venice_image_edit` | 用提示编辑图像。 |
| `venice_image_multi_edit` | 用单个提示同时编辑最多 8 张图像（合成 / 扩图）。 |
| `venice_image_upscale` | 将图像放大 2–4 倍，并可调节 `creativity`。 |
| `venice_image_remove_bg` | 移除图像背景。 |
| `venice_image_styles` | 列出图像风格预设。 |

### 视频

| 工具 | 说明 |
|---|---|
| `venice_video_generate` | 排队视频生成（Sora 2、Veo 3.1、Kling、Wan、LTX 2、Seedance、Runway Gen-4 等），支持图像、视频、音频、参考和元素输入。 |
| `venice_video_status` | 查询视频任务状态（`POST /video/retrieve`）。 |
| `venice_video_complete` | 将已完成的视频标记为已下载；仅在 Venice 确认成功时删除服务端媒体。 |
| `venice_video_quote` | 排队前获取价格报价。 |

### 音频（TTS / ASR）

| 工具 | 说明 |
|---|---|
| `venice_tts` | 文本转语音，支持克隆音色、temperature 和情绪标签。流式输出会被缓冲为一个完整的音频结果。 |
| `venice_asr` | 从 URL 转写音频，可选词/字符时间戳。较大的转写结果通过会话句柄分页返回。 |
| `venice_voice_clone` | 列出实时的按模型音色，或从样本 URL 克隆音色（返回供 `venice_tts` 使用的 `vv_<id>` 句柄）。 |
| `venice_audio_quote` | 获取音乐生成的价格报价。 |

### 音乐

| 工具 | 说明 |
|---|---|
| `venice_music_generate` | 排队音乐生成（`ace-step-15`、`elevenlabs-music`、`minimax-music-v2/v25/v26`、`stable-audio-25`、`mmaudio-v2-text-to-audio`、`elevenlabs-sound-effects-v2`），支持歌词、纯器乐、循环、人声、语言、速度和时长控制。 |
| `venice_music_status` | 查询音乐任务状态。 |
| `venice_music_complete` | 将已完成的音乐任务标记为已下载。 |

### Web augment

| 工具 | 说明 |
|---|---|
| `venice_web_search` | 使用 Brave（默认，零数据留存）或 Google（由 Venice 代理并匿名化）搜索网页。 |
| `venice_web_scrape` | 将单个 URL 抓取为 markdown。 |
| `venice_text_parser` | 从 PDF/DOCX/EPUB/PPTX/XLSX 提取文本。 |

### 目录与 character

| 工具 | 说明 |
|---|---|
| `venice_list_models` | 分页浏览所有类型的实时模型目录，含精简摘要、价格和能力标记。 |
| `venice_model_details` | 获取某个确切模型的完整目录行：`model_spec` 约束、能力和价格。 |
| `venice_model_traits` | 将 trait 名称（`default`、`most_uncensored` 等）映射到当前模型 ID。 |
| `venice_model_compatibility_mapping` | 将兼容模型名称映射到 Venice 模型 ID。 |
| `venice_list_characters` | 列出公开 Venice character，支持搜索、标签、模型和排序筛选。**仅限 API 密钥。** |

| `venice_character_reviews` | 分页列出 character 的公开评价。**仅限 API 密钥。** |

### TEE 证明

| 工具 | 说明 |
|---|---|
| `venice_tee_attestation` | 使用您自己生成的 32 字节 nonce，获取 TEE 文本模型的硬件证明证据（Intel TDX quote、可选 NVIDIA 证据、签名密钥）。 |
| `venice_tee_signature` | 获取已完成的 TEE chat 请求 ID 对应的 enclave 签名载荷。 |

<Warning>
这两个 TEE 工具只返回提供方证据：它们不会验证证据，也不会加密 chat。在信任 TEE 模型之前，请自行验证回显的 nonce、debug 模式状态和签名密钥绑定，并对 TEE 模型使用 `venice_chat`（绝不要用 `venice_responses`）。本服务器拒绝 `enable_e2ee`。
</Warning>

### 加密货币

| 工具 | 说明 |
|---|---|
| `venice_crypto_networks` | 列出 RPC 代理接受的实时网络 slug。 |
| `venice_crypto_rpc` | 将单个 JSON-RPC 请求或最多 100 个请求的批次代理到 Ethereum、Base、Arbitrum、Optimism、Polygon、Solana、Starknet、zkSync、Linea、BSC、Avalanche、Blast 等网络。 |

交易广播（`eth_sendRawTransaction`、`eth_sendUserOperation`、Solana `sendTransaction`、Starknet 写入）必须作为单个请求并携带 `idempotency_key` 发送，重试时复用同一个 key。

| `venice_billing_usage_analytics` | Beta 阶段的按日期、模型和 API 密钥聚合用量（lookback 或自定义区间）。 |
| `venice_billing_usage_history` | 游标分页的详细用量，支持 JSON 或 CSV 输出。 |

<Note>

## 配置

服务器完全通过环境变量配置。

### 模型与请求

| 环境变量 | 默认值 | 说明 |
|---|---|---|
| `VENICE_API_KEY` | _（无）_ | 您的 Venice API 密钥。最简单的配置。 |
| `VENICE_DEFAULT_CHAT_MODEL` | `deepseek-v4-flash-0731` | |
| `VENICE_DEFAULT_IMAGE_MODEL` | `flux-2-pro` | |
| `VENICE_DEFAULT_TTS_MODEL` | `tts-kokoro` | |
| `VENICE_DEFAULT_ASR_MODEL` | `openai/whisper-large-v3` | |
| `VENICE_DISABLE_NSFW` | `0` | 设为 `1` 可从工具描述中移除 NSFW 能力说明。 |
| `VENICE_HTTP_TIMEOUT_MS` | `60000` | |
| `VENICE_SIWX_TOKEN` | _（无）_ | x402 钱包模式身份验证 token。请参阅[下方的 x402](#x402-钱包模式)。 |

如果同时设置 `VENICE_API_KEY` 和 `VENICE_SIWX_TOKEN`，API 密钥优先。

### 响应大小限制

生成的媒体会被缓冲并以 base64 嵌入 MCP 结果，因此每种模态都有字节上限。

| 环境变量 | 默认值 | 适用于 |
|---|---|---|
| `VENICE_MAX_IMAGE_RESPONSE_BYTES` | `33554432`（32 MiB） | `venice_image_generate`、`venice_image_edit`、`venice_image_multi_edit`、`venice_image_upscale`、`venice_image_remove_bg` |
| `VENICE_MAX_VIDEO_RESPONSE_BYTES` | `26214400`（25 MiB） | `venice_video_status` |
| `VENICE_MAX_AUDIO_RESPONSE_BYTES` | `33554432`（32 MiB） | `venice_tts`、`venice_music_status` |

过大的图像或 TTS 结果会被丢弃并报错。过大的视频或音乐会留在队列中，因此提高限制后可以用相同的 queue ID 再次调用状态工具。

### HTTP 服务器

仅在 [Streamable HTTP 部署](#自托管streamable-http)中相关。

| 环境变量 | 默认值 | 说明 |
|---|---|---|
| `PORT` | `3333` | HTTP 监听端口。 |
| `VENICE_MCP_HOST` | `127.0.0.1` | 绑定地址。设为 `0.0.0.0` 可暴露到局域网或容器。 |
| `VENICE_MCP_AUTH_TOKEN` | _（无）_ | 绑定到回环地址之外时 `/mcp` 要求的 bearer token。 |
| `VENICE_MCP_ALLOW_UNAUTHENTICATED_HTTP` | `0` | 对外暴露未认证 HTTP 的应急开关。仅在可信的认证代理之后使用。 |
| `VENICE_MCP_MAX_SESSIONS` | `100` | 最大活跃 Streamable HTTP 会话数。 |
| `VENICE_MCP_SESSION_TTL_MS` | `1800000` | 空闲会话在清理前的存活时间。 |

## 媒体生成行为

- **完成的媒体可能是字节，也可能是 URL。** 视频和音乐任务会返回内嵌的 MP4/音频资源，或包含 `download_url` 的 JSON（以 resource link 形式返回）。请先下载该链接，再调用 `venice_video_complete` 或 `venice_music_complete`；媒体清理绝不会应用于 `download_url` 结果，因为文件删除后链接就会失效。
- **某些模型只在排队时返回 URL。** 对于 VPS 和 Grok Imagine Private 模型，请保存 `venice_video_generate` 返回的 `download_url` 并传给 `venice_video_status`；没有内联 URL 的 `COMPLETED` retrieve 仍会给出可用链接。
- **提示增强结果会回传。** 应用 `enhance_prompt` 后，图像生成、编辑和多图编辑结果会包含 Venice 返回的 URL 解码后的提示。
- **ASR 分页只计费一次。** 带时间戳或超过 8000 字符的转写结果会返回 `result_handle` 和第一页。后续页面用该句柄请求。句柄按 MCP 会话保存在内存中 10 分钟，仅保留最近 16 个。
- **Seedance 同意书不是策略绕过。** 当前公开的 Seedance 模型可能直接拒绝包含可识别人员的媒体。返回 `needs_consent` 响应时，`consents.seedance` 的三个标志是法律确认：只有在用户明确确认每一项声明后才能设为 `true`。

## x402 钱包模式

除了常规 API 密钥流程，Venice 还支持使用由 Base 或 Solana 上预付 USDC 额度支撑的 [Sign-In-With-X 钱包 token](/guides/integrations/x402-venice-api) 进行身份验证。无需邮箱、电话或 KYC：钱包就是唯一身份。

```json
{
  "mcpServers": {
    "venice": {
      "command": "npx",
      "args": ["-y", "@veniceai/mcp-server@0.3.0"],
      "env": { "VENICE_SIWX_TOKEN": "<base64 Sign-In-With-X payload>" }
    }
  }
}
```

MCP 服务器在每次 Venice API 调用时通过 `SIGN-IN-WITH-X` 请求头转发 `VENICE_SIWX_TOKEN`。服务器绝不会看到您的私钥。钱包签名和 USDC 充值授权都在您自己的钱包中完成。

| 流程 | 会发生什么 |
|---|---|
| **一次性设置** | 在钱包中签署 Sign-In-With-X 消息 → 生成 SIWX token（base64 JSON）。 |
| **充值** | `POST /api/v1/x402/top-up` 返回 402 + 支付要求。为返回的 Base 或 Solana 选项之一签署 USDC 支付，重新提交后 Venice 会为您的余额充值。 |
| **每次推理调用** | MCP 服务器发送 `SIGN-IN-WITH-X: <SIWX>`；Venice 从您的预付余额中扣款。 |

最低充值金额为 **\$5 USD**。调用推理的最低余额为 **\$0.10**。充值后，调用耗时可低于 100ms，因为结算在快速信用账户上以链下方式完成。

<Tip>
与已质押 DIEM 的 Venice 账户关联的钱包会从质押余额中扣款，而不是 USDC 额度，因此无需充值。
</Tip>

Venice 不接受推理路由上的支付请求头，因此本服务器从不发送支付头。`PAYMENT-SIGNATURE` 仅用于 `/x402/top-up`，充值辅助工具只查询要求，不提交支付。

### 认证模式覆盖范围

部分端点只接受一种认证模式：

| 工具 | API 密钥 | x402 |
|---|---|---|
| 推理、媒体、web augment、加密货币 RPC、character 聊天 | ✓ | ✓ |
| `venice_list_characters`、`venice_get_character`、`venice_character_reviews` | ✓ | ✗ |
| `venice_billing_*`、`venice_list_api_keys`、`venice_get_api_key`、`venice_api_key_rate_limit_logs` | ✓（admin） | ✗ |
| `venice_api_key_rate_limits` | ✓（任意密钥） | ✗ |
| `venice_x402_balance`、`venice_x402_transactions` | ✗ | ✓ |
| `venice_x402_top_up_info` | ✓ | ✓ |

如果同时设置两种凭据，API 密钥会在所有调用中优先，因此仅支持 SIWX 的辅助工具（`venice_x402_balance`、`venice_x402_transactions`）只有在钱包 token 是您唯一凭据时才能工作。

## 自托管（Streamable HTTP）

对于团队或工作区部署，请通过 HTTP 而非 stdio 运行 MCP 服务器：

```bash
docker run -p 3333:3333 \
  -e VENICE_API_KEY=<your-venice-api-key> \
  -e VENICE_MCP_AUTH_TOKEN=<choose-a-long-random-token> \
  ghcr.io/veniceai/venice-mcp-server:latest
```

服务器现在位于 `http://localhost:3333/mcp`。HTTP 客户端必须发送 `Authorization: Bearer <VENICE_MCP_AUTH_TOKEN>`，并在不带 `mcp-session-id` 请求头的情况下创建新会话，然后复用服务器签发的会话 ID。

<Warning>
`/mcp` 是凭据支持的工具执行端点：调用方可以消耗所配置的 Venice API 密钥或 x402 余额。当 HTTP 模式绑定到回环地址之外时，除非设置了 `VENICE_MCP_AUTH_TOKEN`，或在可信的认证代理之后设置 `VENICE_MCP_ALLOW_UNAUTHENTICATED_HTTP=1`，否则启动会失败。生产环境请显式固定 npm 包版本，而不要依赖 `latest`。
</Warning>
