[Venice MCP Server](https://github.com/veniceai/venice-mcp-server) 是 Venice 的官方 [Model Context Protocol](https://modelcontextprotocol.io/) 服务器。它将 Venice API（聊天、图像、视频、音频、音乐、embeddings、web augment、character、crypto RPC 和 TEE 证明）以及账户操作（账单和 API 密钥）作为 **45 个工具**暴露给任何兼容 MCP 的 agent 调用。

</Card>

## 快速入门

<Steps>
  <Step title="获取 Venice API 密钥">
    从 [venice.ai/settings/api](https://venice.ai/settings/api?utm_source=venice-api-documentation) 生成。逐步说明请参阅 [API 密钥指南](/zh/guides/getting-started/generating-api-key)。
  </Step>

  <Step title="将 Venice 添加到 MCP 宿主配置">
    将以下内容放入您的 MCP 宿主配置文件：

    ```json
    {
      "mcpServers": {
        "venice": {
          "command": "npx",
          "args": ["-y", "@veniceai/mcp-server@0.3.0"],
          "env": { "VENICE_API_KEY": "<your-venice-api-key>" }
        }
      }
    }
    ```

    常见配置路径：

    | 宿主 | 路径 |
    |---|---|
    | Claude Desktop (macOS) | `~/Library/Application Support/Claude/claude_desktop_config.json` |
    | Claude Desktop (Windows) | `%APPDATA%\Claude\claude_desktop_config.json` |
    | Cursor | `~/.cursor/mcp.json` |
    | LM Studio | `mcp.json`（从应用的 MCP 设置中获取） |
  </Step>

  <Step title="重启您的 MCP 宿主">
    您的 agent 现在已具备聊天、图像、视频、音乐、TTS、ASR 以及 39 个其他 Venice 工具。
  </Step>
</Steps>

<Note>
大多数 MCP 宿主只会传递在 `env` 块中**显式列出**的环境变量。系统级环境变量不会被继承。如果您在设置了 API 密钥后仍看到 402 错误，请仔细检查 `VENICE_API_KEY` 是否在配置的 `env` 中。
</Note>

## 您将获得

**45 个工具**，覆盖每种 Venice 模态以及账户操作；**3 个资源**（`venice://models`、`venice://styles`、`venice://voices`）；**3 个 prompt 模板**（无审查研究、NSFW 创意写作、图像风格探索）。

每个工具都声明了明确的 `readOnlyHint`、`destructiveHint`、`idempotentHint` 和 `openWorldHint` 注解，因此宿主可以无需提示直接运行查询类操作，并在执行任何破坏性操作（例如媒体清理或 crypto 中继）之前请求确认。

## 配置

服务器完全通过环境变量配置。

### 模型与请求

| 环境变量 | 默认值 | 备注 |
|---|---|---|
| `VENICE_API_KEY` | _(无)_ | 您的 Venice API 密钥。最简单的设置。 |
| `VENICE_DEFAULT_CHAT_MODEL` | `deepseek-v4-flash-0731` | |
| `VENICE_DEFAULT_IMAGE_MODEL` | `flux-2-pro` | |
| `VENICE_DEFAULT_TTS_MODEL` | `tts-kokoro` | |
| `VENICE_DEFAULT_ASR_MODEL` | `openai/whisper-large-v3` | |
| `VENICE_DISABLE_NSFW` | `0` | 设置为 `1` 可从工具描述中移除 NSFW 能力说明。 |
| `VENICE_HTTP_TIMEOUT_MS` | `60000` | |
| `VENICE_SIWX_TOKEN` | _(无)_ | x402 钱包模式身份验证 token。请参阅[下方的 x402](#x402-钱包模式)。 |

如果同时设置了 `VENICE_API_KEY` 和 `VENICE_SIWX_TOKEN`，大多数调用将优先使用 API 密钥；例外情况请参阅[身份验证模式覆盖范围](#身份验证模式覆盖范围)。

### 响应大小限制

生成的媒体会被缓冲并以 base64 形式嵌入 MCP 结果中，因此每种模态都有字节上限。

| 环境变量 | 默认值 | 适用于 |
|---|---|---|
| `VENICE_MAX_IMAGE_RESPONSE_BYTES` | `33554432` (32 MiB) | `venice_image_generate`、`venice_image_edit`、`venice_image_multi_edit`、`venice_image_upscale`、`venice_image_remove_bg` |
| `VENICE_MAX_VIDEO_RESPONSE_BYTES` | `26214400` (25 MiB) | `venice_video_status` |
| `VENICE_MAX_AUDIO_RESPONSE_BYTES` | `33554432` (32 MiB) | `venice_tts`、`venice_music_status` |

超出大小的图像或 TTS 结果会被丢弃并返回错误。超出大小的视频或音乐结果会保留在队列中，因此您可以在提高限制后使用同一个队列 ID 再次调用状态工具。

### HTTP 服务器

仅在 [Streamable HTTP 部署](#自托管-streamable-http)中相关。

| 环境变量 | 默认值 | 备注 |
|---|---|---|
| `PORT` | `3333` | HTTP 监听端口。 |
| `VENICE_MCP_HOST` | `127.0.0.1` | 绑定地址。设置为 `0.0.0.0` 可在局域网或容器中暴露。 |
| `VENICE_MCP_AUTH_TOKEN` | _(无)_ | `/mcp` 的 Bearer token。绑定在 loopback 之外时必须设置，且长度至少为 16 个字符。一旦设置，loopback 上也会强制校验。 |
| `VENICE_MCP_ALLOW_UNAUTHENTICATED_HTTP` | `0` | 允许暴露未经身份验证的 HTTP 的应急开关。仅在受信任且已做身份验证的代理之后使用。 |
| `VENICE_MCP_MAX_SESSIONS` | `100` | 活跃 Streamable HTTP 会话的最大数量。 |
| `VENICE_MCP_SESSION_TTL_MS` | `1800000` | 空闲会话在被清理前的存活时间。 |

## 媒体生成行为

- **已完成的媒体可能是字节数据或 URL。** 视频和音乐作业会返回嵌入的 MP4/音频资源，或返回包含 `download_url` 的 JSON，该链接会作为资源链接返回。请先下载该链接，再调用 `venice_video_complete` 或 `venice_music_complete`；媒体清理永远不会应用于 `download_url` 结果，因为文件删除后该链接即失效。
- **部分模型仅在排队时返回 URL。** 对于 VPS 和 Grok Imagine Private 模型，请保存 `venice_video_generate` 返回的 `download_url` 并将其传入 `venice_video_status`；即使 `COMPLETED` 的检索结果中没有内联 URL，也仍能得到可用的链接。
- **prompt 增强会回报结果。** 应用 `enhance_prompt` 时，图像生成、编辑和多图编辑的结果会包含 Venice 返回的、经过 URL 解码的 prompt。
- **ASR 分页只计费一次。** 超过 8,000 个字符的转录结果，或时间戳数量超出单页容量（默认每个数组 200 个，通过 `timestamp_limit` 最多 500 个）的转录结果，会随第一页返回一个 `result_handle`。使用该句柄请求后续页面。句柄按 MCP 会话保存在内存中，有效期 10 分钟，且只保留最近的 16 个。
- **Seedance 同意声明并不能绕过政策。** 当前公开的 Seedance 模型可能会直接拒绝包含可识别人物的媒体。如果返回 `needs_consent` 响应，三个 `consents.seedance` 标志属于法律声明：只有在用户明确确认每项声明后，才能将其设置为 `true`。

## x402 钱包模式

除了正常的 API 密钥流程外，Venice 还支持使用由 Base 或 Solana 上预付 USDC 额度支持的 [Sign-In-With-X 钱包 token](/zh/guides/integrations/x402-venice-api)进行身份验证。无需邮箱、电话或 KYC：您的钱包是唯一的身份。

```json
{
  "mcpServers": {
    "venice": {
      "command": "npx",
      "args": ["-y", "@veniceai/mcp-server@0.3.0"],
      "env": { "VENICE_SIWX_TOKEN": "<base64 Sign-In-With-X payload>" }
    }
  }
}
```

MCP 服务器在每次 Venice API 调用上将 `VENICE_SIWX_TOKEN` 作为 `SIGN-IN-WITH-X` 请求头转发。服务器永远看不到您的私钥。钱包签名和 USDC 充值授权在您自己的钱包中进行。

| 流程 | 发生什么 |
|---|---|
| **一次性设置** | 在钱包中签署一个 Sign-In-With-X 消息 → 产生一个 SIWX token（base64 JSON）。 |
| **充值** | `POST /api/v1/x402/top-up` 返回 402 + 付款要求。签署其中一个返回的 Base 或 Solana 选项的 USDC 付款，重新提交，Venice 即为您的余额充值。 |
| **每次推理调用** | MCP 服务器发送 `SIGN-IN-WITH-X: <SIWX>`；Venice 从您的预付余额中扣款。 |

最低充值为 **\$5 USD**。调用推理的最低余额为 **\$0.10**。充值后调用延迟低于 100ms，因为结算在一个快速额度账户上链下进行。

<Tip>
绑定到已质押 DIEM 的 Venice 账户的钱包将从质押余额而非 USDC 额度中消费，因此无需充值。
</Tip>

Venice 不接受推理路由上的付款请求头，因此此服务器永远不会发送付款请求头。`PAYMENT-SIGNATURE` 仅用于 `/x402/top-up`，而充值辅助工具只获取付款要求，不会提交付款。

### 身份验证模式覆盖范围

部分端点只接受一种身份验证模式：

| 工具 | API 密钥 | x402 |
|---|---|---|
| 推理、媒体、web augment、crypto RPC、character 聊天 | ✓ | ✓ |
| `venice_list_characters`、`venice_get_character`、`venice_character_reviews` | ✓ | ✗ |
| `venice_billing_*`、`venice_list_api_keys`、`venice_get_api_key`、`venice_api_key_rate_limit_logs` | ✓（admin） | ✗ |
| `venice_api_key_rate_limits` | ✓（任意密钥） | ✗ |
| `venice_x402_balance`、`venice_x402_transactions` | ✗ | ✓ |
| `venice_x402_top_up_info` | ✓ | ✓ |

同时设置两种凭证时，除 `venice_x402_balance` 和 `venice_x402_transactions` 始终发送钱包 token 外，所有需要身份验证的调用都使用 API 密钥。

## 自托管 (Streamable HTTP)

对于团队或工作区部署，通过 HTTP 而非 stdio 运行 MCP 服务器：

```bash
docker run -p 3333:3333 \
  -e VENICE_API_KEY=<your-venice-api-key> \
  -e VENICE_MCP_AUTH_TOKEN=<choose-a-long-random-token> \
  ghcr.io/veniceai/venice-mcp-server:latest
```

服务器现在可在 `http://localhost:3333/mcp` 访问。HTTP 客户端必须发送 `Authorization: Bearer <VENICE_MCP_AUTH_TOKEN>`，并应在不带 `mcp-session-id` 请求头的情况下创建新会话，然后复用服务器分配的会话 ID。

<Warning>
`/mcp` 是一个由凭证支持的工具执行端点：调用方可花费配置的 Venice API 密钥或 x402 余额。当 HTTP 模式绑定在 loopback 之外时，除非设置了 `VENICE_MCP_AUTH_TOKEN`，或在受信任且已做身份验证的代理之后设置了 `VENICE_MCP_ALLOW_UNAUTHENTICATED_HTTP=1`，否则启动会失败。对于生产环境，请显式锁定 npm 包版本，而不是依赖 `latest`。
</Warning>
