[Kilo Code](https://kilo.ai/) 是面向 VS Code 和终端的开源 AI 编码 agent。Venice 作为**原生提供商**接入，因此您可以直接选择 Venice 模型，而无需配置兼容 OpenAI 的自定义端点。

## 前置条件

- 来自 [venice.ai/settings/api](https://venice.ai/settings/api) 的 Venice API 密钥
- [Kilo Code for VS Code](https://marketplace.visualstudio.com/items?itemName=kilocode.Kilo-Code) 和/或 [Kilo CLI](https://kilo.ai/docs/code-with-ai/platforms/cli)

## 设置

<Tabs>
  <Tab title="VS Code">
    <Steps>
      <Step title="安装 Kilo Code">
        在 VS Code 中打开**扩展**，搜索 **Kilo Code**，并从 [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=kilocode.Kilo-Code) 安装。

        当 Marketplace 的**预发布（Pre-Release）**通道是当前推荐版本时，请优先使用该通道 —— 参见 [Kilo 的安装文档](https://kilo.ai/docs/getting-started/installing)。
      </Step>

      <Step title="获取 Venice API 密钥">
        在 [venice.ai/settings/api](https://venice.ai/settings/api) 生成密钥。请立即复制并妥善保存。
      </Step>

      <Step title="添加 Venice 提供商">
        打开 Kilo 的**设置**（齿轮图标），进入 **Providers** 标签页。选择 **Venice AI** 并粘贴您的 Venice API 密钥。

        扩展会将提供商信息保存到您的 `kilo.json` 配置中。您也可以直接编辑该文件 —— 格式参见 **CLI** 标签页。
      </Step>

      <Step title="选择模型并测试">
        从模型选择器中选择一个 Venice 模型，然后发送一个小任务，例如：

        ```txt
        Review the current file and suggest one safe improvement.
        ```

        可在[文本模型目录](/models/text)中浏览可用的模型 ID。
      </Step>
    </Steps>
  </Tab>

  <Tab title="CLI">
    <Steps>
      <Step title="安装 Kilo CLI">
        ```bash
        npm install -g @kilocode/cli
        kilo --version
        ```

        其他安装方式请参见 [Kilo CLI 文档](https://kilo.ai/docs/code-with-ai/platforms/cli)。
      </Step>

      <Step title="设置 Venice API 密钥">
        在运行 Kilo 的 shell 中导出密钥：

        ```bash
        export VENICE_API_KEY="your-api-key"
        ```
      </Step>

      <Step title="配置 Venice 提供商">
        创建或编辑 `~/.config/kilo/kilo.json`（全局）或 `./kilo.json`（项目）：

        ```json
        {
          "provider": {
            "venice": {
              "env": ["VENICE_API_KEY"]
            }
          },
          "model": "venice/zai-org-glm-5-1"
        }
        ```

        请将 `zai-org-glm-5-1` 替换为[文本模型目录](/models/text)中的任意模型 ID。Kilo 中的模型引用使用 `venice/<model-id>` 格式。
      </Step>

      <Step title="启动 Kilo">
        在您的项目目录中运行：

        ```bash
        kilo
        ```

        如果没有设置默认的 `model`，请从模型选择器中选择一个 Venice 模型，然后发送一个简短的测试提示。
      </Step>
    </Steps>
  </Tab>
</Tabs>

## 验证 Venice API

如果 Kilo 无法连接，请独立确认 API 密钥和模型 ID：

```bash
curl https://api.venice.ai/api/v1/models \
  -H "Authorization: Bearer $VENICE_API_KEY"
```

将模型的 `id` 完整复制到 Kilo 中。在 CLI 配置中，请为其加上 `venice/` 前缀，例如 `venice/zai-org-glm-5-1`。

---

## 配置注意事项

- Venice 是 Kilo 的**原生**提供商。请优先在 Providers 设置中选择 **Venice AI**，而不是使用通用的兼容 OpenAI 自定义端点。
- 扩展和 CLI 共享相同的配置文件（全局的 `~/.config/kilo/kilo.json`，或项目中的 `./kilo.json`）。
- 部分 Venice 模型暴露了推理控制项。当所选模型支持时，Kilo 会映射对应的推理强度（reasoning effort）和禁用思考（disable-thinking）选项。
- 模型 ID 和套餐权限可能会变化。请使用模型选择器、[文本模型目录](/models/text)或 `GET /models` 获取最新列表。
- 请妥善保管您的 Venice API 密钥。不要将其粘贴到源文件或提交到 git。

## 疑难排查

<AccordionGroup>
  <Accordion title="API 密钥无效或 401">
    确认密钥来自 [venice.ai/settings/api](https://venice.ai/settings/api)。使用 CLI 时，请验证 `VENICE_API_KEY` 已在启动 Kilo 的同一环境中设置。在 VS Code 中，请在 **Providers** 下重新连接 Venice AI。
  </Accordion>
  <Accordion title="模型不可用">
    确认您的 Venice 账户有权访问所选模型，从[文本模型目录](/models/text)或 `GET /models` 中复制该 ID，并在 CLI 配置中使用 `venice/<model-id>` 形式。
  </Accordion>
  <Accordion title="扩展中找不到 Provider 设置">
    请更新到 Kilo 当前推荐的版本（当预发布是文档默认版本时也应包含在内）。您也可以按 CLI 标签页所示在 `kilo.json` 中设置提供商 —— 扩展读取的是相同的配置。
  </Accordion>
</AccordionGroup>
