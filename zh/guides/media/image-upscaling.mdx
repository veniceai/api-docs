图片超分能提升现有图像的分辨率与视觉质量。向 `/image/upscale` 发送一张图片，选择缩放倍数和可选的创意程度，Venice 就会以二进制形式返回增强后的图片。

当你已经拥有一张图片，只需要更高分辨率的输出时，可使用图片超分。如果你需要根据提示词生成图片，请使用 [图片生成](/zh/guides/media/image-generation)；如果需要修改图片内容，请使用 [图片编辑](/zh/guides/media/image-editing)。

## 基本用法

<CodeGroup>
```python Python
import base64
import os
from pathlib import Path

import requests

image_base64 = base64.b64encode(Path("input.jpg").read_bytes()).decode("utf-8")

response = requests.post(
    "https://api.venice.ai/api/v1/image/upscale",
    headers={
        "Authorization": f"Bearer {os.environ['VENICE_API_KEY']}",
        "Content-Type": "application/json",
    },
    json={
        "image": image_base64,
        "scale": 2,
        "creativity": 0.01,
    },
)

response.raise_for_status()
Path("upscaled.png").write_bytes(response.content)
```

```javascript Node.js
import { readFile, writeFile } from "node:fs/promises";

const image = await readFile("input.jpg");

const response = await fetch("https://api.venice.ai/api/v1/image/upscale", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.VENICE_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    image: image.toString("base64"),
    scale: 2,
    creativity: 0.01,
  }),
});

if (!response.ok) {
  throw new Error(await response.text());
}

const output = Buffer.from(await response.arrayBuffer());
await writeFile("upscaled.png", output);
```

```bash cURL
IMAGE_BASE64=$(base64 < input.jpg | tr -d '\n')

curl https://api.venice.ai/api/v1/image/upscale \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d "{
    \"image\": \"$IMAGE_BASE64\",
    \"scale\": 2,
    \"creativity\": 0.01
  }" \
  --output upscaled.png
```
</CodeGroup>

你也可以使用 `multipart/form-data` 直接上传文件，而无需进行 base64 编码：

```bash cURL (multipart)
curl https://api.venice.ai/api/v1/image/upscale \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -F "image=@input.jpg" \
  -F "scale=2" \
  -F "creativity=0.01" \
  --output upscaled.png
```

每个请求只能发送一个 `image` 部分。上传的文件必须小于 25 MB。

## 参数

| 参数 | 类型 | 是否必填 | 说明 |
|-----------|------|----------|-------------|
| `image` | string 或文件 | 是 | 源图片。可在 JSON 中以 base64 发送，或使用 `multipart/form-data` 上传文件部分。尺寸至少为 256×256 像素。上传文件须不超过 25 MB；JSON 请求体上限为 35 MB。 |
| `scale` | number | 否 | 放大倍数，介于 `2` 和 `4` 之间。默认值为 `2`；请使用 `2` 或 `4`（介于两者之间的值也会被接受，并按 4x 费率计费）。输出上限为 16,777,216 像素（4096×4096）：如果请求的倍数会超出上限，服务器会自动降低实际倍数。已达到或接近上限的输入会被以 `400` 拒绝，请先缩小尺寸。 |
| `creativity` | number | 否 | 超分模型添加细节和纹理的程度。取值 `0`–`0.02`，默认 `0.01`。值越高添加越多；值越低越贴近原图。超出范围的值会被截断到最近的边界。 |

<Note>
响应是二进制图片数据，不是 JSON。请将响应体直接写入文件，或将其流式写入存储。
</Note>

## 输入建议

- 使用你所能获得的最清晰的源图片。超分能提升细节，但无法完全恢复原图中不存在的信息。
- 在生产工作流中使用适中的放大倍数。过大的输出会增加延迟和文件体积。
- 保留原始图片，以便对比质量或使用不同参数重试。
