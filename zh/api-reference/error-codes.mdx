发生错误时，Venice API 会返回 HTTP 状态码和描述性消息。某些错误还包含额外字段，例如退款状态、建议重试模型、验证细节或请求 ID。

## 错误响应格式

大多数错误返回一个带有人类可读消息的 `error` 字段：

```json
{
  "error": "Invalid request parameters"
}
```

某些端点会包含端点特有的额外字段。例如，视频审核错误可能包含是否退还了额度的信息：

```json
{
  "error": "Your generation was blocked due to the model provider's content policies. Credits have been refunded.",
  "credits_refunded": true
}
```

验证错误可能包含带有字段级验证信息的 `details` 和 `issues` 字段：

```json
{
  "error": "Invalid request parameters",
  "details": {
    "_errors": [],
    "field": {
      "_errors": ["Field is required"]
    }
  },
  "issues": []
}
```

某些 OpenAI 兼容端点可能针对特定情况（如上下文长度错误）返回 OpenAI 风格的错误对象：

```json
{
  "error": {
    "message": "Your request exceeds the model's maximum context. Please reduce your prompt or completion length.",
    "type": "invalid_request_error",
    "param": "messages",
    "code": "context_length_exceeded"
  }
}
```

## 缺少凭据

不带任何凭据的请求会返回 `402 Payment Required`，而不是 `401`。每个付费路由也都接受 [x402 钱包认证](/zh/guides/integrations/x402-venice-api)，因此响应是一个支付质询：它包含 `PAYMENT-REQUIRED` 响应头，以及描述两种认证方式的响应体。

```json
{
  "x402Version": 2,
  "error": "Authentication required",
  "accepts": [ ... ],
  "authOptions": {
    "apiKey": {
      "header": "Authorization: Bearer YOUR_API_KEY",
      "getKey": "https://venice.ai/settings/api"
    },
    "x402Wallet": {
      "header": "SIGN-IN-WITH-X",
      "topUp": "POST /api/v1/x402/top-up"
    }
  }
}
```

如果你打算使用 API 密钥，请检查是否设置了 `Authorization: Bearer` 请求头。存在但无效的密钥会返回 `401`。

## 请求格式错误

这些错误产生于读取请求体阶段，早于任何端点专属的校验。

| HTTP 状态 | 消息 | 原因 |
| --- | --- | --- |
| 400 | `'Content-Type' must be 'application/json'` | 发送 `POST`、`PUT` 或 `PATCH` 请求体时未设置 `Content-Type: application/json`。接受文件上传的端点也接受 `multipart/form-data` |
| 400 | `Invalid JSON request` | 请求体不是有效的 JSON |
| 400 | `Invalid multipart request: malformed part header` | 无法解析的 `multipart/form-data` 请求体 |
| 413 | `Request body exceeds the maximum allowed size.` | 请求体过大 |
| 415 | `Request encoding is not supported` | API 无法解码的 `Content-Encoding` 或字符集 |

错误的 `Content-Type` 返回 `400`，而不是 `415`。因大小限制返回的 `413` 响应还包含一个 `code` 字段：

```json
{
  "code": "PAYLOAD_TOO_LARGE",
  "error": "Request body exceeds the maximum allowed size."
}
```

## 其他错误

上表并不详尽。部分错误返回时不带已列出的错误码，且消息内容可能因模型和端点而异，因此请根据 HTTP 状态而非消息文本进行分支处理。可能遇到但未列入上表的错误：

| HTTP 状态 | 发生场景 |
| --- | --- |
| 400 | 聊天或 Responses 请求中的图像输入格式不受支持 |
| 400 | 所请求的语音不适用于该文本转语音模型 |
| 403 | 请求来自不在 API 密钥允许列表中的 IP 地址 |
| 403 | API 密钥的隐私设置不允许使用所请求的模型 |
| 403 | 对所请求模型的访问受到限制。请联系 support@venice.ai |
| 409 | 获取视频、音乐或变声结果时，结果仍在上传中。请稍后重试 |
| 410 | 该端点已停用 |
| 422 | 音频过长或过短（语音克隆、变声和音频任务） |
| 422 | 视频请求的输入图像宽高比超出模型可接受的范围 |
| 422 | 视频请求的输入被内容审核拦截 |
| 500 | 视频或变声生成失败 |
| 502 | 上游语音合成失败，或无法获取已生成的视频。请重试该请求 |
