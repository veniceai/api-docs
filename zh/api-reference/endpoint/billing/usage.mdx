<Warning>
此端点已于 2026-09-16 停用，现在对所有请求均返回 `410 Gone`。请改用[账单使用历史](/zh/api-reference/endpoint/billing/usage-history)。
</Warning>

账单使用历史以游标分页的方式返回相同的账目条目。迁移方法：

- 将 `page` 和 `limit` 替换为 `pageSize`，并传入每个响应中的 `nextCursor` 以获取下一页。
- 将 `startDate` 和 `endDate` 替换为 `startTimestamp` 和 `endTimestamp`。
