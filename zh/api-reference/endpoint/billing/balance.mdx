<Note>
`balances` 只报告 `diem` 和 `usd`。打包额度不会以数值字段的形式出现。如果打包额度是您下一次请求将扣费的来源，`consumptionCurrency` 会返回 `BUNDLED_CREDITS`。要查看剩余的打包额度金额，请查看 [venice.ai/settings/api](https://venice.ai/settings/api?utm_source=venice-api-documentation)。关于 API 如何在 DIEM、打包额度和 USD 之间进行选择，请参阅 [VVV & DIEM](/overview/vvv-diem#how-funding-works)。
</Note>
