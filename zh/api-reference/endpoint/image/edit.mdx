**定价：** 图像编辑价格因模型而异。默认模型（`qwen-edit`）为**每次编辑 $0.04**。所有可用的编辑模型及其定价请参阅 [Models 端点](/api-reference/endpoint/models/list)。
</Info>

## 质量等级

`/image/edit` 不接受 `quality` 参数，发送该参数会返回 `400`。此端点上的编辑按模型的默认等级计费（`gpt-image-2-edit` 为 `high`）。

如需选择等级（`low`、`medium`、`high`），请使用 [`/image/multi-edit`](/api-reference/endpoint/image/multi-edit)，它在支持的模型上接受 `quality`。各等级价格（1K/2K/4K × low/medium/high）位于 [Models 端点](/api-reference/endpoint/models/list)中 `model_spec.pricing.quality` 下，也在[定价概览](/overview/pricing)中列出。
