在 `url` 中发送 **YouTube** 视频 URL。可选地将 `response_format` 设置为 `json`（默认）或 `text`，具体取决于您需要结构化输出还是纯文本转录。

<Warning>
此端点仅接受 YouTube URL。支持 `youtube.com`、`youtu.be` 和 `youtube-nocookie.com` 域名下的 watch、share、embed、live 和 shorts 链接。任何其他 URL——包括自托管的 MP4、CDN 链接或 S3 对象——都会返回 `400` 及 *"url must be a valid YouTube video URL"*。要转录您自己的媒体文件，请提取音频轨道并改用[音频转录 API](/api-reference/endpoint/audio/transcriptions)。
</Warning>
