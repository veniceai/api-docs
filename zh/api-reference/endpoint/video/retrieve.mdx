如果 `/video/queue` 的响应中包含 `download_url`，请从该 URL 下载已完成的文件（而非通过此端点以二进制方式返回）。否则，此端点会返回视频。有关下载链接的工作方式、重试机制及可选的 `DELETE`，请参阅[私有下载链接](/zh/guides/media/video-generation#私有下载链接)。
