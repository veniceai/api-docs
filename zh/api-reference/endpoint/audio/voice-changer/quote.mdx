在调用 [`/audio/voice-changer/queue`](/zh/api-reference/endpoint/audio/voice-changer/queue) 之前使用此端点，可估算将指定时长的源录音转换为另一种声音的美元费用。语音转换按源录音时长计费，向上取整到最近的整分钟。队列响应会返回实际测得的 `duration_seconds`，方便您与预估值进行对账。

[`/audio/quote`](/zh/api-reference/endpoint/audio/quote) 不接受语音转换（Voice Changer）模型。
