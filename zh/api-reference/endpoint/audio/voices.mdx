上传一段音频样本以创建克隆声音句柄，然后将其作为 `voice` 传给 [`/audio/speech`](/zh/api-reference/endpoint/audio/speech)，并使用创建时相同的 `model`。如需完整演示，请参阅[声音克隆指南](/zh/guides/media/voice-cloning)。

此端点用于创建克隆声音，不会列出声音。每个语音模型的内置声音位于 [`GET /models?type=tts`](/zh/api-reference/endpoint/models/list) 返回的 `model_spec.voices` 中，[文本转语音模型](/zh/models/text-to-speech)页面也列出了这些声音。
