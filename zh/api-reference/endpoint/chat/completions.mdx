<Info>
  **Venice 专属参数位于 [`venice_parameters`](#body-venice-parameters)。** 此端点与 OpenAI 兼容，但 `venice_parameters` 对象可解锁标准 OpenAI API 中没有的功能，许多集成者往往会忽略：

  - **网页搜索与引用** — `enable_web_search`、`enable_web_citations`、`enable_web_scraping`
  - **角色人设** — `character_slug`
  - **系统提示词控制** — `include_venice_system_prompt`
  - **推理控制** — `disable_thinking`、`strip_thinking_response`
  - **隐私** — `enable_e2ee`

  完整列表请参见下方的 [`venice_parameters`](#body-venice-parameters) 部分。
</Info>
