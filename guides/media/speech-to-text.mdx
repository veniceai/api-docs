## Your first transcript

You need an API key in `VENICE_API_KEY` ([create one](/getting-started/quick-start)) and a recording, here `meeting.mp3`.

<CodeGroup>
```bash cURL
curl https://api.venice.ai/api/v1/audio/transcriptions \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -F file=@meeting.mp3 \
  -F model=nvidia/parakeet-tdt-0.6b-v3
```

```python Python
import os

import requests

with open("meeting.mp3", "rb") as audio:
    response = requests.post(
        "https://api.venice.ai/api/v1/audio/transcriptions",
        headers={"Authorization": f"Bearer {os.environ['VENICE_API_KEY']}"},
        files={"file": audio},
        data={"model": "nvidia/parakeet-tdt-0.6b-v3"},
    )
response.raise_for_status()
print(response.json()["text"])
```

```typescript TypeScript
import { readFile } from "node:fs/promises";

const form = new FormData();
form.append("file", new Blob([await readFile("meeting.mp3")], { type: "audio/mpeg" }), "meeting.mp3");
form.append("model", "nvidia/parakeet-tdt-0.6b-v3");

const response = await fetch("https://api.venice.ai/api/v1/audio/transcriptions", {
  method: "POST",
  headers: { Authorization: `Bearer ${process.env.VENICE_API_KEY}` },
  body: form,
});
if (!response.ok) throw new Error(await response.text());

const { text } = await response.json();
console.log(text);
```
</CodeGroup>

```json
{ "text": "Alright, let's start with the launch…", "duration": 184.2 }
```

`duration` is the recording's length in seconds. Always send `model`: the schema lists a default, but a request without one fails with `400`. Send `response_format=text` to get the transcript as plain text instead of JSON.

## Get timestamps

Send `timestamps=true` to a model that returns timings, and the JSON gains a `timestamps` object, in seconds:

```bash
curl https://api.venice.ai/api/v1/audio/transcriptions \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -F file=@meeting.mp3 \
  -F model=elevenlabs/scribe-v2 \
  -F timestamps=true
```

```json
{
  "text": "The quick brown fox jumps over the lazy dog.",
  "duration": 4.099,
  "timestamps": {
    "word": [
      { "word": "The", "start": 0.0, "end": 0.14 },
      { "word": "quick", "start": 0.14, "end": 0.42 }
    ]
  }
}
```

Models with segment timings return `timestamps.segment` instead, with entries such as `{ "text": "…", "start": 0.0, "end": 3.2 }`.

<Warning>
Parakeet accepts `timestamps=true` and ignores it, so the response holds only `text`, with no error. Check that `timestamps` exists before you read it.
</Warning>

No model tells speakers apart, so there's no `speaker` field and a transcript is one stream of text. [Meeting notes](/guides/media/meeting-notes) shows how to work with that.

### Make subtitles

There's no `srt` or `vtt` format, but segment timings turn into subtitles in a few lines. This asks a segment model for timings and writes `meeting.srt`:

```python
import os

import requests

def srt_time(seconds):
    ms = round(seconds * 1000)
    return f"{ms // 3600000:02}:{ms // 60000 % 60:02}:{ms // 1000 % 60:02},{ms % 1000:03}"

with open("meeting.mp3", "rb") as audio:
    response = requests.post(
        "https://api.venice.ai/api/v1/audio/transcriptions",
        headers={"Authorization": f"Bearer {os.environ['VENICE_API_KEY']}"},
        files={"file": audio},
        data={"model": "openai/whisper-large-v3", "timestamps": "true"},
    )
response.raise_for_status()

segments = response.json()["timestamps"]["segment"]
cues = [
    f"{number}\n{srt_time(cue['start'])} --> {srt_time(cue['end'])}\n{cue['text'].strip()}"
    for number, cue in enumerate(segments, start=1)
]

with open("meeting.srt", "w") as f:
    f.write("\n\n".join(cues) + "\n")
```

## Long recordings

Uploads stop at 25 MB, and nothing is split for you. Split a longer recording, transcribe each piece, and add the piece's start time to its timestamps:

```bash
ffmpeg -i long.mp3 -f segment -segment_time 600 -c copy chunk_%03d.mp3
```

Ten-minute pieces of a typical MP3 stay well under the limit.

## Use the OpenAI SDK

The OpenAI SDK's `audio.transcriptions.create` works once it points at Venice:

<CodeGroup>
```python Python
import os

from openai import OpenAI

client = OpenAI(api_key=os.environ["VENICE_API_KEY"], base_url="https://api.venice.ai/api/v1")

with open("meeting.mp3", "rb") as audio:
    transcript = client.audio.transcriptions.create(file=audio, model="openai/whisper-large-v3", language="en")

print(transcript.text)
```

```typescript TypeScript
import fs from "node:fs";
import OpenAI from "openai";

const client = new OpenAI({ apiKey: process.env.VENICE_API_KEY, baseURL: "https://api.venice.ai/api/v1" });

const transcript = await client.audio.transcriptions.create({
  file: fs.createReadStream("meeting.mp3"),
  model: "openai/whisper-large-v3",
  language: "en",
});

console.log(transcript.text);
```
</CodeGroup>

`language` takes an ISO 639-1 code, such as `en` or `ja`. It helps every model except Parakeet, which detects the language itself. The SDKs don't know Venice's `timestamps` field, so request timings with a plain multipart request, as in the first examples.

## Formats and limits

- **Audio formats**: WAV, FLAC, M4A, AAC, MP4, MP3, OGG and WebM. The file needs a matching type or extension, and its bytes must be audio, so renaming a file doesn't get it through.
- **Size**: up to 25 MB, sent as a real multipart file. Base64 inside JSON isn't accepted.
- **Response formats**: `json`, the default, or `text`. There's no `srt`, `vtt` or `verbose_json`.
- **Video**: extract the audio track first, for example with `ffmpeg -i clip.mp4 -vn -c:a aac clip.m4a`. To ask questions about a video instead, send it to a chat model that accepts video.

## Errors

| Status | Meaning | What to do |
|---|---|---|
| `400` | No `model`, no file part, an unsupported format, or a `response_format` other than `json` or `text` | Send multipart with `file` and `model`. A JSON body returns "No audio file provided". |
| `401` | The API key is missing or invalid | Check the `Authorization: Bearer` header. |
| `402` | Not enough balance, or the key reached its spend limit | Add credits at [venice.ai/settings/api](https://venice.ai/settings/api?utm_source=venice-api-documentation). |
| `403` | The key only allows private models, and this one is anonymized | Choose a private model from the table. |
| `404` | The model doesn't exist | Check the ID against `GET /models?type=asr`. |
| `413` | The file is over 25 MB | Split it, as in [Long recordings](#long-recordings). |
| `422` | The provider couldn't process the audio: silent, corrupt, or in an unsupported language | Check the file, or try another model. |
| `429` | Rate limited | Throttle large batches instead of sending them all at once. |
| `502` | A temporary failure upstream | Retry with backoff. |
| `500`, `503` | Transcription failed, or the model is offline | Retry with jitter. |
