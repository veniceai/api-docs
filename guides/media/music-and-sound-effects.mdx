## How a job runs

<div className="vg">
<ol className="vg-flow">
  <li><b>Quote</b><code>POST /audio/quote</code><span>Optional. Prices the job in USD, free and with no API key.</span></li>
  <li><b>Queue</b><code>POST /audio/queue</code><span>Checks the request, charges it, and returns a <code>queue_id</code>.</span></li>
  <li><b>Retrieve</b><code>POST /audio/retrieve</code><span>Reports progress until the job is done, then returns the audio.</span></li>
  <li><b>Complete</b><code>POST /audio/complete</code><span>Optional. Deletes Venice's copy once you've saved yours.</span></li>
</ol>

## Your first track

You need an API key in `VENICE_API_KEY` ([create one](/getting-started/quick-start)). Each example prices a 30-second instrumental from ElevenLabs Music, queues it, polls every 5 seconds, and saves the MP3 as `strings.mp3`.

<CodeGroup>
```python Python
import os
import time

import requests

API = "https://api.venice.ai/api/v1"
HEADERS = {"Authorization": f"Bearer {os.environ['VENICE_API_KEY']}"}
track = {
    "model": "elevenlabs-music",
    "prompt": "Warm cinematic strings with a gentle piano melody, hopeful and spacious",
    "duration_seconds": 30,
    "force_instrumental": True,
}

quote = requests.post(f"{API}/audio/quote", json={"model": track["model"], "duration_seconds": track["duration_seconds"]})
quote.raise_for_status()
print(f"This track costs ${quote.json()['quote']:.2f}")

queued = requests.post(f"{API}/audio/queue", headers=HEADERS, json=track)
queued.raise_for_status()
job = queued.json()

while True:
    result = requests.post(f"{API}/audio/retrieve", headers=HEADERS, json={
        "model": job["model"],
        "queue_id": job["queue_id"],
        "delete_media_on_completion": True,
    })
    result.raise_for_status()
    if not result.headers["Content-Type"].startswith("application/json"):
        with open("strings.mp3", "wb") as f:
            f.write(result.content)
        break
    time.sleep(5)
```

```typescript TypeScript
import { writeFile } from "node:fs/promises";

const API = "https://api.venice.ai/api/v1";
const headers = {
  Authorization: `Bearer ${process.env.VENICE_API_KEY}`,
  "Content-Type": "application/json",
};
const track = {
  model: "elevenlabs-music",
  prompt: "Warm cinematic strings with a gentle piano melody, hopeful and spacious",
  duration_seconds: 30,
  force_instrumental: true,
};

const quote = await fetch(`${API}/audio/quote`, {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ model: track.model, duration_seconds: track.duration_seconds }),
}).then(response => response.json());
console.log(`This track costs $${quote.quote.toFixed(2)}`);

const queued = await fetch(`${API}/audio/queue`, { method: "POST", headers, body: JSON.stringify(track) });
if (!queued.ok) throw new Error(await queued.text());
const job = await queued.json();

while (true) {
  const result = await fetch(`${API}/audio/retrieve`, {
    method: "POST",
    headers,
    body: JSON.stringify({ model: job.model, queue_id: job.queue_id, delete_media_on_completion: true }),
  });
  if (!result.ok) throw new Error(await result.text());
  if (!result.headers.get("content-type")?.startsWith("application/json")) {
    await writeFile("strings.mp3", Buffer.from(await result.arrayBuffer()));
    break;
  }
  await new Promise(resolve => setTimeout(resolve, 5000));
}
```

```bash cURL
QUEUE_ID=$(curl -s https://api.venice.ai/api/v1/audio/queue \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "elevenlabs-music",
    "prompt": "Warm cinematic strings with a gentle piano melody, hopeful and spacious",
    "duration_seconds": 30,
    "force_instrumental": true
  }' | jq -r .queue_id)

while :; do
  STATUS=$(curl -s https://api.venice.ai/api/v1/audio/retrieve \
    -H "Authorization: Bearer $VENICE_API_KEY" \
    -H "Content-Type: application/json" \
    -d "{\"model\": \"elevenlabs-music\", \"queue_id\": \"$QUEUE_ID\", \"delete_media_on_completion\": true}" \
    --output strings.mp3 --write-out '%{http_code} %{content_type}')
  case "$STATUS" in
    "200 application/json"*) sleep 5 ;;
    "200 "*) echo "Saved strings.mp3"; break ;;
    *) cat strings.mp3; break ;;
  esac
done
```
</CodeGroup>

ElevenLabs Music bills by the minute, so this 30-second track costs the same as a 60-second one. A job can still fail after it's queued, for example on a content check. `/audio/retrieve` then returns the error instead of the audio, which is why the examples stop on any response that isn't `200`.

Every model accepts only the options it supports, and anything else returns `400`. [Music & sound effects models](/models/music) has each model's options, and [`GET /models?type=music`](/api-reference/endpoint/models/list) returns them as `model_spec` fields such as `supports_lyrics`, `supports_force_instrumental`, `supports_loop` and `min_duration`. Voice-changer models are listed there too, but these endpoints refuse them: convert a recording with the [Voice changer](/guides/media/voice-changer) API instead.

## Songs with lyrics

Models that write songs take your lyrics in `lyrics_prompt`, up to `lyrics_character_limit` (4,096 by default), with section tags such as `[Verse]` and `[Chorus]`. The `prompt` describes the sound:

```json
{
  "model": "minimax-music-v26",
  "prompt": "Warm indie-pop ballad, female vocals, acoustic guitar",
  "lyrics_prompt": "[Verse]\nLanterns on the water, the city holds its breath\n[Chorus]\nStay until the morning, stay until the bells"
}
```

- **`lyrics_optimizer: true`** writes the lyrics for you from the `prompt`, on models that support it. Leave `lyrics_prompt` empty when you use it.
- **`force_instrumental: true`** drops the vocals.
- **Lyrics are required** by `minimax-music-v2`, and by `minimax-music-v25` and `minimax-music-v26` unless you set `force_instrumental`. MiniMax Music 2.5 also skips them with `lyrics_optimizer`.

## Sound effects and loops

Describe the sound, where it happens and how it moves, and set its length in `duration_seconds`, within the model's range. On ElevenLabs Sound Effects, `loop: true` makes the end flow back into the start, for ambience that repeats without a seam:

```json
{
  "model": "elevenlabs-sound-effects-v2",
  "prompt": "Rain on a canvas awning over a quiet canal, distant church bells",
  "duration_seconds": 15,
  "loop": true
}
```

## Quote the price

`/audio/quote` needs no API key, and takes the fields that set the price:

```bash
curl https://api.venice.ai/api/v1/audio/quote \
  -H "Content-Type: application/json" \
  -d '{ "model": "elevenlabs-music", "duration_seconds": 30 }'
```

```json
{ "quote": 0.69 }
```

Models price in one of three ways, shown on each model's page:

| Priced | How | For example |
|---|---|---|
| By the minute | In whole-minute steps, so 30 seconds costs the same as 60 | ElevenLabs Music |
| By the track | One price whatever the length | MiniMax Music, Lyria 3 Pro, Stable Audio 2.5 |
| By the second | For the length you ask for | ElevenLabs Sound Effects, Sonilo |

Send `duration_seconds` only to models that take a length, since it returns `400` on the rest. Leaving it out prices the model's default length.

## Poll and download

Send `/audio/retrieve` the `model` and `queue_id` from the queue response. While the job runs, it returns JSON with `average_execution_time`, a typical total for the model, and `execution_duration`, the time so far, both in milliseconds:

```json
{ "status": "PROCESSING", "average_execution_time": 20000, "execution_duration": 5200 }
```

When it's done, the body is the audio, and `Content-Type` says which format: `audio/mpeg` for MP3, `audio/wav`, `audio/flac`, or `audio/mp4` for M4A. Each model's format is listed as `default_format` in its `model_spec`. Poll every 2 to 5 seconds, since polling faster doesn't finish sooner and uses up the limit of 120 retrieves a minute.

If the job fails, retrieve returns the error, and the charge is normally refunded. A `422` means the content check rejected it, and may include a `suggested_prompt` to try instead.

Delete Venice's copy once you've saved yours: send `"delete_media_on_completion": true` with the retrieve, as the examples do, or call `/audio/complete` with the same `model` and `queue_id` afterwards. Either way the audio is gone for good, so save it first.

## Errors

| Status | Meaning | What to do |
|---|---|---|
| `400` | An option this model doesn't support, a length outside its range, or an unknown `queue_id` | Build the request from the model's options. Voice errors list the supported voices. |
| `401` | The API key is missing or invalid | Check the `Authorization: Bearer` header. |
| `402` | Not enough balance for this job, or the key reached its spend limit | Add credits at [venice.ai/settings/api](https://venice.ai/settings/api?utm_source=venice-api-documentation). |
| `403` | The key's privacy setting excludes this model, or it isn't available in your region | Use a key that allows this model. |
| `404` | The model doesn't exist, or the audio expired or was already deleted | Check the ID against `GET /models?type=music`. |
| `422` | The content check rejected the prompt or lyrics | Revise them, or try the `suggested_prompt`. The charge is refunded. |
| `429` | Rate limited, at 40 queued jobs or 120 retrieves a minute | Back off, then retry. |
| `500`, `503` | Generation failed, or the model is at capacity | Retry later. |
