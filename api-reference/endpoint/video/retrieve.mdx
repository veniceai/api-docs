For private models, the finished file is downloaded from the `download_url` returned by `/video/queue` (not as binary from this endpoint). See [Private download links](/guides/media/video-generation#private-download-links) for how the link works, retries, and optional `DELETE`.

Seedance 2.5 draft responses include draft metadata (`is_draft`, `draft_task_id`, `draft_expires_at`, `can_upgrade_to_hd`) in JSON status responses and as `x-venice-*` headers on the completed `video/mp4` response. `delete_media_on_completion` does not delete a draft while it can still be upgraded. See [Draft mode](/guides/media/seedance-2-0#draft-mode-seedance-25-only).
