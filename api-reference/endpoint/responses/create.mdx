<Warning>
  **Beta endpoint**, available to all API users. OpenAI models are served natively and behave like OpenAI's Responses API. Other models are translated through [Chat Completions](/api-reference/endpoint/chat/completions), where `instructions`, `text.format`, reasoning replay, and provider-hosted tools are ignored and the Venice system prompt is on by default. Send `x-venice-responses-mode: native` or `compat` to choose the mode. See the [Responses API guide](/guides/features/responses-api#how-requests-are-served) for details and the [limitations](/guides/features/responses-api#limitations) of translated mode.
</Warning>
