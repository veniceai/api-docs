<Warning>
  **Alpha endpoint.** Venice translates Responses requests through [Chat Completions](/api-reference/endpoint/chat/completions), so some Responses features are ignored today: `instructions`, `text.format`, `previous_response_id`, reasoning replay, and provider-hosted tools. The Venice system prompt is also on by default here. See the [Responses API guide](/guides/features/responses-api#limitations) for the full list and workarounds.
</Warning>
