Call this endpoint after you have successfully downloaded converted audio when you want Venice to clean up stored media associated with the request. Passing `delete_media_on_completion: true` to [`/audio/voice-changer/retrieve`](/api-reference/endpoint/audio/voice-changer/retrieve) does the same cleanup inline.

Voice-changer models are not accepted on [`/audio/complete`](/api-reference/endpoint/audio/complete).
