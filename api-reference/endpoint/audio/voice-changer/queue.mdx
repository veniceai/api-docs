Call [`/audio/voice-changer/quote`](/api-reference/endpoint/audio/voice-changer/quote) to estimate cost, then poll [`/audio/voice-changer/retrieve`](/api-reference/endpoint/audio/voice-changer/retrieve) with the returned `queue_id` until the conversion finishes. A queued conversion has already been charged — if this response is lost, poll retrieve rather than queueing again. If you keep converted media after retrieval, call [`/audio/voice-changer/complete`](/api-reference/endpoint/audio/voice-changer/complete) once you have downloaded it.

Voice-changer models are not accepted on [`/audio/queue`](/api-reference/endpoint/audio/queue). See the [Voice Changer guide](/guides/media/voice-changer) for a full walkthrough.
