Use the `queue_id` returned by [`/audio/voice-changer/queue`](/api-reference/endpoint/audio/voice-changer/queue) to check conversion status. While the job is running this returns JSON with `status: "PROCESSING"`; when it finishes it returns `audio/mpeg`. Set `delete_media_on_completion` to `true` to clean up stored media in the same call, or call [`/audio/voice-changer/complete`](/api-reference/endpoint/audio/voice-changer/complete) after you download the file.

Voice-changer models are not accepted on [`/audio/retrieve`](/api-reference/endpoint/audio/retrieve).
