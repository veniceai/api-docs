Use this endpoint before [`/audio/voice-changer/queue`](/api-reference/endpoint/audio/voice-changer/queue) to estimate the USD cost of converting a source recording of a given length. Voice Changer is billed from the source duration, rounded up to the next whole minute. The queue response returns the measured `duration_seconds` so you can reconcile the estimate.

Voice-changer models are not accepted on [`/audio/quote`](/api-reference/endpoint/audio/quote).
