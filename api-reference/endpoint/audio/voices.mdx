Upload an audio sample to create a cloned-voice handle, then pass it as `voice` to [`/audio/speech`](/api-reference/endpoint/audio/speech) with the same `model` used to create it. For a walkthrough, see the [Voice Cloning guide](/guides/media/voice-cloning).
