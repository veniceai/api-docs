---

Upload an audio sample to create a cloned-voice handle, then pass it as `voice` to [`/audio/speech`](/api-reference/endpoint/audio/speech) with the same `model` used to create it. For a walkthrough, see the [Voice Cloning guide](/guides/media/voice-cloning).

This endpoint creates cloned voices; it doesn't list voices. Each speech model's built-in voices are in `model_spec.voices` from [`GET /models?type=tts`](/api-reference/endpoint/models/list), and the [Text-to-Speech models](/models/text-to-speech) page lists them.
