<Warning>
This endpoint was sunset on 2026-09-16 and now returns `410 Gone` for every request. Use [Billing Usage History](/api-reference/endpoint/billing/usage-history) instead.
</Warning>

Billing Usage History returns the same ledger entries with cursor pagination. To migrate:

- Replace `page` and `limit` with `pageSize`, and pass the `nextCursor` from each response to fetch the next page.
- Replace `startDate` and `endDate` with `startTimestamp` and `endTimestamp`.
