When an error occurs, the Venice API returns an HTTP status code and a descriptive message. Some errors also include additional fields, such as refund status, suggested retry models, validation details, or request IDs.

## Error response format

Most errors return an `error` field with a human-readable message:

```json
{
  "error": "Invalid request parameters"
}
```

Some endpoints include additional fields that are specific to the endpoint. For example, video moderation errors can include whether credits were refunded:

```json
{
  "error": "Your generation was blocked due to the model provider's content policies. Credits have been refunded.",
  "credits_refunded": true
}
```

Validation errors may include `details` and `issues` fields with field-level validation information:

```json
{
  "error": "Invalid request parameters",
  "details": {
    "_errors": [],
    "field": {
      "_errors": ["Field is required"]
    }
  },
  "issues": []
}
```

Some OpenAI-compatible endpoints may return OpenAI-style error objects for specific cases, such as context length errors:

```json
{
  "error": {
    "message": "Your request exceeds the model's maximum context. Please reduce your prompt or completion length.",
    "type": "invalid_request_error",
    "param": "messages",
    "code": "context_length_exceeded"
  }
}
```

## Missing credentials

A request with no credentials returns `402 Payment Required`, not `401`. Every paid route also accepts [x402 wallet authentication](/guides/integrations/x402-venice-api), so the response is a payment challenge: it includes a `PAYMENT-REQUIRED` header and a body describing both ways to authenticate.

```json
{
  "x402Version": 2,
  "error": "Authentication required",
  "accepts": [ ... ],
  "authOptions": {
    "apiKey": {
      "header": "Authorization: Bearer YOUR_API_KEY",
      "getKey": "https://venice.ai/settings/api"
    },
    "x402Wallet": {
      "header": "SIGN-IN-WITH-X",
      "topUp": "POST /api/v1/x402/top-up"
    }
  }
}
```

If you meant to use an API key, check that the `Authorization: Bearer` header is set. A key that is present but invalid returns `401`.

## Request format errors

These errors come from reading the request body, before any endpoint-specific validation runs.

| HTTP Status | Message | Cause |
| --- | --- | --- |
| 400 | `'Content-Type' must be 'application/json'` | A `POST`, `PUT`, or `PATCH` body sent without `Content-Type: application/json`. Endpoints that take file uploads also accept `multipart/form-data` |
| 400 | `Invalid JSON request` | The body is not valid JSON |
| 400 | `Invalid multipart request: malformed part header` | A `multipart/form-data` body that can't be parsed |
| 413 | `Request body exceeds the maximum allowed size.` | The request body is too large |
| 415 | `Request encoding is not supported` | A `Content-Encoding` or charset the API can't decode |

A wrong `Content-Type` returns `400`, not `415`. Size-limit `413` responses also include a `code` field:

```json
{
  "code": "PAYLOAD_TOO_LARGE",
  "error": "Request body exceeds the maximum allowed size."
}
```

## Other errors

The table above is not exhaustive. Some errors are returned without a listed code, and messages can vary by model and endpoint, so branch on the HTTP status rather than on message text. Errors you may see that aren't in the table:

| HTTP Status | When it happens |
| --- | --- |
| 400 | An image input in a chat or Responses request is in an unsupported format |
| 400 | The requested voice isn't available for the text-to-speech model |
| 403 | The request comes from an IP address that isn't on the API key's allowlist |
| 403 | The requested model isn't permitted by the API key's privacy setting |
| 403 | Access to the requested model is restricted. Contact support@venice.ai |
| 409 | A video, music, or voice-changer result is still uploading when you retrieve it. Retry shortly |
| 410 | The endpoint has been retired |
| 422 | Audio is too long or too short (voice cloning, voice changer, and audio jobs) |
| 422 | A video request's input image has a width-to-height ratio outside the range the model accepts |
| 422 | A video request's input was blocked by content moderation |
| 500 | Video or voice-changer generation failed |
| 502 | Speech synthesis failed upstream, or a generated video couldn't be retrieved. Retry the request |
