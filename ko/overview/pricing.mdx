### 웹 검색 및 스크래핑

이 요율은 `venice_parameters`를 통해 활성화되는 chat completions의 웹 검색, 웹 스크래핑, X Search에 적용됩니다.

<div id="pricing-websearch-placeholder">

| Feature | Config | Pricing |
|---|---|---|
| Web Search | `enable_web_search: "on"` | $10.00 per 1K requests |
| Web Scraping | `enable_web_scraping: true` | $10.00 per 1K URLs |
| X Search (xAI) | `enable_x_search: true` | $10.00 per 1K results |

</div>

<Info>
**웹 스크래핑(Web Scraping)** 은 요청당 최대 5개의 URL을 자동으로 감지해 콘텐츠를 구조화된 마크다운으로 스크래핑·변환하고, 추출된 텍스트를 모델 context에 추가합니다. 성공적으로 스크래핑된 URL에 대해서만 과금됩니다.

**X Search**는 지원되는 Grok 모델(예: `grok-4-20`)에서 xAI의 네이티브 검색을 활성화합니다. 웹과 X/Twitter를 모두 검색해 실시간 정보를 가져옵니다. 모델이 반환한 검색 결과당 과금됩니다(예: 모델이 검색 결과 10개를 반환하면 결과당 $0.01 × 10 = $0.10 과금).

이 요금은 표준 모델 토큰 과금에 추가로 부과됩니다.
</Info>

### API 사용량 과금 방식

API 요청은 이 페이지의 요율에 따라 사용한 만큼 과금됩니다. 무제한 API 등급은 없습니다. Free 계정도 API를 호출할 수 있으며, 해당 요청은 동일한 요율로 과금됩니다.

Venice는 각 유료 요청을 다음 순서로 차감합니다: DIEM, 그다음 획득 크레딧, 그다음 번들 크레딧, 그다음 USD. 각 잔액은 단위당 1달러의 가치가 있습니다. [VVV & DIEM](/ko/overview/vvv-diem)을 참고하세요.

이러한 잔액으로 요청을 충당할 수 없으면 API는 `INSUFFICIENT_BALANCE`와 함께 `402`를 반환합니다. [오류 코드](/ko/api-reference/error-codes)를 참고하세요.

유료 플랜에는 월간 번들 크레딧 할당량이 포함됩니다. API는 위의 순서에 따라 이를 사용합니다. Free 계정은 이 할당량을 받지 않습니다.

| 플랜 | 월간 할당량 |
| --- | --- |
| Pro | $1 |
| Plus | $75 |
| Max | $225 |

각 모델에는 고유한 가격이 있습니다. API는 모델을 기본 및 프리미엄 가격 등급으로 묶지 않습니다. 일부 모델은 유료 플랜(Pro, Plus, Max)으로 제한됩니다. 그 외 계정은 `PRO_ONLY_MODEL`과 함께 `401`을 받습니다.

`Variable`로 표시된 행은 요청별로 가격이 책정됩니다. 작업을 대기열에 넣기 전에 견적을 확인하세요. [속도 제한](/ko/api-reference/rate-limiting)을 참고하세요.

요청 한도는 모델 가격이 아니라 모델과 Default 또는 Partner 등급에 따라 달라집니다. [속도 제한](/ko/api-reference/rate-limiting)을 참고하세요.

### 유료 플랜

Pro, Plus, Max 구독자는 API 잔액에 일회성 $5 USD 크레딧을 받습니다. 이 크레딧은 USD 잔액으로 한 번만 지급되며 이 페이지의 요율로 사용됩니다. VVV 스테이킹으로 업그레이드한 계정은 이 크레딧을 받지 않습니다.

유료 구독에는 무료 또는 무제한 API 사용이 포함되지 않습니다.
