[Venice MCP 서버](https://github.com/veniceai/venice-mcp-server)는 Venice를 위한 공식 [Model Context Protocol](https://modelcontextprotocol.io/) 서버입니다. Venice API(chat, image, video, audio, music, embeddings, web augment, characters, 크립토 RPC, TEE 증명)와 계정 작업(과금, API 키)을 모든 MCP 호환 에이전트가 호출할 수 있는 **45개 도구**로 노출합니다.

## 빠른 시작

<Steps>
  <Step title="Venice API 키 발급">
    [venice.ai/settings/api](https://venice.ai/settings/api?utm_source=venice-api-documentation)에서 생성하세요. 단계별 안내는 [API 키 가이드](/guides/getting-started/generating-api-key)를 참고하세요.
  </Step>

  <Step title="MCP 호스트 설정에 Venice 추가">
    MCP 호스트의 설정 파일에 다음을 붙여넣으세요:

    ```json
    {
      "mcpServers": {
        "venice": {
          "command": "npx",
          "args": ["-y", "@veniceai/mcp-server@0.3.0"],
          "env": { "VENICE_API_KEY": "<your-venice-api-key>" }
        }
      }
    }
    ```

    일반적인 설정 경로:

    | Host | Path |
    |---|---|
    | Claude Desktop (macOS) | `~/Library/Application Support/Claude/claude_desktop_config.json` |
    | Claude Desktop (Windows) | `%APPDATA%\Claude\claude_desktop_config.json` |
    | Cursor | `~/.cursor/mcp.json` |
    | LM Studio | `mcp.json` (앱의 MCP 설정에서) |
  </Step>

  <Step title="MCP 호스트 재시작">
    이제 에이전트에서 chat, image, video, music, TTS, ASR, 과금, API 키 및 39개의 Venice 도구를 더 사용할 수 있습니다.
  </Step>
</Steps>

<Note>
대부분의 MCP 호스트는 `env` 블록에 **명시된** 환경 변수만 전달합니다. 시스템 환경 변수는 상속되지 않습니다. API 키를 설정했는데도 402 오류가 보이면 설정의 `env` 안에 `VENICE_API_KEY`가 있는지 확인하세요.
</Note>

## 무엇을 얻나요

모든 Venice 모달리티와 계정 작업을 아우르는 **45개 도구**, **3개 리소스**(`venice://models`, `venice://styles`, `venice://voices`), **3개 프롬프트 템플릿**(무검열 리서치, NSFW 창작 글쓰기, 이미지 스타일 탐색)을 제공합니다.

모든 도구가 `readOnlyHint`, `destructiveHint`, `idempotentHint`, `openWorldHint` 어노테이션을 명시하므로, 호스트는 조회는 확인 없이 실행하고 미디어 정리나 크립토 릴레이 같은 파괴적 작업 전에는 확인을 요청할 수 있습니다.

### Chat 및 임베딩

| 도구 | 설명 |
|---|---|
| `venice_chat` | Venice의 전체 LLM 카탈로그를 대상으로 하는 OpenAI 호환 chat completion. 텍스트/이미지/오디오/비디오/파일 블록, 구조화된 출력, function tool, 프롬프트 캐싱, 추론 제어를 지원합니다. 호출은 평문이며 스트리밍하지 않습니다. |
| `venice_responses` | 알파 단계의 상태 비저장 OpenAI 호환 Responses API. 텍스트/이미지 입력과 추론 제어를 지원합니다. E2EE 지원 모델과 tool 필드는 지원하지 않습니다. |
| `venice_embeddings` | 텍스트 입력에 대한 임베딩을 계산합니다. |
| `venice_chat_with_character` | slug로 Venice 캐릭터와 대화합니다. |

### 이미지

| 도구 | 설명 |
|---|---|
| `venice_image_generate` | 이미지를 생성합니다(Flux 2, Lustify SDXL, Anime/WAI, Qwen Image, GPT Image, Nano Banana Pro 등). 화면 비율 또는 너비/높이, 품질 단계, 프롬프트 개선, 스타일 참조, 웹 검색, 변형 개수를 지원합니다. |
| `venice_image_edit` | 프롬프트로 이미지를 편집합니다. |
| `venice_image_multi_edit` | 최대 8개 이미지를 하나의 프롬프트로 함께 편집합니다(합성 / 아웃페인팅). |
| `venice_image_upscale` | 이미지를 2~4배 업스케일하며 `creativity`를 조절할 수 있습니다. |
| `venice_image_remove_bg` | 이미지 배경을 제거합니다. |
| `venice_image_styles` | 이미지 스타일 프리셋을 나열합니다. |

### 비디오

| 도구 | 설명 |
|---|---|
| `venice_video_generate` | 비디오 생성을 큐에 넣습니다(Sora 2, Veo 3.1, Kling, Wan, LTX 2, Seedance, Runway Gen-4 등). 이미지, 비디오, 오디오, 참조, 엘리먼트 입력을 지원합니다. |
| `venice_video_status` | 큐에 있는 비디오 작업의 상태를 확인합니다(`POST /video/retrieve`). |
| `venice_video_complete` | 완료된 비디오를 다운로드됨으로 표시합니다. Venice가 확인한 경우에만 서버 측 미디어를 삭제합니다. |
| `venice_video_quote` | 큐에 넣기 전에 가격 견적을 받습니다. |

### 오디오 (TTS / ASR)

| 도구 | 설명 |
|---|---|
| `venice_tts` | 복제 음성, temperature, 감정 태그를 지원하는 텍스트 음성 변환. 스트리밍은 하나의 완성된 오디오 결과로 버퍼링됩니다. |
| `venice_asr` | URL의 오디오를 전사하며 단어/문자 타임스탬프를 선택적으로 받습니다. 큰 전사문은 세션 핸들로 페이지 처리됩니다. |
| `venice_voice_clone` | 모델별 음성을 실시간으로 나열하거나 샘플 URL로 음성을 복제합니다(`venice_tts`에 넘길 `vv_<id>` 핸들 반환). |
| `venice_audio_quote` | 음악 생성 가격 견적을 받습니다. |

### 음악

| 도구 | 설명 |
|---|---|
| `venice_music_generate` | 음악 생성을 큐에 넣습니다(`ace-step-15`, `elevenlabs-music`, `minimax-music-v2/v25/v26`, `stable-audio-25`, `mmaudio-v2-text-to-audio`, `elevenlabs-sound-effects-v2`). 가사, 연주곡, 루프, 보이스, 언어, 속도, 길이를 제어합니다. |
| `venice_music_status` | 큐에 있는 음악 작업의 상태를 확인합니다. |
| `venice_music_complete` | 완료된 음악 작업을 다운로드됨으로 표시합니다. |

|---|---|

| `venice_list_characters` | 검색, 태그, 모델, 정렬 필터로 공개 Venice 캐릭터를 나열합니다. **API 키 전용.** |

### TEE 증명

| 도구 | 설명 |
|---|---|
| `venice_tee_attestation` | 자체 32바이트 nonce를 사용해 TEE 지원 텍스트 모델의 하드웨어 증명 자료(Intel TDX quote, 선택적 NVIDIA 증거, 서명 키)를 가져옵니다. |
| `venice_tee_signature` | 완료된 TEE chat 요청 ID에 대한 enclave 서명 페이로드를 가져옵니다. |

<Warning>
두 TEE 도구는 제공자 증거만 반환합니다. 직접 검증하지 않으며 chat을 암호화하지도 않습니다. TEE 모델을 신뢰하기 전에 반환된 nonce, 디버그 모드 상태, 서명 키 바인딩을 직접 검증하고, TEE 모델에는 `venice_chat`을 사용하세요(`venice_responses`는 사용하지 마세요). 이 서버는 `enable_e2ee`를 거부합니다.
</Warning>

### 크립토

| 도구 | 설명 |
|---|---|
| `venice_crypto_networks` | RPC 프록시가 허용하는 실시간 네트워크 slug를 나열합니다. |
| `venice_crypto_rpc` | JSON-RPC 요청 하나 또는 최대 100개 배치를 Ethereum, Base, Arbitrum, Optimism, Polygon, Solana, Starknet, zkSync, Linea, BSC, Avalanche, Blast 등으로 프록시합니다. |

## 구성

서버는 환경 변수로만 구성합니다.

### 모델 및 요청

| 환경 변수 | 기본값 | 비고 |
|---|---|---|
| `VENICE_API_KEY` | _(없음)_ | Venice API 키. 가장 간단한 설정입니다. |
| `VENICE_DEFAULT_CHAT_MODEL` | `deepseek-v4-flash-0731` | |
| `VENICE_DEFAULT_IMAGE_MODEL` | `flux-2-pro` | |
| `VENICE_DEFAULT_TTS_MODEL` | `tts-kokoro` | |
| `VENICE_DEFAULT_ASR_MODEL` | `openai/whisper-large-v3` | |
| `VENICE_DISABLE_NSFW` | `0` | `1`로 설정하면 도구 설명에서 NSFW 기능 안내를 제거합니다. |
| `VENICE_HTTP_TIMEOUT_MS` | `60000` | |
| `VENICE_SIWX_TOKEN` | _(없음)_ | x402 지갑 모드 인증 토큰. [아래 x402](#x402-지갑-모드) 참고. |

`VENICE_API_KEY`와 `VENICE_SIWX_TOKEN`이 모두 설정되면 API 키가 우선합니다.

### 응답 크기 제한

생성된 미디어는 버퍼링되어 base64로 MCP 결과에 포함되므로 모달리티마다 바이트 상한이 있습니다.

| 환경 변수 | 기본값 | 적용 대상 |
|---|---|---|
| `VENICE_MAX_IMAGE_RESPONSE_BYTES` | `33554432` (32 MiB) | `venice_image_generate`, `venice_image_edit`, `venice_image_multi_edit`, `venice_image_upscale`, `venice_image_remove_bg` |
| `VENICE_MAX_VIDEO_RESPONSE_BYTES` | `26214400` (25 MiB) | `venice_video_status` |
| `VENICE_MAX_AUDIO_RESPONSE_BYTES` | `33554432` (32 MiB) | `venice_tts`, `venice_music_status` |

너무 큰 이미지나 TTS 결과는 오류와 함께 폐기됩니다. 너무 큰 비디오나 음악은 큐에 남아 있으므로, 한도를 높인 뒤 같은 queue ID로 상태 도구를 다시 호출할 수 있습니다.

### HTTP 서버

[Streamable HTTP 배포](#셀프-호스팅streamable-http)에서만 해당됩니다.

| 환경 변수 | 기본값 | 비고 |
|---|---|---|
| `PORT` | `3333` | HTTP 리스너 포트. |
| `VENICE_MCP_HOST` | `127.0.0.1` | 바인드 주소. LAN 또는 컨테이너 노출 시 `0.0.0.0`. |
| `VENICE_MCP_AUTH_TOKEN` | _(없음)_ | 루프백 외부에 바인드할 때 `/mcp`가 요구하는 bearer 토큰. |
| `VENICE_MCP_ALLOW_UNAUTHENTICATED_HTTP` | `0` | 인증 없는 노출 HTTP용 비상 수단. 신뢰하는 인증 프록시 뒤에서만 사용하세요. |
| `VENICE_MCP_MAX_SESSIONS` | `100` | 최대 활성 Streamable HTTP 세션 수. |
| `VENICE_MCP_SESSION_TTL_MS` | `1800000` | 정리 전 유휴 세션 수명. |

## 미디어 생성 동작

- **완료된 미디어는 바이트 또는 URL일 수 있습니다.** 비디오와 음악 작업은 포함된 MP4/오디오 리소스 또는 `download_url`이 resource link로 돌아오는 JSON을 반환합니다. 먼저 그 링크를 다운로드한 뒤 `venice_video_complete` 또는 `venice_music_complete`를 호출하세요. 파일이 삭제되면 링크가 동작하지 않으므로 `download_url` 결과에는 미디어 정리가 적용되지 않습니다.
- **일부 모델은 큐 시점에만 URL을 반환합니다.** VPS 및 Grok Imagine Private 모델에서는 `venice_video_generate`가 반환한 `download_url`을 보관해 `venice_video_status`에 넘기세요. 인라인 URL 없는 `COMPLETED` retrieve도 사용 가능한 링크를 제공합니다.
- **프롬프트 개선 결과가 반환됩니다.** `enhance_prompt`가 적용되면 이미지 생성, 편집, 멀티 편집 결과에 Venice가 반환한 URL 디코딩된 프롬프트가 포함됩니다.
- **ASR 페이지는 한 번만 과금됩니다.** 타임스탬프가 있거나 8000자를 넘는 전사문은 첫 페이지와 함께 `result_handle`을 반환합니다. 이후 페이지는 그 핸들로 요청하세요. 핸들은 MCP 세션별 메모리에 10분간 유지되고 최근 16개만 보존됩니다.
- **Seedance 동의는 정책 우회가 아닙니다.** 현재 공개 Seedance 모델은 식별 가능한 인물이 포함된 미디어를 아예 거부할 수 있습니다. `needs_consent` 응답이 반환되면 `consents.seedance`의 세 플래그는 법적 확인 사항입니다. 사용자가 각 항목을 명시적으로 확인한 뒤에만 `true`로 설정하세요.

## x402 지갑 모드

Venice는 일반 API 키 흐름 외에도 Base 또는 Solana의 선불 USDC 크레딧으로 뒷받침되는 [Sign-In-With-X 지갑 토큰](/guides/integrations/x402-venice-api) 인증을 지원합니다. 이메일, 전화, KYC가 필요 없습니다. 지갑이 유일한 신원입니다.

```json
{
  "mcpServers": {
    "venice": {
      "command": "npx",
      "args": ["-y", "@veniceai/mcp-server@0.3.0"],
      "env": { "VENICE_SIWX_TOKEN": "<base64 Sign-In-With-X payload>" }
    }
  }
}
```

MCP 서버는 모든 Venice API 호출에서 `VENICE_SIWX_TOKEN`을 `SIGN-IN-WITH-X` 헤더로 전달합니다. 서버는 개인 키를 절대 보지 않습니다. 지갑 서명과 USDC 충전 승인은 사용자의 지갑에서 이루어집니다.

| 흐름 | 무슨 일이 일어나나요 |
|---|---|
| **최초 설정** | 지갑에서 Sign-In-With-X 메시지에 서명 → SIWX 토큰(base64 JSON) 생성. |
| **충전** | `POST /api/v1/x402/top-up`가 402 + 결제 요구 사항을 반환합니다. 반환된 Base 또는 Solana 옵션 중 하나에 대해 USDC 결제에 서명하고 다시 제출하면 Venice가 잔액을 적립합니다. |
| **모든 추론 호출** | MCP 서버가 `SIGN-IN-WITH-X: <SIWX>`를 보내고, Venice가 선불 잔액을 차감합니다. |

최소 충전 금액은 **\$5 USD**입니다. 추론 호출을 위한 최소 잔액은 **\$0.10**입니다. 충전 후에는 빠른 크레딧 계정에서 오프체인으로 정산되므로 호출이 100ms 미만입니다.

<Tip>
DIEM을 스테이킹한 Venice 계정에 연결된 지갑은 USDC 크레딧 대신 스테이킹 잔액에서 차감되므로 충전이 필요 없습니다.
</Tip>

Venice는 추론 경로에서 결제 헤더를 허용하지 않으므로 이 서버는 결제 헤더를 보내지 않습니다. `PAYMENT-SIGNATURE`는 `/x402/top-up`에만 해당하며, 충전 헬퍼는 결제를 제출하지 않고 요구 사항만 조회합니다.

### 인증 모드 지원 범위

일부 엔드포인트는 한 가지 인증 모드만 허용합니다:

| 도구 | API 키 | x402 |
|---|---|---|
| 추론, 미디어, 웹 augment, 크립토 RPC, 캐릭터 chat | ✓ | ✓ |
| `venice_list_characters`, `venice_get_character`, `venice_character_reviews` | ✓ | ✗ |
| `venice_billing_*`, `venice_list_api_keys`, `venice_get_api_key`, `venice_api_key_rate_limit_logs` | ✓ (admin) | ✗ |
| `venice_api_key_rate_limits` | ✓ (모든 키) | ✗ |
| `venice_x402_balance`, `venice_x402_transactions` | ✗ | ✓ |
| `venice_x402_top_up_info` | ✓ | ✓ |

두 자격 증명을 모두 설정하면 모든 호출에서 API 키가 우선하므로, SIWX 전용 헬퍼(`venice_x402_balance`, `venice_x402_transactions`)는 지갑 토큰만 자격 증명일 때만 동작합니다.

## 셀프 호스팅(Streamable HTTP)

팀 또는 워크스페이스 배포에서는 MCP 서버를 stdio 대신 HTTP로 실행하세요:

```bash
docker run -p 3333:3333 \
  -e VENICE_API_KEY=<your-venice-api-key> \
  -e VENICE_MCP_AUTH_TOKEN=<choose-a-long-random-token> \
  ghcr.io/veniceai/venice-mcp-server:latest
```

서버는 이제 `http://localhost:3333/mcp`에서 사용할 수 있습니다. HTTP 클라이언트는 `Authorization: Bearer <VENICE_MCP_AUTH_TOKEN>`을 보내야 하며, `mcp-session-id` 헤더 없이 새 세션을 만들고 서버가 발급한 세션 ID를 재사용해야 합니다.

<Warning>
`/mcp`는 자격 증명 기반 도구 실행 엔드포인트입니다. 호출자는 설정된 Venice API 키나 x402 잔액을 소비할 수 있습니다. HTTP 모드가 루프백 외부에 바인드하면 `VENICE_MCP_AUTH_TOKEN`이 설정되어 있거나, 신뢰하는 인증 프록시 뒤에서 `VENICE_MCP_ALLOW_UNAUTHENTICATED_HTTP=1`을 명시한 경우가 아니면 시작에 실패합니다. 프로덕션에서는 `latest`에 의존하지 말고 npm 패키지 버전을 명시적으로 고정하세요.
</Warning>
