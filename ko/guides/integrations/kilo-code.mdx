[Kilo Code](https://kilo.ai/)는 VS Code 및 터미널을 위한 오픈 소스 AI 코딩 에이전트입니다. Venice는 **네이티브 제공자**로 제공되므로, OpenAI 호환 사용자 지정 엔드포인트를 구성하지 않고도 Venice 모델을 선택할 수 있습니다.

## 사전 요구 사항

- [venice.ai/settings/api](https://venice.ai/settings/api)에서 받은 Venice API 키
- [VS Code용 Kilo Code](https://marketplace.visualstudio.com/items?itemName=kilocode.Kilo-Code) 및/또는 [Kilo CLI](https://kilo.ai/docs/code-with-ai/platforms/cli)

## 설정

<Tabs>
  <Tab title="VS Code">
    <Steps>
      <Step title="Kilo Code 설치">
        VS Code에서 **Extensions**를 열고 **Kilo Code**를 검색한 다음, [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=kilocode.Kilo-Code)에서 설치하세요.

        해당 빌드가 현재 권장 빌드로 지정되어 있다면 Marketplace의 **Pre-Release** 채널을 사용하는 것이 좋습니다 — [Kilo의 설치 문서](https://kilo.ai/docs/getting-started/installing)를 참조하세요.
      </Step>

      <Step title="Venice API 키 발급">
        [venice.ai/settings/api](https://venice.ai/settings/api)에서 키를 생성하세요. 즉시 복사하여 안전하게 보관하세요.
      </Step>

      <Step title="Venice 제공자 추가">
        Kilo **Settings**(톱니바퀴 아이콘)를 열고 **Providers** 탭으로 이동하세요. **Venice AI**를 선택하고 Venice API 키를 붙여넣으세요.

        확장 프로그램은 제공자 정보를 `kilo.json` 설정 파일에 저장합니다. 해당 파일을 직접 편집할 수도 있습니다 — 형식은 **CLI** 탭을 참조하세요.
      </Step>

      <Step title="모델 선택 및 테스트">
        모델 선택기에서 Venice 모델을 선택한 다음, 다음과 같은 작은 작업을 보내보세요:

        ```txt
        Review the current file and suggest one safe improvement.
        ```

        사용 가능한 ID는 [텍스트 모델 카탈로그](/models/text)에서 확인하세요.
      </Step>
    </Steps>
  </Tab>

  <Tab title="CLI">
    <Steps>
      <Step title="Kilo CLI 설치">
        ```bash
        npm install -g @kilocode/cli
        kilo --version
        ```

        다른 설치 옵션은 [Kilo CLI 문서](https://kilo.ai/docs/code-with-ai/platforms/cli)를 참조하세요.
      </Step>

      <Step title="Venice API 키 설정">
        Kilo를 실행할 셸에서 키를 내보내세요:

        ```bash
        export VENICE_API_KEY="your-api-key"
        ```
      </Step>

      <Step title="Venice 제공자 구성">
        `~/.config/kilo/kilo.json`(전역) 또는 `./kilo.json`(프로젝트)을 생성하거나 편집하세요:

        ```json
        {
          "provider": {
            "venice": {
              "env": ["VENICE_API_KEY"]
            }
          },
          "model": "venice/zai-org-glm-5-1"
        }
        ```

        `zai-org-glm-5-1`을 [텍스트 모델 카탈로그](/models/text)의 원하는 모델 ID로 교체하세요. Kilo의 모델 참조는 `venice/<model-id>` 형식을 사용합니다.
      </Step>

      <Step title="Kilo 시작">
        프로젝트 디렉터리에서:

        ```bash
        kilo
        ```

        기본 `model`을 설정하지 않았다면 모델 선택기에서 Venice 모델을 선택한 다음, 짧은 테스트 프롬프트를 보내세요.
      </Step>
    </Steps>
  </Tab>
</Tabs>

## Venice API 확인

Kilo가 연결할 수 없다면, 키와 모델 ID를 독립적으로 확인하세요:

```bash
curl https://api.venice.ai/api/v1/models \
  -H "Authorization: Bearer $VENICE_API_KEY"
```

모델의 `id`를 Kilo에 정확히 복사하세요. CLI 설정에서는 `venice/zai-org-glm-5-1`처럼 `venice/` 접두사를 붙이세요.

## 구성 참고 사항

- Venice는 Kilo의 **네이티브** 제공자입니다. 일반적인 OpenAI 호환 사용자 지정 엔드포인트보다 Providers 설정의 **Venice AI**를 사용하는 것이 좋습니다.
- 확장 프로그램과 CLI는 동일한 설정 파일(전역은 `~/.config/kilo/kilo.json`, 프로젝트는 `./kilo.json`)을 공유합니다.
- 일부 Venice 모델은 추론 제어를 제공합니다. Kilo는 선택된 모델이 지원할 때 추론 노력(effort) 및 사고 비활성화 옵션을 매핑합니다.
- 모델 ID와 요금제 액세스는 변경될 수 있습니다. 최신 목록은 모델 선택기, [텍스트 모델 카탈로그](/models/text) 또는 `GET /models`를 사용하세요.
- Venice API 키는 비공개로 유지하세요. 소스 파일에 붙여넣거나 git에 커밋하지 마세요.

## 문제 해결

<AccordionGroup>
  <Accordion title="잘못된 API 키 또는 401">
    키가 [venice.ai/settings/api](https://venice.ai/settings/api)에서 발급된 것인지 확인하세요. CLI의 경우, Kilo를 실행하는 것과 동일한 환경에 `VENICE_API_KEY`가 설정되어 있는지 확인하세요. VS Code에서는 **Providers**에서 Venice AI를 다시 연결하세요.
  </Accordion>
  <Accordion title="모델을 사용할 수 없음">
    Venice 계정이 선택한 모델에 액세스할 수 있는지 확인하고, [텍스트 모델 카탈로그](/models/text) 또는 `GET /models`에서 ID를 복사하세요. CLI 설정에서는 `venice/<model-id>` 형식을 사용하세요.
  </Accordion>
  <Accordion title="확장 프로그램에서 Providers 설정을 찾을 수 없음">
    현재 권장 Kilo 빌드로 업데이트하세요(Pre-Release가 문서상 기본값일 때는 해당 채널 포함). CLI 탭에 표시된 것처럼 `kilo.json`에서 제공자를 설정할 수도 있습니다 — 확장 프로그램은 동일한 설정을 읽습니다.
  </Accordion>
</AccordionGroup>
