이미지 업스케일링은 기존 이미지의 해상도와 시각적 품질을 향상시킵니다. 이미지를 `/image/upscale`로 전송하고 스케일 배수와 선택적 창의성 수준을 선택하면, Venice가 향상된 이미지를 바이너리 데이터로 반환합니다.

이미 이미지를 가지고 있고 더 높은 해상도의 출력을 원할 때 이미지 업스케일링을 사용하세요. 프롬프트로부터 이미지를 생성해야 한다면 [이미지 생성](/ko/guides/media/image-generation)을, 이미지 콘텐츠를 변경해야 한다면 [이미지 편집](/ko/guides/media/image-editing)을 사용하세요.

## 기본 사용법

<CodeGroup>
```python Python
import base64
import os
from pathlib import Path

import requests

image_base64 = base64.b64encode(Path("input.jpg").read_bytes()).decode("utf-8")

response = requests.post(
    "https://api.venice.ai/api/v1/image/upscale",
    headers={
        "Authorization": f"Bearer {os.environ['VENICE_API_KEY']}",
        "Content-Type": "application/json",
    },
    json={
        "image": image_base64,
        "scale": 2,
        "creativity": 0.01,
    },
)

response.raise_for_status()
Path("upscaled.png").write_bytes(response.content)
```

```javascript Node.js
import { readFile, writeFile } from "node:fs/promises";

const image = await readFile("input.jpg");

const response = await fetch("https://api.venice.ai/api/v1/image/upscale", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.VENICE_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    image: image.toString("base64"),
    scale: 2,
    creativity: 0.01,
  }),
});

if (!response.ok) {
  throw new Error(await response.text());
}

const output = Buffer.from(await response.arrayBuffer());
await writeFile("upscaled.png", output);
```

```bash cURL
IMAGE_BASE64=$(base64 < input.jpg | tr -d '\n')

curl https://api.venice.ai/api/v1/image/upscale \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d "{
    \"image\": \"$IMAGE_BASE64\",
    \"scale\": 2,
    \"creativity\": 0.01
  }" \
  --output upscaled.png
```
</CodeGroup>

base64로 인코딩하는 대신 `multipart/form-data`로 파일을 직접 업로드할 수도 있습니다:

```bash cURL (multipart)
curl https://api.venice.ai/api/v1/image/upscale \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -F "image=@input.jpg" \
  -F "scale=2" \
  -F "creativity=0.01" \
  --output upscaled.png
```

요청당 정확히 하나의 `image` 파트만 전송하세요. 업로드하는 파일은 25 MB 미만이어야 합니다.

## 매개변수

| 매개변수 | 유형 | 필수 여부 | 설명 |
|-----------|------|----------|-------------|
| `image` | string 또는 파일 | 예 | 소스 이미지. JSON에서 base64로 보내거나 `multipart/form-data`로 파일 파트를 업로드하세요. 최소 256×256 픽셀이어야 합니다. 파일 업로드는 25 MB 이하여야 하며, JSON 본문은 최대 35 MB입니다. |
| `scale` | number | 아니요 | `2`에서 `4` 사이의 업스케일 배수. 기본값은 `2`이며, `2` 또는 `4`를 사용하세요(중간 값도 허용되지만 4x 요금으로 청구됩니다). 출력은 16,777,216 픽셀(4096×4096)로 제한됩니다. 요청한 배수가 이 한도를 초과하면 서버가 실제 배수를 자동으로 줄입니다. 이미 한도에 도달했거나 근접한 입력은 `400`으로 거부되므로 먼저 크기를 줄이세요. |
| `creativity` | number | 아니요 | 업스케일러가 추가하는 디테일과 텍스처의 양. `0`–`0.02`, 기본값 `0.01`. 값이 높을수록 더 많이 추가하고, 낮을수록 원본에 더 가깝게 유지됩니다. 범위를 벗어난 값은 가장 가까운 경계값으로 조정됩니다. |

<Note>
응답은 JSON이 아닌 바이너리 이미지 데이터입니다. 응답 본문을 파일에 직접 쓰거나 스토리지로 스트리밍하세요.
</Note>

## 입력 팁

- 최대한 깨끗한 소스 이미지에서 시작하세요. 업스케일링은 세부 정보를 개선하지만, 원본에 없는 정보를 완전히 복원하지는 못합니다.
- 프로덕션 워크플로에서는 적당한 스케일 배수를 사용하세요. 매우 큰 출력은 지연 시간과 파일 크기를 증가시킬 수 있습니다.
- 품질을 비교하거나 다른 설정으로 재시도해야 할 경우를 대비해 원본 이미지를 보관해 두세요.
