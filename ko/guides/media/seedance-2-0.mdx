Seedance는 텍스트, 이미지, 레퍼런스 기반 비디오 생성을 위한 Venice의 대표 멀티모달 비디오 패밀리입니다. **Seedance 2.0** (그리고 Fast)과 **Seedance 2.5**는 동일한 R2V 프롬프트 라우팅 모델을 공유합니다. 단일 reference-to-video 엔드포인트가 **네 가지 서로 다른 워크플로우** (Reference, Edit, Extend, Stitch)를 처리하며, 워크플로우는 **프롬프트의 형태**로부터 추론됩니다.

이 가이드에서는 변형, 네 가지 워크플로우, **faces-off 공개 API 동작**, **패밀리별 멀티모달 제한**, 요금, `curl` 예제를 다룹니다.

<Warning>
**공개 Seedance API에서는 얼굴이 지원되지 않습니다.** Venice는 공개 Seedance 모델에 대해 얼굴 자산 프로비저닝이나 얼굴 동의 확인(`consents.seedance` / `needs_consent`)을 실행하지 않습니다. 얼굴이 포함된 입력은 업스트림에서 콘텐츠 정책/공급자 오류로 거부될 수 있습니다. 얼굴/초상 생성에는 Venice 앱 또는 Studio를 사용하세요.
</Warning>

## 변형

| Model ID | 변형 | 출력 해상도 | 참고 |
|---|---|---|---|
| `seedance-2-0-text-to-video-basic` | T2V | 480p / 720p / 1080p / **4k** | 텍스트 prompt 전용 |
| `seedance-2-0-image-to-video-basic` | I2V | 480p / 720p / 1080p / **4k** | 첫 프레임(선택적으로 마지막 프레임) 이미지 기반 |
| `seedance-2-0-reference-to-video-basic` | R2V | 480p / 720p / 1080p / **4k** | 최대 레퍼런스 이미지 9개 + 레퍼런스 비디오 3개 + 레퍼런스 오디오 도너 3개. Reference / Edit / Extend / Stitch 지원 |
| `seedance-2-0-fast-text-to-video-basic` | Fast T2V | 480p / 720p | 더 빠르고 낮은 품질의 티어(1080p / 4k 불가) |
| `seedance-2-0-fast-image-to-video-basic` | Fast I2V | 480p / 720p | 더 빠르고 낮은 품질의 티어(1080p / 4k 불가) |
| `seedance-2-0-fast-reference-to-video-basic` | Fast R2V | 480p / 720p | 더 빠르고 낮은 품질의 티어(1080p / 4k 불가). 동일한 워크플로우 세트 |
| `seedance-2-5-text-to-video-basic` | T2V | 480p / 720p | 최대 30초 출력, 네이티브 오디오 |
| `seedance-2-5-image-to-video-basic` | I2V | 480p / 720p | 최대 30초 출력, 첫 프레임(선택적으로 마지막 프레임) 기반 |
| `seedance-2-5-reference-to-video-basic` | R2V | 480p / 720p | 최대 이미지 30개 + 비디오 10개 + 오디오 도너 10개. 동일한 Reference / Edit / Extend / Stitch 워크플로우 |

모든 변형은 비동기입니다. `POST /api/v1/video/queue`로 제출한 뒤 응답 본문이 `video/mp4`가 될 때까지 `POST /api/v1/video/retrieve`를 폴링하세요. 일반 큐 흐름은 [Video Generation](/guides/media/video-generation)을 참고하세요.

`resolution`은 `480p`, `720p`, `1080p`, `4k` 중 하나(소문자)로 전달합니다. Seedance **2.0** (Fast 제외)은 네 가지 모두를 허용하며, **2.0 Fast**와 **2.5**는 `480p` / `720p`만 허용합니다. 실시간 모델 ID와 기능은 `GET /models?type=video`로 조회하고, 사용 가능 여부를 하드코딩하지 마세요.

## "하나의 모델, 네 가지 워크플로우" 모델

reference-to-video 변형(`seedance-2-0-reference-to-video-basic`, 그 Fast 형제, 그리고 `seedance-2-5-reference-to-video-basic`)은 동일한 프롬프트 라우팅 패턴을 사용합니다. **모델은 prompt 접두사와 입력의 형태로부터 작업을 추론합니다.** `task`나 `workflow` 필드는 없으며, prompt 구문 자체가 라우팅입니다.

| 워크플로우 | 하는 일 | Prompt 접두사 | 입력 |
|---|---|---|---|
| **Reference** | 업로드된 레퍼런스 파일을 피사체/모션/스타일/오디오의 도너로 사용해 새 비디오 생성 | `Refer to ... in <Image\|Video\|Audio N> to generate ...` | 텍스트 + 이미지 또는 비디오 레퍼런스 1개 이상, 오디오 도너는 선택(개수는 패밀리별 상이 — 제한 참고) |
| **Edit** | 단일 입력 비디오를 수정하고 나머지는 보존 | `Strictly edit <Video 1>, changing its ...` | 입력 비디오 1개 + 텍스트 (이미지는 선택적 기반) |
| **Extend** | 하나의 클립을 앞/뒤로 확장 | `Extend <Video 1>, generate ...` | 입력 비디오 1개 + 텍스트 |
| **Stitch** | 자동 생성 전환으로 입력 클립들을 결합 | `<Video 1> + <transition description> + followed by <Video 2> + ...` | 여러 입력 비디오 + 텍스트 (클립 수/길이 제한은 패밀리별 상이) |

**prompt 구문은 정규 형식이며 대소문자를 구분합니다**: 꺾쇠 괄호, 대문자로 시작하는 첫 글자, 숫자 앞의 단일 공백. 예: `<Video 1>`, `<Image 1>`, `<Audio 1>`.

## 워크플로우 패턴

### Reference 워크플로우

업로드된 레퍼런스 파일을 **도너**(피사체, 장면, 모션, 스타일, 성문)로 사용해 완전히 새로운 비디오를 생성합니다.

**정규 prompt 패턴**:

```
Refer to <Subject N> in <Image N> to generate ...
Refer to the [action | camera scene | style | sound effect] in <Video N> to generate ...
Refer to the [tone | timbre] in <Audio N> to generate ...
```

**예시**:

- `Refer to <Subject 1> in <Image 1> to generate a 5-second clip of the same character riding a horse through snow.`
- `Refer to the camera scene in <Video 1> to generate a similar establishing shot of a futuristic city at dawn.`
- `Refer to <Subject 1> in <Image 1> and use the timbre in <Audio 1> for the narrator describing the scene.` (오디오 도너는 최소 하나 이상의 이미지 또는 비디오 레퍼런스와 함께 사용해야 하며, 오디오만 있는 경우 거부됩니다)

### Edit 워크플로우

단일 입력 비디오를 수정합니다. **prompt에 명시적으로 언급되지 않은 것은 모두 보존됩니다.** 완전히 새로운 비디오가 아니라 국소적인 변경(피사체 교체, 날씨/색상 변경, 요소 추가/제거)이 필요할 때 사용하세요.

**정규 prompt 패턴**:

```
Strictly edit <Video 1>, changing its [original feature] to [new feature] ...
```

**세밀한 제어를 위한 하위 패턴**:

```
Add Elements:
  At [timestamp / timing] and [spatial location] of <Video 1>, add [description of intended element].

Remove Elements:
  Remove [element to be deleted] from <Video 1>, keeping the rest of the video content unchanged.

Modify Elements:
  Replace [description of element to be changed] in <Video 1> with [description of intended element].
```

**예시**:

- `Strictly edit <Video 1>, changing its weather from sunny to a heavy rainstorm.`
- `Add snacks such as fried chicken and pizza to the countertop in <Video 1>.`
- `Remove the red car from <Video 1>, keeping the rest of the video content unchanged.`
- `Replace the perfume featured in <Video 1> with the face cream from <Image 1>, with all original motions and camera work preserved.`

마지막 예시는 Edit와 이미지 레퍼런스를 결합합니다. 완전히 유효하며, 모델은 `<Image 1>`을 교체 대상의 시각적 도너로 사용합니다.

### Extend 워크플로우

단일 클립을 시간상 앞이나 뒤로 이어줍니다. **기본적으로 Seedance는 새로 생성된 콘텐츠만 반환하며**, 원본 입력과 확장이 연결된 결과는 반환하지 않습니다. 이는 전환 연속성을 위한 의도된 동작입니다. 확장과 함께 입력 클립도 보존하려면 명시적으로 지시하세요:

```
Extend <Video 1>, generate [description of extended content]
Extend <Video 1> backward, [description of extended content]
Extend <Video 1>, start with <Video 1>, then [description of extended content]      ← 시작에 입력 보존
Extend <Video 1> backward, [description], and then end with <Video 1>               ← 끝에 입력 보존
```

전환 처리: 모델은 자연스러운 블렌딩을 위해 전환 프레임을 자동으로 추출하며, 입력 비디오의 원본 구간은 재생성되지 않습니다.

**예시**:

- `Extend <Video 1>, generate a dramatic chase scene through narrow alleys at dusk.`
- `Extend <Video 1> backward, the same character walking toward the camera before the original shot begins.`
- `Extend <Video 1>, start with <Video 1>, then the camera pulls back to reveal a vast landscape.`

### Stitch 워크플로우 (Track Completion)

AI가 생성한 전환으로 입력 클립들을 연결합니다. [멀티모달 입력 제한](#multimodal-input-limits)에 명시된 **패밀리별** 결합 길이 및 클립 수 제한을 준수하세요 (Seedance 2.0: 최대 3개 클립 / 결합 15초 이하, Seedance 2.5: 더 높은 비디오 상한).

**정규 prompt 패턴**:

```
<Video 1> + [transition description] + followed by <Video 2> [+ [transition description] + followed by <Video 3>]
```

**예시**:

- `<Video 1> + a smooth seamless cut + followed by <Video 2>`
- `<Video 1>. The moment a leaf falls to the ground, it sets off a special effect of golden particles. A gust of wind blows by, leading into <Video 2>.`
- `<Video 1> + a wisp of smoke transforms into a flock of birds + followed by <Video 2> + a slow dolly-in + followed by <Video 3>`

모델은 연결 지점의 연결 구간을 연속성을 위해 자동으로 다듬습니다.

## 범용 prompt 공식

네 가지 워크플로우 모두에서 권장되는 작성 공식은 다음과 같습니다:

```
Subject + Motion + Environment (Optional)
       + Camera Movement / Cut (Optional)
       + Aesthetic Description (Optional)
       + Audio (Optional)
```

- **Subject + Motion**: 논리적 기반으로, "누가" "어떤 행동을" 수행하는지 정의
- **Environment + Aesthetics**: 공간 배경, 조명, 시각 스타일
- **Camera**: 명시적 샷 유형이나 카메라 무빙
- **Audio**: 몰입감 있는 출력을 위한 주변 사운드 효과나 보이스 디렉션

워크플로우 접두사 위에 이 요소들을 층층이 쌓으면(예: `Strictly edit <Video 1>, changing its <subject + motion + environment + ...>`) 최고 품질의 결과물이 생성됩니다.

## 멀티모달 입력 제한

아래 값은 Venice API가 허용하는 값입니다. 이 범위를 벗어나는 요청은 추론 단계에 도달하기 전에 스키마 계층에서 400으로 거부됩니다.

**Seedance 2.0과 Seedance 2.5는 서로 다른 상한을 사용합니다.** 호출하려는 모델 패밀리에 해당하는 열을 항상 확인하세요.

### 공유 미디어 기준

| 제약 | 값 |
|---|---|
| 이미지/비디오/오디오 입력 방식 | URL (`http://`, `https://`) 또는 Base64 data URL |
| 이미지 형식 | `.jpeg`, `.png`, `.webp`, `.bmp`, `.tiff`, `.gif`, `.heic`, `.heif` |
| 이미지 종횡비 (W / H) | 배타적 `(0.4, 2.5)` |
| 이미지 최소 변 | ≥ 300 px |
| 비디오 형식 | `.mp4`, `.mov` |
| 비디오 코덱 | H.264 / AVC, H.265 / HEVC |
| 오디오 코덱 (컨테이너 내) | AAC, MP3 |
| 오디오 형식 (레퍼런스 오디오) | `.wav`, `.mp3` |
| 클립당 비디오 크기 | ≤ 50 MB |
| 클립당 오디오 크기 | ≤ 15 MB |
| I2V 첫 프레임 이미지 | 1 |
| I2V 첫 + 마지막 프레임 | 2 |

### 패밀리 비교

| 제약 | Seedance 2.0 (+ Fast) | Seedance 2.5 |
|---|---|---|
| 출력 길이 | 4–15초 | 4–30초 (기본 10) |
| 출력 해상도 | 480p / 720p / 1080p / **4k** (Fast: 480p / 720p만) | 480p / 720p만 |
| R2V 레퍼런스 이미지 | 1–9 | 1–30 |
| R2V 레퍼런스 이미지 최대 바이트 | (공유 요청 제한) | 이미지당 ≤ 30 MB |
| R2V 레퍼런스 비디오 | ≤ 3 | ≤ 10 |
| 레퍼런스 비디오당 길이 | `[2, 15]`초 | `[2, 30]`초 |
| 결합 레퍼런스 비디오 길이 | ≤ 15초 | ≤ 30초 |
| R2V 레퍼런스 오디오 클립 | ≤ 3 | ≤ 10 |
| 레퍼런스 오디오당 길이 | `[2, 15]`초 | `[2, 30]`초 |
| 결합 레퍼런스 오디오 길이 | ≤ 15초 | ≤ 30초 |

레퍼런스 오디오는 R2V 변형에서만 지원됩니다. 각 항목은 `role: "reference_audio"` 콘텐츠 항목으로 모델에 전달되며 prompt에서는 `<Audio 1>`, `<Audio 2>` 등으로 참조합니다. 모델은 prompt가 어떻게 구성되었는가에 따라 각 클립을 성문, 사운드 효과, 배경 음악 등에 사용합니다. 레거시 단수형 `audio_url` 필드는 동일한 콘텐츠 구조에 매핑되며 이제는 요소가 하나인 `reference_audio_urls`를 전달하는 것과 동등합니다.

<Warning>
**`reference_audio_urls`만 단독으로 레퍼런스 입력이 될 수는 없습니다.** 모델은 오디오 도너와 함께 최소 하나의 이미지 또는 비디오 레퍼런스를 필요로 합니다. `reference_audio_urls`는 `reference_image_urls`, `reference_video_urls`, `image_url`, 또는 `video_url`과 함께 사용하세요. 오디오만 전송하는 요청은 거부됩니다.
</Warning>

### 요청 크기

큐 엔드포인트는 최대 **35 MB**의 JSON 본문을 허용합니다. 대용량 비디오를 인라인 data URL로 전달하면 이 한도를 초과할 수 있습니다. 특히 다중 클립 Stitch에서는 인라인 base64 대신 URL을 권장합니다.

## 요금

`/video/queue`에 요청을 제출하기 전에 `POST /api/v1/video/quote`를 호출해 특정 요청 형태에 대한 견적을 얻으세요. 견적 엔드포인트가 유일한 권위 있는 소스입니다. 요금 세부 정보는 변경될 수 있으므로 클라이언트 측에서 캐시하거나 중복 저장해서는 안 됩니다.

레퍼런스 비디오가 요청에 포함된 경우, 견적이 `/video/queue`에서 부과할 금액과 일치하도록 `reference_video_total_duration`(모든 레퍼런스 클립 길이의 초 단위 합계)도 함께 전달하세요:

```bash
curl -X POST https://api.venice.ai/api/v1/video/quote \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-2-0-reference-to-video-basic",
    "duration": "5s",
    "resolution": "1080p",
    "aspect_ratio": "16:9",
    "reference_video_total_duration": 5
  }'
```

## 완전한 예제

모든 예제는 `VENICE_API_KEY`가 환경 변수로 설정되어 있다고 가정합니다.

### Text-to-video

```bash
curl -X POST https://api.venice.ai/api/v1/video/queue \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-2-0-text-to-video-basic",
    "prompt": "A golden retriever frolicking through a sunlit meadow at sunset, slow camera dolly-in, shallow depth of field, warm cinematic lighting.",
    "duration": "5s",
    "aspect_ratio": "16:9",
    "resolution": "1080p"
  }'
```

### Seedance 2.0 text-to-video (4K)

```bash
curl -X POST https://api.venice.ai/api/v1/video/queue \
  -H "Authorization: Bearer $VENICE_API_KEY" \
```

### 완료 폴링

큐에 제출할 때마다 반환된 `queue_id`를 저장하고, 응답 본문이 `video/mp4`가 될 때까지 `/video/retrieve`를 폴링하세요:

```bash
curl -X POST https://api.venice.ai/api/v1/video/retrieve \
  -H "Authorization: Bearer $VENICE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-2-0-reference-to-video-basic",
    "queue_id": "123e4567-e89b-12d3-a456-426614174000"
  }' \
  -o output.mp4
```

작업이 완료될 때까지 응답은 JSON(`{ "status": "queued" | "running" | "failed", ... }`)이며, 완료 시점에 응답 본문은 `video/mp4` 바이트로 전환됩니다. 전체 폴링 패턴은 [Video Generation](/guides/media/video-generation)을 참고하세요.

## 문제 해결

### `At least one reference is required for this model`

Reference-to-video 제출에는 `reference_image_urls`, `reference_video_urls`, `image_references`, `video_references` 중 최소 하나가 포함되어야 합니다. 순수 텍스트 전용 생성은 유효한 R2V 워크플로우가 아니며, text-to-video 모델 ID를 사용하세요. `reference_audio_urls`만으로는 충분하지 않습니다 (위 오디오 섹션 참고).

### 레퍼런스 비디오/이미지가 너무 많음

Seedance **2.0**은 R2V를 **이미지 9개**와 **비디오 3개**로 제한합니다. Seedance **2.5**는 이 제한을 **이미지 30개**와 **비디오 10개**로 상향합니다. 패밀리 제한을 초과할 경우, 입력을 다듬거나 사전에 오프라인으로 결합하세요.

### 길이 / 합계 길이 오류

- **2.0:** 레퍼런스 비디오/오디오 클립당 `[2, 15]`초, 결합 비디오/오디오 ≤ 15초, 출력 4–15초.
- **2.5:** 레퍼런스 비디오/오디오 클립당 `[2, 30]`초, 결합 비디오/오디오 ≤ 30초, 출력 4–30초.

제출 전에 클라이언트 측에서 클립을 다듬으세요.

### Prompt가 잘못된 워크플로우로 라우팅됨

워크플로우는 prompt 구문에서 추론됩니다. 흔한 오라우팅 사례:

- **Extend**하려는데 `Refer to ...`로 작성 → 모델이 비디오를 이어갈 캔버스가 아니라 *도너*로 취급
- **Stitch**하려는데 `Refer to ...`로 작성 → 모델이 하나를 도너로 선택하고 나머지는 무시
- **Edit**하려는데 `Generate a video based on <Video 1>`로 작성 → 모호하며, 모델은 기본적으로 Reference로 처리할 수 있음

정규 접두사를 정확히 그대로 사용하세요: `Strictly edit <Video 1>, ...`, `Extend <Video 1>, ...`, `<Video 1> + ... + followed by <Video 2>`.

### 얼굴/초상 입력이 거부됨

공개 Seedance API 모델은 **faces-off**입니다. 동의 확인 흐름을 기대하지 마세요. 얼굴이 포함된 미디어는 콘텐츠 정책/공급자 오류로 실패할 수 있습니다. 초상 워크플로우에는 Venice 앱이나 Studio를 사용하세요.

### 견적이 큐에 부과된 금액과 일치하지 않음

레퍼런스 비디오를 포함했으나 `/video/quote`에 `reference_video_total_duration`을 전달하지 않았다면, 견적과 큐 부과 금액이 다를 수 있습니다. 레퍼런스 비디오가 있는 경우에는 반드시 `reference_video_total_duration`(모든 레퍼런스 클립 길이의 초 단위 합계)을 전달하세요.
