[모델 카탈로그](/ko/models/overview)는 [`GET /models`](/ko/api-reference/endpoint/models/list)를 기반으로 매시간 생성됩니다. 이 페이지에서는 카탈로그의 수치가 어떻게 산출되는지 설명하므로, 직접 재현해 보고 각 수치가 무엇을 의미하고 무엇을 의미하지 않는지 파악할 수 있습니다.

## 패밀리와 변형 {#families-and-variants}

여러 모델 ID가 실제로는 같은 모델을 다른 방식으로 제공하는 경우가 많습니다. 카탈로그는 이들을 하나의 패밀리 페이지로 묶습니다.

| 변형 유형 | 예시 | 별도로 구분하는 이유 |
|---|---|---|
| 프라이버시 | `z-ai-glm-5-3` 및 `e2ee-glm-5-3-p` | E2EE 변형은 증명된(attested) 엔클레이브에서 실행되며 제한이 다를 수 있습니다 |
| 속도 | `claude-opus-5-5` 및 `claude-opus-5-5-fast` | 더 높은 가격으로 더 빠르게 제공됩니다 |
| 모드 | `kling-v3-pro-text-to-video`, `-image-to-video`, `-motion-control` | 입력과 가격이 다릅니다 |
| 작업 | `nano-banana-pro` 및 `nano-banana-pro-edit` | 생성 엔드포인트와 편집 엔드포인트 |

모든 변형은 고유한 모델 ID, 가격, 프라이버시 등급을 유지합니다. 변형의 ID를 `model`로 전달하세요. `deepseek-v4-flash-0731`과 같은 날짜별 스냅샷은 별도 패밀리로 유지되며 **다른 버전** 아래에 표시됩니다.

## 정규화된 가격 {#normalized-prices}

각 모달리티는 고유한 단위로 과금됩니다. 카탈로그는 기본 단위와 하나의 참조 가격을 함께 표시하므로 모델을 정렬하고 비교할 수 있습니다.

| 모달리티 | 기본 단위 | 참조 가격 |
|---|---|---|
| 텍스트 | 입력 및 출력 토큰 100만 개당 | **혼합 가격**: `(3 × input + output) / 4`, Artificial Analysis가 사용하는 3:1 비율입니다. 캐시된 입력 할인율은 `1 − cached ÷ input`입니다. |
| 이미지 | 이미지당, 해상도 등급별 | 선택한 등급(1K, 2K 또는 4K)에서의 이미지당 가격. 편집은 추가 입력에 대해 이미지당 할증료가 붙습니다. |
| 비디오 | 클립당, 해상도·길이·오디오별 | 전체 견적 매트릭스(아래 참조)에서 산출한, 선택한 설정의 초당 및 클립당 가격. |
| 텍스트 음성 변환 | 100만 자당 | 분당 150단어(약 825자) 기준 음성 1분당 가격. |
| 음성 텍스트 변환 | 오디오 1초당 | 오디오 1시간당 및 1,000분당 가격. |
| 음악 및 효과음 | 트랙당, 초당 또는 길이 구간별 | 모델이 허용하는 경우 오디오 1분당, 그렇지 않으면 트랙당 가격. |
| 임베딩 | 입력 토큰 100만 개당 | 변경 없음. |

<Note>
추론 모델은 같은 작업에서 비추론 모델보다 훨씬 많은 출력 토큰을 사용할 수 있으므로, 혼합 가격은 실제 비용을 과소평가합니다. 벤치마크 실행으로 측정한 작업당 비용이 계획되어 있습니다. [벤치마크](#benchmarks)를 참조하세요.
</Note>

### 비디오 가격 {#video-pricing}

비디오 모델은 `GET /models`에 가격을 공개하지 않습니다. 빌드 시 Venice는 각 모델이 지원하는 모든 해상도 × 길이 × 오디오 조합에 대해, 첫 번째로 나열된 화면 비율로 [`POST /video/quote`](/ko/api-reference/endpoint/video/quote)를 호출합니다(화면 비율은 가격에 영향을 주지 않습니다). 카탈로그는 전체 매트릭스를 저장하고 다음 값을 산출합니다.

- **초당 가격**: 특정 해상도와 오디오 설정에서 여러 길이에 걸친 `price ÷ seconds`의 중앙값입니다. 거의 모든 모델에서 가격은 길이에 비례합니다.
- **초안 클립**: 5초, 720p, 무음.
- **프로덕션 클립**: 10초, 1080p, 오디오 포함.

모델이 요청한 설정을 제공하지 않으면, 카탈로그는 지원되는 가장 가까운 설정을 사용하고 해당 가격에 표시를 남깁니다. 편집, 모션 컨트롤, 업스케일 모드는 원본 비디오 길이에 따라 과금되므로 가격 대신 **원본 기준**이 표시됩니다. 정확한 금액을 알려면 대기열에 넣기 전에 항상 `POST /video/quote`를 호출하세요.

## 프라이버시 등급 {#privacy-tiers}

| 등급 | 의미 |
|---|---|
| **E2EE** | 프롬프트는 사용자의 기기에서 암호화되며, 증명된 하드웨어 엔클레이브 내부에서만 복호화됩니다. [TEE 및 E2EE 모델](/ko/guides/features/tee-e2ee-models)을 참조하세요. |
| **TEE** | 추론이 암호학적 증명(attestation)을 갖춘 하드웨어 엔클레이브에서 실행됩니다. |
| **비공개** | Venice가 관리하는 인프라에서 제공되며 데이터를 전혀 보존하지 않습니다. |
| **익명화** | 사용자의 신원 없이 상위 연구소로 프록시됩니다. 연구소는 프롬프트를 보존할 수 있습니다. |

패밀리에는 그 변형들이 제공하는 모든 등급이 나열됩니다. 특정 등급으로 필터링하면 해당 등급의 변형이 고유한 가격과 함께 표시됩니다.

## 참조 프롬프트 세트 {#reference-prompt-suite}

이미지 및 비디오 모델은 고정된 프롬프트 세트로 기본 설정에서 렌더링되며, 같은 모달리티의 모든 모델에 동일한 프롬프트가 사용됩니다. 덕분에 탐색기의 갤러리를 모델 간에 비교할 수 있습니다.

| 모달리티 | 프롬프트 |
|---|---|
| 이미지 | 이미지 내 텍스트, 사실적 표현, 지시 이행, 일러스트레이션 스타일 |
| 이미지 편집 | 원본 사진 한 장을 세 가지 방식으로 편집: 부분 변경, 스타일 변경, 텍스트 추가 |
| 업스케일링 | 512px 사진을 2배 업스케일한 결과와 같은 부분을 바이큐빅으로 확대한 결과를 나란히 비교 |
| 비디오 | 시네마틱 풍경, 끊김 없는 루프, 도시 시네마틱 |
| 비디오 편집 | 원본 클립 하나를 스타일 변경하거나 연장 |
| 비디오 업스케일링 | 480p 클립을 2배 업스케일한 결과와 같은 부분을 바이큐빅으로 확대한 결과를 나란히 비교 |

대부분의 렌더링은 venice.ai의 모델 페이지에서 가져옵니다. venice.ai에 렌더링이 없는 경우 문서에서 Venice API로 같은 세트를 렌더링하며, 클립을 가볍게 유지하기 위해 비디오 모델은 시네마틱 풍경 프롬프트만 사용합니다.

렌더링이 없는 모델은 **아직 참조 렌더링 없음** 아래에 표시됩니다.

## 성능 {#performance}

<Info>
아직 공개되지 않았습니다. 이 섹션은 카탈로그에 표시될 내용을 설명합니다.
</Info>

Venice는 고객 프롬프트가 아닌 합성 프로브만으로 모델을 측정하고 다음 항목을 공개할 예정입니다.

| 모달리티 | 지표 |
|---|---|
| 텍스트 | 가동률, 첫 토큰까지의 시간, 초당 출력 토큰 수, 500토큰 응답까지의 시간, 캐시 적중률, 성공률 |
| 이미지 | 가동률, 1K 이미지 1장 생성 시간(p50 및 p95), 성공률 |
| 비디오 | 가동률, 5초 720p 클립의 대기열 시간 및 생성 시간(별도 보고), 성공률 |
| 오디오 | 가동률, 첫 오디오까지의 시간, 속도 배율, 성공률 |
| 임베딩 | 가동률, 1K 토큰 입력의 지연 시간, 성공률 |

모든 수치에는 측정 기간(가동률은 최근 30일, 지연 시간은 7일), 백분위수, 샘플 수, 프로브 지역이 함께 표시됩니다. 가동률에서는 요청 자체로 인한 4xx 오류를 제외합니다. 캐시 적중률은 전체 트래픽에 대한 `cache_read ÷ (input + cache_read + cache_write)`입니다. 샘플이 너무 적은 모델에는 **예비**로 표시됩니다.

## 벤치마크 {#benchmarks}

<Info>
아직 공개되지 않았습니다. 이 섹션은 카탈로그에 표시될 내용을 설명합니다.
</Info>

벤치마크는 최첨단 모델을 기준으로 선정됩니다. 즉, 최상위권에서도 여전히 변별력이 있고, 오염에 강하며, Venice가 제공하는 그대로의 모델에 대해 실행할 수 있어야 합니다. 모든 점수에는 하나의 출처 라벨이 붙으며, 서로 평균을 내지 않습니다.

- **Venice 검증**: 페이지에 표시된 Venice 엔드포인트에서 실행.
- **독립 측정**: 제3자가 실행하며, 보통 연구소 자체 API에서 실행.
- **연구소 보고**: 모델 제작사가 공개.

각 점수에는 벤치마크 및 하니스 버전, 추론 강도, 테스트 날짜, 신뢰 구간도 함께 표시됩니다. 90일이 지났거나 새 벤치마크 버전으로 대체된 점수는 오래된 것으로 표시됩니다.

| 모달리티 | 계획된 대표 벤치마크 세트 |
|---|---|
| 텍스트 | Artificial Analysis Intelligence Index, 그리고 Humanity's Last Exam, Terminal-Bench, τ³-bench, AA-LCR, IFBench, AA-Omniscience 및 Venice Openness Score |
| 이미지 | Artificial Analysis 및 LMArena 아레나의 인간 선호도 Elo, GenEval 2, 과잉 거부율 |
| 비디오 | Artificial Analysis 텍스트-비디오(오디오 포함 및 미포함) 및 이미지-비디오 Elo, LMArena 텍스트-비디오 |
| 텍스트 음성 변환 | Artificial Analysis Speech Arena Elo, 단어 오류율, 첫 오디오까지의 시간 |
| 음성 텍스트 변환 | Artificial Analysis 단어 오류율, Open ASR Leaderboard, 속도 배율 |
| 음악 | Artificial Analysis Music Arena(연주곡 및 보컬) |
| 임베딩 | MTEB Multilingual, RTEB 및 Venice 비공개 검색 평가 세트 |

이 세트는 분기마다 검토됩니다. 최첨단 모델이 포화 상태에 이르거나 오염 감사를 통과하지 못한 벤치마크는 대표 지표에서 제외되어 최저 기준 점검용으로 전환됩니다.

## 기계 판독 가능한 데이터 {#machine-readable-data}

이 페이지들의 기반이 되는 카탈로그는 [`/data/model-catalog.json`](https://docs.venice.ai/data/model-catalog.json)에 JSON으로 공개되며, 매시간 동기화할 때마다 다시 빌드됩니다. 비교, 분석, 에이전트에 적합합니다. 런타임에 모델을 선택하려면 [`GET /models`](/ko/api-reference/endpoint/models/list)를 호출하세요.

| 필드 | 내용 |
|---|---|
| `version` | 스키마 버전, 현재 `1` |
| `generatedAt` | 데이터를 변경한 마지막 빌드의 ISO 8601 시각 |
| `counts` | 전체 및 모달리티별 모델과 패밀리 총계 |
| `providers` | slug를 키로 하는 모델 제작사 목록, `name`과 `logo` 포함 |
| `families` | 패밀리 배열: `slug`, `name`, `modality`, `task`, `provider`, `description`, `primary`(기본 변형의 ID), `variants`(모델 ID), `created` 및 `updated`(Unix 초), `privacy`(제공되는 모든 등급), `uncensored`, `openWeights` |
| `models` | 모델 ID를 키로 하는 객체: `name`, `type`(`GET /models`와 동일), `modality`, `task`, `variant`, `provider`, `family`(소속 패밀리의 slug), `privacy`, 모달리티 이름을 딴 제한 및 기능 블록 하나(`text`, `image`, `video`, `audio` 또는 `embedding`), 기본 단위의 `pricing`, `headline`(위의 참조 가격), `media`(참조 렌더링) |
| `benchmarks` | 벤치마크 정의. 벤치마크가 공개되기 전까지는 `null` |
| `mediaSuite` | 모달리티별 참조 프롬프트 세트 |

값이 없는 필드는 생략됩니다. 가격은 USD 기준입니다.

## 데이터 출처 {#data-sources}

카탈로그는 직접 호출할 수 있는 공개 엔드포인트로 구축됩니다.

- 사양, 기능, 가격: [`GET /models`](/ko/api-reference/endpoint/models/list)
- 비디오 가격: [`POST /video/quote`](/ko/api-reference/endpoint/video/quote)
- `default_code` 같은 기본값: [`GET /models/traits`](/ko/api-reference/endpoint/models/traits)

가격은 USD 기준입니다. DIEM은 1:1 등가로 과금됩니다.
