**YouTube** 비디오 URL을 `url`에 전달하세요. 구조화된 출력을 원할지 일반 텍스트 전사를 원할지에 따라 `response_format`을 `json`(기본값) 또는 `text`로 선택적으로 설정할 수 있습니다.

<Warning>
이 엔드포인트는 YouTube URL만 허용합니다. `youtube.com`, `youtu.be`, `youtube-nocookie.com` 호스트의 watch, share, embed, live, shorts 링크가 지원됩니다. 그 외의 URL — 자체 호스팅 MP4, CDN 링크, S3 객체 포함 — 은 `400`과 함께 *"url must be a valid YouTube video URL"*을 반환합니다. 자체 미디어를 전사하려면 오디오 트랙을 추출한 다음 [오디오 전사 API](/api-reference/endpoint/audio/transcriptions)를 대신 사용하세요.
</Warning>
