`/video/queue` 응답에 `download_url`이 포함되어 있었다면, 완료된 파일을 해당 URL에서 다운로드하세요(이 엔드포인트에서 바이너리로 받지 않습니다). 그렇지 않으면 이 엔드포인트가 비디오를 반환합니다. 링크 동작 방식, 재시도, 선택적 `DELETE`에 대해서는 [Private download links](/ko/guides/media/video-generation#private-다운로드-링크)를 참조하세요.
