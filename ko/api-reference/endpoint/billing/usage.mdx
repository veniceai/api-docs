<Warning>
이 엔드포인트는 2026-09-16에 지원 종료되었으며 이제 모든 요청에 대해 `410 Gone`을 반환합니다. 대신 [청구 사용 내역](/ko/api-reference/endpoint/billing/usage-history)을 사용하세요.
</Warning>

청구 사용 내역은 커서 페이지네이션으로 동일한 원장 항목을 반환합니다. 마이그레이션 방법:

- `page`와 `limit`을 `pageSize`로 바꾸고, 각 응답의 `nextCursor`를 전달하여 다음 페이지를 가져오세요.
- `startDate`와 `endDate`를 `startTimestamp`와 `endTimestamp`로 바꾸세요.
