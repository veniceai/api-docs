<Note>
`balances`는 `diem`과 `usd`만 보고합니다. 번들 크레딧은 숫자 필드로 표시되지 않습니다. 다음 요청이 번들 크레딧에서 차감될 경우 `consumptionCurrency`는 `BUNDLED_CREDITS`를 반환합니다. 남은 번들 크레딧 금액을 확인하려면 [venice.ai/settings/api](https://venice.ai/settings/api?utm_source=venice-api-documentation)를 확인하세요. API가 DIEM, 번들 크레딧, USD 중에서 선택하는 방식은 [VVV & DIEM](/overview/vvv-diem#how-funding-works)을 참조하세요.
</Note>
