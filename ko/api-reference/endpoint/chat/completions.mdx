<Info>
  **Venice 전용 파라미터는 [`venice_parameters`](#body-venice-parameters)에 있습니다.** 이 엔드포인트는 OpenAI와 호환되지만, `venice_parameters` 객체는 표준 OpenAI API에는 없는 기능을 제공합니다. 많은 통합 개발자들이 이 기능을 놓치곤 합니다:

  - **웹 검색 및 인용** — `enable_web_search`, `enable_web_citations`, `enable_web_scraping`
  - **캐릭터 페르소나** — `character_slug`
  - **시스템 프롬프트 제어** — `include_venice_system_prompt`
  - **추론 제어** — `disable_thinking`, `strip_thinking_response`
  - **프라이버시** — `enable_e2ee`

  전체 목록은 아래 [`venice_parameters`](#body-venice-parameters) 섹션에서 확인하세요.
</Info>
