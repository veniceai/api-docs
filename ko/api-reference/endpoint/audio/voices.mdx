오디오 샘플을 업로드하여 복제된 음성 핸들을 생성한 다음, 생성할 때 사용한 것과 동일한 `model`과 함께 [`/audio/speech`](/ko/api-reference/endpoint/audio/speech)에 `voice`로 전달하세요. 단계별 안내는 [음성 복제 가이드](/ko/guides/media/voice-cloning)를 참조하세요.

이 엔드포인트는 복제 음성을 생성하며, 음성 목록을 제공하지 않습니다. 각 음성 모델의 기본 제공 음성은 [`GET /models?type=tts`](/ko/api-reference/endpoint/models/list)의 `model_spec.voices`에 있으며, [텍스트 음성 변환 모델](/ko/models/text-to-speech) 페이지에도 나와 있습니다.
