변환된 오디오를 성공적으로 다운로드한 후 Venice가 해당 요청과 연결된 저장 미디어를 정리하도록 하려면 이 엔드포인트를 호출하세요. [`/audio/voice-changer/retrieve`](/ko/api-reference/endpoint/audio/voice-changer/retrieve)에 `delete_media_on_completion: true`를 전달하면 동일한 정리를 인라인으로 수행합니다.

보이스 체인저 모델은 [`/audio/complete`](/ko/api-reference/endpoint/audio/complete)에서 허용되지 않습니다.
