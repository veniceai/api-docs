[`/audio/voice-changer/queue`](/ko/api-reference/endpoint/audio/voice-changer/queue)가 반환한 `queue_id`를 사용해 변환 상태를 확인하세요. 작업이 실행 중일 때는 `status: "PROCESSING"`이 포함된 JSON을 반환하며, 완료되면 `audio/mpeg`를 반환합니다. `delete_media_on_completion`을 `true`로 설정하면 동일 호출에서 저장 미디어를 정리하거나, 파일을 다운로드한 후 [`/audio/voice-changer/complete`](/ko/api-reference/endpoint/audio/voice-changer/complete)를 호출하세요.

보이스 체인저 모델은 [`/audio/retrieve`](/ko/api-reference/endpoint/audio/retrieve)에서 허용되지 않습니다.
