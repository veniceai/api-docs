<Info>
**가격:** 이미지 편집 가격은 모델에 따라 다릅니다. 기본 모델(`qwen-edit`)은 **편집당 $0.04**입니다. 사용 가능한 모든 편집 모델과 가격은 [모델 엔드포인트](/api-reference/endpoint/models/list)를 참조하세요.
</Info>

## 품질 등급

`/image/edit`는 `quality` 매개변수를 허용하지 않으며, 보내면 `400`이 반환됩니다. 이 엔드포인트의 편집은 모델의 기본 등급(`gpt-image-2-edit`의 경우 `high`)으로 청구됩니다.

등급(`low`, `medium`, `high`)을 선택하려면 [`/image/multi-edit`](/api-reference/endpoint/image/multi-edit)를 사용하세요. 이 엔드포인트는 지원하는 모델에서 `quality`를 허용합니다. 등급별 가격(1K/2K/4K × low/medium/high)은 [모델 엔드포인트](/api-reference/endpoint/models/list)의 `model_spec.pricing.quality` 아래에 있으며 [가격 개요](/overview/pricing)에 나열되어 있습니다.
