`type` 쿼리 매개변수를 생략하면 응답에는 텍스트 모델만 포함됩니다. 전체 모델 카탈로그를 반환하려면 `type=all`을 전달하세요.

## 모델 항목 읽기 {#reading-a-model-entry}

모델의 `id`를 `model` 파라미터로 보내세요. 필터링에 쓰는 항목 대부분은 `model_spec` 아래에 있습니다:

| 필드 | 의미 |
| --- | --- |
| `type` | 모델이 제공되는 엔드포인트: 채팅 완성은 `text`, 그 외 `image`, `video`, `tts`, `asr`, `embedding` 등 |
| `model_spec.capabilities` | 텍스트 모델이 지원하는 기능(예: `supportsFunctionCalling`, `supportsVision`, `supportsReasoning`, `supportsResponseSchema`, `supportsWebSearch`, `supportsE2EE`) |
| `model_spec.availableContextTokens` | 컨텍스트 윈도우(토큰 단위) |
| `model_spec.pricing` | USD 및 DIEM 기준 가격: 텍스트 모델은 1M 토큰당, 미디어 모델은 단위당 |
| `model_spec.privacy` | `private` 또는 `anonymized`. E2EE 및 TEE 모델은 `private`이며 `supportsE2EE` 또는 `supportsTeeAttestation`을 설정합니다 |
| `model_spec.constraints` | 모델이 받는 파라미터 값(예: 화면 비율, 동영상 길이, 품질 등급) |
| `model_spec.traits` | 모델이 맡는 역할(예: `default`, `fastest`) |
| `model_spec.deprecation` | 모델이 종료될 예정일 때 표시되며, 제거 날짜와 (있는 경우) `replacementModelId`를 포함합니다 |

ID 대신 역할로 모델을 선택하려면 [`GET /models/traits`](/ko/api-reference/endpoint/models/traits)를 호출하세요. 모델을 둘러보고 비교하려면 [모델](/ko/models/overview) 페이지를 참고하세요.

## 품질 등급 가격

선택적 `quality` 매개변수를 허용하는 이미지 모델의 경우, 응답은 `model_spec.pricing.quality` 아래에 품질별 가격 매트릭스를 노출합니다. 각 최상위 키는 해상도 등급(`1K`, `2K`, `4K`)이고 각 중첩 키는 자체 `usd` 및 `diem` 가격을 가진 품질 수준(`low`, `medium`, `high`)입니다:

```json
"pricing": {
  "resolutions": {
    "1K": { "usd": 0.27, "diem": 0.27 },
    "2K": { "usd": 0.51, "diem": 0.51 },
    "4K": { "usd": 0.84, "diem": 0.84 }
  },
  "quality": {
    "1K": {
      "low":    { "usd": 0.02, "diem": 0.02 },
      "medium": { "usd": 0.07, "diem": 0.07 },
      "high":   { "usd": 0.26, "diem": 0.26 }
    },
    "2K": {
      "low":    { "usd": 0.03, "diem": 0.03 },
      "medium": { "usd": 0.13, "diem": 0.13 },
      "high":   { "usd": 0.50, "diem": 0.50 }
    },
    "4K": {
      "low":    { "usd": 0.05, "diem": 0.05 },
      "medium": { "usd": 0.21, "diem": 0.21 },
      "high":   { "usd": 0.83, "diem": 0.83 }
    }
  }
}
```

`pricing.resolutions`는 이전 버전과의 호환성을 위해 유지되는 레거시 이미지별 일정입니다. `pricing.quality`는 `quality` 매개변수가 지원될 때마다 적용되는 (해상도, 품질)별 매트릭스입니다. 클라이언트가 품질 지원을 감지하고 자체 UI에 매트릭스를 표시할 수 있도록 두 필드는 응답에 유지됩니다.
