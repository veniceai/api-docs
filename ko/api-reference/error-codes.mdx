오류가 발생하면 Venice API는 HTTP 상태 코드와 설명 메시지를 반환합니다. 일부 오류에는 환불 상태, 권장 재시도 모델, 유효성 검사 세부 정보 또는 요청 ID와 같은 추가 필드도 포함됩니다.

## 오류 응답 형식

대부분의 오류는 사람이 읽을 수 있는 메시지가 포함된 `error` 필드를 반환합니다:

```json
{
  "error": "Invalid request parameters"
}
```

일부 엔드포인트는 엔드포인트별 추가 필드를 포함합니다. 예를 들어 비디오 검열 오류에는 크레딧이 환불되었는지가 포함될 수 있습니다:

```json
{
  "error": "Your generation was blocked due to the model provider's content policies. Credits have been refunded.",
  "credits_refunded": true
}
```

유효성 검사 오류에는 필드 수준의 유효성 검사 정보가 포함된 `details` 및 `issues` 필드가 포함될 수 있습니다:

```json
{
  "error": "Invalid request parameters",
  "details": {
    "_errors": [],
    "field": {
      "_errors": ["Field is required"]
    }
  },
  "issues": []
}
```

일부 OpenAI 호환 엔드포인트는 컨텍스트 길이 오류와 같은 특정 경우에 OpenAI 스타일의 오류 객체를 반환할 수 있습니다:

```json
{
  "error": {
    "message": "Your request exceeds the model's maximum context. Please reduce your prompt or completion length.",
    "type": "invalid_request_error",
    "param": "messages",
    "code": "context_length_exceeded"
  }
}
```

## 자격 증명 누락

자격 증명이 없는 요청은 `401`이 아니라 `402 Payment Required`를 반환합니다. 모든 유료 라우트는 [x402 지갑 인증](/ko/guides/integrations/x402-venice-api)도 허용하므로, 응답은 결제 챌린지입니다. 응답에는 `PAYMENT-REQUIRED` 헤더와 두 가지 인증 방법을 설명하는 본문이 포함됩니다.

```json
{
  "x402Version": 2,
  "error": "Authentication required",
  "accepts": [ ... ],
  "authOptions": {
    "apiKey": {
      "header": "Authorization: Bearer YOUR_API_KEY",
      "getKey": "https://venice.ai/settings/api"
    },
    "x402Wallet": {
      "header": "SIGN-IN-WITH-X",
      "topUp": "POST /api/v1/x402/top-up"
    }
  }
}
```

API 키를 사용하려고 했다면 `Authorization: Bearer` 헤더가 설정되어 있는지 확인하세요. 키가 있지만 유효하지 않으면 `401`을 반환합니다.

## 요청 형식 오류

이 오류는 엔드포인트별 유효성 검사가 실행되기 전, 요청 본문을 읽는 단계에서 발생합니다.

| HTTP Status | Message | 원인 |
| --- | --- | --- |
| 400 | `'Content-Type' must be 'application/json'` | `Content-Type: application/json` 없이 전송된 `POST`, `PUT`, `PATCH` 본문. 파일 업로드를 받는 엔드포인트는 `multipart/form-data`도 허용합니다 |
| 400 | `Invalid JSON request` | 본문이 유효한 JSON이 아닙니다 |
| 400 | `Invalid multipart request: malformed part header` | 파싱할 수 없는 `multipart/form-data` 본문 |
| 413 | `Request body exceeds the maximum allowed size.` | 요청 본문이 너무 큽니다 |
| 415 | `Request encoding is not supported` | API가 디코딩할 수 없는 `Content-Encoding` 또는 문자 집합 |

잘못된 `Content-Type`은 `415`가 아니라 `400`을 반환합니다. 크기 제한으로 인한 `413` 응답에는 `code` 필드도 포함됩니다:

```json
{
  "code": "PAYLOAD_TOO_LARGE",
  "error": "Request body exceeds the maximum allowed size."
}
```

## 기타 오류

위 표가 모든 오류를 망라하지는 않습니다. 일부 오류는 표에 나열된 코드 없이 반환되며, 메시지는 모델과 엔드포인트에 따라 다를 수 있으므로 메시지 텍스트가 아닌 HTTP 상태를 기준으로 분기하세요. 표에 없지만 발생할 수 있는 오류는 다음과 같습니다:

| HTTP Status | 발생 상황 |
| --- | --- |
| 400 | 채팅 또는 Responses 요청의 이미지 입력이 지원되지 않는 형식입니다 |
| 400 | 요청한 음성을 해당 텍스트 음성 변환 모델에서 사용할 수 없습니다 |
| 403 | API 키의 허용 목록에 없는 IP 주소에서 요청했습니다 |
| 403 | API 키의 개인정보 보호 설정에서 요청한 모델을 허용하지 않습니다 |
| 403 | 요청한 모델에 대한 액세스가 제한되어 있습니다. support@venice.ai로 문의하세요 |
| 409 | 비디오, 음악 또는 음성 변환 결과를 조회할 때 아직 업로드 중입니다. 잠시 후 다시 시도하세요 |
| 410 | 엔드포인트가 지원 종료되었습니다 |
| 422 | 오디오가 너무 길거나 짧습니다(음성 복제, 음성 변환, 오디오 작업) |
| 422 | 비디오 요청의 입력 이미지 가로세로 비율이 모델이 허용하는 범위를 벗어났습니다 |
| 422 | 비디오 요청의 입력이 콘텐츠 검토에 의해 차단되었습니다 |
| 500 | 비디오 또는 음성 변환 생성에 실패했습니다 |
| 502 | 업스트림에서 음성 합성에 실패했거나 생성된 비디오를 가져올 수 없습니다. 요청을 다시 시도하세요 |
